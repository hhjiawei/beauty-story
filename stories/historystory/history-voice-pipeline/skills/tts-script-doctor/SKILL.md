# 旁白语音层设计方案 · IndexTTS2 配音加工手册（v1）

> 定位：流水线里的**配音车间**。接收写作层成稿，输出可直接进剪辑的成品配音音频。
> 核心结论：**成稿不能直接喂 TTS**。写作层交付的是"给人看的稿子"，TTS 吃的是"画本"——标注了停顿、读音、情绪、语速的施工稿。有声书行业最被低估的环节就是画本：把文稿"翻译"成配音演员能直接照着读的格式，画本质量决定成品天花板 [^1^]。
> 铁律：**文字层的任何加工不得改动事实与措辞**——画本只加"声音指令"，不改"说什么"。改措辞是写作层的事，打回去。

**流水线位置**：写作层（成稿）→ **语音层（画本 → 合成 → 后期）** → 剪辑成片。

---

## 一、为什么成稿不能直接喂 TTS

写作层成稿和 TTS 输入之间有四个鸿沟，每一个都会直接变成听感事故：

1. **上古史专有名词读音**。妺喜（mò xǐ）、夏桀、亳（bó）、鸣条、斟鄩、伊尹、有施氏——多音字和生僻字是 TTS 读错的重灾区，必须在文本阶段手动标注 [^2^][^3^]。你的题材是全站读错风险最高的品类之一。
2. **长文本韵律坍塌**。TTS 对单次输入长度敏感，超过约 200 字语调连贯性下降 [^4^]。成稿一整段喂进去，出来的就是"朗读腔"——平、匀、无呼吸。
3. **停顿语义不通用**。成稿里的（顿）是给人看的标记，TTS 不认识；TTS 的停顿靠标点、分段和静音参数控制 [^3^][^5^]。需要翻译。
4. **情绪信息在稿子之外**。大纲的情绪波形、成稿的炸点/动情点标记，是"哪里该起情绪"的图纸——但 TTS 不会自己读出来，必须显式转换成情感参数。

画本层就是把这四道鸿沟一次性填平的工序。

## 二、IndexTTS2 能力地图（先看工具箱，再定方案）

基于官方仓库与文档，IndexTTS2 对本流水线有四项关键能力 [^6^][^7^]：

| 能力 | 机制 | 本流水线的用法 |
| ---- | ---- | -------------- |
| 零样本音色克隆 | 一段参考音频（timbre prompt）即可克隆音色，无需训练 | 建立你的**专属旁白音色库**（见第四节） |
| 情感与音色解耦 | 音色和情感独立控制：用 A 的音色，表现 B 的情感（情感参考音频／情感向量／自然语言描述三选一）[^6^] | **一个音色走全系列，情感按段落切换**——这是"新派写书人"人格在声音层的实现 |
| 自然语言情感软指令 | 基于 Qwen3 微调，用一句中文描述情感（如"压低声音，带着克制的唏嘘"）[^6^][^8^] | 画本的情绪标注直接用人话写，不用学情感向量 |
| 时长控制 | 两种模式：指定 token 数精确控制时长；或自由生成忠实复现韵律 [^6^][^7^] | 地图留白、时间码对齐的段落用精确模式，其余用自由模式 |

> 注意：具体参数名（emo_audio_prompt／emo_alpha／emo_vector／use_emo_text 等）以你本地部署版本的 README 为准，不同 commit 有差异。本文所有代码示例标注"示意"，跑通前先对一遍本地签名。

## 三、语音层 SOP（五步）

```
成稿 → Step 1 画本加工 → Step 2 分段合成 → Step 3 质检返工 → Step 4 后期链路 → Step 5 审听签发
```

### Step 1｜画本加工（核心工序）

把成稿转成《配音画本》——每段一个 JSON 对象，schema 如下：

```json
{
  "段号": 5,
  "对应成稿段": "【段5·高潮】",
  "文本": "鼓声响了。是进军鼓。三万人，冲向四十万。",
  "拆分": ["鼓声响了。", "是进军鼓。", "三万人，冲向四十万。"],
  "情感": "压低后的爆发，克制中带狠劲",
  "情感强度": 0.8,
  "语速": 1.0,
  "前停顿_ms": 400,
  "后停顿_ms": 600,
  "读音表": {"亳": "bó", "妺喜": "mò xǐ"},
  "时长目标_s": null,
  "备注": "短句鼓点段，语速参数不动，靠文本本身的短句出节奏"
}
```

**加工规则**：

| 规则 | 做法 | 依据 |
| ---- | ---- | ---- |
| 拆分 | 按语义拆成 1–3 句的合成单元，每单元 ≤80 字；长句在主语后、从句前主动加逗号断句 [^4^][^3^] | 长文本韵律坍塌 |
| 停顿翻译 | 成稿（顿）→ 前/后停顿参数；炸点后 400–600ms，动情点后 600–800ms，章间 800–1000ms | 停顿是武器（写作层纪律的声音层落实） |
| 读音表 | 全稿扫多音字／生僻字／专名，逐集累积进**系列读音词典**（越做越省力）；数字、年代统一转成口语读法（"公元前1600年"→"公元前一千六百年"）[^2^][^3^] | 读错是硬伤 |
| 情感标注 | **直接抄大纲的"情绪坐标"字段翻译**：高位起跳→明亮有力；回落蓄力→平稳放缓；爬升→渐强；峰顶→该段的炸点类型决定（燃点→有力，唏嘘→压低）；谷底→低沉克制 | 大纲层情绪波形是白捡的情感图纸 |
| 语速 | 全片基准 1.0；蓄力段 0.95，高潮段 1.0–1.05。**语速调整幅度不超过 ±10%**——节奏感靠文本短句和停顿出，不靠参数硬拉 | 参数拉节奏会出机械感 |
| 古文引文 | 【上屏】引文同时需要朗读的，单独拆成一个合成单元，情感标"换声线感"（稍慢、稍重），与正文旁白形成听觉区隔 | 引文是炸点，不能和正文一个声 |

### Step 2｜分段合成

- **逐单元生成，不整段生成** [^4^]。每个合成单元一次 infer，输出独立 wav。
- 情感调用优先级（以本地版本支持为准）：**情感参考音频 > 自然语言描述 > 情感向量**。建议先录 4–6 条情感参考音频（平静叙事／燃／唏嘘／讽刺／惊讶／温情），比调向量稳定——官方也推荐解耦模式下用 emo_audio_prompt [^6^]。
- 情感强度（emo_alpha 类参数）克制在 0.6–0.8：拉满会夸张做作，"旁白情绪越克制，观众情绪越满"的人格纪律在声音层同样成立。
- **情感切换粒度是"段"不是"句"**——相邻单元频繁换情感会出现"情绪抽搐"。常态叙事段全程用基准情感，只在炸点段、动情点段、引文段切换。
- 时长目标不为 null 的单元（地图留白对轴段），用精确时长模式生成；失败则微调文本长度重试 [^6^]。
- 批量脚本示例（示意，参数名以本地 README 为准）：

```python
from indextts.infer_v2 import IndexTTS2
import json, os

tts = IndexTTS2(cfg_path="checkpoints/config.yaml", model_dir="checkpoints")
EMO_REFS = {"平静": "refs/calm.wav", "燃": "refs/fire.wav", "唏嘘": "refs/sigh.wav"}

with open("画本.json", encoding="utf-8") as f:
    pages = json.load(f)

for p in pages:
    for i, unit in enumerate(p["拆分"]):
        tts.infer(
            spk_audio_prompt="refs/narrator.wav",          # 专属音色
            emo_audio_prompt=EMO_REFS[p["情感基调"]],      # 情感参考
            emo_alpha=p["情感强度"],
            text=unit,
            output_path=f"out/{p['段号']:03d}_{i}.wav",
            interval_silence=p["后停顿_ms"],
        )
```

### Step 3｜质检返工（合成层自查）

逐单元听，只查三件事：

- [ ] **读音**：对照读音表，专名全对；
- [ ] **情绪**：该燃的燃了吗？该压的压了吗？抽搐了吗？
- [ ] **自然度**：有无怪语调、吞字、电流音。

**返工纪律**：哪个单元不合格重生成哪个单元，**不重跑全稿**（单元化拆分就是为此设计的）；同一单元重生 3 次仍怪 → 改画本（换断句位置／降情感强度／改措辞谐音字），改措辞类打回写作层。

### Step 4｜后期链路（FFmpeg 全自动）

合成干音直接放进视频会"干"且"飘" [^9^]。后期四板斧，全部可脚本化 [^9^][^10^][^11^]：

| 工序 | 参数建议 | 作用 |
| ---- | -------- | ---- |
| 响度标准化 | 整体 **-16 LUFS**（短视频平台通用），真峰值 ≤ -1 dBTP | 全系列音量统一，观众不用调音量 |
| EQ | 高通 80Hz 去轰隆；2–4kHz 提升 +2dB 增清晰度；300–500Hz 衰减 -2dB 去闷感 [^9^] | 人声清晰温暖 |
| 压缩 | 阈值约 -18dB，比率 3:1 | 动态统一，忽大忽小消失 |
| 混响 | 极小剂量：room 类，mix 8%–12% [^9^] | 让干音"落地"，有空间感。**宁少勿多**——多了糊台词 |

FFmpeg 示意链（响度＋EQ＋压缩一条命令）：

```bash
ffmpeg -i in.wav -af \
"highpass=f=80, equalizer=f=3000:t=q:w=1:g=2, equalizer=f=400:t=q:w=1:g=-2, \
acompressor=threshold=-18dB:ratio=3:attack=10:release=100, \
loudnorm=I=-16:TP=-1.5:LRA=11" out.wav
```

- **BGM 侧链闪避**：旁白轨与 BGM 轨做 ducking，旁白出现时 BGM 自动压 -8~-12dB [^12^]——剪映/FCP/FFmpeg sidechaincompress 均可实现。
- **拼接**：单元间按画本停顿参数 pad 静音后顺序拼接，章间静音 800–1000ms。

### Step 5｜审听签发（人工，10–15 分钟/集）

纯听成品（不看稿），三条过关线：

1. 全程没有一个字读错；
2. 情绪曲线和你在闸门 2 听到的文字版一致——文字咯噔的地方，声音也咯噔了；
3. 忘掉这是 AI——听到第 3 分钟时你已经不注意"声音"本身了（注意力全在故事上）。做不到就说明机械感还在，找塌段返工。

## 四、音色资产方案（一次性投入，系列复用）

**推荐路径：克隆你自己的声音。**

1. **录参考音频**：安静环境、 decent 麦克风、读 30–60 秒平静叙事文本（就用你写好的旁白），节奏平稳、无情绪波动 [^13^]。录 3 条选最干净的。
2. **为什么是自己的声音**：① 零版权风险——用他人声音克隆有法律风险，只应用于自有 IP [^13^]；② 音色即 IP——观众对"新派写书人"的人格认知，一半在文字一半在声音，声音必须独家；③ 情感参考音频也由你自己录（燃／唏嘘／讽刺各录一条 10 秒），情感保真度最高。
3. **音色库管理**：`refs/` 目录固定存放 narrator.wav（基准音色）＋ 4–6 条情感参考，全系列不动。观众对声音的适应成本只付一次。

## 五、与上游的接口（白捡的三个图纸）

| 上游产物 | 语音层怎么用 |
| -------- | ------------ |
| 大纲"情绪坐标"字段 | 画本情感标注的直接输入——大纲层画好的波形，语音层照抄翻译 |
| 成稿（顿）标记 | 翻译成前/后停顿毫秒数 |
| 成稿【上屏】标记 | 引文单元单独拆分＋换声线感朗读 |
| 成稿（地图留白 X 秒） | 该单元设时长目标，用精确时长模式合成，对轴地图动画 |

**打回规则**：画本加工中发现"这句话根本没法读"（超过三层的复句、无法断句的长定语）→ 不是语音层的问题，是写作层朗读测试放水了，打回写作层。

## 六、常见事故速查

| 症状 | 病根 | 处理 |
| ---- | ---- | ---- |
| 专名读错（妺喜读成 mèi） | 画本没建读音表 | 补读音词典，该单元重生 |
| 全程一个调，像新闻播报 | 情感标注没做／全程基准情感 | 回 Step 1 对照情绪波形标情感 |
| 情绪一惊一乍 | 情感按句切换了 | 情感粒度改回"段"，相邻单元同情感 |
| 声音发飘、贴不住画面 | 没做后期 | 跑 Step 4 链路，重点是轻混响＋响度 |
| BGM 盖人声／人声突兀 | 没做侧链闪避 | ducking -8~-12dB |
| 某单元怎么重生都怪 | 断句位置不对或文本本身不可读 | 改画本断句；改不了打回写作层 |
| 每集音量忽大忽小 | 没做响度标准化 | loudnorm -16 LUFS 全系列统一 |
