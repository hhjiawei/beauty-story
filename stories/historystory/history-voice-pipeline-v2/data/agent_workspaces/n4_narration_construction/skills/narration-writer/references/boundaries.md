# 边界与红线

> 本文件为 SKILL.md 的参考文档，按需加载。包含：结构越权、史实越权、人格越权、声画越权、受众距离设定五大红线。

---

## 1. 结构越权

改节点顺序、给过渡节点加戏、砍强化节点、移动炸点位置、改技法指定——**一律禁止**。

发现问题写进交稿备注，退回大纲层。

---

## 2. 史实越权

- 合理推测必须挂标记："有一种说法""后世推测"
- 歧义事件按大纲指定的层累／对勘插件处理，写作层不得替观众下"其实真相是"的独断

---

## 3. 人格越权

- **禁 AI 腔**：众所周知、不得不说、引人深思、历史的洪流、值得我们学习、让我们把时间拨回——全文扫描，一个不留
- **禁闲谈腔**："我"出场必须有功能（"我查过三个版本"），禁止"我怎么怎么"的自我展览
- **禁说教腔**：点评事实，不教训观众；毒舌对准行为决策，不对准容貌出身
- **禁自我感动**：旁白情绪越克制，观众情绪越满

---

## 4. 声画越权

- 不写无法可视化的抒情句（"历史的车轮滚滚向前"没有镜头能拍）
- 引文、地图、名场面按格式标记上屏位

---

## 5. 受众距离设定

核心原则：**同辈亲密，不审判、不冷漠、不卖关子、不摆谱、不讨好**。

所有含"你/我"人称互动的表达必须谨慎。

### 5.1 设定

- 受众距离：**同辈、亲密、略带调侃但不冒犯**
- 禁止距离漂移（前半段像朋友聊天，后半段像老师讲课）
- 禁止"您""诸位""各位观众"等疏远称谓
- 禁止"让我们""大家一起"等集体号召句式
- 禁止"我不懂""我很懵逼""我不看""我不管""说白了""一句话总结"等自以为是的写法

### 5.2 通过标准（5条）

1. **不审判**：不给观众贴"不懂/没发现/不明白"的标签
2. **不冷漠**：不表达"我无所谓/你爱看不看"的姿态
3. **不卖关子**：不反讽、不装傻、不"你细品"
4. **不摆谱**：不用"说白了/一句话总结"等降维句式
5. **不讨好**：不用"家人们/宝子们"等虚假亲密称谓

### 5.3 违禁表达清单与替换

| 类型 | 违禁表达 | 替换为 |
|------|----------|--------|
| 审判型 | "你怎么还没发现…" | "当时的人也没意识到…" |
| 审判型 | "你怎么还不明白…" | "这里有个容易忽略的点…" |
| 审判型 | "你们懂吗/你们知道吗" | "放在当时，这就是…" |
| 冷漠型 | "我不看这段史料…" | "这段史料本身就有矛盾…" |
| 冷漠型 | "我不管/我不在乎" | 删除，或改为"当时的人面临一个问题" |
| 反讽型 | "我不懂，但我大受震撼" | "这件事当时的人也没想明白" |
| 反讽型 | "你品，你细品" | 直接给结论，不绕弯 |
| 反讽型 | "懂的都懂" | 删除，或给出具体解释 |
| 讨好型 | "家人们谁懂啊" | 删除，直接给事实 |
| 讨好型 | "宝子们/姐妹们/咱就是说" | 删除 |
| 降维型 | "说白了，就是…" | "当时的逻辑是这样的…" |
| 降维型 | "你只需要记住…" | 删除引导词，直接给信息 |

### 5.4 快速判断法（人称替换测试）

对含"你/我"的句子执行以下测试，任一通过即有问题：

- **"你"→"您"测试**：换成"您"后更像训话 → 有问题
- **"我"→"本宫"测试**：换成"本宫/本少爷"后更像摆谱 → 有问题
- **删除"你/我"测试**：删除后信息依然完整 → 删除人称词

### 5.5 修改口诀

> 把"你/我"的对抗，改成"当时的人/这件事"的平行。
