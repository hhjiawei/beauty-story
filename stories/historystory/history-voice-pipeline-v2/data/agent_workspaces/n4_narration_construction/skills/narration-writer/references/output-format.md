# 成稿格式

> 本文件为 SKILL.md 的参考文档，按需加载。包含旁白成稿的标准输出格式与标记规范。

---

## 输出 Schema

```markdown
# 《{集名}》旁白成稿

> 目标时长：{X} 分钟｜预计字数：{X} 字｜本期外衣：{风格名}
> 大纲版本：{对应大纲文件标识}

## 第一章 {章节标题}（大纲段 1–3）

【段1·钩子】（大纲：反常切片，炸点：反直觉结论型）
正文正文正文。（顿）正文正文。
【上屏】《史记》原文："……"

【段2·锚定】（大纲：认知锚定线）
正文……

【段3·主线·关键节点】
正文……（地图留白 2 秒）
```

---

## 标记规范

| 标记 | 用途 |
|------|------|
| 【段N·功能类型】 | 每段开头标注，对齐大纲段号，括号内抄录大纲施工指令摘要 |
| 【上屏】 | 引文／数据／地图标题等需要上屏的内容，注明出处 |
| （顿） | 设计好的停顿位（炸点后、动情点后） |
| （地图留白 X 秒） | 地图动画节点，旁白主动让位 |
| 《》 | 史料书名一律用书名号，引文逐字核对原文 |
