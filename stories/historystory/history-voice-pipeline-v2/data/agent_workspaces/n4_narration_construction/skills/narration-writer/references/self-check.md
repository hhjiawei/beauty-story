# 写作层自查清单（Step 7，全绿才交稿）

> 本文件为 SKILL.md 的参考文档，按需加载。包含：结构对齐、听觉纪律、史实与人格三大模块的自查项。

---

## 结构对齐（查施工合规）

- [ ] 每段段号与大纲一一对应，无缺段、无加段
- [ ] 每段功能类型与大纲一致，无功能漂移
- [ ] 每段字数在分级容差内（钩子/收尾 ±40%，主线/插件 ±20%，过渡段只查上限）
- [ ] 指定技法全部落实，落实方式与 `references/technique-table.md` 一致；主备切换的段已在备注声明
- [ ] 炸点位置、类型与大纲一致；每个炸点可对回史料卡；短句鼓点只在炸点窗口内
- [ ] 伏笔登记表逐条核对：埋的都在、收的都收了、盖牌全掀
- [ ] 动情点已施工，处理克制（先事实后情）
- [ ] 收尾段：先落点后金句，80% 分量在最后 30 秒，开场片段已归位

---

## 听觉纪律（查语言质量）

- [ ] 朗读测试已完成：无读不顺的句子、无一口气读不完的长句
- [ ] 一句一个信息抽查 5 段：无从句套从句
- [ ] 强调词在句尾抽查 3 处
- [ ] 每 60 秒有一个信息增量**或情绪增量**（成戏段按情绪增量判定；全程模拟听众逐分钟自查）
- [ ] 名字管理：每个 30–60 秒单元内新名字 ≤2
- [ ] 大数字全部先换算后报数
- [ ] 零信息量感慨句扫描为零（令人深思／历史的尘埃／人性的复杂……）
- [ ] 过渡套话扫描为零（话说回来／言归正传／与此同时／镜头来到）

---

## 史实与人格（查红线）

- [ ] 全文事实逐条可对回事件卡，无卡外事实
- [ ] 推测全部挂标记；歧义事件无独断句式
- [ ] 引文逐字核到原始出处，书名号、出处标注齐全
- [ ] AI 腔禁词全文扫描为零
- [ ] 第一人称出场均有功能性，无自我展览
- [ ] 梗与史实无冲突；动情点前后 30 秒无玩梗
- [ ] 类比均有"精度还回"句，全片 ≤2 处
