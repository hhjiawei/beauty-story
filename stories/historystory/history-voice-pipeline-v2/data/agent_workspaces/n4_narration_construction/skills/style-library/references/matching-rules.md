## 简易特质分析指南

当上游未提供特质标签时，按以下问题链分析：

1. **这个人物/事件的结局是？**
   - 悲剧 → 诺兰/昆汀
   - 喜剧/荒诞 → 周星驰
   - 复杂多面 → 当年明月

2. **最戏剧性的冲突是什么？**
   - 暴力/战争 → 昆汀
   - 心理/抉择 → 诺兰
   - 职场/人际 → 当年明月
   - 荒诞/意外 → 周星驰

3. **观众看完应该有什么情绪？**
   - 唏嘘/思考 → 诺兰
   - 爽/燃 → 昆汀
   - 笑/共鸣 → 周星驰/当年明月
