# 收尾弹药（2发）

> 本文件为 SKILL.md 的参考文档，按需加载。包含2发收尾弹药的完整定义：来源/施工要点/适配/纪律。

---

## 1. 传播点提炼（金句位的上游工序）

- **来源**：杜茹慧做妇好一期，3500年前的人物，最终把传播点提炼为一句话："为了心中认定的事，要不断努力、坚持下去。"这是她明确希望观众带走的观点。
- **施工要点**：你的"80%压最后30秒"之前，先在大纲阶段回答一个问题：**观众看完这集，会在饭局上怎么向朋友复述它？**那句话就是金句的种子。说不出这句话，金句就是空对空。
- **适配**：人物篇必备；朝代篇可提炼为一句"这个朝代教会我们的事"。
- **纪律**：注意你的人格纪律——提炼给观众，不说教给观众，句式用"所以你看"而不是"所以我们要"；提炼不出传播点的集数，宁可收尾只留唏嘘，不硬凑金句。

## 2. 盖棺反差唏嘘（已有，补强）

- **来源**：李正——观众在他的节目里"能体会到雍正留下朱批时是何等的心情，不再意外四十年无所成就的鄂尔泰死后配享太庙的结局"。开场形象与盖棺结局之间的落差，本身就是唏嘘。
- **施工要点**：收尾时把开场钩子里的那个形象再拎出来对照一次（"结尾呼应什么"字段），呼应的不只是事件，是**观众对这个人/这个朝代的感情**。
- **适配**：通用；人物篇盖棺段、朝代篇亡国段。
- **纪律**：对照只摆事实不落泪——唏嘘由落差自动产生，旁白越克制，观众越唏嘘。
