# "我晋"视角与绰号系统

## R — 原文 (Reading)

> "在我晋，有什么值钱的？人命才值钱。"（01）"老影帝司马懿……出生在人均影帝家族的司马昭。"（04）"登基前的他就有了两个重要的加盟伙伴——一个叫做'飞豹'王弥，一个叫做'捷足'石勒。"（16）

---

## I — 方法论骨架 (Interpretation)

三层声音装置。第一层**领属自称**：把叙述的朝代叫"我晋/我大晋"——叙述者从旁观者变成"自家单位的人"，吐槽是家丑外扬，亡国时"我晋"自带痛感；仿写其他朝代同步替换（我大明、我大宋、我大唐）。第二层**判词绰号**：每个人物给一个命中核心特征的固定绰号（司马懿善伪装=老影帝、司马伦高龄篡权=老僵尸、苟晞嗜杀=屠伯、王弥跑得快=飞豹、李世民=二凤），绰号即判词，全篇一致复用不漂移。第三层**称呼降格**：帝王将相职场化（曹老板、老刘、老李），距离感归零。配套玩法：梗编号——人物特征当成就逐个解锁（"桓温身上第一个梗诞生了"）。

## A1 — 书中的应用 (Past Application)

### 案例 1: "影帝"的梗资产管理（04/17 期）
- **问题**: 司马家人物众多性格相近，读者分不清
- **方法论的使用**: 全系列固定"影帝"家族绰号（老影帝司马懿→人均影帝家族司马昭→老乌龟→老僵尸司马伦），每篇复用不漂移
- **结果**: 绰号成了跨篇的记忆锚点，观众看见"影帝"就知道在讲谁家的什么德行

### 案例 2: 16 期标签先行
- **问题**: 王弥、石勒、苟晞同时登场，人物太多
- **方法论的使用**: 登场即贴标签（飞豹/捷足/屠伯），后文事迹全部为标签提供证据
- **结果**: 读者先记标签再记人，人物再多也不混

## E — 可执行步骤 (Execution)

1. **定领属词**：确认叙述对象的"我方阵营"，选定领属自称（我+朝代/政权简称）
   - 完成标准：全文统一使用同一领属词

2. **立判词绰号**：为主要人物各定一个绰号，每个绰号必须能由事迹证明
   - 完成标准：绰号-特征-事迹三者对应表成立
   - 判停条件：找不到能贯穿全篇的特征——该人物不配绰号，直呼其名

3. **称呼降格**：把"皇帝/将军/丞相"等正式称呼按语境换成职场角色（老板/干部/保安队长）
   - 完成标准：正式称呼保留在史料引用中，叙述层用降格称呼

4. **一致性检查**：全文同一人物绰号唯一，跨篇复用既往绰号
   - 完成标准：无绰号漂移（ce05）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 客观中立文体（百科词条、教材、学术论文）
- 悲悯轨段落：死亡现场不喊绰号（"嵇侍中"而非绰号）——绰号有敬意开关

### 作者在书中警告的失败模式
- 绰号系统失控（ce05）：一人多绰号、绰号与事迹不符——记忆锚点崩散
- 绰号刻薄化：对正面英雄人物（祖逖、刘琨）不起贬损绰号——杜氏给他们的是尊称

### 作者的盲点 / 时代局限
- 强"我晋"立场是双刃：写对立阵营（胡人政权）时领属视角会带偏见，需自觉补位（杜氏对石勒、苻坚的翻案式肯定是正面示范）

### 容易混淆的邻近方法论
- 网络"起外号"文化：杜式绰号是判词系统，不是情绪宣泄
