# 史料侦探推理法

## R — 原文 (Reading)

> "我们有理由相信，在石勒刚刚病倒、还没确定侍奉名单之前，石虎就已经通过某种手段，将包含太子和中枢官员在内的这些人全部控制住了。"
>
> — 杜茹慧，两晋 39 期（石勒之死推理）

---

## I — 方法论骨架 (Interpretation)

史书是胜利者/后来人写的案发现场。侦探法三步：**找反常**——敌对三人为何同侍病榻？一个"性仁柔"的评语为何出现在刻薄的本纪里？**列证据链**——用"首先/其次/最后"把散落的记载串成推理序列；**挂声明牌**——结论必须标明推测等级："或许/可能"（弱推测）、"我们有理由相信"（证据链推理）、"以下为个人观点"（强观点）。两个变体：**双簧解读**——对过于工整的政治场面（劝进、推辞、君臣对答），默认多问一层"这是不是演的"，但永远搭配"也或许"的替代解释；**影射分析**——读史论不停在字面褒贬，追问"说这话的人自己的处境是什么"（李世民骂司马衷=影射李建成）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 石勒之死三步推理（39 期）
- **问题**: 《晋书》平铺直叙地记了石勒病中人事安排，但其中"石虎与太子、严政同侍病榻"明显反常
- **方法论的使用**: 找反常（敌对者同侍）→列证据链（侍疾名单→矫诏→软禁）→挂声明牌（"我们有理由相信"）
- **结论**: 石虎在石勒断气前已完成政变
- **结果**: 一段平铺直叙被读成惊悚悬疑，全篇高潮

### 案例 2: 王导信件逐句拆解（33 期）
- **问题**: 王导给叛将王含的信表面上劝退，实际意图暧昧
- **方法论的使用**: 拆成四个信息层（慰问/转移矛头/时间声明/布防透露），指出"字面劝退、实则通风报信"的双层结构
- **结果**: 一封信读出了王导的投机全貌

### 案例 3: 李世民史论的影射分析（17 期）
- **问题**: 李世民为何在《晋书》史论里对司马衷异常刻薄
- **方法论的使用**: 追问说话者处境——李世民自己也是非嫡长子，骂司马衷=骂李建成
- **结果**: 帝王史论被还原为政治表态

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读史料遇到"说不通"的记载："这里好奇怪""为什么这么写"
2. 写历史文想从旧材料里挖出新观点——侦探法是最强的观点制造机
3. 解读任何"官方文本"（史论、诏书、悼词）的弦外之音

### 语言信号

- "这段记载什么意思""这里有蹊跷""史书为什么不写"
- "帮我分析这段话""弦外之音""影射"
- "read between the lines / 推理 / 解密"

### 与相邻 skill 的区分

- 与 `duruhui-source-anchoring`：锚定管"引用得规范"，本 skill 管"从引用里挖出东西"
- 与 `duruhui-psych-os`：心理OS填人物内心，侦探法还原事件真相；前者是共情，后者是推理

## E — 可执行步骤 (Execution)

1. **扫描反常点**：通读材料，标记所有"说不通"处（矛盾、讳饰、过于工整、明显缺环）
   - 完成标准：列出反常点清单，每条写明"哪里不对劲"

2. **组证据链**：为每个反常点收集材料内证据，按"首先/其次/最后"排序
   - 完成标准：证据≥2 条且来自不同段落
   - 判停条件：证据不足 2 条——放弃推理，改写为"存疑"表述

3. **下结论并挂声明牌**：按证据强度选声明等级（或许/我们有理由相信/以下为个人观点）
   - 完成标准：每个推理结论都有对应声明牌，无一个说死

4. **呈现推理过程**：把"反常→证据→结论"完整写给读者看，推理过程本身就是内容
   - 完成标准：读者能复述你的推理链，而不只是记住结论

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 材料本身明确充分，无需推理——硬找"反转"是阴谋论化
- 证据只有一条孤证——只能写"存疑"，不能写"真相"

### 作者在书中警告的失败模式
- 脑补不声明（ce02）：推理不挂声明牌，"通俗化"变质为"编造"
- 把话说死：杜氏永远保留"也或许"的替代解释（50 期双簧解读）

### 作者的盲点 / 时代局限
- 侦探法自带戏剧性偏好，容易高估"阴谋"、低估"混乱"——历史上的很多反常只是记录粗糙
- 杜氏偶有 ASR 错字导致的误读风险；推理前须核对可靠版本

### 容易混淆的邻近方法论
- 历史考据学：考据追求定论，侦探法追求"好故事+诚实的推测声明"
