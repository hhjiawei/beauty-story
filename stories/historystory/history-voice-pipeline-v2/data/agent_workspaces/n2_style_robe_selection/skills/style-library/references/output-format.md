# 风格施工包输出格式

> 本文件为 SKILL.md 的参考文档，按需加载。包含风格施工包的标准输出格式。

---

## 输出 Schema

```markdown
# 风格施工包 · {集名}

> 风格：{风格名}｜题材：{人物/朝代/事件}｜对象：{具体对象}
> 目标时长：{X} 分钟｜主选风格：{风格名}｜备选风格：{风格名}

## 一、风格名与核心气质

{一句话定义该风格的核心气质}

## 二、叙事模板

{针对具体对象的定制化叙事框架，从Hook到结尾}

## 三、语气示例句（3-5句）

1. {示例句1}
2. {示例句2}
3. {示例句3}

## 四、施工要点

{该风格特有的写作纪律}

## 五、禁忌清单

{该风格绝对不能做的事}

## 六、适用性说明

**为什么选这套风格**：{理由}
**预期观众反应**：{情绪描述}
**切换备选的条件**：{什么情况下建议切备选}
```

## 各风格施工要点速查

### 周星驰式

**施工要点**：
- 第一句即荒诞场景，不铺垫
- 古代场景说现代话，制造反差
- 小人物视角贯穿始终
- 情绪突转：搞笑→催泪只隔一句话

**禁忌**：
- 禁止为搞笑牺牲史实
- 禁止在悲情节点玩梗
- 禁止重复梗超过3次

### 昆汀式

**施工要点**：
- 分章节，每章有标题（剧透或误导性）
- 对话必须"离题万里"，通过日常琐碎蓄积张力
- 暴力前必须有长篇闲聊
- 章节之间用黑屏+标题过渡

**禁忌**：
- 禁止对话直奔主题
- 禁止暴力没有铺垫
- 禁止章节超过5个（短视频）

### 诺兰式

**施工要点**：
- 三条时间线围绕同一主题/情感核心
- 用感官和意象在不同时间线间建立呼应
- 每条时间线配独特音效锚点
- 结局提问题，不给答案

**禁忌**：
- 禁止时间线超过3条（短视频）
- 禁止时间线之间无关联
- 禁止给出明确结论

### 当年明月式

**施工要点**：
- 像聊天一样讲历史，语气亲近
- 心理描写用"朋友吐槽式揣测"
- 类比选最俗最日常的
- 点评"歪理正着说"

**禁忌**：
- 禁止学术腔
- 禁止高雅文学比喻
- 禁止在苦难题材使用
