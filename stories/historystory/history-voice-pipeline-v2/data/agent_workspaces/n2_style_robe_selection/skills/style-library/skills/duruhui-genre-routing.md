# 三大文体骨架与场景路由（人物传 / 事件录 / 制度论）

## R — 原文 (Reading)

> 人物传收尾："何意百炼钢，化为绕指柔。"（18）事件录收尾："当然，那就是另外一个故事了。"（33）制度论标题即框架："路线是王道，纪律是霸道。"（50）

---

## I — 方法论骨架 (Interpretation)

杜茹慧 45 篇只有三种文体骨架，路由判据看**叙事主线**：
- **人物传**：主线是某个（群）人的命运弧光。结构=标签登场→前史→关键抉择→弧光转折→盖棺定论（金句/诗文收尾）。心理重构密度最高。
- **事件录**：主线是一段有时限的进程（政变/战役/改革）。结构=地图盘点→编年推进（时间戳倒计时）→多方博弈→结局→影响分析。时间戳密度最高。
- **制度论**（朝代文）：主线是一个结构性问题（为什么会这样）。结构=标题即框架→现象案例群→层层归因→数据锚定→趋势判断。框架密度最高。
拿不准时看材料"天然收束点"：收在人→人物；收在事→事件；收在理→制度。

## A1 — 书中的应用 (Past Application)

### 案例 1: 同为石虎材料，两种路由
- **问题**: 石虎既可写人也可写事
- **方法论的使用**: 39 期写"石勒之死与石虎夺权"走事件录（时间推进+侦探推理）；49 期"最变态君主上线"走人物传（罪行编年+暴君判词）
- **结论**: 同一材料按主线不同可拆成两篇，骨架不混用
- **结果**: 两篇各自成立，互不重复

### 案例 2: 01 期制度论的归因闭环
- **问题**: "西晋为什么速亡"是大问题，容易写成故事串
- **方法论的使用**: 先案例群（斗富）→ 再归因（九品中正制病变）→ 数据与金句收束
- **结果**: 故事全部服务于"为什么"，归因闭环成立

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户丢来一段史料/一篇历史文："帮我改成杜茹慧风格"——第一步永远是路由
2. 用户自己拿不准："这材料该写人还是写事？"
3. 用户写的文章"四不像"：人物传里塞了半篇制度分析

### 语言信号

- "这篇怎么组织/什么结构""写人还是写事"
- "改成杜茹慧风格""仿写""硬核历史文"
- "帮我分析这个材料""structure for this story"

### 与相邻 skill 的区分

- 与 `duruhui-outline-planner`：本 skill 是路由判定（选哪条赛道），planner 是选定后的工序规划
- 与 `duruhui-irony-reversal`：反讽结构是可叠加在三种骨架上的增强件，不是第四种文体

## E — 可执行步骤 (Execution)

1. **提取主线**：用一句话写出材料的叙事主线
   - 完成标准：能说出"主线是某人的命运/某段进程/某个问题"三者之一

2. **套用归属判据**：命运弧光→人物传；有时限的进程→事件录；结构性问题→制度论
   - 完成标准：明确分类+理由
   - 判停条件：材料同时强含人和事时，问用户"你想让读者记住这个人，还是这件事？"

3. **加载对应骨架**：按上表结构输出骨架清单
   - 完成标准：骨架各段都有材料可填；填不动的段标"需补料"

4. **密度自检**：人物传检查心理重构密度；事件录检查时间戳密度；制度论检查归因句存在性
   - 完成标准：对应密度特征成立，否则回到步骤 2 重判

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 用户已明确指定体裁且与材料匹配——尊重用户判断，直接进 planner
- 材料是虚构/小说创作——本路由基于非虚构史料

### 作者在书中警告的失败模式
- 朝代类沉溺个案忘记归因（ce08）：制度论若 80% 篇幅在讲故事、没有"背后是……"归因句，路由错了或执行丢了

### 作者的盲点 / 时代局限
- 杜氏人物传偏好"判词式盖棺定论"，对复杂人物有简单化倾向——争议人物（如冉闵）需保留多面性

### 容易混淆的邻近方法论
- "起承转合"：太粗，无法区分三种骨架的密度配置差异
