## 一、人物术语（杜茹慧黑话）

| 术语 | 含义 | 出处/用法 |
|---|---|---|
| **我晋** | 以晋朝（或所叙朝代）为「自家人」的领属叙事视角：不说「晋军」，说「我晋的军队」 | 全套文案的视角基石 |
| **影帝** | 判词式绰号，封给演技派政治人物（如司马懿「老影帝」），一语定性 | 人物类开场判词 |
| **弹药** | 本仓库核心概念：现代词汇/梗降维用于古代叙事的修辞子弹，讲「错位感×精确性」 | 见下方弹药库 |
| **阴暗小故事** | 正史角落里的残酷细节栏目化叙述；蒸馏时按任务书要求**不提炼血腥细节** | 系列栏目 |
| **版本领先** | 用游戏版本术语形容某方制度/战术/观念领先对手一个时代 | 弹药·游戏电竞类 |
| **编制梗** | 用现代编制/职级/裁员等职场语言翻译古代官制 | 弹药·职场黑话类 |
| **双簧** | 两人物唱双簧式配合的政治表演，一唱一和心照不宣 | 事件类常用解读框架 |
| **话说回来** | 口语转折标志，从戏谑轨换挡进入正题或悲悯轨 | 语气换挡信号词 |
| **同学们/朋友们** | 对观众的固定称呼，建立课堂/茶话会临场感 | 开场与转场 |
| **曹老板** | 以「老板」称呼曹操式的称呼降维：把帝王将相拉回人间 | 弹药·称呼系统 |

> 部署规则见 `duruhui-ammo` skill：弹药必须同时满足**错位感**（古今时代错置）与**精确性**（语义严丝合缝）；空转的弹药不如不用。
