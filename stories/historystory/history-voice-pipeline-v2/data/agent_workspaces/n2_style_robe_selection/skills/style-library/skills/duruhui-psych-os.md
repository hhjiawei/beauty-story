# 心理OS代入与场景脑补

## R — 原文 (Reading)

> "或许被押赴刑场之前，他曾经对儿子嵇绍说过这样一段话：老爹我没有办法……我的责任是以死明志，而你的责任却是扶正山河。"
>
> — 杜茹慧，两晋特别篇 07（"或许"声明 + 脑补对话）

---

## I — 方法论骨架 (Interpretation)

史书省掉的是心理和画面。填补守四条铁律：①**不改史实骨架**——时间地点人物结局一字不动，只填留白；②**符合物理常识**——脑补的细节要能落地（距离、体力、季节）；③**符合人性逻辑**——用现代职场人/普通人的心理去套古人的处境（怕失业、怕站错队、患得患失），古人瞬间变成"有血有肉的打工人"；④**必须挂声明**——"或许""估计他当时在想"是通行证。画面定格是配套动作：把抽象结果变成具象镜头（"粘着血的衣服不许洗"），一个细节顶一段议论（殷浩寄出空信函=名士误国的全部判词）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 石勒劝张㔨督（16 期）
- **问题**: 史书只有"石勒说之，二人乃降"六个字
- **方法论的使用**: 填对话（入股/行情好）+填动作（一拍大腿）+填荒诞画面（几千人"悄悄跟着"一个人）
- **结论**: 留白处可以长出完整场景
- **结果**: 六字记载变成全篇最好笑的段落，且结果一字未改

### 案例 2: 殷浩空信函（47 期）
- **问题**: "殷浩被废后忧郁而死"怎么写出悲剧感
- **方法论的使用**: 抓住"回信拆封十几次、最终寄出空信封"的细节，不加一句评判
- **结论**: 细节即判词
- **结果**: 人物悲剧不靠形容词成立

## E — 可执行步骤 (Execution)

1. **圈留白**：找出史书中"只有结果没有过程"的记载（X 遁、Y 卒、Z 从之）
   - 完成标准：圈出的点都是"史书记载少于人情所需"的位置

2. **定心理逻辑**：用现代人心智套古人处境——他此刻怕什么、贪什么、纠结什么
   - 完成标准：能写出一句"如果我是他，我会想……"且与前后行为不矛盾

3. **填场景**：加动作、对话、环境细节，全部符合物理常识
   - 完成标准：场景可以拍成镜头；每个细节能被"当时真的可能有"辩护

4. **挂声明牌**：段首或段中放"或许/可以想象/估计"
   - 完成标准：脑补段无一例外带声明
   - 判停条件：若场景涉及死亡/殉国——降低戏谑，转白描（见 duruhui-tone-tracks）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 心理活动已有充分史料记载（遗书、奏对）——直接引用，别抢史书的戏
- 肃穆场景的心理戏要克制——死亡面前少加戏

### 作者在书中警告的失败模式
- 脑补不声明（ce02）：去掉"或许"，虚构就成了造谣
- 细节失控：脑补的细节不能反过来改变事件性质（把"被迫"脑补成"主动"就是改史）

### 作者的盲点 / 时代局限
- 现代心理逻辑碾压古人语境：魏晋人的名教观、死亡观与今人差异巨大，套用时注意分寸（BOOK_OVERVIEW §3）

### 容易混淆的邻近方法论
- 历史小说创作：小说是虚构优先，本法是"史实骨架+留白填充"，声明牌是分界线
