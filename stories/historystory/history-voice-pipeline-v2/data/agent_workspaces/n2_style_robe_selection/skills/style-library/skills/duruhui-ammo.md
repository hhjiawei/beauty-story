# 弹药词汇降维术

## R — 原文 (Reading)

> "他任命石勒为副将，让他率领牧人劫掠郡县，并专门去监狱里面招募囚犯，又开专项招聘会，招募山泽中的亡命之徒。"
>
> — 杜茹慧，两晋 16 期

---

## I — 方法论骨架 (Interpretation)

弹药降维 = 把现代概念等价移植到古代场景，制造"错位感×精确性"的笑点。公式：**先找史实逻辑支撑点，再选弹药词**——汲桑确实在定向招募，才配说"专项招聘会"；石勒白手起家，才配说"创业团队"。反过来用就是胡闹。弹药有层级：单词级（编制、KPI）→ 句式级（"领先N个版本"）→ 框架级（让子弹飞三部曲、五胡S3赛季——整个叙事借用一个现代框架）。弹药库按场景分类储备（职场/游戏/网络/制度/金融/校园/体育），写作时按大纲布点投放，同一类弹药不连续出现。弹药是资产：好弹药被反复复用（"我晋""影帝"全系列贯穿），并在复用中增值。

## A1 — 书中的应用 (Past Application)

### 案例 1: "编制"一词三用（17 期）
- **问题**: 李世民修《晋书》的动机很抽象，怎么讲得又好笑又准
- **方法论的使用**: 全文围绕"编制"做文章——蛤蟆分官家私家编制、史书分有编制没编制（二十四史=皇帝批准的编制）
- **结论**: "正史=有编制的史书"精确命中清代钦定二十四史的史实逻辑
- **结果**: 一个弹药词撑起全篇笑点与论点，结尾包袱："司马家和李家造反的时候，有没有编制呢？"

### 案例 2: 让子弹飞三部曲（02 期）
- **问题**: 梁习治理并州胡人的三步政策枯燥难记
- **方法论的使用**: 整段借用电影框架——"第一，请客。第二，斩首。第三，收下当狗。"
- **结果**: 框架级弹药让三段政策变成自带节奏的记忆点

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 仿写历史文时"语言太正经"，需要杜式活性
2. 用户问"这个古代概念用现在的话说是什么"（如：九品中正制≈？）
3. 建立/扩充弹药库："帮我收集这类词""弹药库怎么分类扩展"

### 语言信号

- "加点梗""活泼一点""幽默一点""网感"
- "用现代话说""类比成现在的什么"
- "弹药""meme / 梗 / 网络用语"

### 与相邻 skill 的区分

- 与 `duruhui-tone-tracks`：本 skill 管"造梗"，tone-tracks 管"哪里禁止造梗"
- 与 `duruhui-psych-os`：弹药是词汇层的移植，心理OS是心理层的移植

## E — 可执行步骤 (Execution)

1. **找支撑点**：先确认这段史实的逻辑内核是什么（招募/垄断/考核/站队……）
   - 完成标准：能用一句白话说清"这段史实本质上在发生什么"

2. **选弹药类目**：从弹药库选类目（职场/游戏/网络/制度/金融/校园/体育）
   - 完成标准：所选类目的概念与史实内核一一对应

3. **投放与造句**：单词级替换直接写；句式级套用模板（"领先N个版本"）；框架级先搭三段式
   - 完成标准：删掉弹药后句子信息量仍在（弹药是调味不是主菜）

4. **精度自检**：问"这个词映射的是哪条史实？"答不上来就换或删
   - 完成标准：每个弹药词都能指出史实支撑点

5. **收录新弹药**：新造的好弹药回填弹药库，标注类目+适用场景+例句
   - 完成标准：弹药库条目增长且带场景标签

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 死亡、屠杀、殉国、气节场景——见 ce01，这些段落弹药清零
- 目标读者完全不上网（如严肃出版物）——弹药会全部失效

### 作者在书中警告的失败模式
- 弹药空转（ce03）：为搞笑而搞笑，删掉梗段落信息量为零
- 同段连用三个以上热梗——聒噪，笑点互相踩踏

### 作者的盲点 / 时代局限
- 弹药有保质期：今天的网络热梗两年后过时；弹药库需持续更新，经典类目（职场/游戏）比时效热梗更耐久
- 杜氏弹药偏男性向语境（游戏/体育/职场），面向其他读者群需换类目

### 容易混淆的邻近方法论
- "玩梗"≠弹药：玩梗追求共鸣，弹药追求"共鸣+精确映射"
