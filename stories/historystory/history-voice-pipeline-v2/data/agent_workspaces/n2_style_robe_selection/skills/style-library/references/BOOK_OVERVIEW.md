**小类归属规则**：以"叙事主线是什么"为唯一判据——主线是某个人的命运弧光→人物；主线是一段有时限的进程（政变/战役/改革）→事件；主线是一个跨人物跨时段的结构性问题→朝代。拿不准时看结尾：人物类收在盖棺定论，事件类收在结局影响，朝代类收在规律/趋势判断。

**各类共通性**：都用"我晋"视角、设问驱动、史料锚定、现代弹药词、连续剧集结构。
**各类差异**：人物类心理重构密度最高（内心OS+对话还原）；事件类时间戳密度最高（"七月初一…七月初三"倒计时推进）；朝代类框架密度最高（先立分析框架再填案例）。

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 我晋 / 我大晋 | 对晋朝的第一人称领属称呼 | 把王朝当自家单位，吐槽即家丑外扬 |
| 影帝 / 老乌龟 / 老僵尸 | 司马懿家族的固定绰号 | 绰号即人物判词，全系列复用形成梗资产 |
| 梗编号 | 给人物贴编号标签（"桓温身上第一个梗诞生了——豪杰赐名"） | 把人物特征当游戏成就逐个解锁 |
| 阴暗小故事 | 篇末固定栏目，补冷峻轶闻 | 自嘲名目，实为史料边角料的人性观察 |
| 弹药（任务书术语） | 可移植到古代场景的现代词汇 | 必须词义精确映射史实逻辑才可投放 |
| 史料侦探法 | 从记载的矛盾缝隙推理现场（如石虎夺权三步推理） | 作者会明说"我们有理由相信"，划清脑补边界 |
| 版本领先梗 | "领先梁山好汉N个版本" | 游戏版本术语嫁接历史先后 |
| 编制梗 | "官家蛤蟆还是私家蛤蟆""史书也分有编制没编制" | 体制话语移植到一切古代身份 |

### 核心命题（用自己的话）

1. 王朝崩溃始于意识形态与人才制度，军事失败只是结果。
2. 古人的"蠢操作"放回当时当地往往有其理性——先还原处境，再评判对错。
3. 内斗是组织衰败的第一信号。
4. 精英阶层的精致利己是系统性疾病，三百年乱世是它的账单。
5. 戏谑止步于死亡与气节之前——苦难必须被严肃对待。
6. 史书也是人写的：立场、影射、讳饰都可被拆解（李世民评《晋书》篇）。

### 论证链
案例群展示（具象场景）→ 制度/结构归因 → 心理还原（"如果是你怎么办"）→ 结局反讽（必胜逻辑 vs 真实败局）→ 长时段验证（三百年回望）。

### 作者的时代局限
- 现代词映射是类比不是等同，简化处有失真风险（九品中正制≈阶层固化）。
- ASR 转写质量参差：约 1/5 篇章有错字断句混乱（43 篇"15"代石虎）。

### 作者的立场盲点
- 强"我晋"正统视角，胡人政权多从对面打量（对石勒、苻坚有翻案式肯定是例外）。
- 现代职场价值观滤镜碾压古人伦理语境（死亡观、名教观差异）。
- 心理重构台词系虚构，听众可能把"合理脑补"误记为史实。

### 未被证明的假设
- 默认听众熟知三国人物典故。
- 默认现代心理逻辑对古人普遍适用。

### 最强反对意见
"这是历史的娱乐化解构，不是历史本身"——梗会覆盖史实记忆；脑补若脱离史料密度，就从通俗化滑向段子化。
