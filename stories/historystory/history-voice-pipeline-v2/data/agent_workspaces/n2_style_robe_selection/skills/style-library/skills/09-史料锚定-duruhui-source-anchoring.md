# 史料锚定术

## R — 原文 (Reading)

> "我们来直接看原文吧：'嵇绍遂被害于帝侧，血溅御服。天子深哀叹之。及事定，左右欲浣衣，帝曰：此嵇侍中血，勿去。'"
>
> — 杜茹慧，两晋特别篇 07；另见 24 期"译文来自汉语大词典出版社《二十四史全译·晋书》第四册"

---

## I — 方法论骨架 (Interpretation)

杜氏文本的笑点密度始终被史料锚点密度托底。四件套：①**时间双标**——每个新时间点"年号+公元"（"永兴元年，公元304年"），年号给氛围，公元给坐标；②**原文+翻译配套**——引原文必配白话转译，原文管"信"，翻译管"达"，关键的梗只落在翻译层，不动原文；③**版本注明**——大段引用注明史书卷次甚至译本出版社；④**数据砸实**——宏大判断后必跟具体数字（"人口从五千六百万锐减至一千九百万"），数字出场有宣告语（"直接上数据吧"）。锚点的本质是和读者立约：梗归梗，史归史。

## A1 — 书中的应用 (Past Application)

### 案例 1: 24 期吃人专题的全锚定
- **问题**: "满本都写着吃人"这种惊悚题材最容易被质疑编造
- **方法论的使用**: 每条记录年号+公元双标、《晋书》卷次明确、译文注明出版社版本
- **结论**: 最惊悚的内容用最高密度的锚点
- **结果**: 全篇无一句被质疑的空间，惊悚感反而更强

### 案例 2: 02 期数据锚定
- **问题**: "百年战乱很惨"是废话，怎么砸实
- **方法论的使用**: 宣告语"直接上数据吧"+人口数字+编年清单互证
- **结果**: 宏观判断落地，听众记住的是数字

## E — 可执行步骤 (Execution)

1. **时间轴扫描**：检查全文每个新时间点是否"年号+公元"双标
   - 完成标准：无一处裸年号或裸公元（除连续同段复述）

2. **引文配套**：每处原文引用是否配白话转译；长引用是否注明出处
   - 完成标准：原文≤引用的必要长度，转译紧随其后

3. **数据补位**：找出全文所有宏大判断句，逐句检查后面有没有数字
   - 完成标准：每个宏观判断都有数字或原文托底；没有材料的判断句降级为推测并挂声明

4. **锚点密度比**：笑点段与锚点段交替出现，连续两段纯玩梗即预警
   - 完成标准：全文无连续三段以上零锚点

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 纯虚构/架空创作——锚定是给非虚构上保险
- 材料本身无可靠史料支撑——此时该做的是找材料，不是装锚点

### 作者在书中警告的失败模式
- 只讲段子不锚史料（ce06）：通篇无《》引用、无数字、时间模糊——"硬核历史梗"只剩梗
- ASR 转写稿自身有错字（43 期"15"代石虎）——引用转写稿前须回核史书原文

### 作者的盲点 / 时代局限
- 杜氏锚定到"史书原文"为止，不做学术级版本校勘；学术写作需更进一步

### 容易混淆的邻近方法论
- 学术脚注体：本术是口播场景的轻量锚定，不是论文注释系统
