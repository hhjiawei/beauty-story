> 目标：给定**任何朝代**的人物/事件/朝代文素材，改写成杜茹慧风格的历史口播文案。

## 〇、一句话总结杜茹慧

**把庙堂上的死人，写成你微信群里那个活灵活现的熟人；但在每一个你以为她要开玩笑的地方，她都拿史料砸你一下，在每一个你以为她要一直笑下去的地方，她突然让你鼻酸。**

## 壹、四把板斧（总风格）

杜茹慧的文风不是一堆技巧的随机组合，而是四把板斧支撑的一套系统：

### 第一斧：心理 OS 代入

给历史人物写第一人称、现代语感的内心独白。司马懿装病时不写「懿称疾困笃」，而写他躺在床上心想「来吧，表演」。这一斧解决的是**距离感**——让 1700 年前的人像隔壁工位的同事。

配套 skill：`duruhui-psych-os`

### 第二斧：现代词汇降维（弹药）

用现代职场、游戏、网络词汇翻译古代政治：政变是「裁员」，制度优势是「版本领先」，官制是「编制」。弹药的好坏标准是**错位感×精确性**——既要古今错置得好笑，又要语义对应得严丝合缝。空转的弹药（只为搞笑、无对应机理）是废品。

配套 skill：`duruhui-ammo`

### 第三斧：细节脑补（史料侦探）

正史没写的，她敢补——但永远挂着声明牌：「我们有理由相信……」。脑补不是编造：推理链必须摊开给读者看，戏谑止步于史实。这是**自由度与可信度的契约**。

配套 skill：`duruhui-source-detective`、`duruhui-source-anchoring`

### 第四斧：预期违背反讽

先把一个人/一件事铺得崇高、紧张、悲壮，然后一句话戳破：「早干嘛去了。」反转永远落在段落尾，笑点在预期落空处。但反讽只打权贵、打荒唐，**从不打苦难**。

配套 skill：`duruhui-irony-reversal`

## 贰、先路由，再动笔（文体三分）

拿到任何一篇历史素材，第一件事不是写，是**判类**。三类文章，三套打法：

| 大类 | 叙事轴 | 主力技法 | 小类 |
|---|---|---|---|
| **人物类** | 以人为轴，事件为人服务 | 判词式绰号、心理OS、反讽 | 帝王/权臣/名将/奇葩 |
| **事件类** | 以因果链为轴 | 设问引擎、编年清单、以小见大 | 战争/政变/改革 |
| **朝代类** | 以时间段为轴，人于事皆为论据 | 长时段归因、影射分析 | 兴/衰/转型 |

判错类 = 全文跑偏：把朝代类写成人物传记，归因就立不住；把人物类写成事件流水，判词就立不住。

配套 skill：`duruhui-genre-routing`

判完类，出大纲。杜茹慧的大纲不是提纲挈领的废话，而是两张表：**事件编年顺序表**（先讲什么后讲什么）+ **弹药布点表**（哪一段埋哪类弹药、埋几颗）。弹药布点随语气轨走：戏谑段密集，悲悯段清零。

配套 skill：`02-大纲规划-duruhui-outline-planner`

## 叁、视角：「我晋」与判词绰号

杜茹慧说晋朝，从来不说「晋朝」，说「**我晋**」。一个「我」字，把读者拉进自家人阵营——输了我们一起心疼，赢了我们一起燃。这个视角技巧与朝代无关：写宋就是「我宋」，写明就是「我明」。

与视角配套的是**判词式绰号系统**：给人物一词定性，绰号即判词。司马懿是「老影帝」（演技定终生），苟晞是「屠伯」（史书里现成的判词），王弥是「飞豹」（出处+特性双锚定）。好绰号的标准：**抓核心特质、有史料依据、一念出来人物就立住**。

称呼系统整体降维：帝王将相皆可为「老板」「老哥」「大兄弟」——把神拉回人，是这套文风的底色。

配套 skill：`duruhui-wojin-voice`

## 肆、语气三轨：戏谑、悲悯、热血

杜茹慧的文永远在三条语气轨道上跑：

- **戏谑轨**：弹药密集、反讽频出，用于权贵的荒唐与机关算尽
- **悲悯轨**：弹药清零、句子变短，用于苍生苦难与英雄末路
- **热血轨**：节奏加快、短句排比，用于气节与高光时刻

三轨的价值在**换挡**：「话说回来」一出口，笑声落地，悲悯进场。通篇戏谑会油腻，通篇悲悯会沉闷，通篇热血会疲劳——好文章是三轨的配比艺术。红线只有一条：**悲悯轨段落，绝不戏谑。**

配套 skill：`duruhui-tone-tracks`

## 伍、叙事引擎：设问与反讽的接力

杜茹慧的文章几乎不用陈述句推进，用**设问链**推进：「为什么贾南风能独揽大权？因为她手里有三张牌。」每段以问题开场，答案落地的同时埋下新问题——读者被问题牵着走，滑不到底。

设问负责**立靶子**，反讽负责**击倒**：先用设问把一个人物的算盘亮出来，再用预期违背反转一枪撂倒。两个引擎接力，构成段落级推进力。

结构上首尾闭环：开头用钩子四式（悬念/反差/判词/代入）抓人，结尾用金句收束+下期预告+固定道别，形成连续剧质感——上期回顾、本期正文、下期预告，单篇也是系列的一环。

配套 skill：`duruhui-question-engine`、`duruhui-hook-openers`、`duruhui-ending-serials`

## 陆、史料：这套文风的压舱石

杜茹慧最反直觉的一点：**网感最重的人，史料锚得最死。**

三条铁律：

1. **年号+公元双标**——「永嘉五年，公元311年」，一次都不省
2. **原文+白话翻译**——引《晋书》《资治通鉴》必附翻译，翻译忠实、不掺弹药
3. **脑补必挂声明牌**——「我们有理由相信……」，推理链摊开

**不捏造核心史实**是绝对红线：记不清的年份标存疑或省略，绝不编一个「合理的」。这套文风的可信度，全靠戏谑与史实的这条楚河汉界撑着——读者敢笑，是因为知道你不敢骗他。

配套 skill：`duruhui-source-anchoring`、`duruhui-source-detective`

## 柒、写作全流程（12 skill 调用链）

```
素材到手
  │
  ├─ 1. genre-routing     判类：人物/事件/朝代
  ├─ 2. outline-planner   大纲：编年顺序 + 弹药布点
  ├─ 3. wojin-voice       定视角：我X + 判词绰号
  ├─ 4. hook-openers      开头钩子（四式选一）
  │
  ├─ 正文循环（每段）：
  │   ├─ 5. question-engine   设问推进/立靶
  │   ├─ 6. psych-os          人物内心独白
  │   ├─ 7. ammo              弹药部署（错位×精确）
  │   ├─ 8. irony-reversal    段尾反转
  │   ├─ 9. source-anchoring  全程年号双标+原文翻译
  │   └─ 10. source-detective 脑补挂声明牌
  │
  ├─ 11. tone-tracks      全篇三轨换挡检查
  └─ 12. ending-serials   金句收束 + 下期预告 + 道别
```

## 捌、四条红线（任何情况下不越界）

1. **零广告**——产出文案不含任何广告位
2. **自称「博主」**——复刻文风，不复刻作者身份
3. **不捏造核心史实**——存疑即标注或省略
4. **不渲染血腥**——「阴暗小故事」保留因果，删去感官细节

## 玖、这套东西能带走什么

杜茹慧文风的本质，是**用现代的平视，消解历史的仰视，再用史实的重量，压住消解带来的轻佻**。

这套系统不绑定两晋：视角可平移（我晋→我宋→我明），弹药库可扩展（八类 891 词，见 GLOSSARY.md），路由可复用（任何朝代都有人物/事件/朝代文）。你拿它写唐宋明清，骨架纹丝不动，换的只是血肉。

- 全量术语与弹药库 → `GLOSSARY.md`
- 12 skill 索引与关系图 → `INDEX.md`
- 压力测试集（含唐宋明跨朝代用例） → `test-prompts.json`
- 原文证据层 → `digest.md`（199KB 机械提取）
