# 语气三轨切换

## R — 原文 (Reading)

> "太难过了，黑色幽默一下吧。"（02，瘟疫惨状后切到王粲葬礼学驴叫）／"这段太过于黑暗了，直接翻译吧。"（24）／"真正的民族英雄祖逖，正式上线了。"（23）

---

## I — 方法论骨架 (Interpretation)

杜茹慧的幽默之所以不招人烦，是因为她掌握着三条语气轨道的切换：**戏谑轨**（默认态：弹药、吐槽、绰号）；**悲悯轨**（屠杀、食人、殉国场景：梗全部收起，改用白描+原文直引，24 期全篇无一梗）；**热血轨**（英雄登场、气节高光：语速加快，短句，定格画面+判词，"正式上线了"）。切换有两条纪律：①**题材触发**——轨道由内容决定不由心情决定，段落里出现具体死难者姓名就是切换信号；②**显式宣告**——切换可以明说（"太难过了"），宣告本身是对死难者的敬礼，也是对听众的情绪指令。戏谑的价值由禁区背书：正因为作者知道哪里不笑，她笑的地方才被信任。

## A1 — 书中的应用 (Past Application)

### 案例 1: 07 期嵇绍之死的轨道切换
- **问题**: 一篇讲"魏晋风骨有多好玩"的文章，结尾要落到嵇绍殉国
- **方法论的使用**: 前文戏谑轨（打铁、酒鬼段）→ 嵇绍血溅御服段梗清零、直接上原文 → 引《正气歌》升华
- **结果**: 前文的好玩反衬结尾的沉重，"风骨"的题眼被情绪钉死

### 案例 2: 24 期全篇悲悯轨
- **问题**: 吃人专题，全篇没有一个地方能笑
- **方法论的使用**: 全篇关闭戏谑轨，编年白描+原文+注明译本；结尾用毛泽东《贺新郎·读史》升华到"读史是为了什么"
- **结果**: 黑暗题材获得了最重的分量

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 文章涉及死难/气节/英雄时刻，拿不准分寸："这里还能开玩笑吗"
2. 全文一个语调到底，需要设计情绪曲线
3. 审稿：检查戏谑是否越界进入禁区

### 语言信号

- "这里能玩梗吗""语气""基调""太轻浮了""太沉重了"
- "煽情""泪点""燃""感动"
- "tone / register / 情绪节奏"

### 与相邻 skill 的区分

- 与 `duruhui-ammo`：ammo 造梗，本 skill 管梗的禁区
- 与 `duruhui-irony-reversal`：反讽结构在悲悯轨自动失效

## E — 可执行步骤 (Execution)

1. **题材扫描**：标记全文所有涉及死亡、屠杀、殉国、气节的段落
   - 完成标准：禁区清单完成，无遗漏

2. **逐段定轨**：每段标注轨道（戏谑/悲悯/热血）
   - 完成标准：禁区段落全部为悲悯轨；英雄高光为热血轨；其余默认戏谑轨

3. **清理越界**：悲悯轨段落删除全部弹药、绰号、设问；改白描+原文
   - 完成标准：禁区段落读一遍，零笑点残留

4. **加切换宣告**：轨道切换处加显式过渡句（"太难过了""笑不出来"）
   - 完成标准：每次切换读者能明确感知，不突兀

5. **结尾定调**：检查结尾轨道与全篇主旨一致
   - 完成标准：以悲悯/热血收尾的文章，不在最后三句内抖包袱

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 纯轻松题材（文人趣事、无死难）——全程戏谑轨即可，别硬切悲壮

### 作者在书中警告的失败模式
- 戏谑越界（ce01）：在死难场景玩梗=信任崩塌
- 热血滥用：不是每个历史人物都配"正式上线"，滥发英雄卡会通货膨胀

### 作者的盲点 / 时代局限
- 三轨是口播情绪模型，书面长文可更细腻；本模型是底线不是天花板

### 容易混淆的邻近方法论
- "张弛有度"的泛泛建议：本 skill 给出的是具体轨道、触发信号与禁区清单
