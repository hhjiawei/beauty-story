# 设问驱动叙事引擎

## R — 原文 (Reading)

> "皇帝如果不能亲政事，那么皇权会跑到哪里呢？忘了东汉末年皇权不振……？忘了三国年间皇权衰弱……？忘了曹魏年间皇帝早衰，江山被你司马家给偷到手了？"
>
> — 杜茹慧，两晋 04 期

---

## I — 方法论骨架 (Interpretation)

杜氏文本平均每 2–3 段就有一个问句在重启注意力。引擎有五个挡位：①**标题大设问**——全篇由一个问题驱动（"为什么一定要选弱皇帝接班？"），文末必须回答；②**段首小设问**——段落接力棒（"那鲁迅先生夸赞的是什么呢？"），答案引出下一段；③**三连反问**——同句式重复三遍，造公堂问罪的气势；④**连环议题问**——连续 4–6 个问句铺出分析框架（50 期改革六连问）；⑤**代入式提问**——"如果你是司马炎，你敢立贤吗？"把听众拉进决策现场。设问不是修辞点缀，是叙事发动机：问题制造缺口，史料填缺口，缺口闭合处就是爽点。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 04 期的设问链
- **问题**: "为什么立傻太子"涉及宗法制、司马攸、贾南风多条线，怎么不散
- **方法论的使用**: 标题大设问统摄全篇→段首设问接力（"其他孩子都死绝了吗？"）→代入式提问（"你敢立贤吗？"）→文末正面回答
- **结果**: 制度讲解被包成悬疑解谜，文末"催化剂论"完成闭环

### 案例 2: 39 期三连反问
- **问题**: 东晋为何拒绝石勒求和，干讲外交很无聊
- **方法论的使用**: 代东晋发声，"攻陷京都洛阳的是不是你？"连问三遍
- **结果**: 外交决策变成公堂控诉，气势即答案

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写好的历史文"平铺直叙""像流水账"，需要注入叙事动力
2. 起标题时——杜式标题几乎都是设问式或悬念式
3. 制度/概念类题材枯燥，需要把讲解改造成解谜

### 语言信号

- "太平了""没劲""流水账""不抓人"
- "帮我起标题""怎么开头"
- "boring / flat / 设问 / 悬念"

### 与相邻 skill 的区分

- 与 `duruhui-hook-openers`：开场钩子只管第一段，设问引擎管全篇注意力曲线
- 与 `duruhui-irony-reversal`：反讽是"先立后破"的结构，设问是"提问-解答"的节奏，可叠加

## E — 可执行步骤 (Execution)

1. **找大设问**：把全文主旨改写成一个问题，作为标题/开篇
   - 完成标准：问题具体到人/事/制度，不是"历史给我们什么启示"式空问

2. **布设问点**：通读全文，每隔 2–3 段无问句处，插入段首设问
   - 完成标准：每个设问的答案恰好是下一段的内容；插不进的段落说明该段与主线无关，考虑删

3. **选变体**：情绪高点用三连反问；框架铺设用连环议题问；抉择处用代入式提问
   - 完成标准：变体与情绪匹配，不堆砌同种问法

4. **闭环检查**：标题大设问在文末是否得到回答
   - 完成标准：文末有明确的答案句
   - 判停条件：若答案超出了材料范围，改标题问题，不要编答案

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 悲悯/热血轨段落（死亡、殉国）——设问在那里要减到最低，见 duruhui-tone-tracks
- 设问密度过高（每段都问）——引擎变噪音

### 作者在书中警告的失败模式
- 平铺直叙（ce04）：连续 5 段没有问号 = 听众流失预警
- 问而不答：设问后绕开不答，等于骗听众

### 作者的盲点 / 时代局限
- 设问驱动天然带"讲台感"，追求冷峻文风时不适用

### 容易混淆的邻近方法论
- "多用疑问句"的泛泛建议：本 skill 给的是位置、变体与闭环规则
