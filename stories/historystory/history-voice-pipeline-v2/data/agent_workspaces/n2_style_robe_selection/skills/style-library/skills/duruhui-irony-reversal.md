# 预期违背反讽结构

## R — 原文 (Reading)

> "一边是全方位无死角优秀好青年、皇位有力竞争者司马攸，一边是蠢得冒泡的傻儿子司马衷……别喊了，再喊司马炎真要急眼了！"
>
> — 杜茹慧，两晋 04 期

---

## I — 方法论骨架 (Interpretation)

工序分两道工序：**搭靶**——站在当事人的信息集里，把他的"必胜逻辑"铺到最足（司马攸论素质论出身论口碑全面碾压；殷浩名士光环、朝廷力挺、七万大军），铺得越足，读者越信；**打脸**——然后用最短的文字亮出真实结局（司马攸呕血而死；殷浩全军覆没寄出空信函），落差不靠评论，靠并置。幽默的源泉是视角差：读者被邀请站在当事人的全知幻觉里，再被拽回现代全知视角。关键纪律：打脸段要短、要冷、要克制——靶子越大，锤子越轻。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 04 期司马攸安利大会
- **问题**: "司马炎为何不敢换太子"的答案是制度，干讲很枯燥
- **方法论的使用**: 先用七个"论……"排比把司马攸夸上天（搭靶），一句"别喊了，再喊司马炎真要急眼了"翻脸（亮锤），最后才讲宗法制死局
- **结论**: 读者先共情司马攸，再理解司马炎的恐惧
- **结果**: 制度分析被包进人物冲突里

### 案例 2: 47 期殷浩北伐
- **问题**: 殷浩北伐失败是政治闹剧，怎么写出"可怜可悲可恨"
- **方法论的使用**: 前半篇持续铺垫名士光环（"我大晋有此人，仿佛有了管仲诸葛亮"），后半篇连环翻车（刺客反水/中伏/空信函）
- **结果**: "名士误国"的判词由结构自己说出，作者只补了一句

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写失败者/悲剧人物："想把他的失败写得让人唏嘘"
2. 写"人算不如天算"的荒诞感
3. 史实里有现成的"自信→翻车"弧线（当事人说过大话、做过必胜部署）

### 语言信号

- "反转""打脸""黑色幽默""造化弄人"
- "悲剧感""唏嘘""荒诞"
- "irony / twist / subversion"

### 与相邻 skill 的区分

- 与 `duruhui-question-engine`：设问管节奏，本 skill 管结构；可叠加（设问引出靶子）
- 与 `duruhui-tone-tracks`：打脸段若涉及死亡/殉国，黑色幽默自动关闭，转悲悯轨

## E — 可执行步骤 (Execution)

1. **确认弧线存在**：材料中必须有真实的"自信→失败"对照，没有就不硬造
   - 完成标准：能各引一条材料证据支撑"自信"与"失败"
   - 判停条件：当事人从未自信过（只是单纯的惨）——换 duruhui-psych-os 写悲情，不用反讽

2. **搭靶**：列出当事人视角的全部"有利条件"，用他的逻辑写足
   - 完成标准：读者读到这里"真心觉得他能成"

3. **亮锤**：用最短篇幅给出真实结局，不加评论或只加一句
   - 完成标准：打脸段≤搭靶段长度的 1/5

4. **补判词**：结尾给一句盖棺判词（可以是金句或引文）
   - 完成标准：判词克制，不解释笑话

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 胜利者叙事（官渡、淝水的赢家视角）——强行反转会变成"毒奶"尬梗
- 涉及大规模死难的失败（永嘉之乱）——悲悯轨接管，反讽禁用

### 作者在书中警告的失败模式
- 锤太重：打脸段加一堆评论，把落差笑点评释没了
- 靶太假：搭靶时夹带嘲讽，读者提前出戏——靶必须真诚

### 作者的盲点 / 时代局限
- 全知视角嘲讽当事人有"事后诸葛亮"的天然不公平，杜氏以"还原到当时当地"（p10）做平衡——用本结构时须在搭靶段真诚地还原其合理性

### 容易混淆的邻近方法论
- 欲抑先扬：老话新用，本结构多出"全知视角差"与"锤子要轻"两条操作纪律
