# 大纲规划法（事件顺序 + 弹药布点 + 钩子位置）

## R — 原文 (Reading)

> "打开地图，暂时不考虑司马睿是怎么在长江沿线站稳脚跟的，整个北方的局势只能用'抽象'两个字来形容。在北京、天津、唐山及幽州地区，有……"
>
> — 杜茹慧，两晋 16 期《我，匈奴人，但是要复兴大汉！》

---

## I — 方法论骨架 (Interpretation)

杜茹慧的每一篇都不是"想到哪写到哪"，而是三层规划先于写作：第一层是**编年骨架**——事件按什么顺序讲（通常严格编年，插叙必须挂"话说回来"收拢）；第二层是**弹药布点**——在骨架的每个节点上预分配修辞资源：这段放类比、那段放数据、这段留白给心理 OS；第三层是**钩子位置**——开场用什么起手式、中场在哪收拢、收尾用哪个栏目。"打开地图"段就是大纲的外化：先把全局态势一次性摆清，再逐格展开。写历史文最大的浪费是写完发现结构错了，大纲规划法把结构决策全部前置。

## A1 — 书中的应用 (Past Application)

### 案例 1: 16 期的北方混战（多线叙事的秩序）
- **问题**: 王弥、石勒、苟晞、刘渊四条线同时推进，极易写成一锅粥
- **方法论的使用**: 先"打开地图"固定全局坐标 → 按"王弥起家→苟晞发迹→石勒流亡→三人会师刘渊"收束为多线汇聚 → 每条线入口挂人物标签（飞豹/屠伯）
- **结论**: 多线叙事成立的前提是读者手里始终有地图
- **结果**: 全篇四条线不乱，结尾"第一次洛阳保卫战"完成收拢

### 案例 2: 33 期王敦之乱（时间戳倒计时）
- **问题**: 战役进程琐碎（七月初一/初三/十六/二十四），容易写成流水账
- **方法论的使用**: 编年骨架上标注节奏点——初一"叛军到"（压强）、初三"夜袭"（爽点）、二十四"决战"（高潮），每个时间点预布弹药
- **结果**: 流水账变成有压强曲线的战报

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户给了一段历史材料（任意朝代），说"帮我改成杜茹慧风格"——动笔前必须先走本 skill
2. 用户自己写历史文但"写着写着就散"，需要结构先行的工序
3. 用户要把长史料压缩成一期 10–20 分钟的口播脚本

## E — 可执行步骤 (Execution)

1. **列编年骨架**：把材料中的事件按时间顺序列成清单，每条一行（时间+事件+涉及人物）
   - 完成标准：清单能覆盖材料全部关键事件，无遗漏无乱序

2. **判定文体路由**：调用 `duruhui-genre-routing` 确定人物传/事件录/制度论
   - 完成标准：明确写出"本篇=X 类，因为主线是……"
   - 判停条件：若材料太薄不足以判断，先向用户确认"你想突出人、过程还是规律？"

3. **弹药布点**：在骨架每个节点旁标注弹药类型（类比/绰号/数据/心理OS/原文引用/留白）
   - 完成标准：每个节点至少一个弹药标记；同一类弹药不连续出现两次以上

4. **定钩子与收束**：选开场起手式（调用 `duruhui-hook-openers`）、标出"话说回来"收拢点、选收尾栏目（调用 `duruhui-ending-serials`）
   - 完成标准：大纲首尾完整，中段每 3–5 段有一个收拢点

5. **输出大纲供确认**：把规划后的大纲展示给用户，确认后再动笔
   - 完成标准：用户确认或提出修改

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 用户只要一段赏析/评论，不要完整文章——直接写，别规划
- 纯学术写作（论文、考证）——本大纲是叙事大纲，不是论证大纲

### 作者在书中警告的失败模式
- 广告打断叙事流（ce07）：大纲中绝不预留"广告位"，叙事节奏点只填内容
- 平铺直叙（ce04）：如果大纲全程无设问点、无反讽点，打回步骤 3 重布弹药

### 作者的盲点 / 时代局限
- 默认听众熟知三国典故；若目标读者不熟三国，大纲阶段的类比库需换参照系

### 容易混淆的邻近方法论
- 学校作文的"总-分-总"提纲：本法多出"弹药布点"与"栏目化收尾"两个维度
