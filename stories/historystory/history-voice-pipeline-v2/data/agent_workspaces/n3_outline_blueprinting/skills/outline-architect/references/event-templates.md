# 事件篇大纲模板 v3.1

> 核心范式：**事件发展弧线驱动**。不是过程流水账，是事件从"充满希望"到"彻底崩塌"（或"意外逆转"）的势的起伏。
> 杜茹慧代表作参考：淝水之战（35分钟重点讲述）。

---

## 一、命运弧线定义

事件篇的"命运弧线"不是人的命运，是**事件的"势"**——战前格局、战前误判、决战时刻、战后崩溃、余波影响。

### 标准五段式

| 阶段 | 事件标签 | 情感坐标 | 叙事功能 |
|------|---------|---------|---------|
| 1 | 战前格局 | 高位·有希望 | 钩子：建立"这件事本来可以……"的期待 |
| 2 | 战前误判/蓄力 | 蓄力·紧张 | 铺垫：决策逻辑、双方博弈 |
| 3 | 决战时刻 | 峰顶·窒息 | 炸点：最核心的冲突瞬间 |
| 4 | 战后崩溃/逆转 | 坠落·荒诞 | 转折：结果与预期的巨大落差 |
| 5 | 余波/影响 | 谷底·苍凉 | 动情点：大势已去、历史改写 |
| 6 | （留白） | 留白·余味 | 收束：不总结，让数字自己说话 |

### 弧线纪律

1. **必须有一组反差量化**。兵力、疆域、时间、人口——至少一组有完整史料支撑的数字对比。
2. **人物全部功能化**。苻坚是"决策者"，谢玄是"对手"，不需要完整人物小传。
3. **悬念不在"谁赢了"，而在"怎么从有希望到灭亡的"**。结局观众往往早知道，悬念藏在过程与因果里。

---

## 二、钩子选型

事件篇唯一推荐钩子：**诊断结论前置**。

**定义**：先把事件的"总评"砸在观众脸上，再回头讲过程。

**公式**：
> "很难想象，一个______的局势/国家/联盟，因为______，最终______。"

**示例（淝水之战）**：
> "很难想象，一个曾经一度有希望带领中国走出乱世的国家，居然会在一场战争失利后不到两年就走向国破家亡。"

**纪律**：
- 诊断结论必须包含**时间反差**（"不到两年"）或**数字反差**（"87万对8万"）
- 诊断结论后必须立刻**回头讲战前格局**，不能空泛抒情

---

## 三、温度与声口

### 温度

事件篇默认温度：**温→冷**（理性剖析→苍凉收束）。

- **温**（理性）：战前格局、决策分析、沙盘推演阶段
- **冷**（苍凉）：战后崩溃、余波影响阶段
- **热**（激昂）：极少数例外，适用于以少胜多的热血瞬间（但热后必须立刻转冷，防止煽情）

**纪律**：温度切换必须有明确节点，通常在"决战时刻"后从温转冷。

### 声口样句

事件篇声口特征：
- **算账式**："咱们算一下，87万对8万，十比一。但有时候，数字是骗人的。"
- **推演式**："如果苻坚当时没有……，历史会不会……？但历史没有如果。"
- **透明化**："关于这个数字，我查了三本书，说法不一样……"

**标杆样句**：
> "咱们算一下，87万对8万，十比一。但有时候，数字是骗人的。"
> "关于淝水之战的兵力，我查了三本书：《晋书》说87万，《资治通鉴》说60万，现代学者估计实际参战可能不到30万。咱们按最保守的数字算，也是五比一。但五比一，输了。"

### 外号锚点

事件篇外号较少，但**核心决策者**可以有：

- 外号必须贴合**决策风格**（如苻坚"胡人儒学大师"——突出"文化理想vs军事冒进"的反差）
- 外号只在分析决策逻辑时使用，决战时刻回归正式称谓
- 事件篇外号是**功能性**的，不是情感锚点

---

## 四、焊接工艺（嘴+骨协作）

事件篇的焊接三步法有特殊纪律：

1. **现代类比**：必须贴合**决策逻辑**或**博弈结构**
   - 例：苻坚的冒进类比"All in的赌徒"
   - 例：东晋的抵抗类比"小公司对抗巨头"
2. **史料原文**：必须包含**具体数字或原文**，支撑反差量化
   - 例："坚发长安，戎卒六十余万，骑二十七万"（《资治通鉴》）
3. **自嘲/共情收尾**：必须回到"咱们现代人也会犯同样的错"
   - 例："咱们现在看苻坚觉得可笑，但换到他的位置，你能保证不膨胀吗？"

---

## 五、动情点纪律

事件篇动情点是**大势已去的荒诞感**，不是个人悲剧：

- **先落数字，后落情**：先摆反差量化（87万→0，两年→亡国），再让观众自己品荒诞
- **禁止"如果当时"**：历史没有如果，动情点不是假设，是"事实本身的残酷"
- **必须留白**：战后崩溃段后接沉默/地图空镜/时间流逝画面
- **情从反差里长出来**：不是旁白煽出来的，是数字自己说话的

## 六、完整示例：《淝水之战》

```markdown
# 《淝水之战》事件篇大纲

## 0. 魂（情感定位）
- **情绪目标**：让观众感受到"权力游戏的荒诞——数字越大，输得越惨"
- **一句话主题**：一个拥有87万大军、统一北方的前秦帝国，因为一场8万人的战役，两年内土崩瓦解
- **钩子选型**：诊断结论前置
- **钩子那一帧**："很难想象，一个曾经一度有希望带领中国走出乱世的国家，居然会在一场战争失利后不到两年就走向国破家亡。"

## 1. 骨（命运弧线 = 事件"势"的起伏）

| 段号 | 事件阶段 | 情感坐标 | 功能 | 节点分级 | 史料卡 | 反差量化 |
|------|---------|---------|------|---------|--------|---------|
| 1 | 战前巅峰 | 高位·有希望 | 钩子 | 强化节点 | 前秦统一北方 | 疆域/兵力 |
| 2 | 战前误判 | 蓄力·紧张 | 铺垫 | 关键节点 | 苻坚决策、群臣反对 | 决策逻辑 |
| 3 | 决战时刻 | 峰顶·窒息 | 炸点 | 强化节点 | 淝水对峙、朱序喊退 | 兵力对比 |
| 4 | 战后崩溃 | 坠落·荒诞 | 转折 | 强化节点 | 前秦瓦解、慕容垂反 | 时间跨度 |
| 5 | 余波 | 谷底·苍凉 | 动情点 | 关键节点 | 北方再分裂 | 后续影响 |
| 6 | （留白） | 留白·余味 | 收束 | 过渡节点 | 淝水今貌 | 无 |

## 2. 肉（共情节点·焊接清单）

- **节点1（战前巅峰）**：反差量化——"咱们算一下，前秦统一了北方，疆域从辽东到西域，人口两千万。这是自西晋以来最接近统一的时刻。"
- **节点2（战前误判）**：现代类比——"苻坚就像一个All in的赌徒，手里攥着87万筹码，觉得稳赢。但赌徒最大的敌人不是对手，是自己。"
- **节点3（决战时刻）**：查证透明化——"关于兵力，我查了三本书……咱们按最保守的算，也是五比一。但五比一，输了。"
- **节点4（战后崩溃）**：动情点克制——只摆事实（383年12月战败→384年慕容垂反→385年苻坚被杀→386年前秦亡），旁白不说"可惜"，让观众自己算这两年

## 3. 衣（风格与声口）

- **本期风格**：牌桌复盘（冷静、算计、偶尔一声叹息）
- **温度**：温→冷（战前温、战后冷）
- **声口样句**："咱们算一下，87万对8万，十比一。但有时候，数字是骗人的。"
- **外号锚点**：苻坚→"胡人儒学大师"（贴合"文化理想vs军事冒进"的决策反差）

## 4. 签发清单

- [x] 情感定位明确（权力游戏的荒诞）
- [x] 命运弧线完整（6 阶段）
- [x] 温度切换有明确节点（决战后从温转冷）
- [x] 声口样句已标注
- [x] 外号锚点已标注（贴合决策风格）
- [x] 反差量化至少一组（87万vs8万，两年亡国）
- [x] 每个炸点挂史料卡出处
- [x] 动情点至少1处（节点5，大势已去）
- [x] 动情点有克制纪律（先数字后情绪，无"如果当时"）
- [x] 查证透明化标注（节点3，兵力争议）
- [x] 结尾无余味、无总结、无价值判断
- [x] 无AI腔词汇
- [x] 第一人称克制
```

## 七、事件篇特有签发项

| 签发项 | 标准 | 不通过后果 |
|--------|------|-----------|
| 反差量化至少一组 | 兵力/疆域/时间/人口，有史料支撑 | 大纲退回，补充数字 |
| 人物全部功能化 | 不展开完整人物小传 | 大纲退回，拆分人物篇 |
| 悬念在过程不在结果 | 观众已知结局，悬念是"怎么输的" | 大纲退回，重设钩子 |
| 动情点从反差长出来 | 先数字后情绪，禁止"如果当时" | 写作层退回修改 |
| 温度切换有节点 | 温→冷有明确段落标记 | 写作层退回修改 |
