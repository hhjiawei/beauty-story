# 人物篇大纲模板 v3.1

> 核心范式：**个人命运弧线驱动**。不是时间线堆砌，是一个人从"起点"到"终点"的情感降维。
> 杜茹慧代表作参考：慕容垂、妇好、苻坚。

---

## 一、命运弧线定义

人物篇的"命运弧线"不是时间线，是**情感转折的里程碑**。每个阶段必须对应一个情感坐标，阶段之间是因果关系（上阶段的果是下阶段的因）。

### 标准五段式（可压缩为4段或扩展为6段）

| 阶段 | 命运标签 | 情感坐标 | 叙事功能 |
|------|---------|---------|---------|
| 1 | 起点/少年 | 高位起跳·明亮 | 钩子：建立"这个人本来可以……"的期待 |
| 2 | 转折/中年 | 回落蓄力·压抑 | 铺垫：命运第一次打击，积蓄张力 |
| 3 | 挣扎/老年 | 二次起跳·悲壮 | 高潮前奏：不服输，但时代/身体/局势已变 |
| 4 | 崩塌/终局 | 峰顶坠落·剧痛 | 炸点：最核心的悲剧时刻 |
| 5 | 余波/死亡 | 谷底·苍凉 | 动情点：英雄迟暮、命运唏嘘 |
| 6 | （留白） | 留白·余味 | 收束：不总结，让事实自己落地 |

### 弧线纪律

1. **全片只讲一个人**。其他人物全部功能化（"某位大臣""他的对手"），不展开完整小传。
2. **阶段之间必须有因果链**。不是"然后……然后……"，是"因为A，所以B"。
3. **情感坐标必须可感知**。写作层拿到后，知道这段该用什么语气、什么节奏。

---

## 二、钩子选型

人物篇唯一推荐钩子：**诊断结论前置**。

**定义**：先把人物一生的"总评"砸在观众脸上，再回头讲"怎么走到这一步的"。

**公式**：
> "很难想象，一个______的人，最终______。"

**示例（慕容垂）**：
> "慕容垂13岁开始打仗，打到70岁。咱们算一下，57年，半个多世纪。一个人有多少个57年？他这辈子只干了一件事——打仗。但打完仗，他发现没地方可去了。"

**纪律**：
- 诊断结论必须包含**反差**（辉煌vs苍凉、能力vs结局）
- 诊断结论里可以埋**外号锚点**（如"周家老四"）
- 诊断结论后必须立刻**回头讲起点**，不能空泛抒情

## 三、温度与声口

### 温度

根据人物命运内核，从以下三种温度中选择：

| 温度 | 适用人物 | 命运内核 | 声口样句示例 |
|------|---------|---------|-------------|
| **冷** | 悲剧英雄、末代人物、被时代碾压者 | 孤独死去、壮志未酬、一生替别人守着 | "史料没写他有没有后悔过。所以，我也不猜。" |
| **热** | 传奇突破者、励志人物、碾压时代者 | 打破天花板、成就传奇、人定胜天 | "为了心中认定的事，要不断努力、坚持下去。" |
| **温** | 争议人物、复杂政治家、功过参半者 | 与时代博弈、棋逢对手、理想主义崩塌 | "咱们算一下，87万对8万，十比一。但有时候，数字是骗人的。" |

**选择纪律**：
1. 先看结局：悲剧→冷，励志→热，复杂→温
2. 再看人物与时代关系：被碾压→冷，碾压时代→热，博弈→温
3. 最后看史料密度：稀疏→偏冷，丰富→可温可热
4. 一旦选定，全篇统一，禁止段落间温度跳跃

### 声口样句

人物篇声口特征：
- **克制**：不咆哮、不煽情、不替古人洒泪
- **留白**："史料没写，我不猜"
- **换算**：把古代数字翻译成现代体感
- **自嘲**：先拿自己/现代人开涮，再点评古人

**标杆样句**：
> "史料没写他有没有后悔过。"
> "咱们总说职场35岁危机，他65岁才创业成功，但老天爷好像特别公平——给你什么，就一定会在别处拿走什么。"

### 外号锚点

- 外号必须贴合**命运内核**（如"周家老四"贴合"排行第四、与王位无缘"）
- 外号是**宠溺式调侃**，不是侮辱（禁止"废物""蠢货"）
- 外号一旦设定，全篇统一，骨维度用正式称谓
- 可以没有外号（如慕容垂），但不能为了起外号而起外号

## 四、焊接工艺（嘴+骨协作）

人物篇的焊接三步法有特殊纪律：

1. **现代类比**：必须贴合人物**命运阶段**（不是随便类比）
   - 例："未就国的封君"类比"65岁被裁员创业"
2. **史料原文**：必须包含**具体数字或原文**，不能笼统引用
   - 例："周公不就封，留佐武王"（《史记·鲁周公世家》）
3. **自嘲/共情收尾**：必须回到"咱们现代人也没好到哪儿去"
   - 例："咱们总说职场35岁危机……"

---

## 五、动情点纪律

人物篇动情点是**全片灵魂**，必须存在，但必须克制：

- **先落事实，后落情**：只摆事实（13岁出征→70岁复国→死在回师路上），旁白不说"英雄迟暮"
- **禁止总结句**：动情点后禁止"他的一生告诉我们……"
- **必须留白**：动情点后接沉默/停顿/画面空镜，不立刻接下一个信息点
- **情从史实里长出来**：不是旁白煽出来的，是观众自己品出来的

## 六、完整示例：《周公旦·辅弼与开国》

```markdown
# 《周公旦·辅弼与开国》人物篇大纲

## 0. 魂（情感定位）
- **情绪目标**：让观众感受到"一个一辈子替别人守着的人，最终没给自己留退路"的苍凉
- **一句话主题**：一个排行第四、本该去封地安度余生的王子，替哥哥守祭祀、替侄子守天下，一辈子没走出镐京
- **钩子选型**：诊断结论前置
- **钩子那一帧**："很难想象，一个排行第四、本该在封地安度余生的王子，会在哥哥死后，把自己锁进一个金属柜子的秘密里，然后接过整个天下。"

## 1. 骨（命运弧线 = 个人情感阶段）

| 段号 | 命运阶段 | 情感坐标 | 功能 | 节点分级 | 史料卡 |
|------|---------|---------|------|---------|--------|
| 1 | 周家老四 | 高位起跳·明亮 | 钩子 | 强化节点 | 文王第四子、采邑受封 |
| 2 | 牧野的祭司 | 平稳·神秘 | 铺垫 | 关键节点 | 牧野之战、执掌祭祀 |
| 3 | 未就国的封君 | 回落蓄力·遗憾 | 转折 | 强化节点 | 封鲁留朝、伯禽就封 |
| 4 | 金縢里的秘密 | 峰顶·紧张 | 炸点 | 强化节点 | 金縢之祝、武王病逝 |
| 5 | 踏上前阶的人 | 谷底·沉重 | 动情点 | 关键节点 | 摄政、管叔之乱伏笔 |
| 6 | （留白） | 留白·苍凉 | 收束 | 过渡节点 | 史料未载其悔 |

## 2. 肉（共情节点·焊接清单）

- **节点1（周家老四）**：外号锚定"周家老四"（贴合排行第四、与王位无缘的命运内核）
- **节点3（未就国的封君）**：现代类比"65岁被裁员带着老同事创业" → 史料原文"周公不就封，留佐武王" → 自嘲收尾"咱们总说职场35岁危机，他65岁才创业成功"
- **节点4（金縢里的秘密）**：查证透明化——列出"至诚代死说/政治表演说/战国伪作说/清华简改写说"，倾向"最稳妥说法"，不独断
- **节点5（踏上前阶的人）**：动情点克制——只摆事实（13岁出征→70岁复国→死在回师路上），旁白不说"英雄迟暮"，让观众自己品

## 3. 衣（风格与声口）

- **本期风格**：深秋档案室（白炽灯、翻纸声、低声陈述）
- **温度**：冷（悲悯、苍凉）
- **声口样句**："史料没写他有没有后悔过。所以，我也不猜。"
- **外号锚点**：周公→"周家老四"（宠溺式调侃，非侮辱）；伯禽→"替父赴任的长子"（功能性称谓）

## 4. 签发清单

- [x] 情感定位明确（替别人守着的人，没给自己留退路）
- [x] 命运弧线完整（6 阶段，含留白收束）
- [x] 温度统一（冷，全篇悲悯苍凉）
- [x] 声口样句已标注
- [x] 外号锚点已标注（贴合命运内核）
- [x] 每个炸点挂史料卡出处（金縢之祝→《尚书·金縢》《史记·鲁周公世家》）
- [x] 动情点至少1处（节点5，踏上前阶）
- [x] 动情点有克制纪律（先事实后情绪，无总结句，留白）
- [x] 查证透明化标注（节点4，四版本争议）
- [x] 结尾无余味、无总结、无价值判断
- [x] 无AI腔词汇
- [x] 第一人称克制（能用"咱们"不用"我"）
```

## 七、人物篇特有签发项

| 签发项 | 标准 | 不通过后果 |
|--------|------|-----------|
| 全片只讲一人 | 其他人物功能化，不展开小传 | 大纲退回，拆分多人物 |
| 命运弧线有因果链 | 阶段之间是"因为……所以……" | 大纲退回，重排逻辑 |
| 外号贴合命运内核 | 外号不是随便起的绰号 | 大纲退回，重设外号 |
| 动情点后留白 | 动情点后不立刻接信息点 | 写作层退回修改 |
| 结尾无总结 | 禁止"他的一生告诉我们" | 写作层退回修改 |
