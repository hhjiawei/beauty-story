# 大纲文件 Schema

> 本文件为 SKILL.md 的参考文档，按需加载。包含大纲文件的字段定义、软硬约束分级、JSON 示例。

---

## 字段定义

| 字段 | 软硬 | 说明 |
|------|------|------|
| 段号 | 硬 | 顺序编号 |
| 时间码 | 软 | 预计起止（如 00:00–00:30） |
| 功能类型 | 硬 | 钩子／锚定／主线节点／插件／高潮／收尾／衔接 |
| 章节标题 | 硬 | **观众可见的导航标题**——同章节内各段填同一标题；工整短题是底线不是目标，允许一章内出现一个悬念式章题（参照弹药库第 8 号标题句逻辑：看完才懂，但正片必须兑现） |
| 使用史料卡 | 硬 | 事件卡编号（可多张） |
| 指定技法 | 软 | 主技法＋备选技法（各一）。写作层可在两者间切换，交稿备注声明 |
| 炸点 | 硬 | 类型＋位置＋**史料卡出处**（无卡不许标炸点） |
| 动情点 | 硬 | 有／无＋位置（全片至少一处） |
| 伏笔 | 硬 | 埋设／回收／无（联动登记表） |
| 情绪坐标 | 软 | 在波形图上的位置（谷底／爬升／峰顶等） |
| 预计字数 | 硬 | 按语速换算基准值；**容差按功能类型分级：钩子／收尾 ±40%，主线节点／插件 ±20%，过渡段不设下限只设上限** |
| 备注 | — | 给写作层的特殊指令 |

---
