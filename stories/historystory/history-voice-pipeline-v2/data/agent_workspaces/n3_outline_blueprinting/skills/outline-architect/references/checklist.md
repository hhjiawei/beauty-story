# 签发清单（Step 8，举证式，全绿才进主题否决关）

> 本文件为 SKILL.md 的参考文档，按需加载。大纲层 Step 8 自检清单，v3 新增举证式签发。

---

## 自检项

- [ ] **一句话主题**说得出口，且**过了主题自检三问**（v3 新增）
- [ ] **Step 0 已执行**：有认知反差则登记为反常切片；无则明确标注"本集无认知入口，不强行"
- [ ] **开场钩子选型明确**（反常切片／反差量化／名场面前置／颠覆细节，其一），3秒有钩子，30秒内有锚定
- [ ] **若使用反差量化**：战争题材＋数字有史料出处，**双前提齐全**
- [ ] **节点分级完成**，详略比合理（转折节点成戏，过渡节点一句话）
- [ ] **每 60 秒有一个信息增量或情绪增量**（成戏段的情绪推进算增量，判定对照情绪波形字段）（v3 修订：纯信息流标准会系统性驱逐成戏段）
- [ ] **炸点数量在时长换算区间内**（10分钟3-4个，20-30分钟7-10个），**且每个炸点均挂史料卡出处——无卡炸点一票退回**（v3 修订：密度是上限参照不是 KPI，出处才是门槛）
- [ ] **相邻炸点不同型**（语言／结构／情绪轮换），情绪层炸点 ≥1 个
- [ ] **情绪波形有峰有谷**，无长段平坦
- [ ] **动情点至少一处**，标在段上（无则退回）
- [ ] **伏笔登记表填满**：凡埋必收，开放的标明"交陪审团"
- [ ] **插件数量在纪律内**（引文3~5处，悬案1~2个，历史对照组≤1处）
- [ ] **每段指定技法为"主＋备选"选型制**（只给主技法需备注理由）
- [ ] **章节标题齐全**：每章一个短题，观众可直接当导航用；全片至少一章尝试了悬念式章题（无合适题材则不强行）
- [ ] **结尾有落点＋金句位**
- [ ] **每段都挂了史料卡**，无史料支撑的段不允许存在
- [ ] **签发方式为举证式**：每项给出"过／不过＋在大纲中的具体位置"，不接受空打勾（v3 新增）
