## 一、缺口诊断清单（缺什么决定查什么）

拆完主干事件卡后，对照此表逐项过一遍，命中即补卡：

| 诊断问题 | 若答"否" | 补卡动作 |
|---|---|---|
| 主角出场时观众知道他什么性格吗？ | 人物只是名字 | 拆人物卡 P-：核心特质+绰号素材 |
| 关键对手有"对手的样子"吗？ | 反派扁平 | 拆人物卡 P- |
| 谁和谁一伙、谁防着谁，三句话说得清吗？ | 博弈靠现编 | 拆关系卡 R-：张力点 |
| 不懂某制度/地理，事件动机还成立吗？ | 门槛卡住观众 | 拆背景卡 B- |
| 篇中每个宏大判断后面有数字托底吗？ | 判断悬空 | 拆数据卡 D- |
| 有没有至少一条"原文比白话更精彩"的引文？ | 缺古文炸点 | 回史料找原文，补进事件卡古文原句 |
| 歇后语/相似事件/冷知识有候选吗？ | 彩蛋位空转 | 拆彩蛋卡 E-（没有就空着，不硬凑） |
| 事件链有因果断档或时间空白吗？ | 跳跃处观众会出戏 | 补事件卡 C-，或在备注标注断档提醒大纲处理 |

## 二、搜索查询公式

**基础公式**：`专名 + 事件/主题 + 典籍名或"原文"`

按缺口类型的查询变体：

| 缺口 | 查询模板 | 示例 |
|---|---|---|
| 史实核实 | `人物 + 事件 + 典籍名` | `卫瓘 此座可惜 晋书` |
| 原文定位 | `原文片段关键词 + 典籍名` | `"此座可惜" 晋书 卫瓘传` |
| 纪年换算 | `年号 + X年 + 公元` | `咸宁二年 公元` |
| 制度背景 | `制度名 + 沿革/研究` | `九品中正制 沿革` |
| 数据考证 | `主题 + 数字 + 考证/研究` | `西晋 人口 考证` |
| 人物小传 | `人物名 + 生平/传` | `司马攸 生平 晋书` |
| 相似案例 | `母题 + 朝代` | `权臣 废立皇帝 案例` |
| 歇后语 | `人物/事件 + 歇后语/典故` | `司马昭 歇后语` |

**搜索纪律**：
- 先典籍后网络：能查正史原文的不引用二手转述；
- 一次缺口多查几个角度，别一条查询定终身；
- 转引的"段子级古文"（如名言截图、营销号引文）先怀疑、找到原始出处再使用。

## 三、来源优先级与古籍数据库

| 优先级 | 来源 | 用途 |
|---|---|---|
| 1 | 正史原文：二十四史、《资治通鉴》（中国哲学书电子化计划 ctext.org、维基文库可查原文） | 事件卡、古文原句 |
| 2 | 学术机构/博物馆/考古报告（社科院、高校、各级博物院官网） | 出土文献、数据卡 |
| 3 | 权威媒体、纪录片文本 | 背景补充（降为诸子级使用） |
| 4 | 百科（维基/百度百科） | **仅作线索**，不作入库依据 |

## 四、多源互证规程

1. **关键事实双源**：时间、数字、死因、胜负四类关键事实，力争两个独立来源；只有一源的标"存疑"。
2. **冲突处理**：来源打架时不调和——各版本分别成卡，备注互见卡号（纪律 3.5）。
3. **反常点上报**：与常识或他源矛盾的地方，在事件卡备注写明反常点及现有证据，提醒大纲节点组证据链、挂声明等级。
4. **考古修正**：出土文献与传世文献冲突时，出土文献优先，但仍两说并存。

## 五、定级决策树

```
材料到手
 ├─ 出自二十四史/《资治通鉴》等官修史书？        → 正史
 ├─ 出自甲骨文/金文/简牍/碑刻/考古报告？         → 出土文献
 ├─ 出自诸子百家/笔记小说/文人著述/现代权威转述？ → 诸子
 └─ 出自演义/民间传说/无出处的轶闻？             → 传说（限位使用）
```

定不了级的，降一级处理（宁可低估不可高估）。

## 六、丰富化套路：从事件向外扩三层

事件卡拆完后，按三个圈层主动补料，让卡包立体：

1. **当事人层**：这个事件之前，主角刚经历了什么？（→ 人物卡/补事件卡）
2. **时代层**：同时期天下在发生什么？有没有大趋势当背景？（→ 背景卡/数据卡）
3. **后世层**：这件事后来被怎么评价、怎么演绎？有没有名家判词？（→ 彩蛋卡/名家评语补进史料出处）

每层补 1–3 张即可，目的是给大纲节点留"镜头拉开"的素材，不是写通史。

## 七、常见陷阱

- **百科依赖症**：整段引用百科当出处——百科只能给线索，必须回溯原始出处；
- **伪古文**：网络流传"名人名言"多为伪造，查不到典籍出处的一律按传说级处理或弃用；
- **数字幻觉**：人口、兵力类数字历代注水严重，必须标朝代口径（在籍/实际/号称），并在备注说明；
- **现代概念走私**：把现代民族、国家、阶级概念直接安到古人头上——背景卡写"当时的框架"，对照点放"现代对照点"字段，两层不混；
- **搜索过深**：单缺口搜索控制在能定级为止，不为了一张彩蛋卡挖两小时——彩蛋空着是合法交付。
