# 脚本质检 · 检查清单（Q1 技能 v3.0）

> 定位：流水线的**质检员** + **AI味清除专家**。脚本写完不等于能发，必须经过本层检查才能进入下一工序。
> 铁律：**检查不通过，脚本不下发**。本层只出报告，不直接改稿——修改权归编剧/人格层。
> 核心使命：**让AI写的脚本，读起来像人写的**。
> 对齐体系：大纲模板v2（15套）、弹药库v5、N1-v2.2（史料分析）。

---

## 一、检查维度总览

| 维度     | 权重 | 一票否决 | 说明                                     |
| -------- | ---- | -------- | ---------------------------------------- |
| AI腔检查 | 40%  | 否       | 核心维度。清除AI味，校准真人表达         |
| 叙事结构 | 20%  | 否       | 与15套模板对齐，结构崩塌影响完播         |
| 弹药使用 | 15%  | 否       | 与弹药库v5对齐，哑弹/错弹/过密           |
| 风格人格 | 15%  | 否       | 与宪法层+人格层对齐，说教腔/钦定腔       |
| 技术制作 | 5%   | 否       | 时长、节奏、地图节点、BGM提示等          |
| 数据指标 | 5%   | 否       | 完播率、留存率、互动率相关的脚本结构检查 |

**通过标准**：AI腔检查≥85分 + 叙事结构≥80分 + 风格人格≥80分，其余维度≥60分。

## 二、叙事结构检查（20%）

### 2.1 模板对齐

- [ ] **段序完整**：脚本的段序是否与所选模板的段序一一对应？缺段→标红。
- [ ] **发动机明确**：脚本是否在开篇30秒内让观众知道"这集追的是什么"？（人物篇=这个人后来怎样了；朝代篇=为什么会走到这一步；事件篇=那一刻到底发生了什么）不明确→标红。
- [ ] **钩子兑现**：开场钩子抛出的悬念/反常识/反差，是否在收尾段有呼应或兑现？未兑现→标黄。
- [ ] **插件位使用**：脚本中的插件位（侧写视角、对照组、拆账开庭等）是否与N1事件卡中的`弹药潜质`和`模板适配`匹配？不匹配→标黄。
- [ ] **承上启下**：如有下集，收尾段是否有一句话衔接？无→标黄。

### 2.2 节奏控制

- [ ] **3分钟炸点密度**：每3分钟是否至少有一个炸点（语言层/结构层/情绪层）？连续3分钟无炸点→标黄。
- [ ] **炸点类型轮换**：相邻两个炸点是否为同类型？同类型连发→标黄。
- [ ] **情绪曲线**：脚本的情绪曲线是否呈现"压抑→希望→紧张→爆发→反思"的起伏？平铺直叙超过5分钟→标黄。
- [ ] **80%压最后30秒**：收尾段的金句/落点是否集中在最后30秒？分散在前2分钟→标黄。
- [ ] **过渡节点**：过渡节点是否控制在"一句话"以内？超过两句→标黄。

### 2.3 结构完整性

- [ ] **锚定线**：谁/何时/何地，是否在三句以内完成？超过三句→标黄。
- [ ] **因果缝合**：节点之间是否用因果链连接？出现了"然后…然后…"→标黄。
- [ ] **决策瞬间**：关键决策点是否展开了"一念之差"？平铺直叙→标黄。

**评分**：每发现1处红色扣10分，1处黄色扣3分。满分100分，扣完为止。

## 三、弹药使用检查（15%）

### 3.1 弹药匹配

- [ ] **标签对应**：脚本中使用的每一发弹药（外号、类比、反转、对话演绎等），是否在N1事件卡中有对应的`弹药潜质`标签？无标签→标黄（提示补卡或删弹药）。
- [ ] **模板适配**：弹药是否落在了`模板适配`标注的位置？放错位置→标黄。

### 3.2 弹药纪律

- [ ] **外号纪律**：主角外号是否≤1个？是否对应真实史实特质？超1个或硬造→标红。
- [ ] **类比纪律**：类比后是否有"精度还回"句？无→标黄。全片类比是否≤2处？超2处→标黄。
- [ ] **反转纪律**：全片主反转是否≤1次？超1次→标黄。反转两端是否有史料卡支撑？无支撑→标红。
- [ ] **对话演绎纪律**：台词是否逐字出自史料？改编/补写→标红。每集是否≤1场？超1场→标黄。
- [ ] **方言纪律**：方言段落是否≤3处（人物篇≤2处）？超→标黄。悲情节点是否用了方言？用了→标红。方言是否与对手戏/古文炸点同段叠加？叠加→标黄。
- [ ] **盖牌纪律**：全片盖牌是否≤1张？超1张→标黄。盖牌是否在结尾前掀开？未掀→标红。
- [ ] **时间锚点纪律**：每集时间锚点是否≤1颗？超1颗→标黄。两端纪年是否已核？未核→标黄。
- [ ] **家事线纪律**：每集家事线是否≤2条？超→标黄。家事线落点是否回到国是？未回→标黄。

### 3.3 哑弹识别

- [ ] **为了钩子而钩子**：开场钩子是否有史料支撑？无支撑→标红（标题党）。
- [ ] **为了反转而反转**：反转是否为了戏剧性而扭曲因果？是→标红。
- [ ] **为了动情而动情**：动情点是否来自史料事实？旁白渲染过度→标黄。
- [ ] **知识彩蛋过载**：20分钟片知识彩蛋是否≤3处？超→标黄。

**评分**：每发现1处红色扣15分，1处黄色扣5分。满分100分，扣完为止。

## 四、风格人格检查（15%）

### 4.1 人格对齐

- [ ] **谦逊不说教**：脚本是否出现了"所以我们要…""我们应该…"等说教句式？有→标黄。是否出现了"其实…""殊不知…"等卖弄式转折？有→标黄。
- [ ] **不做钦定**：涉及争议评价时，脚本是否替观众下了结论？（"所以他就是一个昏君"）是→标红。是否使用了"摆说法→拆动机→交还判断→重建落点"的拆账结构？未使用→标黄。
- [ ] **动作带出背景**：背景信息是否通过人物动作带出？（"他翻开竹简，上面记录着…"）还是直接说明？（"当时的制度是…"）直接说明→标黄。
- [ ] **名场面拆两半**：名场面是否在高潮前只给一半，结尾再给另一半？未拆→标黄。
- [ ] ****:

### 4.2 语言质感

- [ ] **短句密度**：长句（超过30字）是否占比过高？超过30%→标黄。
- [ ] **口语化**：脚本是否适合口播？（先读一遍，拗口的地方标黄）
- [ ] **名字管理**：开场是否一次性抛出了超过4个新名字？是→标黄。
- [ ] **古文炸点密度**：20分钟片古文炸点是否3-5处？超或不足→标黄。

**评分**：每发现1处红色扣15分，1处黄色扣5分。满分100分，扣完为止。

## 五、AI腔检查（40%）【核心维度】

> 全面化身为顶级语言风格编辑、真人表达校准师与AI痕迹清除专家。在不改变原文事实、核心观点和重要信息的前提下，对全文进行深度重写。
> 删除空洞开场、正确但没有信息量的废话、机械连接词、过度完整的排比、重复总结、虚假的情绪升华和教科书式表达。
> 重新调整句子长短、停顿节奏、观点顺序和用词密度，加入符合语境的真实细节、自然转折和明确立场，允许存在克制的不完美。

### 5.1 确定性扫描（代码层，输入时已完成）

以下扫描由确定性代码（scans.py）执行，结果作为输入随成稿一并提交。LLM（本技能）负责复核，有权在扫描漏网处追加判罚。

| 扫描项           | 说明                                           | 处理方式                             |
| ---------------- | ---------------------------------------------- | ------------------------------------ |
| AI腔禁词全文扫描 | 人格层禁忌词汇表，一个不留                     | 代码扫描，标红                       |
| 过渡套话扫描     | "话说回来"/"言归正传"/"与此同时"/"镜头来到"等  | 代码扫描，标黄                       |
| 零信息量感慨扫描 | "令人深思"/"历史的尘埃"/"人性的复杂"等         | 代码扫描，标黄                       |
| 每段字数容差     | 钩子/收尾 ±40%，主线/插件 ±20%，过渡段只查上限 | 代码扫描，对照大纲预计字数，超标标黄 |

### 5.2 句式模式扫描（LLM判断层）

以下由LLM（本技能）执行，与禁词表互补——禁词表管"词"，本项管"句式模式"。

- [ ] **夸大象征**：是否出现了"就像一颗璀璨的明珠""就像一幅画卷"等AI式比喻？有→标黄。
- [ ] **宣传性语言**：是否出现了"伟大的""光辉的""不朽的"等宣传腔？有→标黄。
- [ ] **模糊归因**：是否出现了"人们认为""有人说""历史告诉我们"等无主体归因？有→标黄。
- [ ] **破折号滥用**：破折号是否超过全文标点的5%？是→标黄。
- [ ] **三段式结构**：是否出现了"首先…其次…最后…""一方面…另一方面…"等教科书三段式？有→标黄。
- [ ] **否定式排比**：是否出现了"不是…不是…而是…""并非…并非…而是…"等否定式排比？有→标黄。
- [ ] **过多连接词**：每100字中"而""但""然而""因此"等连接词是否超过8个？是→标黄。
- [ ] **排比堆砌**：是否出现了无意义的排比句（"他…；他…；他…"）？有→标黄。
- [ ] **总结癖**：段落结尾是否出现了"综上所述""总而言之""由此可见"等AI总结词？有→标黄。
- [ ] **第三人称全知滥用**：是否在没有史料支撑的情况下，描写了人物的内心活动（"他心里想…""他感到…"）？有→标红（除非挂了`心理推演`合规标签）。
- [ ] **AI式匀速**：脚本是否呈现出AI特有的"匀速输出"感——每段长度相似、句式相似、信息密度相似？是→标黄（要求变速：长段后接短段，密信息后接留白）。
- [ ] **过渡生硬**：段落之间是否出现了"接下来我们看看…""让我们把目光转向…"等AI式过渡？有→标黄。

### 5.3 深度重写门禁（十三道门禁）

以下十三道门禁是AI腔清除的核心方法论。检查脚本时，逐条对照，不符合的标黄或标红。

#### 门禁一：禁用抽象上位词

强制模型停留在下位词层面，拒绝向高概括层级逃逸。

- [ ] 脚本中是否出现了"意义""价值""精神""力量""命运""时代"等抽象大词？有→标黄。
- [ ] 是否可以用更具体的下位词替换？（如"力量"→"他握剑的手在抖"；"命运"→"那天城门关上的声音"）不能→标黄。
- [ ] 检查方法：将疑似抽象词删除，如果句子信息量减少不超过20%，则该词为AI腔填充词，必须删除或替换。

#### 门禁二：禁用跨域通用比喻库

切断"时间-河流""命运-航船""历史-画卷""人生-旅途"等超高频映射的默认激活。

- [ ] 脚本中是否出现了以下跨域通用比喻？有→标黄：
  - 时间 = 河流/长河/流水
  - 命运 = 航船/舵手/风浪
  - 历史 = 画卷/长河/镜子
  - 人生 = 旅途/道路/山峰
  - 权力 = 棋局/棋盘/棋子
  - 战争 = 烈火/风暴/漩涡
- [ ] 替换标准：比喻必须来自本题材的**具体物质世界**（如夏朝的夯土、商朝的青铜、战国的箭矢），而非跨域通用库。

#### 门禁三：禁用情感冗余（删除测试）

要求每一个修饰成分必须通过"删除测试"——如果删除该词，句子的信息量减少超过阈值，才允许保留。

- [ ] 逐句扫描形容词和副词：删除后信息是否仍然完整？是→删除该词，标黄。
- [ ] 扫描"的"字密度：每句话超过2个"的"→标黄（"的"是AI生成中文的标志性填充词）。
- [ ] 扫描"地""得"：非必要不使用，用了→标黄。
- [ ] 扫描"非常""极其""十分""特别"等程度副词：删除后是否影响理解？不影响→删除，标黄。

#### 门禁四：感官通道限定

要求文本必须通过特定感官通道进行编码，而非停留在视觉和听觉的抽象层面。

- [ ] 脚本中是否有**触觉**描写？（温度、质地、重量、疼痛）无→标黄（提示补充）。
- [ ] 脚本中是否有**嗅觉**描写？（烟火气、血腥气、泥土味、祭祀的烟火味）无→标黄（提示补充）。
- [ ] 脚本中是否有**前庭觉**描写？（失衡、眩晕、脚下的震动、马背的颠簸）无→标黄（提示补充）。
- [ ] 脚本中视觉描写是否占比超过70%？是→标黄（提示增加其他感官通道）。
- [ ] 检查方法：统计全文感官词汇分布，视觉+听觉占比超过80%→标黄。

#### 门禁五：动作链优先

用动作序列（action chain）代替状态描述，因为动作有物理约束，不容易滑向套话。

- [ ] 脚本中是否出现了状态描述？（"他很愤怒""局势紧张""气氛凝重"）有→标黄。
- [ ] 替换标准：状态必须转化为动作链。（"他很愤怒"→"他把竹简摔在地上，碎片溅到了台阶下"）
- [ ] 检查方法：每出现一个"很""非常""极其"+形容词的组合，追问"这个动作在物理上长什么样？"

#### 门禁六：物质性锚定

每一个比喻必须包含可触摸的物质属性（密度、温度、质地、重量），而非停留在关系属性上。

- [ ] 脚本中的比喻是否包含物质属性？
  - ❌ 关系属性比喻："权力像一张网"（网是关系，无物质感）
  - ✅ 物质属性比喻："权力像一块烧红的青铜，握在手里会粘住皮"（温度+质地+重量）
- [ ] 检查方法：提取所有比喻，追问"这个比喻的密度/温度/质地/重量是什么？"答不上来→标黄。

#### 门禁七：言语行为明确化

在生成前，必须定义这段文字的以言行事行为（illocutionary act）——它是在命令、哀悼、讽刺、还是宣判？

- [ ] 脚本的每一段是否都有明确的言语行为？
  - 开场钩子 = 挑衅/设问/断言
  - 锚定线 = 陈述/定位
  - 决策瞬间 = 宣判/揭示
  - 动情点 = 哀悼/悲悯
  - 收尾 = 唏嘘/交还判断
- [ ] 检查方法：同一段落中是否混杂了两种以上言语行为？（如哀悼段落里突然说教）是→标黄。
- [ ] 不同的言语行为会激活完全不同的词汇选择策略。哀悼段落用了宣判词汇→标黄。

#### 门禁八：受众距离设定

> 定位：人格层与风格层的最后一道护栏。所有含"你/我"人称互动的表达，必须通过本项检查。
> 核心原则：同辈亲密，不审判、不冷漠、不卖关子、不摆谱、不讨好。

明确文本与受众的关系（亲密/疏离、上级/下级、同辈/异辈），这会强制模型调整敬语系统、隐喻系统的激进程度。

- [ ] 脚本是否保持了统一的受众距离？
  - 你的设定是：**同辈、亲密、略带调侃但不冒犯**
- [ ] 是否出现了距离漂移？（如前半段像朋友聊天，后半段像老师讲课）是→标黄。
- [ ] 是否出现了"您""诸位""各位观众"等疏远称谓？有→标黄。
- [ ] 是否出现了"让我们""大家一起"等集体号召句式？有→标黄。


##### 1、这么写会造成什么影响

| 违禁表达 | 观众听到的 | 关系变成 |
| ---- | ---- | ---- |
| "你怎么还不明白" | "你是个傻子" | 老师→学生（居高临下） |
| "我不看，我不管" | "你爱看不看" | 冷漠者→乞求者（情感勒索） |
| "我不懂，但我大受震撼" | "我懒得解释，你自己品" | 装傻者→被戏弄者 |
| "家人们谁懂啊" | "过度讨好，假得明显" | 虚假亲密 |
| "说白了/一句话总结" | "前面都是废话，我给你翻译" | 降维打击 |

##### 2、通过标准（5条）

1. **不审判**：不给观众贴"不懂/没发现/不明白"的标签
2. **不冷漠**：不表达"我无所谓/你爱看不看"的姿态
3. **不卖关子**：不反讽、不装傻、不"你细品"
4. **不摆谱**：不用"说白了/一句话总结"等降维句式
5. **不讨好**：不用"家人们/宝子们"等虚假亲密称谓

##### 3、违禁表达清单与替换

| 类型 | 违禁表达 | 替换为 |
| ---- | ---- | ---- |
| 审判型 | "你怎么还没发现…" | "当时的人也没意识到…" |
| 审判型 | "你怎么还不明白…" | "这里有个容易忽略的点…" |
| 审判型 | "你们懂吗/你们知道吗" | "放在当时，这就是…" |
| 冷漠型 | "我不看这段史料…" | "这段史料本身就有矛盾…" |
| 冷漠型 | "我不管/我不在乎" | 删除，或改为"当时的人面临一个问题" |
| 反讽型 | "我不懂，但我大受震撼" | "这件事当时的人也没想明白" |
| 反讽型 | "你品，你细品" | 直接给结论，不绕弯 |
| 反讽型 | "懂的都懂" | 删除，或给出具体解释 |
| 讨好型 | "家人们谁懂啊" | 删除，直接给事实 |
| 讨好型 | "宝子们/姐妹们/咱就是说" | 删除 |
| 降维型 | "说白了，就是…" | "当时的逻辑是这样的…" |
| 降维型 | "你只需要记住…" | 删除引导词，直接给信息 |

##### 4、快速判断法（人称替换测试）

对含"你/我"的句子执行以下测试，任一通过即有问题：

- **"你"→"您"测试**：换成"您"后更像训话 → 有问题
- **"我"→"本宫"测试**：换成"本宫/本少爷"后更像摆谱 → 有问题
- **删除"你/我"测试**：删除后信息依然完整 → 删除人称词

##### 5、修改口诀

> 把"你/我"的对抗，改成"当时的人/这件事"的平行。

### 6、签发清单

- [ ] 无"你怎么还不明白"等审判句式
- [ ] 无"我不看/我不管"等冷漠句式
- [ ] 无"你品/懂的都懂"等反讽卖关子句式
- [ ] 无"家人们/宝子们"等虚假亲密称谓
- [ ] 无"说白了/一句话总结"等降维打击句式
- [ ] 所有"你/我"人称互动通过替换测试





#### 门禁九：信息结构优先

要求文本服从信息结构（information structure）而非修辞结构（rhetorical structure）。

- [ ] 每句话是否遵循"已知信息→新信息"的流动路径？
  - ❌ 修辞结构："在漫长的历史长河中，有一位伟大的君主，他做出了一个惊人的决定。"（三个新信息堆在一起，无已知锚点）
  - ✅ 信息结构："这位君主——就是刚才那个在城门口挨骂的年轻人——现在坐在了王位上。"（已知：城门口的年轻人；新：他成了君主）
- [ ] 检查方法：标记每句话的已知信息和新信息，如果一句话包含超过2个新信息且无已知锚点→标黄。

#### 门禁十：张力机制

在prompt中植入互斥的约束条件，迫使模型在冲突中寻找唯一解。

- [ ] 脚本是否同时满足了以下互斥条件？
  - **极度精确** + **极度粗粝**：史实必须精确到年月日，但语言必须粗粝到像刚从土里刨出来
  - **极度克制** + **极度锋利**：情绪不外溢，但每一句话都像刀
- [ ] 检查方法：如果脚本读起来"很顺""很光滑""很正确"，说明没有张力，→标黄。好的文本应该在某个地方让读者感到"硌手"。

#### 门禁十一：认知负荷注入

要求文本在特定位置引入认知断裂（cognitive dissonance）——即违反格赖斯合作原则中的"方式准则"（Manner Maxim），故意制造需要读者填补的语义缺口。

- [ ] AI腔的致命特征是"过度合作"——它从不让读者费力；而好的文本必须要求读者参与解码。
- [ ] 检查方法：脚本中是否有让读者"愣一下"的地方？（如突然中断、语序颠倒、省略主语、用错位的比喻）
  - ❌ AI腔："他做出了一个艰难的决定，这个决定改变了他的一生。"（过度合作，无断裂）
  - ✅ 真人表达："那个决定。他做了。然后一切都不一样了。"（断裂，读者自己补逻辑）
- [ ] 全片认知断裂点是否≥2处？不足→标黄。

#### 门禁十二：语料层隔离

明确指定文本的"时间地层"——它应该像哪个时代的语言？不是词汇层面的仿古，而是句法节奏、信息密度、推理方式的历时锁定。

- [ ] 脚本的语言"时间地层"是否与题材匹配？
  - 夏商周题材：语言应带有**巫祝感**——短促、断言式、神谕般的节奏
  - 春秋战国：语言应带有**策士感**——锋利、对仗、机锋暗藏
  - 秦汉：语言应带有**史官感**——克制、白描、不动声色
- [ ] 检查方法：把脚本中的地名、人名替换成现代名字，如果读起来像一篇现代公众号文章→标黄（说明语料层未隔离，混入了现代语料）。

#### 门禁十三：个体语言记忆

要求文本携带个体语言史（idiolect）的痕迹，即模拟一个具体说话者的历史——他受过什么伤害、有过什么执念、惯用什么样的错误。

- [ ] AI腔是"无历史"的，而人类语言是"有伤疤"的。
- [ ] 检查方法：脚本是否有以下"不完美"的痕迹？
  - 某个词反复出现（口头禅）
  - 某个句式明显偏长或偏短（个人节奏）
  - 某个地方用词不当但符合人物身份（如武将用了文人的词，或反之）
  - 某个地方情绪溢出控制（不该哭的时候哭了，不该笑的时候笑了）
- [ ] 全片"有伤疤"的语言痕迹是否≥3处？不足→标黄。

### 5.4 AI腔评分标准

| 分值区间 | 判定   | 说明                                   |
| -------- | ------ | -------------------------------------- |
| 90-100   | 优秀   | 几乎无AI味，语言有质感、有张力、有伤疤 |
| 80-89    | 良好   | 偶见AI腔，修改后可用                   |
| 70-79    | 及格   | AI腔明显，需大幅修改                   |
| 60-69    | 不及格 | AI味浓重，必须重写                     |
| 0-59     | 失败   | 典型的AI生成文本，完全不可用           |

**评分细则**：

- 每发现1处红色（门禁 violation）扣8分
- 每发现1处黄色（门禁 warning）扣3分
- 确定性扫描漏网1处（代码未检出但LLM检出）额外扣5分
- 满分100分，扣完为止

## 六、技术制作检查（5%）

### 6.1 时长控制

- [ ] **旁白字数**：脚本字数是否与目标时长匹配？（中文口播约200-250字/分钟）超标→标黄。
- [ ] **片头钩子**：前15秒是否完成了钩子？未完成→标红。
- [ ] **收尾密度**：最后30秒是否承载了80%的落点重量？分散→标黄。

### 6.2 多媒体提示

- [ ] **地图节点**：涉及疆域/战线/地形变化的段落，旁白是否给地图留了"半秒空气"？（如"注意看这片区域""地图上这里"）未留→标黄。
- [ ] **数据可视化提示**：涉及数字反差的段落，是否有"相当于…"的现代类比？无→标黄。
- [ ] **BGM情绪提示**：关键情绪转折点是否有BGM切换提示？（如"此处BGM渐强""此处静音"）无→标黄（提示补充，非强制）。
- [ ] **音效提示**：是否有环境音效提示？（如"此处加风雨声""此处加战鼓声"）无→标黄（提示补充，非强制）。

### 6.3 制作可行性

- [ ] **素材可得性**：脚本中提到的画面/地图/文物图片，是否有明确的获取渠道？（如"CHGIS数据库""全历史网""博物馆官网"）无→标黄。
- [ ] **方言音轨提示**：使用方言的段落，是否有"此处切换XX方言音轨"的提示？无→标黄。
- [ ] **字幕规范**：脚本是否为所有旁白/对话标注了字幕位置？未标注→标黄。

**评分**：每发现1处红色扣10分，1处黄色扣3分。满分100分，扣完为止。

## 七、数据指标检查（5%）

### 7.1 完播率相关

- [ ] **前3秒钩子强度**：脚本前3秒是否有明确的"必须看下去"的理由？（悬念/反常识/数字冲击/极端断言）无→标黄。
- [ ] **前15秒信息密度**：前15秒是否完成了"钩子+锚定"？信息过载或信息不足→标黄。
- [ ] **中段留存**：脚本中段（3-8分钟）是否有明确的"继续看下去"的钩子？（盖牌/悬念/未解之谜）无→标黄。
- [ ] **结尾钩子**：结尾是否有"意犹未尽"的感觉？（唏嘘/悬念/思考）戛然而止→标黄。

### 7.2 互动率相关

- [ ] **评论引导**：脚本是否预留了引发评论的"争议点"或"开放问题"？无→标黄。
- [ ] **弹幕预埋**：脚本中是否有"观众必然反应位"？（如数字反差、反常识事实）无→标黄。
- [ ] **转发动机**：脚本是否有"值得分享"的传播点？（金句/冷知识/颠覆认知）无→标黄。

### 7.3 完播曲线优化

- [ ] **3秒完播**：前3秒是否有"画面感"或"声音冲击"？纯文字叙述→标黄。
- [ ] **30秒完播**：30秒内是否完成了第一个小高潮或信息增量？无→标黄。
- [ ] **1分钟完播**：1分钟内是否建立了"这集值得看完"的信任感？无→标黄。

**评分**：每发现1处黄色扣5分。满分100分，扣完为止。

## 九、使用说明

1. **输入**：将完成脚本 + 对应的N1事件卡清单 + 所选模板类型（如"人物篇-A"） + 确定性扫描结果（scans.py输出）一并提交。
2. **执行顺序**：
   - 第一步：接收确定性扫描结果（禁词/套话/零信息量感慨/字数容差）
   - 第二步：LLM执行句式模式扫描（5.2）
   - 第三步：LLM执行十三道门禁深度检查（5.3）
   - 第四步：执行叙事结构、弹药使用、风格人格、技术制作、数据指标检查
   - 第五步：汇总输出质检报告
3. **输出**：只输出质检报告（总评表+问题清单+修改优先级+可选AI腔专项报告），不输出修改后的脚本。
4. **迭代**：编剧根据报告修改后，可再次提交复检，直至通过。
5. **特殊流程**：若AI腔检查得分<60，必须重写，不接受局部修改。
