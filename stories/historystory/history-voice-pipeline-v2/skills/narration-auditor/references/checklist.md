# 签发清单（v3.0 版）

> 本文件为 SKILL.md 的参考文档，按需加载。完整的签发 checklist，用于最终过审前的逐项确认。

---

## AI腔检查

- [ ] 禁词扫描通过（零残留）
- [ ] 过渡套话扫描通过（零残留）
- [ ] 零信息量感慨扫描通过（零残留）
- [ ] 字数容差通过（钩子/收尾 ±40%，主线/插件 ±20%）
- [ ] 无夸大象征句式
- [ ] 无宣传性语言
- [ ] 无模糊归因
- [ ] 破折号占比≤5%
- [ ] 无三段式结构
- [ ] 无否定式排比
- [ ] 连接词密度≤8个/100字
- [ ] 无排比堆砌
- [ ] 无总结癖
- [ ] 无第三人称全知滥用
- [ ] 无AI式匀速
- [ ] 无过渡生硬

## 十三道门禁

- [ ] **门禁一**：抽象上位词已替换为下位词
- [ ] **门禁二**：跨域通用比喻已替换为题材内物质比喻
- [ ] **门禁三**：所有修饰成分通过删除测试
- [ ] **门禁四**：感官通道覆盖触觉/嗅觉/前庭觉（至少2种非视觉）
- [ ] **门禁五**：所有状态描述已转化为动作链
- [ ] **门禁六**：所有比喻包含物质属性（密度/温度/质地/重量）
- [ ] **门禁七**：每段言语行为明确且统一
- [ ] **门禁八**：受众距离统一为同辈亲密
- [ ] **门禁九**：信息结构为"已知→新信息"流动
- [ ] **门禁十**：文本存在互斥张力（精确+粗粝/克制+锋利）
- [ ] **门禁十一**：全片认知断裂点≥2处
- [ ] **门禁十二**：语料层与题材时代地层锁定
- [ ] **门禁十三**：全片"有伤疤"的语言痕迹≥3处

## 叙事结构

- [ ] 段序与所选模板一一对应
- [ ] 开篇30秒内发动机明确
- [ ] 钩子已兑现
- [ ] 每3分钟至少一个炸点
- [ ] 相邻炸点类型不同
- [ ] 80%落点压最后30秒

## 弹药使用

- [ ] 外号≤1个，对应真实史实
- [ ] 类比后有一句"精度还回"，全片≤2处
- [ ] 主反转≤1次，两端均有史料卡
- [ ] 对话演绎台词逐字出自史料，每集≤1场
- [ ] 方言段落≤3处（人物篇≤2处），悲情节点未使用
- [ ] 盖牌≤1张，结尾前已掀开
- [ ] 时间锚点≤1颗，纪年已核
- [ ] 家事线≤2条，落点回到国是

## 风格人格

- [ ] 谦逊不说教，不做钦定
- [ ] 动作带出背景，名场面拆两半
- [ ] 长句占比≤30%，口语化测试通过

## 技术制作

- [ ] 旁白字数匹配目标时长（200-250字/分钟）
- [ ] 前15秒完成钩子
- [ ] 地图节点留半秒空气
- [ ] 数据可视化有现代类比

## 数据指标

- [ ] 前3秒有"必须看下去"的理由
- [ ] 中段有"继续看下去"的钩子
- [ ] 结尾有"意犹未尽"的感觉
- [ ] 预留了评论引导点和弹幕预埋位

## 总原则自查

- [ ] **知识裹情绪**：本集知识是否都裹着情绪
- [ ] **认知门槛**：抽象概念是否都有翻译或前置
