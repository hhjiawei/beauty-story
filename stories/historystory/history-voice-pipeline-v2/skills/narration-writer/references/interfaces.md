# 上下游接口

> 本文件为 SKILL.md 的参考文档，按需加载。包含：上游输入要求、施工权限、下游交付、返工规则。

## 上游：大纲层交付要求

大纲层交付**签发清单全绿且已过主题否决关**的《单集大纲文件》——两关缺任何一关，写作层拒收。

史料卡不全的段，写作层有权停笔等料，**不许拿通识充史料**。

**v3.1 新增：大纲层必须交付以下字段，否则写作层拒收**

| 字段 | 类型 | 说明 | 缺字段后果 |
|------|------|------|-----------|
| 命运阶段 | 硬约束 | 4-6个情感转折里程碑（如"少年战神→中年弃子"） | 拒收，退回大纲层补全 |
| 情感坐标 | 硬约束 | 每段的情感气质（高位起跳·明亮/谷底·苍凉等） | 拒收，退回大纲层补全 |
| 温度 | 硬约束 | 冷/温/热，全篇统一 | 拒收，退回大纲层补全 |
| 声口样句 | 硬约束 | 本期语调标杆示例（1-3句） | 拒收，退回大纲层补全 |
| 外号锚点 | 硬约束 | 核心人物外号及设计逻辑 | 拒收，退回大纲层补全 |
| 焊接清单 | 软约束 | 现代类比+史料原文+自嘲收尾的具体方案 | 可施工，但需在备注中补充 |
| 查证透明化 | 软约束 | 史料争议节点的版本陈列方案 | 可施工，但需在备注中补充 |
| 动情点克制纪律 | 硬约束 | 先事实后情绪、留白标记、禁止总结句 | 拒收，退回大纲层补全 |
| 预计字数 | 硬约束 | 分级容差内施工 | 沿用v1标准 |
| 段号/功能类型 | 硬约束 | 施工图纸基础字段 | 沿用v1标准 |
| 史料卡 | 硬约束 | 段内事实唯一来源 | 沿用v1标准 |
| 炸点/伏笔 | 硬约束 | 位置、类型、埋收关系 | 沿用v1标准 |

## 施工权限

大纲字段分硬软两级（v3 起）：

| 约束类型 | 字段 | 权限 |
|----------|------|------|
| 硬约束 | 段号、功能类型、史料卡、伏笔、动情点、预计字数、命运阶段、情感坐标、温度、声口样句、外号锚点 | **无权改** |
| 软约束 | 指定技法主备切换、炸点起爆句位置、情绪过渡、查证透明化的具体措辞、焊接清单的具体类比 | **可调**，须在交稿备注中逐条声明 |

**v3.1 新增温度纪律**：温度一旦选定，全篇统一，写作层无权在段落间切换温度。发现大纲温度标注不一致，退回大纲层复核。

## 下游：审核层交付

写作层交稿时附：
1. 自查清单全绿记录
2. 施工异议备注（对大纲的疑问，只标注不擅自处理）
3. **v3.1 新增**：声口定调3句（废稿，供审核层核对语调）
4. **v3.1 新增**：人称分布抽查记录（随机3段，标注"咱们/我/你/他"比例）

---

## 返工规则

审核层打回的稿件，写作层按打回条目逐条改，不顺手重写全文——**重写是偷懒，修改才是施工**。

**v3.1 新增：杜茹慧风格专项返工**

| 返工类型 | 返工标准 | 处理方式 |
|---------|---------|---------|
| 温度漂移 | 段落间温度不一致 | 退回写作层，统一温度 |
| 声口不对 | 朗读测试不通过，与声口样句偏差大 | 退回写作层，重写定调3句 |
| 外号错误 | 外号侮辱人格/不贴合命运内核/骨维度未回归正式称谓 | 退回写作层，重设外号 |
| 焊接断裂 | 类比完不跟史料，或史料完不翻译 | 退回写作层，补全焊接 |
| 动情点煽情 | 先情绪后事实，或动情点后有总结句 | 退回写作层，事实前置 |
| 膈应话术 | 出现"你懂吗/我不猜/说白了"等 | 退回写作层，逐句替换 |
| 结尾总结 | 出现"他的一生告诉我们"等总结句 | 退回写作层，改为悬停收束 |
| 人称漂移 | "咱们/我/你/他"比例严重失衡 | 退回写作层，调整人称 |

## 附：写作层心法（三句话）

1. **观众此时知道什么？观众此刻还想知道什么？**——每写一句前问一遍
2. **这句话用嘴说出来，像人话吗？**——写完一段读一遍
3. **这个细节，事件卡里有吗？**——落笔之前查一遍

4. **这个梗是在帮观众理解，还是在炫耀我聪明？**——抖机灵前问一遍
