## 一、栏目化骨架（成稿节奏）

整套写作由一套稳定的"栏目化骨架"支撑，六个一级模块**递进排列**（非并列）：

| 序 | 栏目 | 任务 | 典型手法 |
|---|---|---|---|
| 1 | 钩子栏目（开篇） | 制造"观众吓一跳"的打开率 | 血腥/荒诞细节、洋梗对比、设问、极端人设 |
| 2 | 史料铺陈栏目 | 摆出"原著党"姿态，建立可信度 | 引《晋书》《资治通鉴》原文 + 司马光/苏轼/陈寅恪评语 + 诗词 |
| 3 | 现代黑话降维栏目 | 消解严肃感，八卦感主源 | 官职/战略/朝堂 → 职场/游戏/网络热梗 |
| 4 | 心理代入栏目 | 填史书留白，古人变"打工人/老同志" | 内心OS、对话脑补、动作特写 |
| 5 | 反讽/反转结构栏目 | 制造黑色幽默 | 先立"赢麻了"的必胜逻辑靶子，再用真实结局打脸 |
| 6 | 收束栏目 | 留余味、钩下期 | 主题升华 / 阴暗小故事尾声 / 下期预告 / 单句钉死 |

**流动关系**：钩子 → 铺陈 →（降维 ∥ 代入，平行填充血肉）→ 反讽收束 → 尾声/预告。
栏目是节奏单位，不是死板分段——一个自然段可以同时承担铺陈+降维两个栏目职能。

**这套骨架要解决的问题**：让"看得懂、学不会"的硬核历史，对普通读者产生吃瓜式代入与自来水传播力——把学术性史实降维成大众愿意看完、看完能转述的叙事产品。

## 二、核心命题（五条写作原理）

1. **留白填补**：史书只记"做了什么"，作者强行补"怎么想的"——心理代入把古人变成有血有肉的打工人。
   - 样本实证（两晋01）："刚刚走上统治地位的士族门阀阶层，长长地吸了一口气。他们是又窃喜又后怕。"——史书只记士族奢靡，作者补出阶层集体心理。
2. **时空错位**：现代黑话嫁接到古代场景，消解严肃感，让读者用吃瓜心态秒懂复杂局势。
   - 样本实证（两晋02）："这是最早的一批有编制的匈奴。"
3. **细节脑补**：史书简略的冲突/对峙，用符合物理常识与人性反应的具象画面补出。
   - 样本实证（两晋03）：司马师眼珠子被吓掉后"死死地咬住被子，一声不吭"——史书只记"啖被"二字级别的事实，画面由作者按生理反应补全。
4. **预期违背**：先立当事人"必胜逻辑"，再用历史结局打脸，形成"一本正经推理最后全错"的黑色幽默。
   - 样本实证（两晋02）："事情似乎在往好的一方面发展，然而人世难逢开口笑，天能遂人愿吗？"
5. **栏目化可复制**：钩子—铺陈—降维—代入—反转—尾声的固定骨架，保证成稿节奏稳定、可批量复制、与朝代无关。

## 三、论证链（四层叠加）

严肃历史可以用轻松语态讲清且更好传播，靠四层叠加：

```
第一层 史实骨架：史料引用（正史原文、名家评语、数字）——保证不瞎编、可被核验
第二层 血肉填充：心理代入 + 场景重构——保证可感
第三层 现代语态：词汇降维（黑话弹药）——保证好懂
第四层 情绪炸弹：反讽结构 + 悲悯轨反差——保证好传
```

第一层是底线，任何时候不可牺牲；后三层是杠杆，密度可调。四层已在两晋、晚清、隋朝材料上跨朝代验证一致——手法与具体朝代无关。

## 四、叙事视角与声音

- **主视角**：上帝全知视角 + 现代网感第一人称混合。制造"主讲人在你耳边唠嗑"的亲密感。
- **打破第四面墙**：直接与观众对话，是签名动作。
  - "咱们猜猜他手底下有没有羌族的士兵呢？"（两晋02）
  - "同学们，那是司马懿的封地啊！"（两晋04）
  - "直接上数据吧。"（两晋02）
- **领属词人格化**：把王朝当自家品牌——"我晋""我大晋""在我晋，有什么值钱的？人命才值钱"。一个系列一个领属词，全篇统一。
- **人物声音化**：给人物配内心独白和台词，偶尔第一人称限知（如黑道大哥自述体），增强沉浸。

## 五、画面感与镜头语言

文本必须"readable as video"——强分镜意识：

- **场景重构 = 分镜脚本**：把抽象结果脑补成具象画面（对骂两个时辰、膝盖不能打弯）。
- **特写定格**：高光瞬间放慢——石崇铁如意砸珊瑚"眼皮都不抬一下"、王敦抱痰盂敲着唱歌、司马师"露着一只空洞的眼眶，指挥诸军进行反击"。
- **蒙太奇剪辑**：多线快速切换——帝国崩散时的"破鼓万人锤"式群像。
- **对切**：双方立场来回切——石崇砍美人 vs 王敦"他杀他的奴婢，关我什么事"。

写作自检：每一段读出来，脑子里能不能出画面？出不了画面的抽象论述段，要么补场景，要么删。

## 六、语气调性

- **主调**：戏谑、反讽、吃瓜。
- **辅调**：间以温情升华（祖逖中流击楫式的人物弧光）与悲悯（大瘟疫、人口锐减）。
- **暴行处理**：常被喜剧化定格（"率兽食人得到最完整具象化"），但**大规模死亡、文明浩劫走悲悯轨**，此处零梗。
- **口癖节奏词**："简单来说""说点不好听的""当然了""别喊了""不说了，心累"——口语顿挫，模拟真人唠嗑。

## 七、信息密度与节奏

- 节奏公式：**强钩子 — 快铺陈 — 密集梗 — 反转收束**，单位时间信息密度高，服务短视频完播。
- 段长控制：口播稿一段 2–6 句为宜；超过 8 句的段落必须内部有节奏起伏（排比、设问、转折）。
- 句长控制：长短句交错。连续三个长句后给一个短句钉住（"这是一个漫长的故事。""第三，收下当狗。"）。
- 数字轰炸与名单流是合法的节奏武器（详见 craft-techniques.md §7）。

## 八、系列化编排

篇尾互钩成"连续剧"，制造追更粘性：

- 预告下一期矛盾："这个咱们准备下期讲""下期我们慢慢拆分"。
- 埋远期人物线："匈奴的第一个皇帝刘渊，此时在首都被各方势力忌惮……""距离他围杀晋朝最后仅剩的二十万军队，却没有几年了。"
- 呼应开头设问收尾，形成单集闭环 + 系列开口的双层结构。
