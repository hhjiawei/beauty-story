## 一、禁区清单（逐段扫描项）

成稿后逐段对照扫描，命中即改：

**事实禁区**
- [ ] 核心史实（时间、人名、官职、事件、结果）零捏造；不确定的已取证或挂"存疑"。
- [ ] 每个新时间点年号+公元双标。
- [ ] 原文引用准确、未改字；白话翻译忠实。
- [ ] 宏大判断后均有数字或原文托底。
- [ ] 孤证推测只写"存疑"，未写成定论。
- [ ] 史无明文的心理/场景脑补，全部挂了声明牌（或许/估计/可以想象/大概率/以下为个人观点）。

**风格禁区**
- [ ] 领属词全文统一，未中途更换。
- [ ] 人物绰号与声音卡一致，未前后不一。
- [ ] 史料原文内未混入降格称呼和弹药。
- [ ] 同类弹药未连续出现两次以上；单段弹药 ≤2 处；同一黑话词全篇 ≤2 次。
- [ ] 每个弹药都能答出映射的史实（答不出的已删）；相邻炸点不同型（语言/结构/情绪轮换）。
- [ ] 无 AI 腔禁语："值得注意的是""综上所述""总而言之""由此可见一斑""不禁让人""这是一个……的故事"（起手除外）"在……的背景下""随着……的发展"。
- [ ] 无 PPT 腔过渡："接下来我们讲""下面介绍""首先其次再次最后"连环。
- [ ] 无解释笑话行为（判词后未追加"所以这说明……"）。

**口播禁区**
- [ ] 广告植入全部剥离（口播原稿中的带货段落是噪声，不进入成稿）。
- [ ] 无书面语长定语堆叠（口播念不出来的句子已拆短）。
- [ ] 每段开头已标注大纲段号【段N】，且与大纲一一对应、无缺段。

## 二、逻辑与因果核销（全文级）

历史叙事的说服力来自因果链，不来自堆料。阶段三对全文做三项核销：

**因果链核销**
- [ ] 每个结论都能沿"因→果"链条回溯到前文证据；无因之果段已重写。
- [ ] 每个论点句后都有本段内的证据支撑（原文/数字/细节）；有论无据段已补证据。
- [ ] 设问全部已回答（本段或紧随其后）；不存在悬空设问。
- [ ] 段间咬合成立：每段结尾要么是下一段的因（余震式），要么抛出下一段要答的问（悬念式），要么显式交代换视角的理由。
- [ ] 意外类转折（荒诞意外炸点）后已补"能接住这个意外，靠的是……"——运气不许充当因果。
- [ ] 决策现场只摆当事人当时真实拥有的约束与选项；后见之明（观众或当事人当时都不可能知道的信息）未混入。
- [ ] 归因层次清晰：直接原因 / 深层结构原因分开陈述，不把巧合写成规律，也不把规律讲成宿命。

**钩子台账核销（兑现纪律）**
- [ ] 台账逐条核销：反常识断言、悬念标题、盖牌、高潮前置、开头设问——每个埋钩都在正片或收尾兑现。
- [ ] 兑现不了的钩已撤除或改成平实表述（兑现不了＝标题党）。
- [ ] 盖牌 ≤1 张/集，且掀开的内容配得上铺垫的期待。
- [ ] 高潮前置的片段在结尾已归位；开头立的问题/误判，结尾已回答或推翻（单集逻辑闭环）。

**上下集逻辑（系列篇适用）**
- [ ] 预告的下期矛盾与本集结尾态势一致，不虚构悬念。
- [ ] 与上集衔接处的人物/态势描述与上集结论不矛盾。

## 三、悲悯轨规则

**触发场景**：大规模死亡（瘟疫、屠城、饥荒）、文明浩劫、人物悲剧收束、全文升华段。

**规则**：
1. 悲悯轨段落内：弹药清零、绰号清零、玩梗清零。
2. 笔法改白描 + 原文直引（悼亡诗文优先）。
3. 进轨要有显式过渡句（"战争和瘟疫交织成建安二十二年的人间炼狱"），出轨回主调也要（"太难了，黑色幽默一下吧"）。
4. 悲悯轨内允许一处"黑色幽默呼吸口"，但落点必须是悲凉而非笑点。
5. 悲悯轨收尾段禁用搞笑栏目；可用"阴暗小故事"尾声（见下）。

**标注约定**：写作时给悲悯轨段落开头加标记 `【段N·悲悯】`，供检查脚本识别（详见 §五）。

## 四、收尾四件套检查

按需组合，至少命中两件：

- [ ] **总结排比**：全文回想式收束（"总结一下吧。在魏晋禅代之际……"）。
- [ ] **金句/诗文收束**：记忆锚点（"他们是开启乱世的钥匙，也是引领隋唐光明的第一批献祭者"）。
- [ ] **栏目收尾**：主题升华，或独立的"阴暗小故事"尾声（两晋03 张春华杀婢灭口是范式：与正文形成互文，最后一句翻转判词"若论毫无道德底线，还是得看我司马懿呀"）。
- [ ] **下期预告钩连**：呼应开头设问 + 抛出下期矛盾（"这个咱们准备下期讲"）。
- [ ] **单句钉死（可选强化）**：全文最后用一个短句钉住（"三百年大乱世，开始了。"）。

## 五、出口标准（三零）

交付前最后一遍通读（建议出声读，口播稿必须用耳朵验收）：

1. **零语病**：出声读一遍，凡拗口、歧义、成分残缺处改掉。
2. **零流水句**：无三个以上连续并列短句凑数；无一句话里塞两个以上信息点。
3. **零逻辑失衡**：每段的论点都有本段内的证据支撑；因果链无跳步；设问必有回答。

## 六、check_output.py 使用与配置

硬闸门脚本，成稿必过：

```bash
# 基本用法（无大纲，跳过段号覆盖检查）
python3 scripts/check_output.py 成稿.txt

# 完整用法（对照大纲检查段号覆盖）
python3 scripts/check_output.py 成稿.txt --outline 大纲.txt

# 只看报告不因失败退出（调试用）
python3 scripts/check_output.py 成稿.txt --no-fail
```

**段号标注约定**：正文每段开头 `【段N】`；悲悯轨段 `【段N·悲悯】`。大纲文件每段一行、以 `段N` 或 `N.` 或 `N、` 开头均可被识别。

**检查项与判定**：

| 检查项 | 判定级别 | 说明 |
|---|---|---|
| 段号覆盖 | FAIL | 大纲每段都有对应【段N】，无缺段、无重号 |
| 广告词残留 | FAIL | 命中广告黑名单（带货口播残留） |
| AI腔禁语 | FAIL | 命中禁语表 |
| 悲悯轨弹药 | FAIL | 【段N·悲悯】段内检出绰号/弹药词 |
| 声明牌缺失 | WARN | 推测句式附近无声明牌，人工复核 |
| 时间锚定 | WARN | 年号出现但附近无公元纪年，人工复核 |
| 弹药密度 | WARN | 连续两段命中同类弹药，或单段弹药 >2 |
| 黑话重复 | WARN | 同一弹药词全篇出现 >2 次（跨篇复用允许，单篇须换说法） |
| 埋钩兑现 | WARN | 检出埋钩句式（"这个后面说"等），逐条列出供人工核对兑现位置——盖了不掀＝挖坑不填 |
| 超长流水句 | WARN | 单句 >120 字，或单段 >450 字 |
| 领属词一致性 | WARN | 检出多个不同领属词 |
| 收束完整性 | WARN | 结尾 300 字内未检出预告/总结/金句特征 |

**退出码**：任一 FAIL → 退出码 1（不过闸，回炉重写对应段后复检）；仅 WARN → 退出码 0 但必须在交付说明中列出未处理的 WARN 及理由。

**自定义词表**：脚本顶部 `AD_BLACKLIST`、`AI_CLICHE`、`AMMO_LEXICON`、`DISCLAIMERS`、`HOOK_PATTERNS` 五个词表可直接编辑扩充——新系列的绰号、新发现的广告词、新弹药、新埋钩句式都应回写到这里，让闸门越用越准。
