# 成稿格式

> 本文件为 SKILL.md 的参考文档，按需加载。包含旁白成稿的标准输出格式与标记规范。
> v3.1 新增：画本层可直接提取的标记（顿/沉默/地图留白/上屏/声口对齐）。

---

## 输出 Schema

```markdown
# 《{集名}》旁白成稿

> 目标时长：{X} 分钟｜预计字数：{X} 字｜本期外衣：{风格名}
> 大纲版本：{对应大纲文件标识}

## 第一章 {章节标题}（大纲段 1–3）

【段1·钩子】（大纲：反常切片，炸点：反直觉结论型）
正文正文正文。（顿）正文正文。
【上屏】《史记》原文："……"

【段2·锚定】（大纲：认知锚定线）
正文……

【段3·主线·关键节点】
正文……（地图留白 2 秒）
```

## 标记规范

| 标记 | 用途 | 画本层处理 |
|------|------|-----------|
| 【段N·功能类型】 | 每段开头标注，对齐大纲段号，括号内抄录大纲施工指令摘要 | 段落索引 |
| 【上屏】 | 引文／数据／地图标题等需要上屏的内容，注明出处 | 文字浮现，旁白同步翻译 |
| （顿） | 设计好的停顿位（炸点后、动情点后、句间短顿） | 前停顿 200-300ms |
| （沉默 X 秒） | 动情点后留白 | 画面空镜/地图，无旁白 X 秒 |
| （地图留白 X 秒） | 地图动画节点，旁白主动让位 | 画面切换地图，旁白暂停 X 秒 |
| > 声口对齐 | 写作层自查标记，标注本段应向哪个声口对齐 | 最终输出删除 |

**v3.1 新增标记说明：**

### （顿）—— 句间短顿

使用场景：
- 句与句之间的自然呼吸
- 信息点切换时的短暂停顿
- 炸点前蓄力

画本层处理：前停顿 200-300ms

示例：
```
约公元前11世纪，（顿）
岐山之下的周原，（顿）
一个男婴出生在王族深宫。（顿）
```

### （沉默 X 秒）—— 动情点后留白

使用场景：
- 动情点事实堆叠后的沉默
- 重大转折后的呼吸空间
- 结尾悬停前的停顿

画本层处理：画面空镜或地图，无旁白 X 秒

示例：
```
祈祷完毕，他把祝文封进金縢之匮，锁进密室，叮嘱左右：（顿）
"不许说出去。"（顿）

（沉默 2 秒）

第二天，武王的病竟然好转了。（顿）
```

### （地图留白 X 秒）—— 地图镜头

使用场景：
- 空间转换时
- 战役/行军路线展示时
- 朝代疆域变化时

画本层处理：画面切换地图，旁白暂停 X 秒

示例：
```
周军势如破竹，从牧野直抵朝歌。（地图留白 3 秒）
纣王退回朝歌，自焚于鹿台。（顿）
```

### > 声口对齐 —— 写作层自查标记

使用场景：
- 每段开头标注本段应向哪个声口对齐
- 温度切换处标注新温度
- 动情点处标注克制纪律

画本层处理：最终输出删除，不进入配音稿

示例：
```
> 声口对齐：温和、克制、建立画面（冷）

【段1·钩子】
约公元前11世纪，（顿）
岐山之下的周原，（顿）
一个男婴出生在王族深宫。（顿）
```

## 格式纪律

1. 每段必须以 `【段N·功能类型】` 开头
2. 引文必须用 `【上屏】` 标记，注明出处
3. 停顿标记必须紧跟在句末标点之后
4. 留白标记必须单独成行
5. 声口对齐标记必须在段首，最终输出删除
6. 全稿无总结段，以事实闭环或史料未载收束
