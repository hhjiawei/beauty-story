# 写作层自查清单（Step 7，全绿才交稿）

> 本文件为 SKILL.md 的参考文档，按需加载。包含：结构对齐、听觉纪律、史实与人格、杜茹慧风格四大模块的自查项。
> v3.1 新增：杜茹慧风格模块（温度、声口、外号、焊接、动情点、人称、留白等11项）。

---

## 结构对齐（查施工合规）

- [ ] 每段段号与大纲一一对应，无缺段、无加段
- [ ] 每段功能类型与大纲一致，无功能漂移
- [ ] 每段字数在分级容差内（钩子/收尾 ±40%，主线/插件 ±20%，过渡段只查上限）
- [ ] 指定技法全部落实，落实方式与 `references/technique-table.md` 一致；主备切换的段已在备注声明
- [ ] 炸点位置、类型与大纲一致；每个炸点可对回史料卡；短句鼓点只在炸点窗口内
- [ ] 伏笔登记表逐条核对：埋的都在、收的都收了、盖牌全掀
- [ ] 动情点已施工，处理克制（先事实后情）
- [ ] 收尾段：先落点后金句，80% 分量在最后 30 秒，开场片段已归位

---

## 听觉纪律（查语言质量）

- [ ] 朗读测试已完成：无读不顺的句子、无一口气读不完的长句
- [ ] 一句一个信息抽查 5 段：无从句套从句
- [ ] 强调词在句尾抽查 3 处
- [ ] 每 60 秒有一个信息增量**或情绪增量**（成戏段按情绪增量判定；全程模拟听众逐分钟自查）
- [ ] 名字管理：每个 30–60 秒单元内新名字 ≤2
- [ ] 大数字全部先换算后报数
- [ ] 零信息量感慨句扫描为零（令人深思／历史的尘埃／人性的复杂……）
- [ ] 过渡套话扫描为零（话说回来／言归正传／与此同时／镜头来到）

---

## 史实与人格（查红线）

- [ ] 全文事实逐条可对回事件卡，无卡外事实
- [ ] 推测全部挂标记；歧义事件无独断句式
- [ ] 引文逐字核到原始出处，书名号、出处标注齐全
- [ ] AI 腔禁词全文扫描为零
- [ ] 第一人称出场均有功能性，无自我展览
- [ ] 梗与史实无冲突；动情点前后 30 秒无玩梗
- [ ] 类比均有"精度还回"句，全片 ≤2 处

---

## 杜茹慧风格（v3.1 新增，全绿才交稿）

- [ ] **温度统一**：全篇温度一致（冷/温/热），无段落间跳跃。温度切换处有明确节点标记
- [ ] **声口样句对齐**：朗读测试通过，3句定调句已写且通过人格禁忌扫描
- [ ] **外号锚点正确**：嘴维度使用外号，骨维度回归正式称谓；外号贴合命运内核，非侮辱性；全篇统一
- [ ] **焊接三步法完整**：现代类比 → 史料原文 → 自嘲/共情收尾，每组最小叙事单元完整
- [ ] **查证透明化**：史料争议处版本陈列（≥2个来源）→ 倾向声明（附理由）→ 保留开放
- [ ] **动情点克制**：先落事实后落情；事实堆叠，无形容词；动情点后有留白标记（沉默X秒）；禁止总结句
- [ ] **无膈应话术**：全文扫描"你懂吗/我不猜/你们想想/说白了/我XX你XX"等，出现一处→标黄
- [ ] **人称分布合规**："咱们"60%、"我"15%、"你"15%、"他"10%；"你"只邀请不命令，"我"只查证不观点
- [ ] **每句话≤25字**：抽查5段，超过25字的句子已拆句；从句套从句全部拆开
- [ ] **结尾悬停**：无余味、无总结、无价值判断；三选一（事实闭环/史料未载/数字收束）；最后一句平淡
- [ ] **个体语言记忆**：全片"有伤疤"的语言痕迹≥3处（口头禅、个人节奏、情绪溢出）
- [ ] **史料空白诗意化**：全片史料空白处理点≥2处（"史料没写，我不猜"/"大概"+场景/版本陈列）

以上四大模块全绿，方可交稿。
