## 4.0 篇型差异速查表（本层仅有的篇型相关条款）

| 施工面 | 人物篇（情绪驱动） | 朝代篇（因果驱动） | 事件篇（张力驱动） |
|--------|-------------------|-------------------|-------------------|
| 观众在追什么 | "这个人后来怎么样了" | "事情怎么会变成这样" | "这场仗怎么输的" |
| 节点间缝合（Step 4） | **命运感缝合**：接口句回答"这一步把他推向了哪"，允许带克制的回望感（"他还不知道，这一步已经回不了头了"） | **因果缝合**：接口句回答"为什么会走到这一步"，禁用"然后……然后……" | **势局缝合**：接口句回答"局势怎么从优势变劣势的" |
| 高潮段（4.5） | 弧光顶点：命运高潮，双线渲染偏"他多想成／有多难成" | 冲突顶点：决战／决定性事件，双线渲染偏"牌面悬殊／约束条件" | 张力顶点：决策瞬间／逆转时刻，双线渲染偏"信息不对称／心理博弈" |
| 收尾段（4.6） | 弧光闭合·盖棺：与开场形象的落差唏嘘 | 结局落定：呼应开头片段，朝代教人的一件事（提炼不出则只留唏嘘） | 结果落定：数字收束，反差量化自动产生唏嘘 |
| 动情点常见落点 | 弧光顶点或收尾；小人物瞬间优先 | 战役／徭役／灾荒节点；被变革碾过的小人物 | 战后崩溃／大势已去；决策者的无力感 |
| 名字管理 | 外号弹药可用时高频顶替本名 | 势力名顶替人名（"商国那边"而非连续报臣子名） | 决策者用外号，对手功能化 |
| **温度（v3.1 新增）** | **冷**（悲悯）为主，极少热 | 阶段切换（热→温→冷） | 温→冷（理性→苍凉） |
| **声口特征（v3.1 新增）** | "史料没写，我不猜" | "就像一锅煮糊了的粥" | "咱们算一下" |

## 4.1 钩子段（0–15 秒）

- **第一句即炸**：不铺垫、不报幕、不寒暄。禁止"大家好""今天给大家讲""在中国历史上"三类开场腔。
- 施工选型按大纲指定（反常切片／反差量化／名场面前置／颠覆细节／外号定格式／命运压缩句等），写法要求统一：**一个具体的人＋一个具体的反常处境**，不是抽象悬念。
- 名场面前置的施工纪律：前置的是**矛盾最激烈的一帧**（画面），不是信息最全的一段——给结果和冲突，藏过程和原因。
- 钩子段结尾必须留下一个"观众此刻最想知道的问题"，锚定段不许回答它。

**v3.1 新增：诊断结论前置（人物篇/事件篇默认钩子）**

- **定义**：先把人物一生的"总评"或事件的"总评"砸在观众脸上，再回头讲"怎么走到这一步的"。
- **公式**："很难想象，一个______的人/国家，最终______。"
- **纪律**：
  - 诊断结论必须包含**反差**（辉煌vs苍凉、能力vs结局、数字vs结果）
  - 诊断结论里可以埋**外号锚点**（如"周家老四"）
  - 诊断结论后必须立刻**回头讲起点**，不能空泛抒情
  - 人物篇示例："慕容垂13岁开始打仗，打到70岁。咱们算一下，57年，半个多世纪。一个人有多少个57年？他这辈子只干了一件事——打仗。但打完仗，他发现没地方可去了。"
  - 事件篇示例："很难想象，一个曾经一度有希望带领中国走出乱世的国家，居然会在一场战争失利后不到两年就走向国破家亡。"

## 4.2 锚定段（15–30 秒）

- **三句以内**交代：谁／什么时候／在什么地方。三句之外的信息一个不许有。
- 锚定是回落蓄力段，情绪坐标必须真的落下来——钩子在高位起跳，锚定段语速、句式、信息密度整体放缓，给后面留落差。
- 锚定段末句回到时间线起点，完成交棒。

**v3.1 新增：锚定段电影分镜式施工**

```
时间码 + 场景定位 + 主体动作 = 三个短句或半句

示例：
"约公元前11世纪，（时间码）
岐山之下的周原，（场景定位）
一个男婴出生在王族深宫。"（主体动作）
```

## 4.3 主线节点段

按大纲分级三种施工规格：

| 分级 | 施工规格 | 写法 |
|------|----------|------|
| 强化节点 | 成戏 | **决策瞬间替换法**：不概述"他做了什么决定"，写决定落地前的那一刻——约束条件摆出来，可选项摆出来，选择落地。有场景、有动作、有对话（对话必须有史料依据） |
| 关键节点 | 细讲不成戏 | 因果链讲清，动词驱动，3–6 句收束 |
| 过渡节点 | 一句话 | 只交代"时间过了多久、位置移到了哪、局势变了什么"三要素中变化的那个，绝不多写 |

- 节点内部的背景纪律沿用大纲层：**背景不许单独成段，用动作带出来**。制度、格局信息织在具体的人做事的过程里。
- 每个节点收尾自问：本段的信息增量是什么？答不出的段退回压缩。

**v3.1 新增：命运阶段施工纪律（人物篇）**

人物篇强化节点施工时，必须对照大纲"命运阶段"标签调整声口：

| 命运阶段 | 情感坐标 | 语速/句式 | 施工要点 |
|---------|---------|----------|---------|
| 少年XX/起点 | 高位起跳·明亮 | 稍快，短句为主 | 建立"这个人本来可以……"的期待 |
| 中年XX/转折 | 回落蓄力·压抑 | 放缓，中长句铺开 | 制造落差，积蓄张力 |
| 老年XX/挣扎 | 二次起跳·悲壮 | 变速，先抑后扬 | 不服输，但时代/身体已变 |
| XX之殇/崩塌 | 峰顶坠落·剧痛 | 短句鼓点，动词拉满 | 动作链，不塞新信息 |
| 死在XX/终局 | 谷底·苍凉 | 极慢，事实堆叠 | 无形容词，留白标记 |
| （留白） | 留白·余味 | 沉默/停顿 | 不总结，让事实落地 |

## 4.4 插件段

- 插件是"暂停主线挂装备"，进插件前主线必须停在一个**观众愿意等你回来**的位置（悬念半空中，不是事讲完了）。
- 各插件写法按弹药库施工要点执行（见 `references/technique-table.md`），写作层只加一条统一纪律：**插件段开场第一句就要让观众知道这段好看**，不许用"这里需要解释一下背景"开场。
- 插件段结束必须落回主线，落回句自带信息量（顺手交代主线此刻的状态），不许"好，我们继续讲"。

**v3.1 新增：情绪透气口插件**

```
公式："我想先停下来，跟你说一件有意思的事——"

功能：信息密集后的换气，把学术争议包装成闲聊
纪律：
- 每10分钟至少一个透气口
- 透气口后必须立刻回到主线
- 透气口内容必须是"有意思的事"（史料争议、反常识细节），不是废话
```

## 4.5 高潮段（弧光顶点／冲突顶点）

- 高潮段是全片唯一允许"全力以赴"的段落：欲望与阻碍双线拉满、短句鼓点起爆、盖牌掀开按大纲指定组合使用。
- **短句鼓点施工法**：高潮落地的约 30 秒窗口，长句全部砍短，一句一个动作，动词密度拉满；鼓点段**不塞新信息**——只用观众已知的材料，高速重放。
- 高潮前检查弹药库第 9 号工序：看懂这个高潮需要的全部前置知识，是否都已在前面无痕埋好？缺一件，本段炸不响，退回大纲层补埋。

**v3.1 新增：高潮段查证透明化**

```
高潮段如涉及史料争议，必须在高潮前或高潮后插入查证透明化：

公式："关于______，我查了三本书，说法不一样。
《____》说____，《____》说____，现代学者认为____。
咱们按最保守的算，也是____。但____，输了/死了/亡了。"

纪律：
- 查证透明化不破坏高潮节奏，可放在高潮前作为蓄力，或高潮后作为余波
- 倾向声明必须给出理由（"因为《晋书》成书更早"）
- 保留开放（"但你可以有自己的判断"）
```

## 4.6 收尾段

- 施工顺序写死：**先落点，后金句**——先把结局的事实落定（人怎么死的、国怎么亡的、东西留在哪），再出金句位。顺序反了就是煽情。
- **80% 分量压最后 30 秒**：全片最重的金句／翻转／唏嘘，只允许出现在最后 30 秒窗口；前面写得再好，收尾塌了全片白干。
- 呼应开场：大纲"结尾呼应什么"字段指定的片段在此归位——前置的名场面还另一半，开场的形象拎出来对照。呼应**只摆事实不解释**，唏嘘由落差自动产生。
- 动情点收尾纪律：克制。情从史实里长出来，旁白不喊出来。最后三句不许出现"让我们""值得我们""不禁"起头的感慨句。

**v3.1 新增：悬停收束法**

```
收尾段禁止：
- "他的一生告诉我们……"式总结
- "让我们把时间拨回"式号召
- "不禁让人深思"式感慨
- "这就是历史的魅力"式升华

收尾段三选一：
1. 事实闭环：回扣开头钩子，只摆事实不解释
   例："这个排行第四的王子，一辈子都在'替别人守着'。"

2. 史料未载："史料没写____。所以，我也不猜。"
   例："史料没写他有没有后悔过。所以，我也不猜。"

3. 数字收束：三个时间点+总跨度，无形容词
   例："290年司马炎死→291年八王之乱→316年西晋亡，26年。"

最后一句必须是平淡的："咱们下期见。"（无预告，无悬念）
```

## 4.7 衔接段（承上启下，可选）

- 有下集才写，一句话：本集的果如何变成下集的因。不超过两句，不预告剧情细节。

**v3.1 新增：朝代篇伏笔接力**

```
朝代篇单集结尾必须埋设下一集伏笔：

公式："上一集的果 → 下一集的因"

示例：
"上一集我们讲到司马炎统一三国，建立了西晋。这一集，他的孙子司马衷登基，一个智商有问题的皇帝，坐在了天下最高的位置上。"

纪律：
- 伏笔必须具体（人名/事件/时间），不能空泛
- 伏笔必须在下集开头回收
- 全系列伏笔登记表由大纲层维护
```
