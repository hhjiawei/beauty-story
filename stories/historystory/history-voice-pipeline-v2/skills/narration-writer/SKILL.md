# 旁白成稿写作（纯写作层 · 裸稿）

## 0. 节点边界

**输入**：完整大纲（篇级总卡+段落表，每段开头标注【段N·相位】，情绪坐标列由大纲节点产出）+ 资料卡包 + 前一章末段（逐章施工时）。
**输出**：逐章施工产出 JSON（本章正文/本章钩子台账/施工异议）；全稿缝合产出 JSON（成稿/自查清单）。

**弹药分工（2026-09-18 工序重排：弹药装配已整体上移至下游节点，本节点产裸稿）**：

- 弹药挂载点识别、弹药自造、热梗检索 → 全部归 `../style-library/`（下游装配节点消费**本节点产出的成稿**，在句级安装弹药）；
- 本节点**不装一发弹药、不预留弹药位**：写作时任何「弹药清单」字段都不存在，也不得为了日后好挂弹而写生硬的占位表达。修辞克制即美德——裸稿阶段把结构（段间咬合/欠条链）、事实（史料双保险）、情绪（照段落表情绪坐标兑现）、声口（绰号/称呼策略）四件事做扎实；
- 反讽结构、心理OS、场景脑补等**结构性技法**仍属本节点（它们是表达骨架不是贴上去的弹）。

**红线**：不捏造核心史实。脑补只能落在史书留白处（怎么想、怎么对峙的画面），史实骨架（时间、人名、事件、结果）一处不许改。

# 一、声音与基调：写得有趣的底层设定

> 本章是**知识层**——只定义标准，不产生动作。由第七章各阶段显式调用（调用关系见第七章总表）。

## 1.1 写给"听"，不是写给"看"

- 句子短，口语化断句："苻坚极为孝顺，与兄长的情感深厚。面对苟夫人的命令，苻坚无所适从。" 短句自带节奏感和停顿，适合一口气讲下来。
- 单句信息量低：一个镜头只讲一件事，绝不在一句话里塞两个信息点。强调词放句尾；大数字先换算成体感再抛出。
- 有"现场感"的口语连接词："话说回来""但话又说回来""就这样""结果没成想""咱也不知道""可以说""不得不说"。这些词没有实际意义，但它们是"呼吸"，让讲述有语气。**同一连接词每篇≤3次**，超了即口头禅污染。

## 1.2 叙事策略：把史书翻译成"戏"

史料往往只有一句话（《晋书》可能只记"垂至邺，丕疑之"）。写作层的任务是补全画面、心理和对白：
"苻丕听说慕容垂北上，内心是惊疑不定：一方面……但另一方面……苻丕开始本想二话不说直接杀了慕容垂……结果也被慕容垂以'不宜轻举妄动'给拒绝了。就这样麻杆打狼两头怕的苻丕和慕容垂，在虚伪的礼节和欢迎之下，共同进入了邺城。"
拆解这套手法：

- **给人物加内心戏**："内心是惊疑不定""心里就有些五味杂陈了"。史书不记心理，讲述者替你脑补出来，人物就活了。（脑补纪律见 generation-rules 第六节四铁律：不改骨架、符合物理、符合人性、挂声明牌）
- **制造两难和对立**："一方面……但另一方面……"——几乎所有关键决策都用两难结构呈现，悬念天然存在。
- **提炼一个精准的画面比喻**："麻杆打狼两头怕""卧榻之侧睡了蛟龙猛虎"——把复杂局势压缩成一个具象画面，观众一秒记住。
- **引用对白原文但翻译成白话**：苻登哭营、姚苌祷告那段，几乎把史书对白直接搬来当台词，戏剧张力拉满。（对话演绎的落位与密度见 mount-point-rules P08）

## 1.3 情绪与立场：做一个"有态度的讲述者"

评论和叙事比例约三七开，评论极其情绪化、人格化：

- **人设标签化**：先给人贴一个炸裂的标签再展开叙述。"没有下限就能胜利""教科书级别的金蝉脱壳""苻坚灵魂食用者"。
- **爱憎极其鲜明**："姚苌这种又无能又无耻又卑鄙的小人，也算得上是世俗罕见，可以进博物馆那种罕见。"不怕观点极端，怕的是没观点。
- **夹叙夹议，随时下判词**：讲完事件立刻跟一句定性。先给结果，再给评价，观众情绪始终被牵着走。
- 每讲完一段史实，强迫自己写一句"判词"——它可以偏激、可以俗，但必须是你自己的态度。

## 1.4 语域分层：梗不进正文

- 讲正史情节时用古意，插科打诨时用网感，两种语域分层清晰。
- 现代梗只用于评论和类比层，**从不污染叙事正文**。原文引用配白话翻译时，梗只落翻译层、不动原文。
- 降维词、热梗的选型与密度上限见 mount-point-rules 武器库表与 generation-rules 三级弹药（上游 N2 已把关，写作层执行密度纪律）。

## 1.5 节奏控制：波浪式推进

- **悬念前置**：开头永远抛一个问题或冲突。第一句就定情绪、勾好奇。
- **一波三折**：每个事件至少反转两次。苻丕杀慕容垂→被劝住→慕容垂拜庙→又不杀→石越哀叹。
- **快慢交替**：大战前故意慢下来写细节（参合陂之夜拓跋珪的沉思），开打时突然加速："这是一次单方面的屠杀。2万魏军从小山坡的顶峰向下飞驰……"
- **章回式钩子**：结尾必留悬念。"那就是下一期的故事""刘裕能从容应对吗"。

## 1.6 细节特写与情感爆破点

用具体感官细节（土色、白骨、哭声）替代抽象抒情。悲伤不写"悲"，写吐血；恐惧不写"怕"，写"整夜整夜被吓得难以入睡"。

## 1.7 预期违背式造句

- **来源**：预期违背的四种可复用句式（歇后语体/废话回环/举重若轻/对仗落差），原理是前半句把预期引向A，后半句落在-A或绕回原点。
- **纪律**：每种句式每期≤2处；句式是调味料不是主菜。

# 二、灵气三律

> 知识层，同第一章。

灵气 = "情感共振" × "陌生化" ÷ "陈词滥调"。三条律各配一道写作工序，落地为可执行动作。

## 2.1 准确律：不是找比喻，是找"唯一的那个词"

准确的检验标准：**删掉这个比喻，信息会缺损**。

- "麻杆打狼两头怕"好，不是因为它俏皮，而是它同时说清了三个事实：双方都怕、谁也不敢先动、局面滑稽。
- "可以进博物馆那种罕见"好，因为"罕见"被拖到了一个具体的参照系里，侮辱完成了升级。
- 工序：**每段写完问一句——这段的灵魂是什么？能不能用一个名词或动词钉死？** 钉不死，重写。
- 正面示范："姚苌拖着60岁的身躯，每天不是四处救火就是身犯险境。"——"救火"两个字同时说出了忙碌、狼狈、被动，比"疲于奔命"准。
- 反面对照："姚苌晚年四处征战，十分辛苦。"——空转，删掉无损失。

## 2.2 陌生化律：不是修辞新奇，是视角与切入顺序的换位

历史观众对熟知段落已有预期，陌生化就是打破预期。四种手法（优先用前两种，成本最低）：

1. **换视角**：所有人写淝水写苻坚，你写那座被江南百姓叫"氐富山"的关押俘虏的山——一个脚注细节，比百万大军溃败更让人心里一沉。
2. **重新对焦**：参合陂不写慕容宝怎么蠢，写"25年前他就是在这儿降生的"——同一个战场，从命运的角度再看一遍。
3. **反序切入**：把最怪诞的细节提到最前面（苻坚篇先讲背上写着"草付臣又土王咸阳"），历史瞬间变成陌生世界。
4. **小人物入镜**："士卒的妻子女儿全部抓起来赏给手下"，比"百姓苦不堪言"共振强十倍——群体是统计，个人是命运。

- 纪律：每篇陌生化≤2处（密度上限见 mount-point-rules），多了观众跟不上；目标是"愣住然后会心"，不是"没听懂"。

## 2.3 共振律：让观众的心跟着人物跳一下

- **时间重量**：把数字换成人生——"慕容垂57岁了，天下的英雄，高句丽、宇文部、段部、冉魏，再加上一个桓温，哪一个我没打过？"
- **命运对照**：A的年龄/处境 vs B的年龄/处境放在一句里（52岁的苻登 vs 29岁的姚兴）。
- **延迟兑现的悲伤**：先铺日常，再砸结局（慕容垂"战神"铺垫整集，结尾一头栽倒在参合陂）。
- 工序：**每段标注一个情绪目标**（炸/悲/燃/讽/缓，照施工卡「情绪坐标」），写完后检查——本段的情绪目标兑现了吗？用哪个细节兑现的？答不出＝本段白写。

# 三、弹药焊接术（已上移至下游装配节点，本章仅存档备查）

> **2026-09-18 工序重排**：弹药装配已整体上移至下游节点（style-library 消费本节点产出的**成稿**做句级装弹）。本章原"弹药投放"引擎不再在本节点执行——本节点产**裸稿**，写作时弹药一律不碰、不预留弹药位。以下内容保留为知识层，供理解下游装配逻辑与自检对照使用。

上游传入的弹药是散件：一句话标签、一个比喻、一个梗、一条歇后语。焊接的好坏直接决定成片质感——零件直接镶进正文会显得拼贴感重，下游装配层的价值就是把拼贴感洗掉。

## 3.1 位置三原则

- **判词放在事件结果之后**，不前置泄气。
- **画面比喻放在局势最复杂处**，负责"一秒说清"。
- **梗放在情绪低点之后当呼吸口**，不在炸点处抢戏。

## 3.2 形态转换与抽走测验

大纲给"狗皮膏药"三个字，正文要扩成"苻登就像是一块狗皮膏药，缠上姚苌就不走了"——**让比喻长在句子里，不是贴上去**。
**抽走测验**：把弹药抽走，句子应该残废；句子完好说明是贴的，改写形态让它长进句子里；句子残废但读起来别扭，说明焊接处需要垫连接。

## 3.3 密度纪律（下游装配层执行权）

- 装配报告/台账里标注的密度上限（每类弹药每期≤N处）由下游装配层把关，机检 check_ammunition.py 落地。
- **宁可弃弹，不堆弹**：弃用不叫浪费，硬塞才叫。
- 弹药打架时按 mount-point-rules 的互斥对与降级链条执行。

## 3.4 职责边界（工序重排后）

- **本节点**：产裸稿——结构（段间咬合/欠条链）、事实（史料双保险）、情绪（照段落表情绪坐标兑现）、声口（绰号/称呼策略）四件事做扎实；反讽结构、心理OS、场景脑补等结构性技法仍在本节点。
- **下游装配节点**：消费裸稿做句级装弹（筛句→选弹→安装→复检），抽走测验在那里执行。
- 原因：先想好笑的词再找史实硬贴＝穿帮；造弹是装配层「先支撑后弹药」工序的专属权力，两道工序分离后各管各的验收。

# 四、峰值克制与动情点红线

> 知识层（禁区清单），同第一章。

- 抖包袱的反面不是不抖，是**在最该安静的地方安静下来**。慕容垂经过参合陂看到白骨、大军嚎哭那段几乎没有任何网感修饰，全是白描——那是全集最重的几行字。
- **动情点前后30秒禁梗、禁降维、禁方言、禁反讽**（详见 mount-point-rules P18）。
- 进入悲悯轨后不回跳攻击轨：换挡声明（E6）之后，语域保持悲悯到段尾。
- 悲剧段落加速的写法：越惨的地方句子越短、越白。"1万5千名燕军或死于屠杀，或死于践踏，或溺死于河中。"——不加一个形容词。

# 五、陈词滥调黑名单（灵气自检的检查表）

> 知识层（检查表），同第一章。

命中即改。黑名单是开放的，写作中遇到新的"万金油表达"随时补录。

| 黑名单              | 问题           | 替换思路                     |
| ------------------- | -------------- | ---------------------------- |
| 不禁让人感叹/唏嘘   | 讲述者偷懒退场 | 讲述者亲自下场感叹，或删     |
| 可想而知            | 把想象空间掐死 | 把"想"的画面写出来           |
| 那叫一个惨/非常悲痛 | 形容词空转     | 给一个具体数字或细节         |
| 历史总是惊人的相似  | 万金油         | 指出具体哪里相似，相似才成立 |
| 可歌可泣            | 无信息量       | 写"可歌"的那个动作           |
| 冥冥之中自有天意    | 偷懒的宿命论   | 写一个具体的征兆细节         |
| 震惊/震惊了         | 标题党残留     | 删掉，用事件本身吓人         |
| 就这样，……了        | 高频流水句     | 每篇≤3次，超了换具体动词     |

替换示范（同一史实，左坏右好）：

- 坏："苻丕得知慕容垂到来后非常疑虑，不知如何是好。" → 好："苻丕听说慕容垂北上，内心是惊疑不定：一方面……但另一方面……"
- 坏："这场战役非常惨烈，燕军死伤无数。" → 好："1万5千名燕军或死于屠杀，或死于践踏，或溺死于河中，剩下的5万人全部被俘。"
- 坏："慕容垂悲痛万分，一病不起。" → 好："在撕心裂肺的哭声当中，慕容垂大口大口地吐血，直到一头栽倒在当场。"

# 六、成稿格式与标注规范

> 知识层（成稿硬格式），施工与缝合时逐条执行。

- **段标**：每段正文开头标 `【段N·功能类型】`，与大纲一一对应，无遗漏。
- **声音/画面标注**：（顿）标停顿位；【上屏】标引文上屏；（地图留白 X 秒）标地图节点。标注只加不改措辞。
- **时间双标**：新时间点一律年号+公元双标（如"太元八年（383年）"）。
- **原文引用**：古文原句照录不动，必配白话翻译；梗只落翻译层。
- **F/I/T 纪律**：施工卡标【I｜推断】的心理动机按声明牌纪律外显（"或许/可以想象/估计"），不把 I 写成 F；【T｜理论透镜】表述只落反转段，不把 T 写成事实断言；宏大判断必须有 D 卡数字或原文托底。
- **称呼策略**：朝代/政权称呼随语境自然换用，全篇多样；**禁用全篇统一的"我X"领属词自称**（以篇级总卡「声音素材」为准）。
- **零广告**：剥离一切广告植入痕迹。

| 六 成稿格式   |    取证纪律     | 声音素材落格式 |         随写随标          | **双保险复核＋组装**  |

**阶段零 读料取证**　【仅"含第1段的章"执行；调用：0红线、六】

动笔前：通读本章施工卡引用的全部资料卡。按篇级总卡「驱动分型＋结构选型」定调；对施工卡弹药清单逐条斟酌预判，与史实或声口明显不合的预先标记（阶段二处理）。

**阶段一 声音卡定稿**　【仅首章执行，后续章沿用；调用：1.3、六】

声音卡由本节点自建定稿：绰号—特征—事迹对照依史实自定（后续章节不换）；签名句式只服务节奏不承担事实；
朝代称呼策略按第六章规范锁定。后续章节与前一章末段声口对齐，不另起炉灶、不中途改称呼策略。

**阶段二 逐段施工**　【调用：1.1–1.6、二、四；每段完稿后灵气自检——**写裸稿，弹药一律不碰**】

每段过三道引擎，顺序执行：

1. **心理OS与场景脑补**（→1.2、四）：只填史书留白，不改史实骨架，必挂声明牌"或许/可以想象/估计"。隔离带内按第四章：白描、零梗、句子越短越白。
2. **反讽结构**（→1.7）：材料有真实"自信→翻车"弧线才用；搭靶用当事人信息集铺到最足，亮锤最短、不加评论，锤长≤靶长1/5；搭靶段保持克制不泄压。
3. **段间咬合三问**（→段落表「引出方式＋段尾欠条」）：本段凭引出方式承接上段什么／本段欠条留了什么给下段／与下段怎么咬合——三问答不出，回炉。

每段完稿后**灵气自检**（→二、五）：①黑名单逐句扫描，命中即改；②准确律——这段的灵魂钉死了吗？删掉比喻信息会缺损吗？③情绪目标（照段落表「情绪坐标」）兑现了吗，用哪个细节兑现的？

**阶段三 全稿缝合**　【调用：六、二、四；对应旧工序的朗读/红线/冷读】

1. **缝合**：逐接口检查——上一段的余震引出下一段的地震；插件进出用挂接句，禁用过渡套话；绰号全篇统一（以阶段一声音卡为准）。
2. **朗读测试**（→1.1）：拆读不顺、一口气读不完的句子；每60秒查信息/情绪增量。
3. **史料双保险复核**（→六）：年号+公元双标无遗漏；原文引用配白话翻译；宏大判断有数字/原文托底；反常处证据链≥2条，孤证只写"存疑"。
4. **逻辑核销**：各章钩子台账逐条核销——埋钩必兑现，兑现不了删钩改平实表述；设问必已回答；意外转折已补"能接住意外靠的是……"；决策现场未混入后见之明；收尾回扣开头，单集逻辑闭环。
5. **情绪质检**（→四）：对照段落表「情绪坐标」扫悲悯轨；轨道切换过渡句；动情点隔离区。
6. **灵气质检＋成稿组装**（→二、五）：黑名单全文逐句扫描零命中；连接词与"就这样"每篇≤3；陌生化≤2；**删无感句**——凡是"当时觉得好、现在无感"的比喻，按准确律重审，不准就删（本层无弹药，修辞克制即美德，弹药装配归下游节点）。段标/（顿）/【上屏】/地图留白按格式收齐，广告痕迹全部剥离。

## 出口硬闸门（必过）

成稿与大纲分别写入文件后运行校验脚本，FAIL 项回到对应段落重写后复检，全绿才可交付：

python3 /skills/narration-writer/scripts/check_output.py <成稿.txt> --outline <大纲.txt>

# 八、自检清单（阶段三·6 与硬闸门使用）

**机检项（归 check_output.py，脚本未覆盖前由阶段三·6人工核查）**：

- [ ] 每段开头有【段N·相位】标注，与大纲段落表一一对应，无遗漏
- [ ] 史实钉子（时间/人名/事件/结果）与大纲一致；新时间点年号+公元双标无遗漏
- [ ] 脑补处全部挂了"或许/可以想象/估计"式声明；推断未写成事实断言
- [ ] 每种预期违背句式≤2处；同一连接词≤3次；"就这样"≤3次
- [ ] 全稿无弹药占位/硬塞痕迹（裸稿纪律：弹药归下游装配节点）
- [ ] 峰值/动情点30秒隔离带内零梗零降维零方言零反讽

**Agent 自检项（阶段三·6执行，机器判不了"好不好"，只判"有没有"）**：

- [ ] 黑名单逐句扫描零命中
- [ ] 陌生化≤2处且每处成立（"愣住然后会心"，非"没听懂"）
- [ ] 抽走测验：抽走比喻信息缺损（结构性比喻）；无"贴上去"的修辞
- [ ] 每段情绪目标已兑现，且能指出兑现细节
- [ ] 删无感句已完成（比喻类重灾区逐条重审）
- [ ] 全文出声朗读一遍，无拗口长句、无一口气读不完的句子
