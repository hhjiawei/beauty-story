# 爆款历史旁白写作（硬核历史八卦文）

## 节点定位

- **输入**：完整大纲（可附带素材、上期摘要、弹药/引用备选）。
- **输出**：《单集旁白成稿》一份。要求：写作内容依据大纲（每段正文开头标注对应大纲段号，如 `【段3】`）、零语病、零流水句、零逻辑失衡。
- **红线**：不捏造核心史实。脑补只能落在史书留白处（怎么想、怎么对峙的画面），史实骨架（时间、人名、事件、结果）一处不许改。

## 两层分工（重要）

- **本文件（SKILL.md）**：管"怎么写"——基调设定、趣味引擎、施工流程、成稿自检。
- **references/ammunition.md（弹药语料库）**：管"用什么炸"——总纪律、选配五问、**炸点 12 发**、方言 5 发、词汇指纹九类、黑话映射表、绰号/降格/领属词、自造规则。写作时按需取弹，本文件不重复其细则，只在流程节点标注"此处该调哪一发"。

**风格一句话**：正史骨架（史料引用）＋ 血肉填充（心理代入/场景重构）＋ 现代语态（词汇降维）＋ 情绪炸弹（反讽结构与炸点排布）。史料保证不瞎编，后三层负责好看、好懂、好传。手法与朝代无关，可仿写任意朝代。

# 一、声音与基调：写得有趣的底层设定

## 1.1 栏目化骨架（成稿节奏）

整套写作由一套稳定的"栏目化骨架"支撑，六个一级模块**递进排列**（非并列）：

| 序 | 栏目 | 任务 | 典型手法 |
|---|---|---|---|
| 1 | 钩子栏目（开篇） | 制造"观众吓一跳"的打开率 | 血腥/荒诞细节、洋梗对比、设问、极端人设 |
| 2 | 史料铺陈栏目 | 摆出"原著党"姿态，建立可信度 | 引《晋书》《资治通鉴》原文 + 司马光/苏轼/陈寅恪评语 + 诗词 |
| 3 | 现代黑话降维栏目 | 消解严肃感，八卦感主源 | 官职/战略/朝堂 → 职场/游戏/网络热梗 |
| 4 | 心理代入栏目 | 填史书留白，古人变"打工人/老同志" | 内心OS、对话脑补、动作特写 |
| 5 | 反讽/反转结构栏目 | 制造黑色幽默 | 先立"赢麻了"的必胜逻辑靶子，再用真实结局打脸 |
| 6 | 收束栏目 | 留余味 | 主题升华 / 单句钉死 |

**流动关系**：钩子 → 铺陈 →（降维 ∥ 代入，平行填充血肉）→ 反讽收束 → 尾声。
栏目是节奏单位，不是死板分段——一个自然段可以同时承担铺陈+降维两个栏目职能。这套固定骨架保证成稿节奏稳定、可批量复制、与朝代无关。

## 1.2 叙事视角与声音

- **主视角**：上帝全知视角 + 现代网感第一人称混合。制造"主讲人在你耳边唠嗑"的亲密感。
- **打破第四面墙**：直接与观众对话，是签名动作。
  - "咱们猜猜他手底下有没有羌族的士兵呢？"（两晋02）
  - "同学们，那是司马懿的封地啊！"（两晋04）
  - "直接上数据吧。"（两晋02）
- **领属词人格化**：把王朝当自家品牌——"我晋""我大晋""在我晋，有什么值钱的？人命才值钱"。一个系列一个领属词，全篇统一（领属词系统细则见弹药库 §十三）。
- **人物声音化**：给人物配内心独白和台词，偶尔第一人称限知（如黑道大哥自述体），增强沉浸。

## 1.3 语气调性

- **主调**：戏谑、反讽、吃瓜。
- **辅调**：间以温情升华（祖逖中流击楫式的人物弧光）与悲悯（大瘟疫、人口锐减）。
- **暴行处理**：常被喜剧化定格（"率兽食人得到最完整具象化"），但**大规模死亡、文明浩劫走悲悯轨**，此处零梗（悲悯轨细则见 §3.2）。
- **口癖节奏词**："简单来说""说点不好听的""当然了""别喊了""不说了，心累"——口语顿挫，模拟真人唠嗑。

## 1.4 信息密度与节奏

- 节奏公式：**强钩子 — 快铺陈 — 密集梗 — 反转收束**，单位时间信息密度高，服务短视频完播。
- 段长控制：口播稿一段 2–6 句为宜；超过 8 句的段落必须内部有节奏起伏（排比、设问、转折）。
- 句长控制：长短句交错。连续三个长句后给一个短句钉住（"这是一个漫长的故事。""第三，收下当狗。"）。
- 数字轰炸与名单流是合法的节奏武器（细则见 §2.4）。

# 二、趣味引擎库（核心）

## 2.1 开头钩子四模板（含路由选择）

| 模板 | 适用路由 | 样本正例 |
|---|---|---|
| ① 血腥/荒诞细节 | 事件录 | "敛财成为能力的象征，炫富成为高贵的表现，整个社会都在一种病态的追求中沉沦。"（两晋01，排比+荒诞） |
| ② 洋梗对比 | 制度论/人物传 | "如果在法国，你吃不起面包了——我有个高贵的公主会说：'农民吃不起面包？那他们吃奶油蛋糕就不会饿肚子了。'"（两晋04，玛丽王后梗×何不食肉糜同框） |
| ③ 设问破题 | 制度论首选 | "匈奴不是早就被汉帝国的长城决战……给一波带走了吗？怎么突然出现在了河南附近，还跟曹老板打了一架呢？"（两晋02） |
| ④ 极端人设/名场面直击 | 人物传首选 | "哭了又怎样。我们哭的是，大魏朝中不幸出了你这个篡逆恶贼！"（两晋03，曹髦台词开场） |

执行细则：
- 钩子全长 ≤300 字，最后一句必须落在正题入口（"这就是史上有名的'何不食肉糜'的皇帝——孝惠皇帝司马衷"）。
- 洋梗对比要求中外两件事**结构同构**（都是统治者对民间疾苦的离谱回应），不能只蹭热度。
- 设问破题的答案必须构成全文主线，结尾要回扣（回扣检查见 §4.4）。

## 2.2 炸点 12 发：选用索引

炸点全量细则（来源/施工要点/适配/纪律）在**弹药库 §四**，此处只给"什么场景调哪一发"的索引——写作时按索引取弹，细则照弹药库施工。

| 节点场景 | 首选弹药（弹药库 §四编号） | 一句话用途 |
|---|---|---|
| 主线节奏调节 | #2 预期违背式造句、#3 持续造梗、#1 史料原文炸点 | 穿插在节点之间，保持"每3分钟一个炸点"的密度 |
| 战役/政变/命运急转 | #8 短句鼓点、#12 决策现场燃点、#4 荒诞意外 | 炸点落地 30 秒的提速与颅内高潮 |
| 翻盘/逆转节点 | #7 盖牌、#10 欲望与阻碍双线 | 信息分层披露、把弓拉满 |
| 牌面悬殊（兵力/疆域对比） | #11 预判弹幕 | 留半秒空气，让弹幕替你说"卧槽" |
| 人物翻案/争议事件 | #5 认知推翻式反转 | 开头立的误判，此处抽掉（与 #6 高潮前置常配对使用） |
| 名场面前置（高潮前置） | #6 高潮前置·选帧标准 | 只前置矛盾最激烈的一帧，结尾必须归位 |
| 排布总纪律 | #9 多高潮点排布＋类型轮换 | 相邻炸点不同层；密度是上限不是 KPI |

## 2.3 反讽结构（引擎三细则）

**启用条件**：材料里存在真实的"自信→翻车"弧线才用。没有弧线硬造，就是编段子不是讲历史。

**三步搭建**：
1. **搭靶要真诚**：认真摆出当事人视角的必胜逻辑，让观众真心觉得他能赢。靶子越结实，打脸越响。
   - 正例（两晋04）：先用一整段"论个人素质……论长辈评价……论名声……论出身……"的排比，把司马攸堆成完美继承人。这也是"预期违背"原理在结构层的运用——先引观众入 A，再落在 -A。
2. **亮锤要短**：真实结局一句话砸下来，长度 ≤ 搭靶段的 1/5。
   - 正例："——当然，表演归表演。咸熙二年，公元265年，司马昭将晋王爵位传给自己的嫡长子司马炎。"
3. **判词克制**：不解释笑话。一句收住就走（"别喊了，再喊司马炎真要急眼了！"），绝不补"所以这说明……"。

**变体：规律碾压个人**。先立观众的情感期待（"如果刘备诸葛胜利了"），再用结构规律碾过去（改变不了人口锐减、气温下降、大庄园经济、胡马南下四个事实）——"开开玩笑或者骗一骗无涯过客就罢了"。

> 句子层的"预期违背"（歇后语体/废话回环/举重若轻/对仗落差四句式）见弹药库 §四 #2，与本节结构层反讽共用同一原理，一处学两处用。

## 2.4 节奏武器：数字轰炸与名单流

- **编年清单轰炸**：连续罗列年份+事件，不给评论，用密度制造眩晕感，最后一句点睛。
  - 正例（两晋02）："184年，黄巾起义……189年，董卓进京……221年，夷陵之战。"连排十几条后接："请问这一百年的战火的燃料是什么？"
- **排比评估流**："论个人素质……论长辈评价……论出身正统……论个人能力……论人伦孝道……"逐项加码，把读者情绪推到顶点后一句剪断。
- **设问连环**：连续抛问不答，逼观众自己得出离谱结论，再官方确认。
  - 正例（两晋04）："他的其他孩子都死绝了吗？其他孩子里面没有智商超过五十的吗？"

**使用纪律**：三种武器一篇各用 1–2 次为宜；轰炸段之后必须跟一个短句或判词收口。

## 2.5 镜头语言写作法

文本必须"readable as video"——强分镜意识。写作自检：每一段读出来，脑子里能不能出画面？出不了画面的抽象论述段，要么补场景，要么删。

- **特写定格**：高光/残暴瞬间放慢到逐帧。"石崇见了，眼皮都不抬一下，随手用铁如意一棒棒几下就给砸碎了。"
- **对切**：两方立场交替给镜头。石崇杀美人劝酒 ←→ 王敦"还在装犊子" ←→ 王导"强逼自己喝下去" ←→ 王敦"他杀他的奴婢，关我什么事？"
- **蒙太奇**：群像快切收大场面。帝国崩散、军队溃败时用。
- **定格开场**：用一个具体时间+一个画面破题。"初平三年，公元192年。此时还是一位小年轻的曹操……"
- **第一人称限知（变体）**：重大事件可切换当事人第一人称自述，增强沉浸，用毕即还。

## 2.6 心理OS与场景脑补（引擎一细则）

**原理**：史书只记"做了什么"，作者强行补"怎么想的"；史书越克制，脑补空间越大。**选点**：专挑史书的留白动词——X遁、Y卒、Z从之、"大骇""默然""遂许之"。

**写法**：
- 补心理：把阶层/人物的行为翻译成动机。"刚刚走上统治地位的士族门阀阶层，长长地吸了一口气。他们是又窃喜又后怕。"
- 补对话：用人物立场推出他会说的话。曹爽："我认怂了，他答应我，让我回去做个富家翁。"
- 补画面：按物理常识补动作链。史书只记"啖被"级别的事实，画面按生理反应补全——司马师眼珠子被吓掉后"死死地咬住被子，一声不吭。军中大将看到司马师安睡如常，也渐渐定下心来"。
- 补吐槽式旁白：替观众说出心里话。"别喊了，再喊司马炎真要急眼了！"

**铁律四条**（违一条即重写该处）：
1. 不改史实骨架（时间、人名、事件、结果）；
2. 符合物理常识（人受惊会咬被子，不会飞）；
3. 符合人性逻辑（动机要立得住）；
4. 必挂声明牌："或许""可以想象""估计""大概率"——史无明文的心理推测都要挂。

## 2.7 词汇降维与人物声音（黑话系统）

词汇指纹九类与四张黑话映射表（职场/游戏/网络热梗/影视综艺）全量在**弹药库 §六～§十二**，写作时按"位置搭配总规则"取词：称谓替换放主语位、动作能力词放权谋转折处、评价定性词放出场/结局判定处、转折衔接词放反转落点前。

此处只立三条写作时必须执行的规则：

1. **称呼降格**（声音卡原料，全文一致）：皇帝→老板、权臣→话事人、将军→军区领导/保安队长、官职→编制、士族子弟→二代/公子哥、投降部族→养的狗/收下当狗。**只对叙述层降格，史料原文引用内保留原称呼。**（映射表见弹药库 §七）
2. **人物绰号**：绰号=从最炸的事迹反推，绰号—特征—事迹三者对应（司马懿装病骗曹爽→"老影帝"；熬死曹家三代→"老乌龟"）。绰号一经启用写入声音卡，全篇统一；悲悯轨内禁用；一集主角外号 ≤1 个，配角不起外号。（范式表见弹药库 §八）
3. **每个梗必须答得出"它映射哪条史实"**——答不上就删。这是八卦感和瞎编的分界线，也是弹药总纪律第 1 条。

## 2.8 方言场景（声音层花活）

方言是"给古人换乡音"的声音层技法：不改变史实、不改变叙事结构，靠方言自带的喜感与地气制造笑点。五发细则（分配·按籍贯定音 / 自言自语·内心戏外放 / 对手戏·乡音碰撞 / 吐槽位·旁观者碎嘴 / 选型硬过滤）在**弹药库 §五**，此处立使用决策：

- 全片方言 ≤3 处（人物篇 ≤2 处），每处必过弹药库 §五第 5 发的四条硬过滤（非悲情、地域可考、功能明确、密度有余量），任一不满足退回正常旁白音。
- 方言只是"配音"不改台词，台词逐字出自史料或仅译大意；悲情、诀别、殉难场景禁用。
- 一个节点只挂一层花活：方言不与对手戏、古文炸点同段叠加。

# 三、克制与切换：有趣不失可信的分寸

## 3.1 史料引用规范（原著党姿态）

1. **引用三层结构**：原文直引 → 白话翻译 → 吐槽/梗。**梗只落在翻译层，原文一字不动**。
   - 正例（两晋04）："直接上原文：'朝臣咸谓纯质，不能亲政事。'傻子不能说傻，要敬称为'纯质'。"
2. **名家评语作权威背书**：司马光、苏轼、陈寅恪《隋唐制度渊源略论稿》、白居易/辛弃疾诗词，用以托住宏大判断。
3. **时间双标**：新时间点首次出现，年号+公元双标（"咸熙二年，公元265年"）；同段重复出现可省。
4. **数字托底**：宏大判断后必须跟数字或原文（"华夏主体民族人口从五千六百万锐减至一千九百万"）。
5. **争议处挂观点牌**："以下为个人观点""不排除""大概率"，并给出推理链（两晋02 对鲁肃死因的推测是标准范式：先说史料只记病故，再给两条旁证，再下或然结论）。

## 3.2 情绪渲染与悲悯轨切换

**共情/荒诞由心理代入制造；余味由结尾反差制造**：
- 正例（两晋01结尾）："他们是开启乱世的钥匙，也是引领隋唐光明的第一批献祭者。三百年大乱世，开始了。"

**悲悯轨启用场景**：大规模死亡（瘟疫、屠城）、文明浩劫、人物悲剧收束。

**悲悯轨纪律**：
1. 删净全部弹药和绰号；
2. 改白描 + 原文直引（引曹植、曹丕悼亡文字是标准动作）；
3. 进出悲悯轨都要显式过渡句：
   - 进："战争和瘟疫交织成建安二十二年的人间炼狱。"
   - 出（回主调）："太难过了，黑色幽默一下吧。"
4. 悲悯段内允许"黑色幽默"做呼吸口（王粲葬礼学驴叫），但幽默的落点是悲凉，不是笑点。

## 3.3 动情点隔离（总纪律直通）

悲悯轨段落弹药绰号清零；**动情点前后 30 秒不玩梗、不上方言**；悲情、诀别、殉难场景禁用方言。密度上限、类型轮换、一节点一花活等其余弹药纪律见弹药库 §一，施工时逐条自查。

# 四、施工流程（逐段写作怎么走）

```
阶段零 诊断定调 ──→ 阶段一 全局决策 ──→ 阶段二 逐段施工 ──→ 阶段三 收束自检
（不写正文）        （产出两张卡片）      （每段过四道引擎）    （收束四件套+硬闸门）
```

四个阶段按序执行，禁止跳过阶段零直接动笔。

## 4.1 阶段零：诊断定调（不写一个字正文）

1. **读料取证**：通读大纲与素材。
2. **定叙事路由**（三选一，判据一句话：想让观众记住这个人、这件事、还是这个规律？）：
   - **人物传**：命运弧光 + 盖棺定论。起手式用名场面直击或心理独白。
   - **事件录**：编年推进 + 多方博弈。起手式用场景定格或荒诞细节。
   - **制度论**：框架先行 + 层层归因。起手式用设问破题或规律先行。
3. **弹药斟酌**：对照弹药库 §二五问，逐条验证大纲中提到的弹药、引用素材——是否准确？有没有不妥？能否更精炼？不准确的宁可弃用；有缺口的按弹药库 §十四"自造规则"补弹。

## 4.2 阶段一：全局决策（只做一次，全文共享）

产出两张卡片，后续每一段写作都带着它们，防止风格割裂：

**声音卡**：
- 主要人物绰号对照表：按 §2.7 规则 2，绰号—特征—事迹三者对应，从最炸的事迹反推（例：司马懿=老影帝/老乌龟）。
- 称呼降格规则：按 §2.7 规则 1 建表，降格后全文一致，史料原文引用内保留原称呼。
- 领属词：一个系列一个（我晋/我大隋/我大清），全篇统一。

**钩子卡**：按 §2.1 四模板选起手式（路由对照表在 §2.1），300 字以内，最后一句必须落在正题入口。

## 4.3 阶段二：逐段施工（每段固定过四道引擎）

每段正文开头标注大纲段号 `【段N】`。写作时上下文必须携带「声音卡 + 大纲全局 + 前一段结尾 + 已用弹药清单」，否则段间丢人设、丢绰号、情绪断层、埋钩丢失。

**引擎一：心理OS与场景脑补**（细则 §2.6）
专挑史书"只记做了什么、不记怎么想"的留白，补对话、动作、画面、吐槽旁白；铁律四条照章执行，必挂声明牌。

**引擎二：弹药投放（去弹药库取弹，不许凭感觉上弹药）**
每写到一个需要"加料"的节点，按下面三步取弹：
1. **查索引**：按节点场景查 §2.2 索引表 → 定位到弹药库具体弹药（炸点 → 弹药库 §四；方言 → §五，先过第 5 发硬过滤；词汇与黑话 → §六～§十三；造句句式 → §四 #2）。
2. **过五问**：按弹药库 §二走查——功能定位 → 题材适配 → 史料锚点 → 密度轮换 → 兑现能力，任一问答不上就撤弹或换弹。
3. **挂联动**：埋了反常识断言/悬念/盖牌/高潮前置的，记下"埋于哪段、计划在哪兑现"——埋钩必兑现，兑现不了当场撤弹，不许留坑。

**引擎三：反讽结构**（细则 §2.3）
材料里存在真实的"自信→翻车"弧线时才用；搭靶真诚、亮锤短、判词克制。

**引擎四：因果链校验（每段写完必过）**
历史叙事的说服力来自因果，不来自堆料。每段写完回答三问：
1. **这段的因从哪来**——是本段交代的，还是前段结出的果？无因之果段重写；
2. **这段的果落在哪**——论点句后面必须跟着本段内的证据（原文/数字/细节），有论无据段补证据；
3. **和下一段怎么咬合**——本段结尾要么是下一段的因（余震式），要么抛出下一段要答的问（悬念式）。答不上第三问，补过渡句。

**段间衔接**：段与段是流动不是拼接，三种合法衔接：
1. **余震式**：上一段的结局是下一段的引子。"司马昭去世，司马炎承袭了晋王称号……但是并没有。"
2. **悬念式**：段尾抛钩子。"记住这个司马攸，这将是后面一场滔天巨浪的导火索。"
3. **视角切换式**：显式拉镜。"现在我们把目光从匈奴身上放开来，看看中原大地。"

禁用：无过渡硬切话题；"接下来我们讲"式PPT腔（除非刻意玩梗）。

## 4.4 阶段三：收束与自检

**收束四件套按需组合**：总结排比（全文回想）→ 金句/诗文收束（记忆锚点）→ 栏目收尾（悲悯轨禁用搞笑栏目，可用"阴暗小故事"尾声）→ 回扣开头（开头立的问题/误判，结尾必须给出答案或推翻——单集逻辑闭环）。

**成稿自检清单**（逐项过，不过就回炉对应段落）：
- [ ] 大纲段号全覆盖，每段有 `【段N】`；
- [ ] 开头钩子 ≤300 字且落在正题入口；设问已回答、误判已回收；
- [ ] 时间锚定：新时间点年号+公元双标；原文引用配白话翻译，梗只在翻译层；
- [ ] 宏大判断都有数字或原文托底；争议处有观点牌+推理链；
- [ ] 每段过因果三问；埋钩全部兑现；意外转折补了"能接住靠的是……"；决策现场无后见之明；
- [ ] 悲悯轨零梗零绰号、有进出过渡句；动情点前后 30 秒无梗无方言；
- [ ] 弹药密度：词汇黑话 8–15 处、单段 ≤2 处、同词 ≤2 次、相邻炸点不同层、方言 ≤3 处；
- [ ] 领属词、绰号、降格称呼全文统一（以声音卡为准）；
- [ ] 广告植入全部剥离；零语病、零超长流水句。

**出口硬闸门**：以上自检全过后，运行检查脚本，全部通过才可交付；不过闸的项，回到对应段落重写后复检：

```bash
python3 scripts/check_output.py <成稿.txt> --outline <大纲.txt>
```

脚本检查项：大纲段号覆盖、广告词残留、AI腔禁语、声明牌缺失、时间锚定、弹药密度、超长流水句、领属词一致性、收束完整性。

# 五、关键纪律速查

- 取证在动笔前，不在写完后。
- 上弹药过五问：功能定位 → 题材适配 → 史料锚点 → 密度轮换 → 兑现能力；答不上就撤弹。
- 每段过因果三问：因从哪来、果落在哪、和下段怎么咬合；设问必答，埋钩必兑现，意外必补"能接住靠的是……"。
- 脑补必挂声明牌；原文不动，梗只落在翻译层；后见之明不进决策现场。
- 悲悯轨零梗零绰号，切换必补过渡句；动情点前后 30 秒不玩梗不上方言。
- 领属词、绰号全文统一，以声音卡为准。
- 广告植入全部剥离，但可保留其"插入位"作为节奏参考。
- 检查脚本全绿才可交付。
