# 爆款历史旁白写作（硬核历史八卦文）

## 节点定位

- **输入**：完整大纲（可附带素材、上期摘要、弹药/引用备选）。
- **输出**：《单集旁白成稿》一份。要求：逐段对齐大纲（每段正文开头标注对应大纲段号，如 `【段3】`）、零语病、零流水句、零逻辑失衡、剥离一切广告植入。
- **红线**：不捏造核心史实。脑补只能落在史书留白处（怎么想、怎么对峙的画面），史实骨架（时间、人名、事件、结果）一处不许改。

## 风格一句话

正史骨架（史料引用）＋ 血肉填充（心理代入/场景重构）＋ 现代语态（词汇降维）＋ 情绪炸弹（反讽结构）。史料保证不瞎编，后三层负责好看、好懂、好传。手法与朝代无关，可仿写任意朝代。

## 写作流程总览

```
阶段零 诊断定调 ──→ 阶段一 全局决策 ──→ 阶段二 逐段循环施工 ──→ 阶段三 质检收尾
（不写正文）        （产出两张卡片）      （每段过四道引擎）       （双保险+硬闸门）
```

四个阶段必须按序执行，禁止跳过阶段零直接动笔。

---

## 阶段零：诊断定调（不写一个字正文）

1. **读料取证**：通读大纲与素材。对不确定的年份、人名、官职、事件，先联网搜索核实——取证必须发生在动笔前，不是写完再补。
2. **定叙事路由**（三选一，判据一句话：想让观众记住这个人、这件事、还是这个规律？）：
   - **人物传**：命运弧光 + 盖棺定论。起手式用名场面直击或心理独白。
   - **事件录**：编年推进 + 多方博弈。起手式用场景定格或荒诞细节。
   - **制度论**：框架先行 + 层层归因。起手式用设问破题或规律先行。
3. **弹药斟酌**：大纲中提到的弹药、引用素材逐条验证——是否准确？有没有不妥？能否更精炼？不准确的素材宁可弃用，不可硬用。

## 阶段一：全局决策（只做一次，全文共享）

产出两张卡片，后续每一段写作都带着它们，防止风格割裂：

**声音卡**：
- 领属词全文统一（如"我晋""我大隋"，只选一个，全篇不换）。
- 主要人物绰号对照表：绰号—特征—事迹三者对应，从最炸的事迹反推绰号（例：司马懿=老影帝/老乌龟，出自装病骗曹爽、熬死所有人的事迹）。
- 称呼降格规则：皇帝→老板、将军→军区领导/保安队长，但**史料原文引用内保留原称呼**。

**钩子卡**：按路由选起手式，300字以内，最后一句必须落在正题入口。四类钩子模板：
1. 血腥/荒诞细节（制度类慎用）；
2. 洋梗对比（外国典故×中国史实同框）；
3. 设问破题（制度类首选）；
4. 极端人设/伦理炸裂（人物类首选）。

## 阶段二：逐段循环施工（核心循环）

对大纲的每一段，按固定顺序过四道引擎。每段写完，开头标注对应大纲段号 `【段N】`。

**引擎一：心理OS与场景脑补**
专挑史书"只记做了什么、不记怎么想"的留白（X遁、Y卒、Z从之），用现代心理逻辑补对话、动作、画面。铁律四条：
1. 不改史实骨架；
2. 符合物理常识；
3. 符合人性逻辑；
4. 必挂声明牌（"或许""可以想象""估计""以下为个人观点"）。

**引擎二：弹药投放（选配五问，不许凭感觉上弹药）**
每个需要加料的节点，按固定顺序过五问，任一问答不上就撤弹或换弹：
1. **功能定位**：这个位置是开场钩子/炸点/中段插件/动情点/收尾/方言场景/词汇降维？——决定去哪个库取弹；
2. **题材适配**：路由（人物传/事件录/制度论）与时长达标吗？——对照弹药"适配"字段初筛；
3. **史料锚点**：这发弹药映射哪条史实？——答不上就删，撑不起宁可空着；
4. **密度轮换**：查「已有弹药清单」——单段 ≤2 处、同词本篇 ≤2 次、相邻炸点不同型、方言全片 ≤3 处、避让动情点隔离区与悲悯轨；
5. **兑现能力**：埋下反常识断言/悬念/盖牌/高潮前置，立刻登记「钩子台账」（埋钩位置 → 计划兑现位置）；兑现不了＝标题党，当场撤弹。
   
弹药总库见 references/ammunition.md（含五问细则、词汇指纹九类、位置搭配规则）；技法弹 26 发分存 references/opening-hooks.md（开场钩子 9 发，仅开头）、references/explosion-points.md（炸点 12 发，全篇）、references/dialect-ammunition.md（方言 5 发，先过选型硬过滤）。

**引擎三：反讽结构**
只有材料里存在真实的"自信→翻车"弧线时才用。搭靶要真诚（让观众真心觉得他能赢），亮锤要短（不超过搭靶段的 1/5），判词克制、不解释笑话。

**引擎四：因果链校验（每段写完必过）**
历史叙事的说服力来自因果，不来自堆料。每段写完回答三问：
1. **这段的因从哪来**——是本段交代的，还是前段结出的果？无因之果段重写；
2. **这段的果落在哪**——论点句后面必须跟着本段内的证据（原文/数字/细节），有论无据段补证据；
3. **和下一段怎么咬合**——本段结尾要么是下一段的因（余震式），要么抛出下一段要答的问（悬念式）。答不上第三问，补过渡句。

**段间衔接**：段与段是流动不是拼接——用上一段的余震引出下一段的地震。逐段写作时，上下文必须携带「声音卡 + 禁区清单 + 钩子台账 + 大纲全局 + 前一段结尾」，否则段间丢人设、丢绰号、情绪断层、埋钩丢失。

## 阶段三：双保险 + 质检收尾

**史料双保险（可信度）**：
- 锚定：每个新时间点年号+公元双标（"咸熙二年，公元265年"）；每处原文引用配白话翻译，梗只落在翻译层、不动原文；每个宏大判断后跟数字或原文托底。
- 侦探：遇到反常/矛盾处，组≥2条证据链推理，按强度挂声明等级，孤证只写"存疑"。

**逻辑核销（因果与兑现）**：
- 核销「钩子台账」：逐条核对每个埋钩（反常识断言/悬念/盖牌/高潮前置/开头设问）在正片或收尾已兑现；兑现不了的删钩改平实表述，不许留坑。
- 全文通读一遍因果链：每个结论都能沿"因→果"链条回溯到前文证据；设问必已回答；意外类转折已补"能接住意外靠的是……"；决策现场未混入后见之明。
- 收尾回扣开头：开头立的问题/误判，结尾必须给出答案或推翻——单集逻辑闭环。

**情绪质检**：
- 对照禁区清单逐段扫描：悲悯轨段落删净全部弹药和绰号，改白描+原文直引；轨道切换处补显式过渡句（"说到这儿，笑不出来了""太难了，黑色幽默一下吧"）。完整禁区清单见 references/quality-gates.md。
- 收尾四件套按需组合：总结排比（全文回想）→ 金句/诗文收束（记忆锚点）→ 栏目收尾（悲悯轨禁用搞笑栏目，可用"阴暗小故事"尾声）→ 下期预告钩连（呼应开头设问，制造连续剧粘性）。

**出口硬闸门**：成稿后必须运行检查脚本，全部通过才可交付；不过闸的项，回到对应段落重写后复检：

```bash
python3 scripts/check_output.py <成稿.txt> --outline <大纲.txt>
```

脚本检查项：大纲段号覆盖、广告词残留、AI腔禁语、声明牌缺失、时间锚定、弹药密度、超长流水句、领属词一致性、收束完整性。检查规则的可配置说明见 references/quality-gates.md 末节。

## 关键纪律速查

- 取证在动笔前，不在写完后。
- 上弹药过五问：功能定位 → 题材适配 → 史料锚点 → 密度轮换 → 兑现能力；答不上就撤弹。
- 每段过因果三问：因从哪来、果落在哪、和下段怎么咬合；设问必答，埋钩必兑现，意外必补"能接住靠的是……"。
- 脑补必挂声明牌；原文不动，梗只落在翻译层；后见之明不进决策现场。
- 悲悯轨零梗零绰号，切换必补过渡句；动情点前后 30 秒不玩梗不上方言。
- 领属词、绰号全文统一，以声音卡为准。
- 广告植入全部剥离，但可保留其"插入位"作为节奏参考。
- 检查脚本全绿才可交付。
