# candidates/terms.md — 术语视角候选单元

> 提取器视角：术语（term）。输入：STYLE_CORE + AMMUNITION + BOOK_OVERVIEW。

## TM-1 四把板斧
- 内容：心理代入 / 词汇降维 / 场景重构 / 反讽结构 的统称，杜氏风格核心手法集合。
- 候选类型：term → 进 GLOSSARY，不独立成 skill

## TM-2 弹药（ammunition）
- 内容：仿写可复用的现代黑话/句式/代入式/史料例句集合（AMMUNITION.md，349条/9类）。
- 候选类型：term → 进 GLOSSARY，作为弹药库的统称

## TM-3 杜味
- 内容：指杜茹慧口播史评的独特质感——黑话嫁接+心理代入+画面脑补+反讽收束的组合体感。
- 候选类型：term → 进 GLOSSARY

## TM-4 黑话指纹词
- 内容：我晋 / 咱 / 老登 / 基本盘 / 牛马 / 属于是 / 丝滑小连招 / 老影帝 / 梭哈 等跨篇复用个人语料指纹。
- 候选类型：term → 进 GLOSSARY，作为弹药库"称谓/动作/评价"类样本
