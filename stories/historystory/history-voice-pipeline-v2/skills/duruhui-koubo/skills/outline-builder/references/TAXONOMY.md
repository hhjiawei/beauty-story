## 3. 材料→风格选择规则（核心交付）

### 3.0 通用装配原则（任何材料都先套这层）

- **骨架**：钩子 → 史料铺陈+降维 →（心理代入 ∥ 场景重构）→ 反讽收束 → 尾声/预告。
- **四把板斧**：心理代入（补古人内心 OS）、词汇降维（现代黑话嫁接）、场景重构（具象画面/特写定格）、反讽结构（先立必胜逻辑→历史结局打脸）。
- **设问**：几乎每篇至少一个"为什么/如果/怎么办"驱动段落。
- **史料**：引原文 + 名家评语（司马光"迷弟"、苏轼、陈寅恪、《资治通鉴》），保持"原著党"姿态。
- **钩子四型**：①血腥/荒诞细节 ②洋梗对比 ③设问破题 ④极端人设/伦理炸裂；朝代越古，现代梗密度越可激进。
- **清洗项**：广告段、文末"阴暗小故事"、自我介绍("小杜app")在仿写时剥离或仅保留其"插入位"作为节奏参考。

## 4. 边界与例外

- **跨类篇**：「武帝烂摊子」同时是"制度奠基"与"速亡"，归主导对象（朝代/制度总账）；「魏晋辟谣」跨"社会风貌+反常识驳论"，归入社会风气·文化现象。跨类时优先按"叙事落点"而非"题材标签"判定。
- **人物 vs 事件**：以单个人物生平为主 → 人物；以一个事件过程为主（即便主角知名）→ 事件。人物事件交叉时（如「慕容垂」出现在多事件篇），按该篇的主标题叙事对象定类。
- **阴暗小故事**：分布不均（约半数有），是作者固定栏目但须**整段剥离**（改写/下游 skill 的 Boundary）。表中"有暗"标注便于清洗；无任何暗的篇多见于南北朝批次与晚期两晋。
- **广告植入**：中插带货（电动牙刷/护颈枕/米诺地尔/HFP/夸克/角鲨烯/按摩仪等）属口播噪声，表中"广"标注；仿写时可保留"插入位"作节奏参考，但正文须剥离。
- **编号错位**：batch 笔记与 manifest/manifest 文件名存在"篇号文件号 ≠ 文件夹顺序"的缺口与错位（如两晋18/20/21、文件63），本表用标题关键词作唯一简写以避免歧义。
- **南北朝 vs 两晋差异**：南北朝人物更"疯批化"、黑话更密、战争描写更"电竞解说化"（送人头/基建狂魔/平A大师），仿写南北朝材料可适当加重游戏/职场梗密度；但四把板斧不变。

## 5. 使用说明（仿写引擎查表法）

1. 拿到材料 → 判断主导对象：**人物 / 事件 / 朝代**。
2. 在该大类下选**中类**（如"事件·战争·以少胜多"）。
3. 套用 §3 对应规则卡的「钩子类型 + 手法组合 + 节奏 + 收束」。
4. 从弹药库抽取对应现代黑话（如战争→丝滑连招/降维打击；暴君→超雄患者/疯批）。
5. 末尾按 §4 清洗广告与阴暗小故事，保留"原著党"史料姿态。

> 验证证据：同上手法在晚清/隋朝材料上与两晋**完全一致**（batch-08 结论），故本表规则可迁移至任意朝代材料，无需换手法、只换史实骨架与弹药词。
