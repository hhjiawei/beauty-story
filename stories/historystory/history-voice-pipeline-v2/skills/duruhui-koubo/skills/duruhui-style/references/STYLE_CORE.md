# STYLE_CORE — 杜茹慧历史口播风格 · 总风格定义

> 本文是全部 skill 的**共享底座**。它定义「什么是杜茹慧风格」的**充要特征**与**可选变体**，并证明该风格**不绑定具体朝代**——从任意历史材料（人物/事件/朝代）都能套用。
> 证据来自：`BOOK_OVERVIEW.md`（四系列通读汇总）、`techniques/agent-A~D.md`（10 篇精读 + 跨朝代理论溯源）、`notes/batch-01~10.md`（93 篇结构笔记）、`AMMUNITION.md`（弹药库）。
> 验证口径：每条板斧须在**≥3 个不同系列**的文章中出现，并各附原文佐证。

---

## 0. 一句话总风格

**用「当代视角的心理代入 + 现代黑话降维 + 场景细节脑补 + 预期违背式反讽」四把板斧，把正史留白处「脑补」成有血有肉、可读可感的八卦式历史叙事，让复杂乱世史变得好吃瓜、好传播。**

底座是**史料引用**（保证不瞎编），其余四手负责「好看、好懂、好传」。六者叠加 = 杜氏风格内核。

## 1. 四把板斧（充要特征，跨系列已验证）

### 1.1 心理代入（心理 OS / 脑补古人想法）

- **定义**：给古人补「内心 OS」，用现代心理逻辑填补史书「只记做了什么、不记怎么想」的留白。机制是「古今共情」——把读者经验与角色经验叠合。
- **跨系列佐证（≥3）**：
  - 两晋：`两晋01`「刚刚走上统治地位的士族门阀……长长地吸了一口气。他们是又窃喜又后怕。」
  - 南北朝：`南北01`「史书上没有写，咱也不能问……想必都不难猜出：贺夫人在刘显帐中留宿一夜意味着什么吧。」
  - 隋：`大隋01`「大臣心里哭诉」「（文帝）手又痒了」——第三人称调侃式代入。
  - 晚清：`千年变局01`「我是震惊到了」——读者反应式代入。
- **验证结论**：✅ 稳定。载体可变（第一人称浸入/ 第三人称调侃「老登」/ 读者反应「我震惊了」），**机制同一**。

### 1.2 词汇降维（现代黑话 / 网络梗 / 当代概念嫁接古代）

- **定义**：把官职/战略/朝堂/人物嫁接到职场/游戏/网络热梗/当代制度语汇，制造时空错位（八卦感主源）。黑话是**插槽式变量**，随朝代换词。
- **跨系列佐证（≥3）**：
  - 两晋：`两晋01`「我晋有什么值钱的？人命才值钱」；`两晋06`「废物门阀」；`两晋37`「这一大堆骚操作」。
  - 南北朝：`南北19`「没饭吃就抱富婆，没权利就飙演技」「像个 NPC 一样过完一个小兵的一生」「得加钱」；`南北12`「给整个民族来一次彻底的系统重装」「跑步进入封建社会」。
  - 隋：`大隋01`「老登」「酷刑园区」「PPT 没做好被棍打」。
  - 晚清：`千年变局01`「80 万打不过 7000」「都是弟弟」「时代变了」。
- **验证结论**：✅ 稳定。「我晋」与「老登」是同一手法的不同实例化；朝代专属词（如「我晋」）仅出现在第一人称浸入场景，属**表皮变量**。

### 1.3 场景重构（细节脑补 / 画面定格）

- **定义**：史书简略的冲突/对峙，用符合物理常识与人性反应的具象画面补出，形成「分镜脚本」般的画面感。
- **跨系列佐证（≥3）**：
  - 两晋：`两晋01`「石崇用铁如意一棒棒几下把珊瑚砸碎」「在石崇家上一次厕所就等于当了一次神仙」。
  - 南北朝：`南北19`「高欢忘记自己没资格坐下吃饭，被京城老爷吊起来打了四十鞭子」；`南北12`「拓跋宏站在演讲台上：朕要御驾亲征！」。
  - 隋：`大隋01`「（文帝）PPT 没做好被棍打」——把制度失误脑补成现代职场画面。
  - 晚清：`千年变局01`「几十名兵守县城」——把清军消失的荒诞脑补成具体画面。
- **验证结论**：✅ 稳定。跨朝代通用，与具体史实无关。

### 1.4 反讽结构（预期违背 / 先立后打脸）

- **定义**：先立当事人「必胜逻辑」靶子，再用真实历史结局打脸，形成「一本正经推理最后全错」的黑色幽默。
- **跨系列佐证（≥3）**：
  - 两晋：`两晋01`「敛财成为能力的象征，炫富成为高贵的表现……人命才值钱」——价值倒置反讽；`两晋06`「西晋各方面都很拉胯，但灭吴自有非凡意义」。
  - 南北朝：`南北01`「纵横草原三大步的女强人，也没料到儿子拓跋珪如此有出息吧」（以「有出息」反讽弑亲称帝）。
  - 隋：`大隋01`「文帝埋雷」——把制度隐患写成「埋雷」反讽。
  - 晚清：`千年变局01`「80 万打不过 7000」——数字反差反讽。
- **验证结论**：✅ 稳定。最强支撑点：反讽落差锚点（可量化/可对照）在三类主题迥异材料中均存在。

### 1.5 两把辅助（与板斧同频出现，并入内核）

- **设问钩子**：开头/段间设问、反问、自问自答，制造悬置。「打不过敌人怎么办？」「这救还是不救？这是一个问题。」（`两晋01`/`南北19`）——四类材料均稳定。
- **史料引用**：引《晋书》《资治通鉴》等原文 + 名家评语，建立权威、托底反讽（防轻佻）。`南北01`「魏书……早在唐朝就有人将魏书贬为秽史」；`两晋41`引《重赠卢谌》——四类材料均稳定。

## 3. 充要特征 vs 可选变体（风格边界，供 skill 引用）

**充要条件（缺一则不像杜氏风格）**：
1. 心理代入（给古人加内心 OS 或当代视角反应）
2. 词汇降维（至少一处现代黑话/概念嫁接古代）
3. 反讽结构（存在预期违背/价值倒置）
4. 史料引用托底（不瞎编，可被核验）
5. 栏目化骨架（钩子—铺陈—反转—收束的成稿节奏）

**可选变体（有则更浓，无也不破功）**：
- 场景重构的详略（可简可繁）
- 第一人称「我 X」浸入 vs 第三人称「老登」调侃（取决于系列定位）
- 具体黑话词选择（「我晋/老登/牛马/基本盘」随朝代换插槽）
- 阴暗小故事尾声（部分篇有，部分无；**改写时整段去除**）
- 广告口播插入（口播属性噪声；**改写时剥离**）
- 标题极端化强度（可温和可炸裂）

> **关键判断**：黑话是「词汇降维」的**插槽变量**，不是风格本身。换朝代 = 换史料骨架 + 换一套合适的当代降维词 + 找准反讽落差锚点，手法板斧不变。

## 4. 风格不绑定具体朝代（可被任意材料套用）

- **已验证**：六手法在 **两晋（65）、南北朝（23）、隋（1）、晚清（5）** 四套材料上全部稳定出现，无漂移（agent-D §4.4，强支撑）。
- **迁移条件**：只要材料含（a）可量化/可对照的反讽落差；（b）可被当代语汇降维的人物或制度；（c）可想象的主观反应或场景，即可套用同一套板斧。
- **迁移成本**：仅为「为该朝代选一套合适的当代降维词 + 找准其反讽落差锚点」。
- **结论**：总风格是**可迁移的方法论内核**，仿写时只替换史实骨架与弹药词，不必换手法。所有下游 skill 必须按此原则设计——**不锁定两晋南北朝**。
