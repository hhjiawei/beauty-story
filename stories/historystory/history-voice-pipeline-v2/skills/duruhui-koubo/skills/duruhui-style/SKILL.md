# 杜茹慧历史口播风格 · 总控改写引擎

## R — 原文 (Reading)

> 已知明年就要发动灭国大战，如果你是皇帝，那么今年你要做些什么呢？在五胡十六国时代，前秦和东晋之间，就曾经爆发了一场南北终极大战——淝水之战。……甚至我们可以粗暴地将整个前秦中央的工作高度概括为两件事……
> 所以说啊朋友们，苻坚最终遭到背叛，还真有自己一手酿成的原因。

> — 杜茹慧《两晋55·淝水之战前奏》

这两段浓缩了风格的四个标志：开篇**设问钩子**（"如果你是皇帝…"）、**词汇降维**（"粗暴概括""咱们的苻天王"）、**心理代入**（脑补古人处境）、**反讽结构**（"真有自己一手酿成的原因"）。

---

## I — 方法论骨架 (Interpretation)

这是一个"任意历史素材 → 杜氏口播史评"的固定改写引擎，由三层稳定结构组成：

1. **手法引擎（四把板斧，不变）**：心理代入（脑补古人内心OS）、词汇降维（现代黑话嫁接古代）、场景重构（细节脑补还原画面）、反讽结构（预期违背/平反式收束）。加两个辅助：设问钩子、史料引用。
2. **栏目骨架（六模块，不变）**：钩子 → 史料铺陈+降维 → 核心展开 → 高潮反转 → 收束升华 → 尾声预告。
3. **插槽变量（变）**：黑话/句式是跨朝代"插槽"，拿到哪个朝代的材料就换哪套史实骨架与弹药词，**手法引擎与栏目骨架永不换**。

关键洞见（来自 93 篇跨四套材料的验证）：这套风格**与朝代无关**——两晋、南北朝、晚清、隋的语料上四把板斧完全同构。所以仿写任意朝代，只换"史实 + 弹药"，不换"手法 + 骨架"。

## A1 — 语料中的应用 (Past Application)

### 案例 1：淝水之战（事件·以少胜多）
- **问题**：如何把一场著名以少胜多战争写出"杜味"？
- **方法论的使用**：钩子用数字反差("8万打哭97万")+设问；展开中心理代入还原双方决策心理、场景重构战场画面、词汇降维作"电竞解说"(丝滑小连招)；史料引《资治通鉴》原文；收束反讽"赢家未必真赢/公平辩证法"。
- **结论**：固定六模块 + 四把板斧可稳定产出识别度极高的口播史评。
- **结果**：该篇成为系列播放高峰，手法可复用于任意以少胜多战争。

### 案例 2：八王之乱（事件·连环内斗）
- **问题**：如何写一串互相内斗的宗室而不乱？
- **方法论的使用**：钩子"跑路预警/内斗流行"+词汇降维(梭哈/反复横跳)+反讽("天道不爽没来")+多线收束+下期预告。
- **结论**：内斗类用"反复横跳+反讽落空"组合，节奏在四套材料上一致。
- **结果**：跨篇复用，读者凭手法即可识别作者。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行（引用同包 `references/` 下的共享文件）：

1. **定类**
   - 读取 `references/TAXONOMY.md` §1，判主导对象：人物 / 事件 / 朝代。
   - 完成标准：选定一个中类（如"事件·战争·以少胜多"）。

2. **选手法组合**
   - 读取 `references/TAXONOMY.md` §3 对应中类规则卡，抄下「钩子偏向 + 重点手法 + 节奏收束」。
   - 完成标准：得到该类的钩子类型与手法组合清单。

3. **抽弹药**
   - 调用 `ammunition-lookup` skill（或读 `references/AMMUNITION.md`），按类别抽：黑话/句式 ≥6 条、代入式 ≥3、史料例句 ≥2、反讽句 ≥2。
   - 完成标准：弹药清单齐备且均来自真实语料例句（不杜撰）。

4. **按六模块写正文**
   - 参考 `references/OUTLINE_TEMPLATE.md`：①钩子（设问/数字反差/迷因）②史料铺陈+降维 ③核心展开（每2-3段插心理代入+场景重构）④高潮反转（反讽结构）⑤收束升华（平反/告别金句）⑥尾声仅留下期预告。
   - 完成标准：六模块齐全，字段达标。

5. **应用四把板斧**
   - 心理代入（`technique-empathy`）、词汇降维（`technique-decay`）、场景重构（`technique-scene`）、反讽结构（`technique-irony`）各就各位。
   - 判停条件：若材料无明确史实骨架（纯虚构），跳回步骤1重选"事件类·社会风气"或说明无法托底。

6. **清洗（硬约束）**
   - 删除文末"阴暗小故事"尾声、删除任何广告/带货/自我介绍；核对史料 ≥2 条属实。
   - 完成标准：无清洗项残留，反模式自检通过（`references/STYLE_CORE.md` Boundary）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 纯学术/论文写作、客观百科词条、正式公文——这些要严谨，不要黑话降维与反讽。
- 用户明确要求"严肃/学术/不幽默"的历史表述时。
- 材料为完全虚构且无史料可引时（缺史料托底会失"杜味"权威感）。

### 作者在语料中暴露的失败模式（须规避）
- **阴暗小故事**：约半数原文有固定"文末阴暗小故事"栏目，属猎奇尾声，仿写须整段剥离。
- **广告植入**：中插带货（电动牙刷/护颈枕/米诺地尔等），属口播噪声，须剥离。
- **纯科普无代入**：缺心理代入与场景重构会丢失"杜味"。
- **平铺无反转**：高潮无反讽结构是最大特征缺失。
- **换朝代换手法**：误以为不同朝代需换手法；实证四把板斧跨朝代稳定，只换史实与弹药。

### 作者的盲点 / 时代局限
- 风格高度依赖"现代黑话嫁接"，对极冷门/无当代类比点的史实可能降维生硬；此时优先保史料与代入，降维从简。
- 反讽收束若过度会滑向虚无史观，收束仍须有"文明韧性/史实教训"的落脚点。

### 容易混淆的邻近方法论
- 普通"幽默写作"skill：缺四把板斧的固定组合与史料托底，不构成"杜味"。
- 普通"历史科普"skill：缺心理代入密度与反讽收束，不构成口播史评质感。
