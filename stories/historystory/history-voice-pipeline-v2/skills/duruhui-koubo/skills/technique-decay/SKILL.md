# 手法 · 词汇降维（Decay / 黑话嫁接）

## R — 原文 (Reading)

> 所以说啊朋友们，苻坚最终遭到背叛，还真有自己一手酿成的原因。
> 咱们的苻天王有一个好，就是无论到前秦的什么地方，他都比别人善。

> — 杜茹慧《两晋55·淝水之战前奏》

"咱们的苻天王""比别人善"——把当代口语/网络腔安到公元4世纪皇帝头上，荒诞感即"杜味"来源。

---

## I — 方法论骨架 (Interpretation)

词汇降维 = 用**当代语言系统**重新描述**古代对象**，制造"时代错位笑点"。三类来源：
1. **称谓降维**：我晋 / 咱 / 老登 / 基本盘 / 牛马 / 老影帝。
2. **动作降维**：丝滑小连招 / 梭哈 / 金蝉脱壳 / 逆天改命 / 开挂。
3. **概念降维**：职场 / 系统重装 / 版本玩家 / 电竞解说 / 小镇做题家。

关键：**黑话是插槽变量，手法不变**。仿写任意朝代，只换黑话词、不换"用当代词讲古人"这个动作。须有史料托底（见 `duruhui-style` 清洗约束），否则沦为段子。

---

## A1 — 语料中的应用 (Past Application)

### 案例：苻坚"善"的降维
- **问题**：如何把"苻坚屡赦宗室最终被叛"写出讽刺？
- **方法论的使用**：称"咱们的苻天王""比别人善"，用亲昵黑话消解皇帝威严，反衬其优柔致祸。
- **结论**：降维让"制度缺陷"变成"人设笑话"，记忆点强。
- **结果**：该口吻跨篇复用（我晋/老登），成个人语料指纹。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 写历史想加笑点但不想硬挠。
2. 要把复杂古代制度/关系类比成现代人懂的概念。
3. 做口播，需要"金句黑话"撑节奏。

### 语言信号
- "这里用个现代梗" "降维一下" "加个黑话" "用网络语讲这段"

### 与相邻 skill 的区分
- 与 `technique-empathy`：decay 是"用词"，empathy 是"用心"；常同句（"他肯定想：这皇位谁爱坐谁坐"）。
- 与 `technique-irony`：decay 提供"荒诞词"，irony 提供"反转结构"；降维词常是反讽的燃料。

   - 完成标准：黑话 ≥6 条，全来自真实语料例句。

   - 把黑话安到古人头上，确保紧邻处有史料/事实支撑。
   - 判停：若某黑话与史实严重违和，换更贴合词条而非硬塞。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 严肃学术/文言文仿写：须保历史语体。
- 黑话与史实完全无关处：无托底的降维 = 脱口秀，失"杜味"权威感。

### 作者暴露的失败模式
- **降维过度**：满篇黑话淹没史实，读者不知讲啥。
- **错代黑话**：把后世才有的概念安到前代（如给汉人安"公务员"尚可，安"程序员"需看语境）。

### 容易混淆
- 普通"戏仿/parody"：缺"跨朝代稳定插槽+史料托底"的工程化约束。
