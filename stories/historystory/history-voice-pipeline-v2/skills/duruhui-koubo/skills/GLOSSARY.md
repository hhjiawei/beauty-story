# GLOSSARY — 杜茹慧历史口播风格 术语表

> 本包专用术语。阅读 skill 前先读本表，避免歧义。

## 核心概念

**四把板斧（Four Axes）**
心理代入 / 词汇降维 / 场景重构 / 反讽结构 的固定组合，加两个辅助（设问钩子、史料引用）。杜氏风格的方法论引擎，**跨朝代稳定不变**。

**六模块栏目骨架（Six-Module Skeleton）**
钩子 → 史料铺陈+降维 → 核心展开 → 高潮反转 → 收束升华 → 尾声预告。
全库 93 篇稳定呈现；⑥尾声**只留下期预告，禁阴暗小故事**。

**三大类叙事变体（Three Genres）**
人物（人设钩子→名场面→命运转折→盖棺）、事件（反差钩子→过程多线→反转收束）、朝代（总账钩子→枚举拆解→崩塌/转折）。
仿写时先定类，再查 `TAXONOMY.md` §3 选手法组合。

**弹药（Ammunition）**
仿写可复用的现成零件：现代黑话、转折句式、心理代入标记、史料考据例句。
库见 `AMMUNITION.md`（349 条 / 9 类）。**只取真实语料例句，不杜撰**。

**杜味（Du-flavor）**
杜茹慧口播史评的独特质感 = 黑话嫁接 + 心理代入 + 画面脑补 + 反讽收束 的组合体感。质检标准：缺任一项即"不像"。

**跨朝代插槽变量（Cross-era Slot Variable）**
黑话/句式是随朝代更换的"插槽"，手法引擎不变。例：两晋"我晋" → 隋"老登" → 南北朝"基本盘/牛马"。仿写任意朝代只换插槽、不换引擎。

## 清洗相关

**阴暗小故事（Dark Tail）**
原语料约半数有的固定"文末阴暗小故事"尾声栏目（独立于主线外的猎奇/低俗片段）。
**清洗对象**：仿写须整段剥离，⑥尾声只留预告。

**Boundary（硬约束）**
内置清洗规则：禁阴暗小故事、禁广告/带货/自我介绍、反模式质检（无反转=不像、纯科普无代入=失杜味、换朝代换手法=误解）。
写文后须逐条自查（见 `STYLE_CORE.md` Boundary）。

## 验证术语

**三重验证（Triple Verification）**
V1 跨域（≥2 独立语境佐证）/ V2 预测力（外推书未明说场景）/ V3 独特性（非常识）。
详见 `../../verified.md` 与 `../../rejected/README.md`。
