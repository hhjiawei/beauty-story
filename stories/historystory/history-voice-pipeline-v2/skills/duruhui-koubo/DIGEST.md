## 一、这套风格到底是什么

杜茹慧的历史口播，表面是"用现代梗讲历史"，底层是一套**固定且跨朝代稳定的方法论引擎**。我们从 93 篇语料（两晋 65 / 南北朝 23 / 晚清 5 / 隋 1）中提炼出一个最关键结论：

> **四把板斧（心理代入 / 词汇降维 / 场景重构 / 反讽结构）在四套完全不同的材料上零漂移**——两晋、南北朝、晚清、隋，手法同构，只换史实骨架与黑话词。

这意味着一件事：你拿到**任意朝代**的历史素材，都不用重新学写法，只把"史实 + 弹药（黑话）"换掉，手法引擎原封不动。这是支撑"仿写任意朝代"的硬证据。

一句话定义"杜味"：黑话嫁接 + 心理代入 + 画面脑补 + 反讽收束的组合体感。缺任一项，读者就觉得"不像"。

## 二、核心方法论一：四把板斧

### 1. 心理代入（脑补古人内心 OS）
**解决什么问题**：历史常写成"事件词条"，干巴巴没人味。
**核心逻辑**：把古人当活人写，替他补"所思"——用"他当时肯定想…""X 觉得自己…"补全史料没写的内心戏，再用"咱/朋友们"拉平古今距离。
**代表案例**（两晋55 淝水前奏）：
> 灭代之后，苻洛觉得自己是大秦功臣，想要开府仪同三司的待遇，结果被苻坚拒绝，由此满腔怒火、萌发异志。

一句"觉得自己…由此满腔怒火"，把制度结果翻译成人的情绪反应，读者秒懂。
**何时失效**：纯学术/纪传须保持客观，过度代入（每句都"他想"）会喧宾夺主；无史实骨架处代入 = 虚构。

→ 深入：`skills/technique-empathy/`

### 2. 词汇降维（现代黑话嫁接古代）
**解决什么问题**：古代人名地名制度，现代人隔层纱，进不去。
**核心逻辑**：用当代语言系统重新描述古代对象，制造"时代错位笑点"。三类来源——称谓降维（我晋 / 咱 / 老登 / 基本盘 / 牛马）、动作降维（丝滑小连招 / 梭哈 / 金蝉脱壳）、概念降维（职场 / 系统重装 / 版本玩家）。
**代表案例**（两晋55）：
> 咱们的苻天王有一个好，就是无论到前秦的什么地方，他都比别人善。

把当代口语安到公元 4 世纪皇帝头上，荒诞感即"杜味"来源。**黑话是插槽变量**：两晋"我晋"→隋"老登"→南北朝"基本盘/牛马"，换朝代换词、不换机制。
**何时失效**：无史料托底的降维沦为段子；错代黑话（把后世概念硬安前代）失真。

→ 深入：`skills/technique-decay/`

### 3. 场景重构（细节脑补还原画面）
**解决什么问题**：史料只给结果（"X 大胜"），读者脑补不出过程。
**核心逻辑**：把概述还原成"谁→什么动作→对方什么反应→下一招"的连续动作链，加器物/环境细节，拍成电影分镜。
**代表案例**（两晋55 彭城救援）：
> 谢玄先玩了一手围魏救赵：猛攻留城。彭超见状分兵保护辎重。谢玄旋即打出声东击西：何谦之突然中途转向，直扑防守薄弱的彭城……

干瘪地名变成战术爽片。
**何时失效**：史料对过程零记载处过度脑补 = 虚构；动作堆砌无因果链则读者不知谁赢。

→ 深入：`skills/technique-scene/`

### 4. 反讽结构（预期违背 / 平反收束）
**解决什么问题**：平铺直叙的结尾没劲，记不住。
**核心逻辑**：在高潮/收束处制造预期违背。三种形态——归因反转（看似被害，实是自作）、胜负辩证法（赢家未必真赢）、平反式收束（给污名者翻案）。且须与史料托底绑定。
**代表案例**（两晋55）：
> 所以说啊朋友们，苻坚最终遭到背叛，还真有自己一手酿成的原因。

把"被叛"反转为"自酿"，悲剧升级为教训。
**何时失效**：无史料支撑的强行反转 = 歪曲；过度虚无（只嘲讽无落点）让读者空虚。收束仍须有"文明韧性/史实教训"的落脚点。

→ 深入：`skills/technique-irony/`

## 三、核心方法论二：六模块栏目骨架

全库 93 篇稳定呈现同一结构，仿写时直接套：

1. **钩子**（1–3 句抓人：设问 / 数字反差 / 网络迷因）
2. **史料铺陈 + 降维**（立权威但立刻破冰）
3. **核心展开**（事件链/人物弧光，每 2–3 段插心理代入 + 场景重构）
4. **高潮反转**（反讽结构爆破）
5. **收束升华**（平反 / 告别 / 辩证法金句）
6. **尾声预告**（**只留钩子，禁阴暗小故事、禁广告**）

节奏曲线：起（钩子一秒抓人）→ 承（铺陈立威）→ 转（展开爬升）→ 合（反转爆破→升华留白）→ 尾（回落留悬念）。

→ 深入：`skills/outline-builder/` + `OUTLINE_TEMPLATE.md`

## 四、核心方法论三：三大类叙事变体

拿到材料先定类，再查表选手法组合（详见 `TAXONOMY.md` §3）：

- **人物类**：人设钩子 → 名场面 → 命运转折 → 盖棺评价。帝王弱主（司马衷）用洋梗钩子；暴君（苻生/刘子业）用伦理炸裂+酷刑清单；后妃用"霸道女王/PUA"降维；门阀用"关系户/牛马/基本盘"群体钩子。
- **事件类**：反差钩子 → 过程多线 → 反转收束。以少胜多战争用数字反差+电竞解说降维+史料+反讽；政变篡位用电影画面+反讽（"清君侧只是清君侧"）；制度变革用职场/系统重装降维+史料诏书。
- **朝代类**：总账钩子 → 枚举拆解 → 崩塌/转折。开国用设问（"做错了什么"）+枚举（四大昏招）；亡国用城破场景+降维+史料；跨朝代转折用"赛季/版本"降维。

**关键**：跨类时按"叙事落点"而非"题材标签"定类。

## 五、弹药库与跨朝代插槽变量

仿写不靠临场想词，靠**弹药库**（`AMMUNITION.md`，349 条 / 9 类：称谓/动作/评价/制度/转折/代入/史料/设问/通用黑话）。每篇配比：黑话 ≥6、代入式 ≥3、史料 ≥2、反讽 ≥2，且全部来自真实语料例句（不杜撰）。

黑话是"跨朝代插槽变量"——这是整套风格最巧的设计：
- 两晋：「我晋」「属于是」「丝滑小连招」
- 南北朝：「基本盘」「牛马」「老影帝」
- 晚清/隋：「老登」

仿写唐朝"安史之乱"，就把"我晋"换成"我唐"、"老登"换成对应称谓，手法引擎不动。弹药检索机制见 `skills/ammunition-lookup/`。

## 六、反例与陷阱（必看）

这些是从语料中识别出的**清洗对象**与**失败模式**，仿写时须规避：

1. **文末阴暗小故事**：原语料约半数有固定的"文末阴暗小故事"栏目（独立于主线的猎奇/低俗片段）。**仿写须整段剥离**，尾声只留下期预告。
2. **广告植入**：中插带货（电动牙刷/护颈枕/米诺地尔/夸克等）属口播噪声，须剥离。
3. **纯科普无代入**：缺心理代入与场景重构会丢失"杜味"，须每 2–3 段插内心 OS 或画面。
4. **平铺直叙无反转**：高潮无反讽结构是最大特征缺失，无反转 = 不像杜氏。
5. **换朝代就换手法**：这是误解；实证四把板斧跨朝代稳定，只换史实与弹药。

→ 清洗硬约束内置进总控：`skills/duruhui-style/` 的 Boundary 段。

## 七、作者的局限

只报喜不报忧是软文，不是蒸馏。这套风格有三个真实局限：

1. **降维依赖当代类比**：对极冷门、无任何当代类比点的史实，降维会生硬；此时优先保史料与代入，降维从简。
2. **反讽滑向虚无的风险**：反转收束若过度，会消解历史教训，须有"文明韧性/史实教训"落点。
3. **黑话密集的审美疲劳**：南北朝材料黑话更密、更"电竞解说化"，仿写时需按材料密度调节，勿全篇堆黑话淹没史实。

## 八、怎么用这套 skill

用户给历史素材 → 直接调 `duruhui-style`（总控），它自动调度：
`outline-builder`（大纲）→ `ammunition-lookup`（抽弹药）→ `hook-factory`（钩子）→ 四手法（执行）→ 清洗。

只想练某手法，直接调对应 `technique-*`；只想规划结构，调 `outline-builder`。

## 九、一句话带走

杜茹慧历史口播 = **四把板斧（固定） + 六模块骨架（固定） + 弹药插槽（随朝代换）**。学会这套，你能把任意朝代的历史，写成有"杜味"的口播文案——前提是把"阴暗小故事"和"广告"留在原视频里，别带进你的稿子。
