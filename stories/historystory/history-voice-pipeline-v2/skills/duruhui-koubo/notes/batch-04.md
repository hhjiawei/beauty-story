### [两晋] 31 门阀与皇权首次对决，琅琊王氏为何能屹立不倒？
- 初步分类倾向: 事件（东晋内乱·王敦之乱第一次）
- 一句话主旨: 王敦第一次发兵建康，因甘卓犹豫、周札献城、王导周旋，门阀与皇权首次对决以王家未倒收场。
- 结构骨架(起承转合): ①王敦起兵与后方甘卓/司马承两股势力；②甘卓反复横跳、乐道融反水促成甘卓出兵；③王敦东进、王导宫门外长跪、周顗"我不杀伯仁"名场面；④石头城周札不战而降、建康沦陷、王敦清君侧大清洗。
- 开头钩子: "公元322年，晋元帝永昌元年，大将军王敦向朝廷上书，列数罪状，并以诛杀刘隗为名，发兵建康。东晋立国以来第一次内战——王敦之乱，正式爆发了。"
- 结尾收束: "王敦此行可谓是手忙脚乱、阻碍重重，但却都被江南朝廷的各色人物的各种瞎搞给活生生地促成了……任何一个'如果'，都有可能改写这场叛乱。"
- 显著手法: 心理代入 / 场景重构 / 反讽结构（"号称清君侧，没想到最后真的只是清君侧"）
- 弹药样本:
  - "思前想后、辗转反侧，睡不着的王敦，最终做出了一个违背祖宗的决定：要当曹操。"
  - "王敦准备顺流而下进行反扑。"
  - "王家子弟与王敦彻底决裂"——"时空错位的发丧戏法"
- 文末阴暗小故事: 无（本篇收尾于大清洗开启，未单列）

### [两晋] 32 敲打敲打皇帝就行了，怎么，你来真的啊？！
- 初步分类倾向: 事件（王敦之乱善后与清洗）
- 一句话主旨: 王敦乱后清洗太子党与反对派，刁协刘隗覆灭、周顗被默许赐死、甘卓被阴杀，明帝即位开启与王家拉锯。
- 结构骨架: ①刁协刘隗逃亡与覆灭；②王敦借废太子发难被温峤挡下；③周顗之死（王导沉默即默许）；④甘卓被"捕鱼调虎离山"计杀、王氏铺排；⑤明帝即位、王敦篡权三件套、钱凤上中下三策、周札灭门。
- 开头钩子: "本期视频，我要遗憾地宣布：虽然能力手段有些欠缺，但是作为一个合作伙伴，晋元帝司马睿还是很有人情味的……应该是保不住了。"
- 结尾收束: "周氏族人尽被株连……最终冤死在王敦之手。再想想试图投靠王敦、给王敦开门的周札，最终结果是子侄尽死、全族覆灭。看来在我大晋，心狠手辣还真是一个基本功啊。"
- 显著手法: 设问句 / 反讽结构 / 史料引用
- 弹药样本:
  - "怎么，你来真的啊？！"（标题及文中反复出现）
  - "王导所谓的'我不杀伯仁，伯仁因我而死'，根本就是一个伪命题。"
  - "我大晋无能为力。"
  - "解锁黄钺、班剑以及奏事不名、入朝不趋、剑履上殿经典套餐。"
- 文末阴暗小故事: 有（周札献城反被灭门，"心狠手辣是基本功"）

### [两晋] 33 皇帝亲自带兵夜袭，保卫首都，东晋全明星参战！
- 初步分类倾向: 事件（王敦之乱第二次·建康保卫战）
- 一句话主旨: 温峤卧底脱身、明帝全明星阵容反击，王敦病死、王含沈充钱凤溃败，第二次叛乱终结并埋下苏峻之乱伏笔。
- 结构骨架: ①王敦病重逼宫、温峤入营做间谍挑拨；②温峤争取丹阳尹脱身、王导决裂发丧；③明帝全明星布防、夜袭越城破王含；④石虎式叛军内讧、沈充上中下三策不用、决战溃败；⑤余党清算、北方连锁效应引出苏峻之乱。
- 开头钩子: "古往今来，当权臣的前途一般只有两条：要么就是顺利进步，成为下一个朝代的皇帝……要么就是自己和家族全部灰飞烟灭……王敦就忍不住当了一把权臣。"
- 结尾收束: "王敦之乱的影响却远远没有结束……庾亮有鉴于东晋帝国以来皇权不振的现实，开始疯狂集权……最终导致东晋初年的第二场内战——苏峻之乱。"
- 显著手法: 心理代入 / 场景重构 / 史料引用
- 弹药样本:
  - "东晋中兴名臣、第一流人物、硬核赌神骗婚犯温峤开始了他的表演。"
  - "王敦听说温峤这个浓眉大眼的家伙也开始骗人了"
  - "把王敦的尸体用席子裹起来……在议事厅的办公室下面挖了个坑，然后埋了。"
  - "曹操、刘琨、王导都曾经做过司空"（沈充嘲讽司空骗局）
- 文末阴暗小故事: 无（收尾于苏峻之乱预告）

### [两晋] 34 时不再来！羯胡是如何抢抓战机，在两三年间迅速扫平北方的？
- 初步分类倾向: 事件（北方后赵灭群雄·统一进程）
- 一句话主旨: 刘琨被害、段部鲜卑崩溃、曹嶷与徐龛反复横跳，石勒抓住东晋内乱两年扫平北方、逼近与前赵决战。
- 结构骨架: ①刘琨段匹磾联盟被段末波借刀杀人瓦解；②石虎灭邵续/段匹磾/段文鸯、控制三州；③曹嶷反复横跳终被石勒吞并齐鲁；④徐龛三反终被装皮袋摔死，总结"要有气节"。
- 开头钩子: "有这样一个英雄人物，他有着精致的面庞、高贵的出身，他的名字里带有'琨'字……没错，他就是我们大晋深入敌后的刘司空——刘琨。"
- 结尾收束: "徐龛战败投降……石勒把他装到一个皮袋子里面，然后从一百多尺高的城楼上扔下来，活活摔死……所以说啊，在这片土地上还是要有点气节的，不然不仅自己人唾弃，连敌人也要羞辱你。"
- 显著手法: 心理代入 / 词汇降维 / 反讽结构（"得了我晋的真传"）
- 弹药样本:
  - "段末波虽然是个小人，但是这个手法真是得了我晋的真传：挑拨离间、趁虚而入、螳螂捕蝉、黄雀在后"
  - "反复横跳的故事毕竟不会成为历史主流，还是要像石勒一样靠自我奋斗。"
  - "一个人的命运啊就是不可预料"
  - "打歼灭战，不争霸，只求统一"
- 文末阴暗小故事: 有（徐龛反复横跳终被皮袋摔死、心肝被仇家妻挖食）

### [两晋] 35 前后赵领导人的差距有多大？领袖自身的定位，到底是什么？
- 初步分类倾向: 人物（刘曜 vs 石勒对比·领袖定位）
- 一句话主旨: 刘曜事必躬亲、表演贤君、亲征酗酒致败；石勒定位清晰、用张宾石虎、恢复秩序，二人差距决定国运。
- 结构骨架: ①刘曜宠羊献容、改国号前赵；②石勒亦称赵王，前后赵决裂；③刘曜亲征内耗、大修陵墓、酗酒杀谏；④石勒定位清晰、君子营、号胡人为国人、恢复制度；⑤"小刘邦"叙事收束。
- 开头钩子: "李世民先生曾经锐评曹老板为'一将之智有余，万乘之才不足'……真正把皇帝这份职业干成了事必躬亲的，只有我们今天故事的主角——匈奴的皇帝刘曜。"
- 结尾收束: "随后石勒又把武乡地区三代人的赋税免除，并表示：'武乡就像汉高祖丰沛老家一样……最终也要回到武乡。'这是什么呀朋友们？这不就是高祖《大风歌》里面唱的'威加海内兮归故乡'吗？"
- 显著手法: 心理代入 / 史料引用 / 词汇降维
- 弹药样本:
  - "刘曜很忙，忙着四处征战，把不服匈奴的民族都打服。"
  - "石勒对自己的定位很清晰。"
  - "号胡人为国人"
  - "石勒更像是小刘邦"（对标叙事）
- 文末阴暗小故事: 有（"高祖小故事"：石勒免武乡三代赋税、与李阳和解，模仿刘邦《大风歌》）

### [两晋] 37 废物门阀：一手好牌打个稀烂，一箭射死自己人，无能门阀请滚出大晋
- 初步分类倾向: 人物/事件（东晋门阀改革·庾亮专权致苏峻之乱）
- 一句话主旨: 明帝改革削王氏、提拔庾亮，明帝早逝后庾亮剪宗室、逼反苏峻祖约，建康再陷。
- 结构骨架: ①明帝战后改革、拉一派打一派削藩；②庾亮外戚上位、明帝托孤早逝；③主少国疑、庾亮杀司马宗；④庾亮不听劝逼反苏峻（雷池典故）；⑤建康陷落、庾亮射死船夫逃命。
- 开头钩子: "太宁二年，公元324年秋七月，二次作乱的王敦死了……王敦把持朝政期间为祸一时……改革，必须要改革，这是明帝心中最强烈的呐喊。"
- 结尾收束: "干啥啥不行、跑路第一名的庾亮，把明帝开创的大好局势折腾得天翻地覆……再次沦陷的首都建康，城里的百姓也要迎来一次惨无人道的劫掠了。"
- 显著手法: 反讽结构 / 心理代入 / 词汇降维（"废物门阀"）
- 弹药样本:
  - "如果有一个人物，他抱负远大，却才能有限；明明是执牛耳的领导者，却最喜欢微操……不，他不是常凯申，他是庾亮。"
  - "不要越过雷池一步"
  - "我宁可在山头望监狱，绝不会在监狱望山头"（山囚廷尉）
  - "干啥啥不行、跑路第一名"
- 文末阴暗小故事: 有（庾亮逃亡射死掌舵船夫，还开玩笑"只能射死船夫，又怎么能抵御贼寇"）

### [两晋] 39 五胡乱华中最残暴君主，最精明的智商，最恶毒的上位

- 弹药样本:

  - "主上子孙，我会一个不留全部杀光"
  - "大丈夫行事应当光明磊落，如日月皎然，无论如何也不应该像曹操和司马懿那样，欺凌他人孤儿寡母"
  - "跟中山王共享天下"（一语成谶）
- 文末阴暗小故事: 有（326年石虎夜闯程遐府毒打、奸淫其家眷、掠财，石勒仅轻罚调职）
