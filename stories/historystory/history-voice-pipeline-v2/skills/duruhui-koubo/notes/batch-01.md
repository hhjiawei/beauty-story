### [两晋] 两晋01（阶级固化·意识沉沦）
- 初步分类倾向: 朝代-制度变迁（九品中正制·门阀奢靡）
- 一句话主旨: 西晋速亡的根子在士族门阀纵欲沉沦、九品中正制固化阶级、以及傻子继承人，意识形态先崩、江山后亡。
- 结构骨架: 钩子(奢靡金句)→炫富案例铺陈(任恺/王济/石崇王恺斗富)→制度病变(九品中正制倒退)→傻子接班人收束→下期预告+升华(三百年乱世开启)
- 开头钩子: "敛财成为能力的象征，炫富成为高贵的表现，整个社会都在一种病态的追求中沉沦。"
- 结尾收束: "他们是开启乱世的钥匙，也是引领隋唐光明的第一批献祭者。三百年大乱世，开始了。"
- 显著手法: 词汇降维 / 场景重构 / 设问句 / 史料引用（石崇、王导等）
- 弹药样本:
  - "在我晋，有什么值钱的？人命才值钱。"
  - "王敦就是不喝，还在装犊子。"（现代口语"装犊子"嫁接入晋）
  - "做那个仅存的人上人就行了"
  - "怎么体现贵呢？扭曲变态，肆意妄为，无人敢管就是贵。"
- 文末阴暗小故事: 无（正文收束即结尾，无独立尾声）

### [两晋] 两晋02（胡马·瘟疫·野心家）
- 初步分类倾向: 事件-长期趋势（蛮夷五百年包围华夏·人口锐减）
- 一句话主旨: 从汉到西晋，蛮夷内附、战争瘟疫交织使华夏主体民族人口从五千六百万跌到一千九百万，胡人马鞭已深入中原腹地。
- 结构骨架: 钩子(192年曹操遇匈奴悬念)→汉匈三百年缠斗史→曹魏时期胡人深度参战→梁习"让子弹飞三部曲"治理并州→建安大疫与文化转向→人口数据收束
- 开头钩子: "初平三年，公元192年。此时还是一位小年轻的曹操，正率领军队跟土匪和叛军作战。"
- 结尾收束: "265年，魏晋禅代之际，五部匈奴首领刘豹的儿子刘渊来到了首都洛阳。280年，西晋灭吴，兴盛的国家实质上统一了。十一年后，八王之乱开始了，西晋径直走向沉沦。"
- 显著手法: 词汇降维 / 场景重构 / 设问句 / 史料引用
- 弹药样本:
  - "共同建设大美并州"（"大美XX"网感句式）
  - "经典的让子弹飞三部曲：第一请客、第二斩首、第三收下当狗"（电影梗+三步归纳）
  - "把豪帅的家人打包快递到首都邺城"（"快递"现代词）
  - "试图跟曹老板比划比划的南匈奴"
- 文末阴暗小故事: 无

### [两晋] 两晋03（司马氏篡权关键四年）
- 初步分类倾向: 人物-权臣（司马师·高平陵之变）
- 一句话主旨: 司马师以铁腕冷血夯实曹魏篡权基业，却因早亡、无子留下西晋政治死局，其四年执政是晋速亡的隐性伏笔。
- 结构骨架: 钩子(哭丧戏谑)→司马师文艺青年期与浮华案→发妻夏侯徽死/双重打击→高平陵之变(电影画面感)→废帝曹芳/淮南二叛(眼珠崩出)→死局总结+阴暗小故事
- 开头钩子: "哭了又怎样。我们哭的是，大魏朝中不幸出了你这个篡逆恶贼！大胆！哎嘿嘿呀，啊啊啊啊——"
- 结尾收束: "他和发妻夏侯徽有着伉俪情深的忠贞感情……司马师扔下死局走了。若论毫无道德底线，还是得看我司马懿呀！"
- 显著手法: 心理代入(内心OS) / 场景重构 / 反讽结构 / 设问句 / 史料引用
- 弹药样本:
  - "我们经常戏称司马懿是老乌龟，但本质上应该称之为老狐狸。"
  - "他妈的，跟你们混，真是要被你们害得灭族了。"（桓范骂曹爽，口语爆粗）
  - "曹真、曹子丹，盖世英雄，怎么生了你们两个废物玩意儿！"
  - "最令人作呕的幽默"（反讽小标题式表达）
- 文末阴暗小故事: 有。讲司马懿装病被婢女撞破，妻张春华杀婢灭口亲下灶烧饭，点出"毫无道德底线还是得看我司马懿"，呼应前文司马师"毒杀"传闻被证伪。

### [两晋] 两晋05（宗室气绝·党争毁王朝）

- 结构骨架: 钩子(贾南风杀帅哥悬念)→贾逵忠臣世家→贾充弑君发迹→贾南风入选太子妃→齐王出镇党争爆发→司马攸暴毙/裂痕收束+阴暗小故事

- 结尾收束: "但是还没完，还有好几个更可怕的雷还没安上……带着蛀甲羊司马衷一起完蛋，以及带着第一帝国和中华民族一起沉沦。"
- 显著手法: 词汇降维 / 心理代入 / 场景重构 / 设问句 / 史料引用

- 文末阴暗小故事: 有。司马攸子司马㻱亲见父被逼吐血死，幼时埋恨，十余年后联合诸王参与八王之乱攻入旧齐王府，"洛阳城，久违了。over，新年快乐呀！"

### [两晋] 两晋06（晋武帝的烂摊子·万字长篇）
- 初步分类倾向: 朝代-制度总账（太康之治假象·四大昏招）
- 一句话主旨: 司马炎留下外戚权重、诸王分封、州郡罢兵、胡人内附四大烂摊子，其宽容本是皇权衰弱下的无奈，反成助纣为虐的毒药。
- 结构骨架: 钩子(反差提问：混球怎创太康之治)→灭吴统一盛况→病危控禁/四昏招拆解→司马炎性格两面(宽仁+妥协)→世族投机本质→躺平青年收束+阴暗小故事
- 开头钩子: "有一个问题，由于反差太过于强烈，以至于不得不向观众老爷们提问：既然西晋那么不堪了，那怎么还创造了东汉二百年以来罕见的太康之治呢？"
- 结尾收束: "回想四十年前，有谁敢在曹操面前炫耀富贵……如今在西晋，不浪费、不奢靡、不发癫，都不好意思说自己是权贵。那么看到如此情景，那群人生无望的年轻人会怎么办？"
- 显著手法: 设问句 / 词汇降维 / 心理代入 / 史料引用 / 反讽结构
- 弹药样本:
  - "向观众老爷们提问"（直播口播腔）

  - "围绕矛盾造成的结果缝缝补补"（现代修补隐喻）
- 文末阴暗小故事: 有。西晋末全社会普遍"反晋、弃晋、灭晋"，除祖逖刘琨等极少数豪杰外无群体试图救大晋，点出"拜拜"收尾。
