# OUTLINE_TEMPLATE — 杜茹慧历史口播文案写作大纲模板

> 本文为「杜茹慧历史口播风格蒸馏」项目 · Task 007 交付。
> 配套文件：`STYLE_CORE.md`（总风格/六手法）、`TAXONOMY.md`（材料→手法查表）、`AMMUNITION.md`（弹药库）、`techniques/`（手法卡+理论溯源）。
> 核心前提（来自 BOOK_OVERVIEW + batch-08 跨朝代验证）：四把板斧（心理代入 / 词汇降维 / 场景重构 / 反讽结构）+ 设问 + 史料引用，在**两晋 / 南北朝 / 隋 / 晚清**四套材料上高度稳定、与朝代无关。本模板给出**可照填**的骨架与弹药布置位，仿写者"换史实骨架、不换手法引擎"。

## 0. 使用前置（三步索引）

1. **定类**：拿到材料 → 判主导对象 → 人物 / 事件 / 朝代（见 TAXONOMY §1）。
2. **选手法组合**：查 `TAXONOMY.md §3` 对应中类规则卡，抄下「开头钩子偏向 + 重点手法组合 + 节奏收束」。
3. **抽弹药**：从 `AMMUNITION.md` 按类别抽黑话/句式/代入式/史料例句（每篇 ≥6 条），遵守 `STYLE_CORE.md` 六手法强度配比。

> 若材料跨类，按"叙事落点"而非题材标签定类（见 TAXONOMY §4）。

## 1. 通用栏目骨架（六模块，全篇稳定）

全库 93 篇均呈「钩子 → 史料铺陈+降维 → 核心展开 → 反转/反讽 → 收束升华 → 尾声/预告」六模块。任一朝代材料均套此骨架，仅史实与弹药不同。

| 模块 | 功能 | 推荐手法（来自 STYLE_CORE 六手法） | 弹药布置位 | 全篇字数占比 |
|---|---|---|---|---|
| **① 钩子** | 1–3 句抓住注意力，立反差/设问/伦理炸裂 | 设问钩子 + 词汇降维（黑话前置） | 直接放 1 条强黑话或数字反差 | 5% |
| **② 背景铺陈** | 交待时代/矛盾，立史料权威 | 史料引用 + 词汇降维（现代概念嫁接） | 史料原文 ≥1 条 + 降维类比 1 条 | 20% |
| **③ 核心展开** | 事件链/人物弧光，逐段推进 | 场景重构（画面脑补）+ 心理代入（内心OS） | 每 2–3 段 1 条代入式 + 1 条黑话 | 45% |
| **④ 高潮/反转** | 矛盾顶点，预期违背 | 反讽结构（荒诞对比）+ 词汇降维 | 反讽句 + 1 条神操作/骚操作类黑话 | 15% |
| **⑤ 收束升华** | 点题、拔高、留白 | 反讽结构 + 史料收束 / 升华 | 收束金句（平反式/告别式） | 10% |
| **⑥ 尾声/预告** | 下期钩子（**不含阴暗小故事/广告**） | 设问钩子 | 下期悬念 1 句 | 5% |

> **清洗硬约束**（STYLE_CORE Boundary）：模块⑥ 只写"下期预告/互动提问"，**严禁**生成"阴暗小故事"尾声、严禁植入广告/自我介绍。

## 2. 节奏情绪曲线（全篇通用）

```
情绪/张力
  高 |        ╱╲           ╱▔▔╲        ╱（高潮反转④）
     |      ╱    ╲        ╱    ╲      ╱
  中 |    ╱        ╲    ╱        ╲    ╱
     |  ╱  展开③     ╲ ╱   收束⑤    ╲ ╱
  低 |╱ 钩子①  铺陈②  ╲╱  尾声⑥（回落，留悬念）
     +------------------------------------------------→ 字数
```

- **起**：钩子①一秒抓人（反差/设问）；**承**：铺陈②用史料立权威但立刻降维破冰；
- **转**：展开③密集"代入+场景"推进，张力爬升；**合**：高潮④反讽爆破 → 收束⑤升华留白；
- **尾**：尾声⑥只留钩子，不拖泥带水、不阴暗。

## 3. 三大类变体模板（照填）

### 3.1 人物类（帝王 / 权臣·枭雄 / 将领 / 后妃 / 门阀 / 士人）

**标准弧**：人设钩子 → 出身/名场面 → 命运转折（高光或崩塌）→ 盖棺评价（平反/反讽）。

| 段位 | 内容 | 手法 | 弹药位 |
|---|---|---|---|
| 钩子 | 人设反差（"疯批天花板"/"最危险的瘸子"） | 词汇降维 + 设问 | 1 条强标签黑话 |
| 铺陈 | 时代与出身，史料立人 | 史料 + 降维 | 史料 ≥1 + 降维类比 |
| 名场面 | 1–2 个高光/炸裂事件，画面化 | 场景重构 + 心理代入 | 代入式 ≥2 + 黑话 ≥1 |
| 转折 | 权力/命运拐点（篡位/败亡/反转） | 反讽结构 + 心理代入 | 反讽句 + 内心OS |
| 收束 | 盖棺定论（平反式/遗臭式） | 反讽 + 史料收束 | 收束金句 |

> 帝王弱主（司马衷）→ 洋梗钩子(何不食肉糜)；暴君（苻生/刘子业）→ 伦理炸裂+酷刑清单(史料)；后妃 → 霸道女王/PUA 降维；门阀 → 关系户/牛马/基本盘 群体钩子。

### 3.2 事件类（战争 / 政变 / 制度 / 内斗 / 外交 / 风气）

**标准弧**：钩子立反差 → 因果铺陈 → 过程展开（多线/多回合）→ 高潮反转 → 收束点题。

| 子类 | 钩子偏向 | 手法组合 | 收束 |
|---|---|---|---|
| 以少胜多战争 | 数字反差(8万打哭97万) | 代入战场恐惧+电竞解说降维+史料+反讽(赢家未必赢) | "绝非侥幸" |
| 奔袭灭国 | "不打招呼直接灭国" | 赌徒心理代入+误敲鼓场景+喜提/屎壳郎降维 | 如履薄冰独白 |
| 政变篡位 | 篡逆/惊天阴谋戏谑 | 心理代入+电影画面场景+反讽(清君侧只是清君侧) | 埋下隐患 |
| 制度变革 | 设问(改革就要杀人?) | 职场/系统重装降维+杀鸡儆猴场景+史料诏书 | 野心外露/献祭 |
| 八王类内斗 | 跑路预警/内斗流行 | 梭哈/反复横跳降维+反讽 | 多线+下期预告 |
| 社会风气 | 网络迷因破题(荒唐且美好?) | 避雷/科技狠活降维+史料钩沉+反讽 | 文明韧性升华 |

### 3.3 朝代类（开国 / 鼎盛 / 亡国 / 跨朝代转折）

**标准弧**：钩子立总账反差 → 制度/事件枚举拆解 → 矛盾累积 → 崩塌/转折 → 主题收束（"再见X"）。

| 子类 | 钩子偏向 | 手法组合 | 收束 |
|---|---|---|---|
| 开国与制度奠基 | 设问(做错了什么/为何速亡) | 枚举拆解(四大昏招)+史料+降维+代入 | 埋雷/引爆 |
| 鼎盛与危机 | 反差(有望走出乱世) | 心理代入+宝可梦/超级自信降维+史料 | 即将崩塌/预告 |
| 亡国与崩塌 | 不到两年国破反差 | 城破场景+破鼓万人锤降维+史料 | 升华/告别式 |
| 跨朝代转折 | 丝滑过渡/S3赛季 | 赛季/版本降维+代入+场景 | 新时代开启 |

## 4. 弹药布置位细则（总表）

| 全篇位置 | 首选手法 | 弹药类型（见 AMMUNITION.md） | 示例 |
|---|---|---|---|
| 开篇第 1 句 | 设问 / 词汇降维 | 强标签黑话 / 数字反差 | "8万打哭97万" / "我晋没好人了" |
| 段落转承处 | 词汇降维 | 转折句式（"说白了"/"然而"/"最骚的是"） | "结果最骚的操作来了" |
| 古人心理处 | 心理代入 | 代入式（内心OS标记） | "他当时肯定想：这皇位谁爱坐谁坐" |
| 战争/动作处 | 场景重构 + 降维 | 动作描写（丝滑连招/送人头/基建狂魔） | "一套丝滑小连招直接带走" |
| 史料出现处 | 史料引用 | 史料考据（原文+出处） | "《资治通鉴》载：……" |
| 高潮反转处 | 反讽结构 | 评价/反讽句 | "清君侧，清的当然是君侧" |
| 收束句 | 反讽 / 升华 | 收束金句（平反/告别） | "这，就是基本盘的反噬" |

> 密度建议：全篇黑话/句式 ≥6 条，代入式 ≥3 处，史料 ≥2 条，反讽 ≥2 处；南北朝材料可加重游戏/职场梗密度（见 TAXONOMY §4）。

## 6. 反模式（绝对不要做）

- ❌ **不要写"文末阴暗小故事"**：原语料约半数有此固定尾声栏目，但它是清洗对象，仿写须剥离（STYLE_CORE Boundary）。
- ❌ **不要植入广告/带货**：电动牙刷/护颈枕/米诺地尔/夸克等中插属口播噪声，须剥离；可保留"插入位"作节奏参考但正文清空。
- ❌ **不要纯科普无代入**：缺心理代入与场景重构会丢失"杜味"，须每 2–3 段插入 1 处内心OS或画面脑补。
- ❌ **不要只降维不史料**：黑话需史料权威托底，否则像段子；每篇史料 ≥2 条。
- ❌ **不要平铺直叙无反转**：缺反讽结构是最大特征缺失，高潮处必须有预期违背。
- ❌ **不要换朝代就换手法**：四把板斧跨朝代稳定，仿写任意朝代只换史实骨架与弹药词，手法引擎不变。
