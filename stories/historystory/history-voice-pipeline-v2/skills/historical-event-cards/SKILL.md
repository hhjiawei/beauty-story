# 史料分析 · 事件卡选矿（N1 技能）

> 定位：流水线的**选矿工**。把史料原文拆成事件卡，并给每张卡打"弹药潜质"标记。
> 铁律：**事件卡是下游一切节点的唯一事实来源**。卡上没有的事实，大纲、旁白一个字都不许有。
> 铁律：**拆卡即适配**——拆卡时就要预判这张卡能喂给哪些模板、落在模板的哪个段序/插件位，不能等下游来猜。

## 一、事件卡 Schema（严格字段，不自创）

每张卡一个 JSON 对象。字段分三层：**基础层**（所有卡必有）、**类型专属层**（按人物/朝代/事件三类选填）、**模板适配层**
（标注该卡可落入哪些模板的哪些位置）。

### 1.1 基础层字段（所有卡片必填）

| 字段    | 类型     | 说明                                                    |
|-------|--------|-------------------------------------------------------|
| 卡号    | string | 格式 `C-001` 起递增，全库唯一                                   |
| 时间    | string | 事件时间（存疑纪年标"约/通行说法"）                                   |
| 地点    | string | 事件地点                                                  |
| 人物    | string | 涉及人物及角色，格式：`主角名[主角]/对手名[对手]/旁观者名[旁观者]`，多个人用 `/` 分隔    |
| 冲突    | string | 这张卡的核心矛盾/事件内容，一两句话说清                                  |
| 史料出处  | string | 史料出处，多源并记时用 `/` 分隔（如 `史记·夏本纪/竹书纪年·夏纪`）                |
| 可信度   | string | 四级：`正史` / `诸子` / `传说` / `出土文献`                        |
| 本集用不用 | string | `用` / `不用` / `待定`（给出取舍建议，最终人工拍板）                      |
| 弹药潜质  | string | 弹药潜质标签，多个标签用 `/` 分隔，见 §1.4 枚举值                        |
| 模板适配  | string | 适配模板位置，多个位置用 `/` 分隔，格式见 §1.5                          |
| 叙事角色  | string | 叙事功能角色：`钩子` / `锚定` / `推进` / `转折` / `高潮` / `收尾` / `插件` |

### 1.5 模板适配层书写格式

每张卡可落入多个模板的多个位置，用 `/` 分隔：

```
人物篇-A:弧光顶点[高]/人物篇-B:第一幕-转机[高]/人物篇-C:颠覆认知[中]
```

格式规则：`模板名:位置名[置信度]`，多个适配项用 `/` 分隔。

**模板名枚举**：

- 人物篇：`人物篇-A`（情绪驱动） / `人物篇-B`（三幕式沉浸） / `人物篇-C`（认知颠覆） / `人物篇-D`（限知叙事） / `人物篇-E`（弧光顶点）
- 朝代篇：`朝代篇-A`（因果驱动） / `朝代篇-B`（势局搏杀） / `朝代篇-C`（主线压缩） / `朝代篇-D`（地图时间线） / `朝代篇-E`（制度演进）
- 事件篇：`事件篇-A`（张力驱动） / `事件篇-B`（沙盘推演） / `事件篇-C`（悬疑解谜） / `事件篇-D`（8段节奏） / `事件篇-E`（数据反差）

**位置名枚举**：

- 人物篇通用：`开场钩子/锚定线/起点段/人生推进/弧光顶点/收尾/承上启下`
- 人物篇插件：`侧写视角/历史对照组/拆账开庭/古文炸点/心理推演/决策瞬间`
- 朝代篇通用：`开场钩子/锚定线/起因段/事件推进/冲突顶点/收尾/承上启下`
- 朝代篇插件：`制度织入/历史对照组/拆账层累表/地图节点`
- 事件篇通用：`开场钩子/锚定线/土壤段/进程推进/事件高潮/收尾/承上启下`
- 事件篇插件：`决策瞬间/数据可视化/蝴蝶效应/争议拆账/环境氛围/关键决策/意外变量/个体命运/战后复盘/史料矛盾/考古新证/动机推演`

**置信度**：`高` / `中` / `低`

## 二、类型分支拆卡规则（按15套模板分别说明）

### 2.1 人物篇拆卡规则（5套模板共用底层卡池）

**拆卡粒度**：按人生阶段拆卡，每卡只装一个事件/一个冲突。一个人物生平拆出 20-50 张卡为常态，重大人物（如汉武帝、朱元璋）可拆至
80-100 张。

**拆卡时必须完成的动作**：

1. **人生阶段标注**：每张卡必须标 `人生阶段`，且阶段内按时间排序。
2. **弧光位置预判**：拆卡时就要判断这张卡在整个人物弧光中的位置（`弧光位置`），不是等写大纲时再想。
3. **情绪类型标注**：每张卡必须标 `情绪类型`，确保人物情绪曲线不重复、有起伏。
4. **颠覆印象度评分**：所有卡必须打 `颠覆印象度`，1-2 分的卡优先用于过渡节点（一句话带过），4-5 分的卡优先用于钩子、弧光顶点、拆账开庭。
5. **决策瞬间识别**：凡涉及人物做出选择的卡，必须标 `决策瞬间: true`，并在 `冲突` 中写清"
   当时有哪些选项，他为什么选了这一个"。
6. **侧写视角预绑定**：凡涉及他人对主角评价/观察的卡，必须填 `侧写视角`，供人物篇-A侧写视角插件位直接调用。
7. **对照组预绑定**：凡涉及与另一人物处境相似但结局不同的卡，必须填 `对照目标`，供对照组插件位调用。
8. **模板适配预填**：拆卡时就要在 `模板适配` 中标注该卡适合人物篇哪几套的哪个位置。一张卡可适配多套模板。

**各子模板拆卡侧重**：

| 子模板          | 拆卡侧重                                |
|--------------|-------------------------------------|
| 人物篇-A（情绪驱动）  | 重点拆"情绪转折点"和"决策瞬间"，确保弧光完整            |
| 人物篇-B（三幕式沉浸） | 重点拆"技能/行动细节"和"困境-转机-执行"三段素材         |
| 人物篇-C（认知颠覆）  | 重点拆"争议性评价"和"反常识事实"，确保有翻案弹药          |
| 人物篇-D（限知叙事）  | 重点拆"多角色视角"和"信息差"素材，确保限知视角可切换        |
| 人物篇-E（弧光顶点）  | 重点拆"主线节点"和"情绪峰值"，非主线素材标 `本集用不用: 不用` |

### 2.2 朝代篇拆卡规则（5套模板共用底层卡池）

**拆卡粒度**：按因果链拆卡（起因→经过→转折→结果→余波），一个朝代拆出 30-80 张卡为常态。

**拆卡时必须完成的动作**：

1. **因果位置标注**：每张卡必须标 `因果位置`，且同一因果链上的卡必须能回答"如果不这样，会怎样"。
2. **制度关联绑定**：凡涉及制度创立/变革/极端执行的卡，必须填 `制度名称` 和 `制度角色`，供朝代篇-A/E插件位调用。
3. **疆域变化记录**：凡涉及疆域变动（扩张/收缩/迁都/失地）的卡，必须填 `疆域变化` 和 `地理引用`，供地图节点调用。
4. **"势"的素材识别**：凡能体现"天道轮回/必然命运/制度惯性"的卡，必须标 `势类型`，供朝代篇-B造势段调用。
5. **博弈方标注**：凡涉及多方势力互动的卡，必须填 `博弈方`，供势-局-搏杀型模板调用。
6. **胜负手识别**：凡涉及关键抉择导致局势逆转的卡，必须填 `胜负手`，供胜负手段落调用。
7. **模板适配预填**：拆卡时就要在 `模板适配` 中标注该卡适合朝代篇哪几套的哪个位置。

**各子模板拆卡侧重**：

| 子模板          | 拆卡侧重                               |
|--------------|------------------------------------|
| 朝代篇-A（因果驱动）  | 重点拆"因果缝合点"，确保每个转折都有"如果不这样"的对应卡     |
| 朝代篇-B（势局搏杀）  | 重点拆"势→局→胜负手"三段素材，博弈双方卡片数量尽量均衡      |
| 朝代篇-C（主线压缩）  | 重点拆"主线节点"，支线素材标 `本集用不用: 不用` 或 `待定` |
| 朝代篇-D（地图时间线） | 重点拆"疆域变化节点"，每张卡必须含可可视化的地理信息        |
| 朝代篇-E（制度演进）  | 重点拆"制度变形史"，从诞生→极端→漏洞→补丁→废除的完整链条    |

### 2.3 事件篇拆卡规则（5套模板共用底层卡池）

**拆卡粒度**：按事件阶段拆卡（土壤→触发→升级→转折→高潮→收尾→余震），一个事件拆出 15-40 张卡为常态，复杂战役可拆至 60 张。

**拆卡时必须完成的动作**：

1. **事件阶段标注**：每张卡必须标 `事件阶段`，确保事件进程完整。
2. **多方视角拆分**：同一时刻、不同势力的行动/决策，必须拆成多张卡，分别标 `多方视角`，供事件篇-A多方视角切换调用。
3. **可量化数据提取**：凡涉及数字（兵力、伤亡、粮草、距离、时间）的卡，必须填 `量化指标`、`量化数值`、`现代类比`，供数据反差模板调用。
4. **环境因素记录**：凡涉及天气、地形、季节、疫病、粮荒的卡，必须填 `环境因素`，供环境氛围插件位调用。
5. **决策点识别**：凡涉及关键人物在转折点做出选择的卡，必须填 `决策人`，并在 `冲突` 中写清"一念之差"。
6. **蝴蝶效应追踪**：凡能追溯到远期影响的卡，必须填 `蝴蝶效应`，供蝴蝶效应插件位调用。
7. **争议等级评定**：凡涉及事件定性争议的卡，必须标 `争议等级`，4-5 分的卡优先用于争议拆账插件位。
8. **谜案线索提取**：凡涉及史料矛盾、考古新证、动机不明、心理留白的卡，必须填 `谜案类型` 和 `谜案描述`，供悬疑解谜模板调用。
9. **战役数据提取**：凡战役相关卡，必须填 `甲方兵力`、`乙方兵力`、`战场地形`、`后勤状态`、`士气描述`，供沙盘推演模板调用。
10. **8段式节奏预标**：凡适合短视频节奏模板的卡，必须标 `节奏位置`，确保3-5分钟版本可直接抽取。
11. **模板适配预填**：拆卡时就要在 `模板适配` 中标注该卡适合事件篇哪几套的哪个位置。

**各子模板拆卡侧重**：

| 子模板         | 拆卡侧重                          |
|-------------|-------------------------------|
| 事件篇-A（张力驱动） | 重点拆"多方视角切换点"和"决策瞬间"，确保张力层层递进  |
| 事件篇-B（沙盘推演） | 重点拆"战前沙盘数据"和"推演节点"，确保信息可还原给读者 |
| 事件篇-C（悬疑解谜） | 重点拆"证据缺口"和"史料矛盾"，确保有谜可解       |
| 事件篇-D（8段节奏） | 重点拆"节奏卡点"，确保每30秒一个情绪起伏        |
| 事件篇-E（数据反差） | 重点拆"可量化数字"和"现代类比"，确保数字冲击力     |

## 三、拆卡纪律（与15套模板对齐）

### 3.1 一卡一事

一张卡只装一个事件/一个冲突，装不下就拆两张。**禁止**把"鸿门宴全过程"塞进一张卡，必须拆为：刘邦赴宴（卡1）、项庄舞剑（卡2）、樊哙闯帐（卡3）、刘邦尿遁（卡4）。

### 3.2 歧义事件列版本

同一事件多个史料版本时，各版本分别成卡或在一卡内列全版本与出处，不抹平分歧（人格层·骨）。**特别要求**：凡涉及 `争议等级 >= 3`
的卡，必须在 `史料出处` 中列全矛盾出处，并在 `谜案描述` 或 `冲突` 中写明矛盾点。

### 3.3 可信度就实不就虚

传说就是传说，不许把传说洗成正史。`可信度` 字段严格四级：

- `正史`：二十四史、资治通鉴等官修史书
- `诸子`：诸子百家、笔记小说、文人著述
- `传说`：民间传说、演义、口传史料
- `出土文献`：甲骨文、金文、简牍、碑刻等考古材料

**模板适配规则**：

- 人物篇-A（情绪驱动）的弧光顶点、朝代篇-A的冲突顶点、事件篇-A的事件高潮：优先选用 `正史` 或 `出土文献` 卡
- 钩子、侧写视角、心理推演：可适度引入 `诸子` 卡，但必须标注
- `传说` 级卡片：仅可用于钩子、知识彩蛋、氛围营造，**禁止**进入拆账开庭、胜负手、解谜高潮等核心论证位置

### 3.4 弹药潜质从材料里长出来

这张卡本身有反差、有意外、有情绪才标；史料撑不起的潜质宁可标 `无`。

**弹药不可伪造清单**：

- `钩子`：必须有明确的反常事实或数字冲击，不能"为了钩子而钩子"
- `转折`：必须存在明确的"选择A还是选择B"的决策场景
- `情绪峰值`：必须有史料支撑的情绪描写或可通过行为推断的情绪状态
- `数据可视化`：必须有具体数字，禁止估算后编造
- `谜案证据`：必须是真实的史料矛盾或考古缺口，不能制造伪悬疑

### 3.5 拆卡即审

拆的时候就是史实红线的第一关，拿不准可信度的在 `本集用不用` 标 `待定`，交人工闸门裁决。

**新增：模板适配审校**

- 每张卡的 `模板适配` 必须至少匹配一套模板，完全匹配不上的卡标 `本集用不用: 待定`
- 同一模板同一位置的候选卡超过3张时，必须在 `本集用不用` 中给出取舍建议（如 `用-优先` / `用-备选` / `待定`）

### 3.6 一卡多模，复用优先

一张卡可能被多个模板复用，必须标注所有适配。例如"韩信胯下之辱"这张卡：

- 可喂给人物篇-A（情绪驱动）的"人生推进"段
- 可喂给人物篇-B（三幕式沉浸）的"困境与转机"幕
- 可喂给人物篇-C（认知颠覆）的"颠覆认知"段（"你以为韩信是懦夫？"）
- 可喂给事件篇-A（张力驱动）的"决策瞬间"插件位

**禁止**：为不同模板重复拆内容几乎相同的卡。复用优先，差异通过 `模板适配` 中的置信度和说明来区分。

### 3.7 节奏标记强制化

凡涉及短视频模板（人物篇-B/C、事件篇-D/E）的卡，必须在拆卡时完成 `节奏位置` 或 `颠覆印象度` 标注，确保下游可直接按节奏抽取，无需二次分析。

### 3.8 地图数据强制绑定

凡标 `地图节点` / `地理奠基` / `地域演进` / `战役沙盘` 的卡，必须同时填 `地理引用` 或 `疆域变化`，禁止"有卡无图"。

### 3.9 数字现代类比强制化

凡标 `数据可视化` 或填了 `量化指标` 的卡，必须在 `现代类比` 中给出至少一种现代类比（人口、面积、距离、时间、经济规模），禁止只给古代数字。

### 3.10 古文原句强制保留

凡涉及可引用古文炸点的卡，必须在 `古文原句` 中保留原文，并标注出处。禁止只记大意、不记原文——下游风格层可能需要逐字引用。
