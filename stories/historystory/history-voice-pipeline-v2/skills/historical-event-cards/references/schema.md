## 一、通用约定

1. **必填最小化**：每种卡型只有少量必填字段；可选字段有内容才写，没有就直接省略整个字段（不写空字符串）。
2. **卡号**：前缀字母 + 三位数字，按卡型各自递增（C-001、P-001……），全库唯一。
3. **可信度**：四级枚举 `正史` / `诸子` / `传说` / `出土文献`，每卡必填。
4. **史料出处**：多源并记用 `/` 分隔；网搜补料写明具体来源（书名/机构/页面标题），不许只写"网络"。
5. **存疑标注**：时间、数字、版本存疑时，在对应字段内标注 `约` / `通行说法` / `存疑`，并在备注说明。
6. **叙事角色**（事件卡专用）：`钩子` / `锚定` / `主线节点` / `插件` / `高潮` / `收束` / `衔接`——与大纲节点功能类型对齐，一卡可多个，用 `/` 分隔。
7. **弹药潜质**：自由标签（推荐词表见 §八），多个用 `/` 分隔；含 `古文炸点` 时 `古文原句` 必填。

## 二、事件卡 C-（主干）

**必填字段**

| 字段 | 说明 |
|---|---|
| 卡号 | `C-001` 起递增 |
| 卡型 | 固定 `事件` |
| 时间 | 事件时间，存疑标"约/通行说法" |
| 地点 | 事件地点（古地名可括注今地） |
| 人物 | `主角名[主角]/对手名[对手]/旁观者名[旁观者]`，多人用 `/` 分隔 |
| 冲突 | 核心事件，将原文片段摘出 |
| 史料出处 | 多源用 `/` 分隔 |
| 可信度 | 四级枚举 |

**可选字段（按需启用）**

| 字段 | 何时启用 |
|---|---|
| 古文原句 | 有可引用原文时（弹药潜质含"古文炸点"时必填） |
| 叙事角色 | 预判下游位置：钩子/锚定/主线节点/插件/高潮/收束/衔接 |
| 弹药潜质 | 预判亮点类型，见 §八推荐词表 |
| 本集用不用 | 卡片库复用场景：`用` / `备用` / `不用` |
| 人生阶段 | 人物篇：早年/崛起/巅峰/转折/落幕 |
| 弧光位置 | 人物篇：起点/上扬/顶点/下坠/终点 |
| 情绪类型 | 燃/虐/荒诞/悲壮/唏嘘 |
| 颠覆印象度 | 与大众既有印象的反差：高/中/低 |
| 决策瞬间 | 命运决策点描述（供决策燃点用） |
| 争议等级 | 史学界/大众认知争议：高/中/低 |
| 因果位置 | 朝代篇：远因/近因/导火索/结果/余波 |
| 制度名称 | 涉及的制度 |
| 事件阶段 | 事件篇：背景/爆发/胶着/转折/结局/余波 |
| 多方视角 | 事件篇：各方立场一句话 |
| 备注 | 反常点、互见卡号、取证说明 |

## 三、人物卡 P-

**必填**：卡号 / 卡型=`人物` / 人物名 / 身份 / 核心特质（一句话，带事迹支撑）/ 史料出处 / 可信度

**可选**：

| 字段 | 说明 |
|---|---|
| 绰号素材 | `特征—事迹` 对照（供大纲声音素材反推绰号），如 `善伪装—装病骗曹爽` |
| 名言 | 原文+出处（可作上屏炸点） |
| 人生阶段 | 阶段分期一句话 |
| 争议点 | 翻案空间的说明 |
| 关系指向 | 关联关系卡卡号 `R-___` |
| 备注 | 其他 |

## 四、关系卡 R-

**必填**：卡号 / 卡型=`关系` / 双方（`甲 vs 乙`）/ 关系性质（`恩怨`/`同盟`/`君臣`/`血缘`/`利益`/`师徒`，可复选用 `/`）/ 关键事件指向（`C-___`）/ 史料出处 / 可信度

**可选**：

| 字段 | 说明 |
|---|---|
| 张力点 | 谁欠谁、谁防谁一句话——关系网摆盘开场的直接素材 |
| 演化 | 关系随时间的变化（盟友→反目） |
| 备注 | 其他 |

## 五、背景卡 B-

**必填**：卡号 / 卡型=`背景` / 主题（`制度`/`地理`/`时代氛围`/`风俗`/`经济`）/ 要点（一句话说清"观众懂了这个才能懂事件"）/ 史料出处 / 可信度

**可选**：现代对照点（降维嫁接的候选）/ 适用段落建议 / 备注

## 六、数据卡 D-

**必填**：卡号 / 卡型=`数据` / 指标 / 数值 / 时间范围 / 史料出处 / 可信度

**可选**：对比基准（"相当于……"，供数字轰炸与弹幕反应位）/ 可视化建议 / 备注

## 七、彩蛋卡 E-

**必填**：卡号 / 卡型=`彩蛋` / 类型（`歇后语`/`相似事件`/`冷知识`/`名言`）/ 内容 / 史料出处 / 可信度

**可选**：挂接事件（`C-___`）/ 建议用法（`铺垫`/`对照`/`判词`/`氛围`）/ 备注

**纪律**：传说级彩蛋必须标可信度=`传说`，提醒下游挂声明牌。

## 八、枚举值总表

| 字段 | 合法值 |
|---|---|
| 卡型 | 事件 / 人物 / 关系 / 背景 / 数据 / 彩蛋 |
| 可信度 | 正史 / 诸子 / 传说 / 出土文献 |
| 叙事角色 | 钩子 / 锚定 / 主线节点 / 插件 / 高潮 / 收束 / 衔接 |
| 本集用不用 | 用 / 备用 / 不用 |
| 关系性质 | 恩怨 / 同盟 / 君臣 / 血缘 / 利益 / 师徒 |
| 彩蛋类型 | 歇后语 / 相似事件 / 冷知识 / 名言 |
| 弹药潜质（推荐词表，允许新词，校验仅提示） | 钩子 / 锚定 / 情绪峰值 / 侧写 / 对照组 / 拆账 / 古文炸点 / 心理推演 / 因果缝合 / 制度织入 / 地图节点 / 数据可视化 / 蝴蝶效应 / 环境氛围 / 沙盘决策 / 谜案证据 / 造势 / 胜负手 / 现代对照 / 意外变量 / 士兵视角 / 知识彩蛋 / 节奏留钩 |
