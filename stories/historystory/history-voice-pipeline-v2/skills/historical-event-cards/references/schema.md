# 事件卡 Schema 完整定义

> 本文件为 SKILL.md 的参考文档，按需加载。包含：基础层字段、三类型专属字段、模板适配层格式、弹药潜质枚举值。

---

## 一、基础层字段（所有卡片必填）

| 字段 | 类型 | 说明 |
|------|------|------|
| 卡号 | string | 格式 `C-001` 起递增，全库唯一 |
| 时间 | string | 事件时间（存疑纪年标"约/通行说法"） |
| 地点 | string | 事件地点 |
| 人物 | string | 涉及人物及角色，格式：`主角名[主角]/对手名[对手]/旁观者名[旁观者]`，多个人用 `/` 分隔 |
| 冲突 | string | 这张卡的核心矛盾/事件内容，一两句话说清 |
| 史料出处 | string | 史料出处，多源并记时用 `/` 分隔（如 `史记·夏本纪/竹书纪年·夏纪`） |
| 可信度 | string | 四级：`正史` / `诸子` / `传说` / `出土文献` |
| 本集用不用 | string | `用` / `不用` / `待定`（给出取舍建议，最终人工拍板） |
| 弹药潜质 | string | 弹药潜质标签，多个标签用 `/` 分隔，见 §1.4 枚举值 |
| 模板适配 | string | 适配模板位置，多个位置用 `/` 分隔，格式见 §1.5 |
| 叙事角色 | string | 叙事功能角色：`钩子` / `锚定` / `推进` / `转折` / `高潮` / `收尾` / `插件` |

## 二、人物篇专属字段（写人物时必填）

| 字段 | 类型 | 说明 |
|------|------|------|
| 人生阶段 | string | `幼年/少年/青年/壮年/暮年/盖棺` |
| 颠覆印象度 | int | 1-5 分，供认知入口与钩子选型 |

| 弧光位置 | string | `起点/上升/顶点/下降/终点/侧写/对照` |
| 侧写视角 | string | 侧写视角持有者（如 `伊尹眼中的桀`），无则留空 |
| 对照目标 | string | 历史对照组目标人物（如 `韩信 vs 项羽`），无则留空 |

| 古文原句 | string | 可直接引用的古文原句，供古文炸点/彩蛋插件位。无则留空 |

## 五、模板适配层书写格式

每张卡可落入多个模板的多个位置，用 `/` 分隔：

```
人物篇-A:弧光顶点[高]/人物篇-B:第一幕-转机[高]/人物篇-C:颠覆认知[中]
```

格式规则：`模板名:位置名[置信度]`，多个适配项用 `/` 分隔。

### 5.1 模板名枚举

- **人物篇**：`人物篇-A`（情绪驱动） / `人物篇-B`（三幕式沉浸） / `人物篇-C`（认知颠覆） / `人物篇-D`（限知叙事） / `人物篇-E`（弧光顶点）
- **朝代篇**：`朝代篇-A`（因果驱动） / `朝代篇-B`（势局搏杀） / `朝代篇-C`（主线压缩） / `朝代篇-D`（地图时间线） / `朝代篇-E`（制度演进）
- **事件篇**：`事件篇-A`（张力驱动） / `事件篇-B`（沙盘推演） / `事件篇-C`（悬疑解谜） / `事件篇-D`（8段节奏） / `事件篇-E`（数据反差）

### 5.2 位置名枚举

- **人物篇通用**：`开场钩子` / `锚定线` / `起点段` / `人生推进` / `弧光顶点` / `收尾` / `承上启下`
- **人物篇插件**：`侧写视角` / `历史对照组` / `拆账开庭` / `古文炸点` / `心理推演` / `决策瞬间`
- **朝代篇通用**：`开场钩子` / `锚定线` / `起因段` / `事件推进` / `冲突顶点` / `收尾` / `承上启下`
- **朝代篇插件**：`制度织入` / `历史对照组` / `拆账层累表` / `地图节点`
- **事件篇通用**：`开场钩子` / `锚定线` / `土壤段` / `进程推进` / `事件高潮` / `收尾` / `承上启下`
- **事件篇插件**：`决策瞬间` / `数据可视化` / `蝴蝶效应` / `争议拆账` / `环境氛围` / `关键决策` / `意外变量` / `个体命运` / `战后复盘` / `史料矛盾` / `考古新证` / `动机推演`

### 5.3 置信度

`高` / `中` / `低`
