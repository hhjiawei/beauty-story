## 九模块

流水线是骨骼，模块是血肉。**模块是节拍器而非内容**——内容可换，节拍不可缺席；对固定模块的自觉取消（明示其缺席）本身构成更强效的节拍信号。

| 模块 | 功能 | 位置限制 |
| --- | --- | --- |
| 1. 钩子 | 注意力捕获 | 开场与每节开头 |
| 2. 插播 | 声明跑题边界、管理注意力、播种伏笔；实质是安抚好奇心（"你此刻想问的，先记下，后面还"）；信号词"顺便说一句""提示一下""话说回来" | **只允许出现在第二、三段之间**（立场已松、高压未至的间隙） |
| 3. 证据排比 | 第三段主体 | 第三段 |
| 4. 反问转场 | 分节兼泵压 | 只插在第三段阵间及第三、四段之间 |
| 5. 缓冲／商单勾连（合并） | 缓冲位与广告位是同一个坑位；商单统一用"语义钩连"转场——广告前最后一句与产品共享一个语义钩（实例："直挺挺健康的颈椎"→护颈枕；"夜观天象"→"古人对动物也投射情感"→文物书；"探查风土人情找到强身健体利器"→苹果醋；"崽卖爷田不心疼，咱们普通人得精打细算"→二手平台） | 只插在第三段中点之后、过载拐点之前；钩连句在大纲布点阶段埋好，成稿后不硬塞 |
| 6. 定场 | 单篇结尾固定栏目——栏目化收束（阴暗小故事／高祖小故事／太傅小故事／知识点补充），栏目名固定、内容轮换，本身即系列资产 | 单篇结尾 |
| 7. 透镜 | 每人每事配一个命名的现代理论框架，全篇一次 | 第四段归因处或盖棺判词处 |
| 8. 视角切换／地图盘点 | 多线叙事先"打开地图"固定全局坐标再逐格展开；同一事件可用第二视角重述一次（"如果我们把视角切换到鲜卑慕容家族，这个故事将会有另外一种说法"）；多线收拢必须打信号（"现在时间线收束了""目光回到正面战场"） | 多线段落起点与收拢点 |
| 9. 互动钩子 | 直接向观众提问自答（"细心的小伙伴可能发现了……他是谁呢？"）或向观众征答（"有没有文笔好的小伙伴魂穿一下……我一定订阅连载"）；管理注意力＋养评论区互动率 | 每篇至少一处，证据群阵间或收束段之前 |

## 语气三轨与禁区

情绪曲线解决"何时压、何时松"，三轨纪律解决"此处能不能开玩笑"。**在死人堆里说段子＝本体系最大事故，质检时第一个删。**

| 轨道 | 适用范围 | 纪律 |
| --- | --- | --- |
| 戏谑轨 | 默认轨道 | 弹药、绰号、设问、职场降格全部合法 |
| 悲悯轨 | 苦难、殉国、冤死、理想主义者之死专用 | **弹药清零、绰号清零、设问清零**，只白描＋原文直引；禁配搞笑定场栏目收尾 |
| 热血轨 | 英雄高光、绝地反击、临危受命专用 | 短句排比＋判词，节奏加密 |

切换规则：

- 轨道切换处必须有显式过渡句（"不过话说回来""好了，总结一下""故事讲到这儿，笑不出来了"）；
- 悲悯段落清单在大纲布点阶段即全部锁定，写作时不得临时改轨。

实例锚点：悲悯轨——刘渊之死（"老天给了他推翻旧时代的机会，却没有给他时间"）、徐嵩之死、萧懿之死；热血轨——北宫纯夜袭、萧懿一夜扭转建康（"保家卫国、临危受命的故事，任何时候都值得传颂"）。

## 声音系统（梗是消耗品，句式与人设是资产）

### 签名句式资产库（跨期复用的节奏锚点，相当于评书定场诗）

- 插叙收拢："话说回来"；反转预告："不出意外地，又出现了意外"；阅历标榜："身经百战，见得多了"；学习梗："加强学习一个"；死亡通报："下线了"；补充声明："顺便说一句""提示一下""小豆必须要补充个知识点"。
- 大纲布点阶段即标注落点；同类句式不连续出现两次以上；同一签名句式全系列有总配额，用尽即换新锚点，不可复读到油。

### 称呼系统

- **朝代自称**："我晋""我大汉"确立自家人视角与阵营体温；
- **在场感称呼**："观众朋友们""小伙伴们"，开场钩子内或紧随其后必出现一次；
- **绰号系统**：从人物最炸的事迹反推（老乌龟司马懿、小波皮王浚、右侯张宾、猪王刘彧），绰号—特征—事迹三者对应；正面英雄不起贬损绰号；
- **职场降格**：正式称呼换现代职场角色（干部、老板、打申请、升职加薪、带资进组、开班会），史料引用内保留原称呼。

### 弹药（现代语域词）

- 先找史实逻辑支撑点，再选语域（职场／游戏／网络／校园／体育／金融）；
- 精度自检：每个弹药词必须答得出"它映射哪条史实"，答不上就删；
- 同类弹药不连续出现两次以上。

## 可信度系统（与营销号的分水岭；完播靠情绪，关注转化靠信任）

### 锚定四规

1. **年号＋公元双标**：每个新时间点双轨标注（"西晋永嘉二年，汉赵永凤元年""公元370年正月"）；
2. **原文＋白话翻译**：原文照录，梗只落在转述层，不动原文；
3. **数据砸实**：每个宏大判断后跟数字托底（石勒称王"二十四郡二十九万户"；前燕户籍"157郡1579县998万余人"）；
4. **史源明示**：观点与争议标出处（"《中国军事通史》曾毫不客气地批判""有一部分史学家认为"）。

### 推理声明等级

- 或许／估计 → 弱推测；
- 我们有理由相信 → 证据链推理（≥2 条不同段落证据）；
- 以下为个人观点 → 强观点；
- 孤证 → 只写"存疑""史书没有告诉我们"。

推理过程本身写给观众看，是内容不是瑕疵。

### 评价姿态：呈现优先于裁决

争议人物的终评不做结论，做展示。实例（冉闵）：「每个人心中都有衡量的标准……我所能做的，就是把他的所作所为展示给大家。」此姿态是信任资产，不是立场缺失。
