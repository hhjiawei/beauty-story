## 一、史料清单（来源等级 + 用途分类）

**来源等级四分**：

| 等级 | 含义 | 使用规则 |
|---|---|---|
| A | 正史原文（《史记》《汉书》《晋书》《资治通鉴》等二十四史+通鉴） | 可直接引用上屏 |
| B | 正史旁证、通鉴考异、出土文献（墓志、简牍、碑刻） | 可引用，注明出处 |
| C | 名家研究与评语（司马光"臣光曰"、苏轼、陈寅恪、吕思勉等） | 作权威背书，托住宏大判断 |
| D | 野史笔记、后世演绎、民间传说（《世说新语》轶闻、演义、玛丽王后式典故） | **必须挂声明牌**（"野史记载""相传""演绎里说"），在清单"用途"列注明 |

**用途分类**（填在清单"用途"列，指导写作节点怎么用这条史料）：
- `上屏炸点`：口语感/反差感原文，直接引用（引文优先级：口语感＞情绪浓烈＞信息量）；
- `权威背书`：名家评语，托判断；
- `数据托底`：兵力、人口、时间等数字，宏大判断后砸实；
- `翻译素材`：需白话翻译的原文，梗只落在翻译层；
- `判词依据`：盖棺定论时的原文凭据。

**查找路径**：事件卡"史料出处"字段 → 核原文（不确定就联网核实，转引的段子级"古文"先怀疑后使用）→ 定级 → 定用途。每篇 A 级引文 3–5 处为宜，多了掉书袋。

## 二、歇后语清单（传统 + 自创）

**每条四字段**：歇后语本体 ＋ 挂接事件 ＋ 建议入点（S-___）＋ 类型（传统/自创）。

**传统歇后语怎么找**：
1. 从本集人物/事件的成语典故出发——人物有成语就有歇后语（司马昭之心——路人皆知；徐庶进曹营——一言不发；周瑜打黄盖——一个愿打一个愿挨）；
2. 从事件结构出发找通用歇后语（竹篮打水——一场空，用于白费力气型事件；肉包子打狗——有去无回，用于送死型决策）；
3. 挂接点必须与事件**结果同构**——歇后语的后半句就是事件的结局，对不上的不用。

**自创歇后语体怎么造**（历史场景＋现代俗语后半句）：
- 公式：`历史场景——现代俗语判词`，前半句给画面，后半句给反转判词；
- 正例："烽火戏诸侯——拿全天下开玩笑""食人部落BBQ——那是老熟人了"；
- 造完自检：后半句是否同时是"观众对该事件的正确评价"？是才成立。

**密度纪律**：传统+自创合计每篇 1–3 处；自创体每集每种句式 ≤2 处（与炸点弹药第 2 发"预期违背式造句"共享额度）；悲悯段禁入。

## 三、相似事件（历史母题对照库）

**每条三字段**：案例（朝代+事件）＋ 相似点 ＋ 引申方式。

**相似点的合格标准**：结构同构，不是属性相似。"都是坏人"不合格；"同为权臣废立皇帝"合格。

**引申方式三选一**：
- `铺垫`：提前埋观众认知（讲司马师废曹芳前，先点"上一个废皇帝的是董卓"——观众自动调出董卓记忆，不用解释就懂了严重性）；
- `对照`：抬高或反衬本段（同样北伐，诸葛亮五次与姜维九次对照；同样托孤，刘备托孤与曹叡托孤对照）；
- `判词`：借前例下结论（"历来政变，一念生、一念死——巫蛊之祸亲儿子都杀"→ 曹爽必须死）。

**常见历史母题对照库**（联想起点，非穷举）：

| 母题 | 可对照案例群 |
|---|---|
| 权臣废立 | 董卓废少帝／霍光废昌邑王／司马师废曹芳／桓温废司马奕 |
| 托孤翻船 | 刘备托孤（成）／曹叡托孤司马懿（翻）／孙策托孤（成） |
| 继承人埋雷 | 司马衷／刘禅／朱允炆／扶苏vs胡亥 |
| 功高震主 | 韩信／年羹尧／檀道济／郭子仪（善终对照组） |
| 政变一念生死 | 高平陵之变／玄武门之变／夺门之变／巫蛊之祸 |
| 绝境翻盘 | 昆阳之战／淝水之战／鄱阳湖之战 |
| 接班人太贤也是错 | 司马攸／朱标／李建成 |
| 胡汉关系 | 白登之围／五胡乱华／安史之乱／靖康之变 |
| 奢靡亡国 | 石崇斗富／隋炀帝／八旗子弟 |

使用纪律：每篇相似事件 1–3 条；引申材料必须正史有据（A/B 级）；一笔带过为主，展开超过三句就变离题。

## 四、弹药清单（推荐写法标准）

**每条四字段**：`弹药名（类型）｜作用｜推荐度｜原因`。

- **弹药名（类型）**：类型 ∈ 开场技法弹／炸点技法弹（语言·结构·情绪）／方言弹／词汇弹（九类指纹之一）；
- **作用**：对这段的节奏/理解/情绪起什么具体作用（"3秒抓人""把排比情绪推到顶点""给观众留弹幕反应位"）；
- **推荐度**：`强烈推荐`（每篇 ≤4 处，没它效果明显受损）／`可选`；
- **原因**：为什么这段配得上它——史料锚点是什么、与上下文怎么配合。

**反面 vs 正面示例**：
- 反面：`让子弹飞｜好用｜强烈推荐｜很配`——全是废话；
- 正面：`让子弹飞三部曲（词汇弹·网络）｜把梁习收编胡人豪帅的三步流程讲成一个观众秒懂的结构｜强烈推荐｜C-012 恰好是"请客→扣押人质→收编"三步，与梗的映射一一对应`。

## 五、联网补弹规程

本地弹药库查不到合适弹药时：

1. 先确认不是"该段不需要弹药"——空着是合法答案；
2. 确需补弹：联网搜索该类素材（歇后语、相似案例、热梗），搜索结果按 §一来源等级定级；
3. 搜来的弹药入清单时标注来源与等级，D 级材料注明"须挂声明牌"；
4. 新弹药若质量高，回写进 references/ammunition.md 对应类别，让库越用越厚。
