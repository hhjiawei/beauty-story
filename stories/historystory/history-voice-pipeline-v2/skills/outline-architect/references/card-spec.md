## 一、篇级总卡（字段规格）

大纲包的第一张卡，写作节点阶段一"全局决策"直接复用。

```
───────────────────────────────────────────────────────
【篇级总卡】
───────────────────────────────────────────────────────
题目/集名   ：
叙事路由    ：人物传 / 事件录 / 制度论 ＋ 判定理由（一句话）
目标时长    ：__分钟 → 总字数预算 ____字（×270字/分钟）
主线因果链  ：因为……所以……最终……（一句话讲完全篇逻辑）
开头前置    ：前置片段 ＋ 选帧理由（为什么是矛盾最激烈的一帧）
结尾呼应    ：前置片段归位方式 ＋ 开头设问回收方式
声音素材    ：领属词 ＋ 主要人物绰号候选（绰号—特征—事迹）
伏笔总台账  ：F-01 埋设 S-___ → 回收 S-___（内容一句话）；逐条登记
炸点总表    ：S-___（层型）逐条列出——核对相邻不同型
情绪地图    ：各段轨道一览（戏谑/悲悯/热血+强度），悲悯段标【悲悯】
弹药总表    ：全篇弹药汇总——查重：同词 ≤2 次、同类不连续两段
字数预算表  ：各段预计字数合计 = 预算 ±10%
自补清单    ：缺失施工件 / 存疑史实及处理方式
───────────────────────────────────────────────────────
```

填写规则：
- **主线因果链**写不出一句话，说明第1步因果主干没排好，返回重排；
- **伏笔总台账**是机检对象：每个埋设必须有回收，回收段号 > 埋设段号；
- **弹药总表**由段级卡汇总而成，用于全篇查重（同词 ≤2 次、同类弹药不连续两段）。

## 二、段级施工卡（字段规格逐条）

```
───────────────────────────────────────────────────────
【段级施工卡】S-001 ｜ 模块归属：①钩子/②铺陈/③展开/④高潮/⑤收束/⑥尾声
───────────────────────────────────────────────────────
段意       ：
功能类型   ：
时间码     ：
使用史料卡 ：
节点分级   ：
指定技法   ：
因果接口   ：
弹药清单   ：
史料清单   ：
歇后语清单 ：
相似事件   ：
炸点       ：
伏笔       ：
情绪坐标   ：
预计字数   ：
备注       ：
───────────────────────────────────────────────────────
```

| 字段 | 必填 | 填写规则 |
|---|---|---|
| S-编号＋模块归属 | 是 | S-001 起连续递增；模块六选一（①~⑥） |
| 段意 | 是 | 一句话概括本段讲什么。写不出段意＝这段不该存在，合并或删 |
| 功能类型 | 是 | 钩子 / 锚定 / 主线节点 / 插件 / 高潮 / 收束 / 衔接 |
| 时间码 | 是 | `__:__–__:__`，由累计字数 ÷ 270 字/分钟推算 |
| 使用史料卡 | 是 | `C-___`，多张用 `/` 分隔；⑥尾声段填 `—` |
| 节点分级 | 是 | 强化 / 关键 / 过渡；钩子等特殊段填 `—` |
| 指定技法 | 是 | 六技法复选：[心理代入] [词汇降维] [场景重构] [反讽] [设问] [史料引用]；悲悯段只许 [史料引用] |
| 因果接口 | 是 | `本段之因 ← S-___ ｜ 本段之果 → S-___`；①钩子段之因填 `—`，⑥尾声段之果填 `—`（下集） |
| 弹药清单 | 可空 | `弹药名（类型）｜作用｜推荐度｜原因`；多条分行；无则填 `空` |
| 史料清单 | 可空 | 小表：`\| # \| 典籍 \| 原文摘录 \| 对应事件卡 \| 来源等级 \| 用途 \|`；无则填 `空` |
| 歇后语清单 | 可空 | `歇后语 ＋ 挂接事件 ＋ 建议入点 ＋（传统/自创）`；无则填 `空` |
| 相似事件 | 可空 | `案例 ＋ 相似点 ＋ 引申方式（铺垫/对照/判词）`；无则填 `空` |
| 炸点 | 是 | `语言/结构/情绪 类型＋位置` 或 `无` |
| 伏笔 | 是 | `埋设 F-__` ／ `回收 F-__` ／ `无` |
| 情绪坐标 | 是 | 戏谑/悲悯/热血（强度 _/5）；悲悯必须显式写出 |
| 预计字数 | 是 | 整数；全篇合计 = 预算 ±10% |
| 备注 | 可空 | 只写施工指令（怎么写、避什么坑、呼应哪里），**禁写正文句子** |

三个关键字段的判定细则：

**因果接口**：本段之因 = 哪一段的结论/态势是本段发生的前提；本段之果 = 本段结尾的态势是哪一段的引线。填不出因的段是孤立的——要么补过渡段，要么把它并进有因的段。例外：①钩子段之因填 `—`（它是剪来的前置片段，因在全篇）；⑥尾声段之果填 `—（下集）`。

**推荐度**：`强烈推荐` = 这段没了它效果明显受损，必须写清"为什么非它不可"；`可选` = 锦上添花，一句话即可。强烈推荐每篇 ≤4 处——处处必选项等于没有重点。

**情绪坐标**：悲悯段一旦标出，本段弹药清单必须为 `空`、技法只留 [史料引用]、歇后语/方言禁入。

## 三、完整填写示例（两晋·司马衷立储篇）

### 篇级总卡示例

```
───────────────────────────────────────────────────────
【篇级总卡】
───────────────────────────────────────────────────────
题目/集名   ：我晋没好人了？为什么一定要选弱皇帝司马衷接班？
叙事路由    ：制度论（框架先行+层层归因）——要让观众记住"嫡长子继承制锁死一切"这个规律
目标时长    ：15分钟 → 总字数预算 4050字（×270字/分钟）
主线因果链  ：因为司马师意外早逝、司马攸过继归宗，所以司马炎死守嫡长子继承制不敢立贤，最终傻皇帝上位、死局成型
开头前置    ："何不食肉糜"名场面＋洋梗对比（法国公主版）——最荒诞的一帧，观众一秒抓住"皇帝是傻子"
结尾呼应    ：回收设问"为什么非要立傻子"——答案：不是看不见傻，是不敢立贤；预告八王之乱
声音素材    ：领属词"我晋"；老影帝—演技—装病骗曹爽（司马懿）；傻皇帝—地狱笑话—何不食肉糜（司马衷）；好圣孙—聪慧—祖父钦点（司马遹）
伏笔总台账  ：F-01 埋设 S-002（"记住这个司马攸，这将是滔天巨浪的导火索"）→ 回收 S-005（立贤即归司马攸，死局揭晓）
              F-02 埋设 S-001（设问：为什么一定要立傻子？）→ 回收 S-006（因为不敢立贤）
炸点总表    ：S-003（结构·认知铺垫）→ S-005（语言·排比评估流剪断）→ S-006（情绪·决策现场燃点）——相邻不同型 ✓
情绪地图    ：S-001~005 戏谑（3/5~4/5）；S-006 戏谑转凝重（4/5）；无悲悯段
弹药总表    ：老影帝×2、锁死×2、影帝×1、站队×1、刷履历×0……同词 ≤2 次 ✓
字数预算表  ：S-001(350)+S-002(700)+S-003(600)+S-004(750)+S-005(800)+S-006(850) = 4050 ✓
自补清单    ：风格施工包第6件"史料双保险"缺失 → 已按 A/B 级史料规则自补锚点检查单
───────────────────────────────────────────────────────
```

```

功能类型   ：钩子
时间码     ：00:00–01:18

弹药清单   ：课本/影视认知反差（开场技法弹）｜用法国公主梗降低进入门槛｜强烈推荐｜中外同构"统治者对民间疾苦的离谱回应"，3秒抓人

时间码     ：07:24–10:22
使用史料卡 ：C-004/C-005
节点分级   ：强化

            | 1 | 《晋书·齐王攸传》 | "攸性孝友，多材艺，清和平允" | C-004 | A | 排比弹药库 |
            | 2 | 《晋书·齐王攸传》 | 司马懿封司马攸舞阳侯 | C-005 | B | 细节炸点：舞阳是司马懿封地 |
歇后语清单 ：空
相似事件   ：朱标之于朱元璋（铺垫）——"好圣孙/贤嗣子"母题，供写作节点引申一句即可，不展开
炸点       ：语言·排比评估流（段尾"别喊了，再喊司马炎真要急眼了"剪断）
伏笔       ：回收 F-01（司马攸=导火索在此引爆）
情绪坐标   ：戏谑（强度 4/5）
预计字数   ：800
备注       ：排比六项以内，逐项须有 C-004/C-005 支撑，不许虚构美德；剪断句后立刻转判词，不追加解释；搭靶段长度 ≥ 后段亮锤的 5 倍
───────────────────────────────────────────────────────
```

## 四、常见填写错误

1. **备注写正文**：备注里出现可直接播读的完整句子——备注只写指令（"钩子≤300字""挂声明牌"），正文是写作节点的事。
2. **因果接口空转**：全文每段的果都填"→ 下一段"——等于没填。果要写出喂给哪段的什么内容（态势/问题/情绪）。
3. **弹药只列名**：弹药清单只写弹药名不写作用与原因——写作节点无法判断保留还是撤弹。
4. **伏笔有埋无收**：F-编号只有埋设没有回收，或回收段号 ≤ 埋设段号——机检 FAIL。
5. **悲悯段挂弹药**：情绪坐标标了悲悯，弹药清单却不为空——机检 FAIL。
6. **歇后语硬凑**：与事件八竿子打不着的歇后语——清单允许空着，空着胜过硬凑。
7. **相似事件乱引申**：相似点不成立（只是都是"坏人"）——相似点必须落在结构同构上（同为废立、同为托孤、同为功高震主）。
