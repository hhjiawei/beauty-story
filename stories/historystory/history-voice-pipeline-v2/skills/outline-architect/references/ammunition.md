## 一、弹药总纪律（先于一切）

1. **映射自检**：每个梗必须答得出"它映射哪条史实"，答不上就删——八卦感和瞎编的分界线。
2. **史料底线**：所有弹药素材（外号、引文、意外、关系、乡音依据）必须正史有据；撑不起的位置宁可空着，不许注水凑密度。
3. **兑现纪律**：反常识断言、悬念标题、盖牌、高潮前置——开场/中段埋的钩，正片与收尾必须兑现；兑现不了＝标题党，撤弹。维护一张「钩子台账」：埋钩位置 → 兑现位置。
4. **密度上限**：3000–6000 字成稿，词汇黑话 8–15 处；单段 ≤2 处；同一黑话词单篇重复 ≤2 次（跨篇复用是风格指纹，允许）；同一句不叠 2 个以上评价定性词。
5. **类型轮换**：相邻炸点不得同型（语言→结构→情绪交替），同型连发会脱敏。
6. **悲悯/动情隔离**：悲悯轨段落弹药绰号清零；动情点前后 30 秒不玩梗、不上方言；悲情、诀别、殉难场景禁用方言。
7. **原文隔离**：史料原文引用内保留原称呼，弹药只落在白话翻译层和叙述层。
8. **一节点一花活**：方言不与对手戏、古文炸点同段叠加。

## 二、弹药选配决策：五问流程

每写到一个需要"加料"的节点，按固定顺序自问五问。任何一问答不上，就撤弹或换弹——**不许凭感觉上弹药**。

```
问1 功能定位 → 问2 题材适配 → 问3 史料锚点 → 问4 密度轮换 → 问5 兑现能力
```

**问1：这个位置的功能是什么？——决定去哪个库取弹**

| 节点功能 | 取弹路径 | 选弹范围 |
|---|---|---|
| 开场钩子 | references/opening-hooks.md | 9 发，按题材筛，主钩子每集仅 1 发，禁止挪到中段 |
| 炸点 | references/explosion-points.md | 12 发，注意语言/结构/情绪三层轮换 |
| 中段插件 | references/explosion-points.md | 优先语言层（造句/造梗/原文）＋盖牌 |
| 动情点 | references/explosion-points.md | 情绪层为主（决策燃点），禁用方言、梗 |
| 收尾 | references/explosion-points.md | 结构层归位类（高潮前置回收、盖牌掀牌、反转兑现） |
| 方言场景 | references/dialect-ammunition.md | 5 发，先过第 5 发"选型标准"硬过滤，四条全过才准上 |
| 词汇降维（叙述层润色） | 本文件 §四～§十一 | 按句法位置选配（见 §四位置搭配规则） |

**问2：题材与路由是否适配？——对照"适配"字段初筛**
- 人物篇/人物传：外号定格式、命运压缩句、决策燃点、方言自语优先；
- 朝代篇/制度论：设问破题、小切口大历史、关系网摆盘、高潮前置优先；
- 事件篇/事件录：荒诞意外、短句鼓点、预判弹幕优先。
- 时长换算密度：10 分钟人物篇 ≈3-4 个炸点；20-30 分钟朝代篇 ≈7-10 个，其中情绪层 ≥1 个。

**问3：材料撑得起吗？——史料锚点检查**
先找史实逻辑支撑点，再嫁接弹药。答不出"这发弹药映射哪条史实"的，删。没有真实"自信→翻车"弧线的段落不上反转；没有史料记载的偶发事件不上荒诞意外；后见之明不许进入决策现场。

**问4：密度与轮换过了吗？——对照「已有弹药清单」查重查量**
- 该词汇本篇是否已用满 2 次？该段是否已有 2 处黑话？
- 上一个炸点是什么层？同层必须换。
- 方言是否超全片 ≤3 处（人物篇 ≤2 处）？本节点是否已挂了别的花活？
- 是否落在动情点前后 30 秒隔离区 / 悲悯轨内？

**问5：能兑现吗？——登记钩子台账**
只要埋下反常识断言、悬念、盖牌、高潮前置，立刻登记「埋钩位置 → 计划兑现位置」；阶段三质检时逐条核销。兑现不了的钩，当场撤弹，不留到成稿。

## 四、词汇指纹库（九类，含位置搭配规则）

从 93 篇语料聚合的高频"词汇指纹"，仿写任意朝代通用（跨朝代已验证）。每类附代表词条与样本句。

**① 称谓与身份替换**——放段落主语位置，奠定"现代视角看古人"基调：
我晋（"在我晋，有什么值钱的？人命才值钱"）、咱/咱们（"咱们猜猜他手底下有没有羌族的士兵呢？"）、老影帝、老登（偏昏暴帝王）、基本盘（偏权力结构分析）、属于是（句尾补刀："满门'忠烈'了，属于是"）、乖宝宝、卷王。

**② 动作与能力描写**——放战局/权谋转折处，制造爽感：
骚操作、花招、锁死（"嫡长子继承制锁死了一切可以变革的渠道"）、梭哈（"只要有点本钱，大家都想梭哈"）、苟且发育、金蝉脱壳、丝滑（"非常丝滑地出卖了曹魏"）、连招/组合拳、发癫、翻脸、作妖、一拍即合、抽抽、带节奏、下分。

**③ 评价与定性词**——放人物出场或结局判定处，一锤定音：
狠人（"史上有名的丑女和狠人——贾南风"）、猛人、最猛、顶流、拉胯、破防/红温、上头、摆烂、躺平、内卷/极限内卷、摸鱼、裂开、妖/作妖、剧本（"天命剧本在身"）、流量体质、神仙。

**④ 现代制度与概念嫁接**——放制度分析处，制造荒诞反差：
表演/表演归表演、站队（"以为是给了自己一次站队的机会"）、内耗、焦虑、天命、玄学、编制、刷履历、背锅、优化流程。

**⑤ 转折与衔接句式**——放预期违背的落点前，制造反转：
其实（高频签名词："其实都看出来了，而且都觉得傻子接班很不妥"）、也就是说（逻辑换算："不立长就立贤"）、结果呢、说到底、殊不知、说白了、坦白来说。

**⑥ 心理代入标记**——脑补触发词，配合引擎一：
如果说……（"如果说桓温的'忠'始终被人放在放大镜下质疑"）、其实（引出动机）、不过别担心、估计也是纳了闷儿了。

**⑦ 史料考据引用**——权威建构，不抢戏：
"直接上原文"、据《晋书》/《资治通鉴》、"司马光老先生终于忍不了了"。

**⑧ 设问与反问**——钩子/段间悬念：
但结果呢？、那么问题来了、为之奈何？、翻译翻译什么叫……、想打胜仗吗？、"怎么它还强大上了呢？"

**⑨ 通用黑话/句式**：
套路（"东晋朝廷的套路还是一如既往的熟悉"）、杀胡令式专有名词玩梗、Buff（"又有四个 Buff 摆在咱们大晋面前"）。

**位置搭配总规则**：称谓替换 → 段落主语位；动作能力词 → 战局/权谋转折处；评价定性词 → 出场/结局判定处；转折衔接词 → 反转落点前；史料考据与设问 → 权威建构与悬念处。开头钩子与结尾收束各留 1 处强标签即可，中段可密。

## 十一、领属词系统

- 一个系列只认一个领属词："我晋""我大晋"（两晋系列）、"我大隋""我大清"（其他系列）。
- 用法：领属词 + 反常识判词，形成招牌句式——"在我晋，有什么值钱的？人命才值钱。"
- 领属词同时承担立场功能：以王朝为"自家"视角叙事，乱臣贼子自然成了"你"。

## 十二、弹药自造规则（新朝代）

写新朝代时弹药不够，按此流程自造：

1. **找史实锚点**：先确定这条史实是什么（制度/事件/人物行为）。
2. **找现代同构**：现代生活里什么场景与它有相同结构？（九品中正制 ≈ 招聘只看爹；阴养死士 ≈ 偷偷攒团队）
3. **选弹药池**：词汇弹九类 / 技法弹 26 发 / 方言弹，按节点功能避重选择。
4. **过五问**：功能定位 → 题材适配 → 史料锚点 → 密度轮换 → 兑现能力（§二）。
5. **写入对照表**：新弹药补进声音卡，保证后文复用一致。
