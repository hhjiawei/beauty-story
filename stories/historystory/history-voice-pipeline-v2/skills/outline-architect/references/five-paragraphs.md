# 五段写作规程（细则）

本文件是五段流水线每段的完整规程，大纲布点时对照执行。

## 目录

- 第一段：开场（冷热双形态）
- 第二段：翻案（含无翻案变体）
- 第三段：证据群轰炸
- 第四段：理性人反转
- 第五段：收束甩钩（四形态）
- 流水线运行规则（成稿顺序/落差守恒/删减优先级）

---

## 第一段：开场——冷热双形态 

### 形态A：冷开场（异常定格）——新系列首篇、单点篇用

- **任务**：在观众心中种下未经解释的情绪判断。只负责让人感到"这里有问题"，不传授知识。
- **步骤**：选点（挑反常细节，标准是无需背景知识即可感到异样）→ 放大（感官化、场景化语言撑满）→ 定格（最刺眼的瞬间停笔，不解释、不追溯）→ 提问（必须是"为什么"，不能是"是什么"）→ 封口（暗示"这不是偶然"，只暗示不证明）。
- 实例：「1861年，31岁的咸丰皇帝咳血不止，但他拒绝吃药，反而变本加厉地酗酒……这究竟是为什么？」「黄金、宫殿、玉足。这是南齐皇帝萧宝卷最喜爱的三样东西。」
- **验收**：删去一切背景知识仍成立；陌生读者十秒内能指出"哪里不对劲"；问题无法在本段内自答。
- **禁区**：年代地点铺陈；复述常识；提前泄露归因方向；在情绪最高点追加解释。

### 形态B：热开场（承接递进）——连续剧篇用

- **任务**：三十秒内让没看上期的观众跟上，同时把上期悬念升级为本期危机。
- **步骤**：上期收束点一句话回收 → 本期危机递进 → 落在本期主线悬念。拟声词起手（"啊啊啊！"）是合法情绪起手式。
- **验收**：新观众三十秒可入戏；老观众有"接着上次"的连续感；开场即定本期主线。

## 第二段：翻案——含"无翻案"合法变体

### 标准形态

- **任务**：把将被推翻的对象辩护到最高点。产出不是洗白，是落差起点。
- **步骤**：复述共识（先替观众说出其进场时的主流判断）→ 选峰值维度（找对象最无可争议、反驳成本最高的维度）→ 推峰（排比阵列逐项加码，不穿插任何贬损与"但是"）→ 峰值停笔（最高点直接切断，论证悬空）。
- 实例：刘曜——先立儒学修养、书法一字千金、纳谏"古人之风"，再破"沉迷表演"；慕容评——先立"目光老辣、生擒冉魏太守"的军事资历，再破卖水卖柴。
- **验收**：辩护强到令立场相反的读者暂时点头；全段无一贬义词；峰值后戛然而止。
- **禁区**：提前找补；用后人信息辩护；优缺点平均展示。

### 变体：无翻案（展示—归因两段式）——暴君篇、纯展示篇

- **启用判据**：对象不存在"反驳成本最高的峰值维度"（如十五岁的变态皇帝），硬立靶子反而假。
- **结构**：事迹连排层层加码（展示）＋结构归因（回答"为什么这个时代能源源不断养出这种人"）。
- 实例：苻生、刘子业、萧宝卷——均无翻案段，直接展示接归因。
- **规则**：翻案的缺席必须是**明示的变体选择**，不是漏写。敲是节拍，不敲也是节拍。

## 第三段：证据群轰炸

- **任务**：完成本篇唯一论点的论证。全文主体，前段铺垫在此兑现。
- **步骤**：
  1. **一句话论点**：压缩为一句可证伪的判断。凡不能归队于它的素材，删。
  2. **拆分论点**：拆为 3—5 个分论点，各配一次证据阵列。少于 3 单薄，多于 5 拖沓。
  3. **证据阵列四种合法形态**（可混用）：事迹连排（证明"是习惯不是偶然"）；时间连排（证明"是过程不是瞬间"）；数据连排（证明"是规模不是感觉"）；引文连排（证明"是共识不是我言"）。
  4. **阵内排序**：从弱到强或从具体到抽象，最强条目压尾。
  5. **定音句**：每阵之后接一两句短促判断，句长必须明显短于阵列——长阵列配短判句，节奏方成立。实例：「三个月不到，八位辅政大臣被干掉了一半」。
  6. **反问转场**：阵与阵之间以设问开场，分节兼泵压。
  7. **缓冲位**：证据群中点之后、最后一阵之前插一次缓冲，剂量以"观众刚要喘不过气"为限。**此坑位与商单位同坑**。
- 实例：苻生九阵——改元事件→劝修德→劝酒→东海大鱼→挖心→凿头顶→吃枣→剥皮→阿谀诽谤，由杀大臣升级到剥面皮，每阵配短定音句。
- **验收**：随机删任一条证据，分论点仍成立→该证据为赘肉；各分论点可独立站住；定音句连读自成缩略论证；通读有周期性"被顶住"感。
- **禁区**：证据与论点两张皮；阵中夹叙夹议（判断一律归定音句）；证据未铺满即入反转。

## 第四段：理性人反转——归因升级＋理论透镜

- **任务**：归因切换——从"这个人坏／蠢"切换到"这个结构让好人也这么做"。情绪对象从个人转移到系统。
- **步骤**：
  1. **冻结道德判断**：承认第三段证据全部成立，不翻供。反转换框架，不推事实。
  2. **重建信息条件**：站进当事人位置，只列他当时可见、可触、必须面对之物。后人视角、结局倒推一律禁用。多视角争端按当事方逐一还原（老太妃视角／奕訢视角／咸丰视角，各说各的理）。
  3. **列选项集**：写出他当时真实可走的全部路径。"理论上最好的"不是选项，"他真能选的"才是。
  4. **证逐项合理**：每条路径的合理性依据是利益、风险、惯例、先例——不是性格，不是善恶。
  5. **叠加收束**：论证各条局部合理的选择如何相互咬合，叠加成系统性灾难。核心句式："单独看都成立，合起来就是要命。"
  6. **理论透镜**：归因段或盖棺段配一个**被命名的现代概念**做统摄框架，全篇只用一次。实例：姚苌→"皈依者狂热"；王猛→"最高纲领与最低纲领"；桓温迁都→鲁迅"开窗论"；刘子业→"超雄患者"。透镜不是玩梗，是归因工具——用一个现代理论把散乱事迹瞬间统摄成可理解的结构。
  7. **冷判断收口**：一句不带情绪的判断。禁感叹，禁抒情。越冷，越疼。
- **验收**：掩去姓名后，普通人会说"换我也只能这样选"；全程无道德词汇；愤怒转化为不安（指向结构）。
- **禁区**：写成洗白（结论不是"他没错"，而是"错不在他一人，这才是问题"）；证据松动时强行反转；反转后追加道德重新定性。

## 第五段：收束甩钩——四形态

- **任务**：只做两件事——情绪定格；为下一篇开口。
- **通用步骤**：缩焦（只选一个最小单位——一人、一句、一物、一地）→ 定格（动词多，形容词少；不评价，不总结）→ 甩钩（抛出一个未闭合缺口）。
- **四种形态及选用规则**：
  1. **阴冷型**：定格单位为被结构碾过者，笔法下沉（苦难浓度高的篇目用）；
  2. **幽默回扣型**：定格单位带反讽余味，笔法轻佻（情绪濒临过载的篇目用）；
  3. **盖棺判词型**：人物传默认收束——给死者下判词，常配理论透镜。实例：「东昏侯的'昏'字成了这个荒唐少年一生的评价」「汉赵帝国像他坚持的仁义一样，宛如昙花一现」；
  4. **远期伏笔型**：事件录默认收束——把镜头拉到十年后、数十年后。实例：「或许萧衍也不知道，自己会在六十年之后走上跟萧宝卷一样的道路」。
- 全系列相邻篇目收束形态不重复，构成系列级呼吸。
- **验收**：无"综上所述"；末句可原封充当下篇开场前提；只读此段仍有余味。
- **禁区**：引入新证据新人物；钩子虚构事实（可夸大情绪，不可消耗信任）。

## 流水线运行规则

- **成稿顺序**：三段→二段→四段→一段→五段。先搭论证主体，再反向校准辩护峰值，再做归因升级，再回头定制咬住论证的开场，最后定格。从头到尾顺序写，最易开场与论证脱节——开场应是论证的果，不是论证的因。（大纲阶段同样按此顺序组织思考，但输出文档按一段→五段排列。）
- **落差守恒**：二段峰值＝三段落差上限＝四段反转说服力上限。后段失守，回查前段是否给足料。
- **单点故障自检**：任一段验收失败，只许回炉该段及其上一段；禁止用后段补救前段——补则臃肿，肿则节奏塌陷。
- **删减优先级**：超标时先砍缓冲剂量，再砍阵内次要条目，再砍分论点数量。永不许砍：定音句、反转的叠加论证、收束的定格——三者是骨架，砍之即塌。
- **终点检验**：观众以为在看个人善恶的狗血剧，看到最后发现看的是结构——每个选择都局部合理，合在一起就是亡国。这就是大纲要制造的最后一击。
