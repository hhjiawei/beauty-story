# 朝代篇大纲模板 v3.1

> 核心范式：**朝代兴衰弧线 + 人物接力**。不是编年流水账，是朝代的"呼吸"——开国（热）→鼎盛（温）→混乱（温/荒诞）→崩溃（冷）→余波（冷/苍凉）。
> 杜茹慧代表作参考：搅动两晋风云（系列）。

---

## 一、命运弧线定义

朝代篇的"命运弧线"是**朝代的呼吸**，用关键人物接力串起朝代命脉。单集内部可能是人物篇或事件篇，但全系列必须形成统一的朝代弧线。

### 标准五段式（系列级）

| 阶段 | 朝代标签 | 情感坐标 | 叙事功能 | 单集类型 |
|------|---------|---------|---------|---------|
| 1 | 开国/夺权 | 热·激昂 | 钩子：打破刻板印象 | 人物篇（开国君主） |
| 2 | 鼎盛/制度 | 温·理性 | 铺垫：制度如何运转 | 制度篇/事件篇 |
| 3 | 转折/混乱 | 温·荒诞 | 炸点：制度崩坏的瞬间 | 事件篇（八王之乱） |
| 4 | 崩溃/灭亡 | 冷·惨烈 | 动情点：大势已去 | 人物篇（末代君主） |
| 5 | 余波/影响 | 冷·苍凉 | 收束：历史如何改写 | 事件篇/制度篇 |
| 6 | （留白） | 留白·余味 | 承上启下：伏笔接力 | 系列衔接 |

### 弧线纪律

1. **单集是人物篇或事件篇，系列是朝代篇**。每集内部用对应模板，但标注"在系列中的位置"。
2. **单集之间用伏笔接力**。上集结尾埋的因，下集开头收的果。
3. **必须打破刻板印象**。朝代篇的钩子不是"这个朝代很伟大"，是"这个朝代连皇帝都被俘虏"。

---

## 二、钩子选型

朝代篇唯一推荐钩子：**反常切片**。

**定义**：打破观众对朝代的刻板印象，用反常识细节建立认知缺口。

**公式**：
> "这是一个______的朝代，一个______的朝代，一个理论上______、但实际上______的朝代。"

**示例（两晋）**：
> "这是一个连皇帝都被俘虏的朝代，一个士大夫比武将更能打的朝代，一个理论上存在了一百五十年、但实际上没人记得它做过什么的朝代。"

**纪律**：
- 反常切片必须包含**具体事实**（"皇帝被俘虏"），不是空泛评价（"很混乱"）
- 反常切片后必须立刻**进入开国叙事**，不能停留在吐槽
- 系列第一集用反常切片，后续集可以用**承接上集伏笔**作为钩子

## 三、温度与声口

### 温度

朝代篇温度**按阶段切换**，不是全篇统一：

| 朝代阶段 | 温度 | 情感气质 |
|---------|------|---------|
| 开国/夺权 | 热 | 激昂、热血、权谋 |
| 鼎盛/制度 | 温 | 理性、剖析、平视 |
| 转折/混乱 | 温→冷 | 荒诞、讽刺、逐渐下沉 |
| 崩溃/灭亡 | 冷 | 惨烈、悲悯、苍凉 |
| 余波/影响 | 冷 | 苍凉、反思、留白 |

**纪律**：温度切换必须有明确节点，通常在"转折事件"后从温转冷。

### 声口样句

朝代篇声口特征：
- **宏观切入+微观着陆**：先讲大势，再落到一个人、一个场景
- **接力感**："上一集我们讲到……这一集，另一个人站了出来"
- **历史轮回感**："这不是第一次，也不会是最后一次"

**标杆样句**：
> "两晋的历史，就像一锅煮糊了的粥——你分不清哪粒米是哪粒米，但糊味是统一的。"
> "上一集我们讲到司马炎统一三国，建立了西晋。这一集，他的孙子司马衷登基，一个智商有问题的皇帝，坐在了天下最高的位置上。"

### 外号锚点

朝代篇外号是**系列级记忆星座**：

- 每集一个核心人物外号，系列内外号形成互文
- 外号可以**跨集呼应**（如第3集提到"古惑仔阿祖"时，观众想起第2集的内容）
- 外号是**情感锚点**，不是一次性梗

## 四、焊接工艺（嘴+骨协作）

朝代篇的焊接三步法有特殊纪律：

1. **现代类比**：必须贴合**制度逻辑**或**历史轮回**
   - 例：九品中正制类比"古代版内推系统"
   - 例：门阀政治类比"家族企业垄断董事会"
2. **史料原文**：必须包含**制度原文或关键诏书**
   - 例："上品无寒门，下品无势族"（《晋书》）
3. **自嘲/共情收尾**：必须回到"咱们现代人也在这个轮回里"
   - 例："咱们现在说'阶层固化'，两晋人早就体验过了，而且体验了一百年。"

---

## 五、动情点纪律

朝代篇动情点是**制度崩坏的历史轮回感**，不是个人悲剧：

- **先落制度，后落情**：先讲制度如何崩坏，再让观众品"原来历史真的会重复"
- **禁止"以史为鉴"**：不说"这告诉我们什么道理"，让制度本身的荒诞说话
- **必须留白**：崩溃段后接地图变化/时间流逝/朝代更替画面
- **情从轮回里长出来**：不是旁白煽出来的，是观众自己意识到"原来如此"

## 六、完整示例：《搅动两晋风云·第1集：司马氏的赌局》

```markdown
# 《搅动两晋风云·第1集：司马氏的赌局》朝代篇大纲

## 0. 魂（情感定位）
- **情绪目标**：让观众感受到"权力交接的荒诞——三代人赌一局，赌输了整个天下"
- **一句话主题**：一个靠三代人阴谋夺权的家族，在统一三国后不到四十年，就把天下输给了自己人
- **钩子选型**：反常切片
- **钩子那一帧**："这是一个连皇帝都被俘虏的朝代，一个士大夫比武将更能打的朝代，一个理论上存在了一百五十年、但实际上没人记得它做过什么的朝代。这就是两晋。"
- **系列位置**：第1集，开启两晋系列，伏笔：司马炎的继承人问题

## 1. 骨（命运弧线 = 朝代兴衰阶段 / 人物接力）

| 段号 | 朝代阶段 | 情感坐标 | 功能 | 核心人物 | 史料卡 |
|------|---------|---------|------|---------|--------|
| 1 | 高平陵之变 | 热·激昂 | 钩子 | 司马懿 | 夺权开端 |
| 2 | 司马师/司马昭 | 热·阴鸷 | 铺垫 | 司马师、司马昭 | 权力巩固 |
| 3 | 司马炎登基 | 热·辉煌 | 高潮前奏 | 司马炎 | 西晋建立 |
| 4 | 继承人隐患 | 温·荒诞 | 炸点 | 司马衷 | 制度缺陷 |
| 5 | （留白） | 留白·紧张 | 收束 | — | 八王之乱伏笔 |

## 2. 肉（共情节点·焊接清单）

- **节点1（高平陵之变）**：现代类比——"司马懿就像一个潜伏了十年的卧底，在老板曹爽最放松的时候收网。但卧底最怕的不是对手，是时间——他70岁了，等不起了。"
- **节点3（司马炎登基）**：反差量化——"从司马懿发动高平陵之变（249年）到司马炎统一三国（280年），整整31年。三代人，做了一件事：夺权。"
- **节点4（继承人隐患）**：查证透明化——"关于司马衷的智商，我查了三本书……《晋书》说他'不慧'，但'不慧'到什么程度？史料没写细节。所以，我不猜。"
- **节点5（留白）**：动情点克制——只摆事实（司马炎死后，贾南风掌权，八王之乱开始），旁白不说"可惜"，让观众自己算时间（290年司马炎死→291年八王之乱→316年西晋亡，26年）

## 3. 衣（风格与声口）

- **本期风格**：牌桌复盘（冷静、算计、偶尔一声叹息）
- **温度**：热→温（夺权热、制度温）
- **声口样句**："两晋的历史，就像一锅煮糊了的粥——你分不清哪粒米是哪粒米，但糊味是统一的。"
- **外号锚点**：司马懿→"洛阳老狐狸"（贴合潜伏、算计、长寿）；司马衷→"坐在龙椅上的孩子"（贴合智商问题与权力反差）

## 4. 签发清单

- [x] 情感定位明确（权力交接的荒诞）
- [x] 命运弧线完整（5 阶段，含留白收束）
- [x] 温度切换有明确节点（夺权热→制度温）
- [x] 声口样句已标注
- [x] 外号锚点已标注（系列级记忆星座）
- [x] 反常切片有具体事实（皇帝被俘虏、士大夫比武将更能打）
- [x] 系列位置已标注（第1集，开启系列，埋下八王之乱伏笔）
- [x] 每个炸点挂史料卡出处
- [x] 动情点至少1处（节点5，制度崩坏的轮回感）
- [x] 动情点有克制纪律（先制度后情绪，无"以史为鉴"）
- [x] 查证透明化标注（节点4，司马衷智商争议）
- [x] 结尾无余味、无总结、无价值判断
- [x] 伏笔已登记（八王之乱，埋设段5，回收段2集开头）
- [x] 无AI腔词汇
- [x] 第一人称克制
```

## 七、朝代篇特有签发项

| 签发项 | 标准 | 不通过后果 |
|--------|------|-----------|
| 反常切片有具体事实 | 不是空泛评价，是具体史实 | 大纲退回，重设钩子 |
| 系列位置已标注 | 明确在系列中的位置、承接、开启 | 大纲退回，补充系列信息 |
| 温度按阶段切换 | 热→温→冷有明确节点 | 写作层退回修改 |
| 单集之间伏笔接力 | 上集结尾埋因，下集开头收果 | 系列大纲退回，重排衔接 |
| 外号形成系列记忆星座 | 外号跨集呼应，不是一次性梗 | 大纲退回，重设外号体系 |
| 动情点从轮回长出来 | 先制度后情绪，禁止"以史为鉴" | 写作层退回修改 |
| 结尾承上启下 | 朝代篇结尾必须接下一集伏笔 | 写作层退回修改 |
