# 历史长视频大纲生成（方法论 v3）

把传入的素材转化为一份可施工的五段大纲。总纲：先有问题，再有结构，最后才有文辞；先让观众动情，再让观众明理；归因到结构，落笔在人命。

**本技能只产出大纲，不写正文。** 大纲的每个段落要定到"这一段用什么素材、证明什么、什么语气、埋什么钩"，细到写手无需再查史料。

---

## 输入规范

### 标准输入：素材卡 JSON 数组

用户输入为一张**素材卡数组**（JSON），每张卡是一个带类型的史料单元。六种卡型：

| 卡型   | 编号前缀 | 用途                     | 必填字段                                                     |
| ------ | -------- | ------------------------ | ------------------------------------------------------------ |
| 事件卡 | C-       | 有冲突、有动作的历史节点 | 卡号、卡型、时间、地点、人物、冲突、史料出处、可信度         |
| 人物卡 | P-       | 篇中人物                 | 卡号、卡型、人物名、身份、核心特质、史料出处、可信度         |
| 关系卡 | R-       | 双方张力与演化           | 卡号、卡型、双方、关系性质、张力点、演化                     |
| 背景卡 | B-       | 制度/地缘/时代机制       | 卡号、卡型、主题、要点、史料出处、可信度                     |
| 数据卡 | D-       | 数字托底                 | 卡号、卡型、指标、数值、对比基准、史料出处、可信度、备注（争议须注明） |
| 彩蛋卡 | E-       | 歇后语/梗/氛围素材       | 卡号、卡型、类型、内容、挂接事件、建议用法                   |

**约定字段（各卡通用）**：

- `本集用不用`：用 / 封存 / 待定——用户在输入阶段即可初筛，"封存"卡不进正文但仍列入台账；
- `叙事角色`：主线节点 / 支线 / 背景铺垫 / 氛围；
- `情绪类型`：愤怒 / 荒诞 / 唏嘘 / 悲悯 / 爽感——供情绪地图取用；
- `古文原句`：凡有可引原文一律照录，写作时直接使用；
- `可信度`：正史 / 野史 / 孤证 / 存疑——孤证与存疑卡使用时必须带声明。

### 非标准输入

若用户直接粘贴史料原文或散述，先执行**卡片化**：通读后将全部可用素材点拆解为上述六类卡，编号输出并请用户确认，再进入流程。禁止跳过卡片化直接写大纲。

## 输入判读

收到素材卡后先清点，再动笔：

1. **遍历卡片**，按卡型归类清点：几张 C 卡（事件节点够不够撑起主线）、几张 P/R 卡（人物与张力）、几张 B 卡（结构归因弹药）、几张 D 卡（数字托底）、几张 E 卡（仅限氛围，禁入悲悯段）。人物动机若无心理史料，只能记为【I｜推断】，见可信度台账。

---

## 第〇步：选题价值诊断 【v3 新增】

动笔前先用三个问题检验这个题值不值得做长视频，三问全部有答案才进入第一步：

1. **观众原本相信什么？**——写出目标观众的常识结论（如"咸丰是个昏庸皇帝"）。
2. **看完之后不得不重新相信什么？**——写出与常识冲突的最大认知落差（如"不是不知道问题，而是结构里没有可行选择"）。认知落差即选题内核，必须能用一句话说清。
3. **删掉这个题，观众损失什么？**——若答案只是"了解了一段历史"，选题不合格，退回换题或换主角；合格答案是"他会重新理解一个习以为常的历史结论"。

诊断结论写入篇级总卡「认知落差」字段，全篇五段都服务于这一条落差。

**悖论分级**（取代旧的"悖论即选题"单一开关）：事实反差（"这个皇帝居然做了这件事"）只够做短视频，**因果反转 / 价值反转**（"看起来是 A 导致结果，真正决定的是 B"／"换一个结构位置，道德判断站不住"）才是长视频合格线。本技能只受理后两类。

## 第一步：驱动分型 + 结构选型 【v3 改造】

先问："想让观众记住这个人/这个规律，还是这段进程？"

- 记住人/规律 → **单点篇**：问题驱动，全篇拆开标题里的一个追问。
- 记住进程 → **编年篇**：主线悬念驱动，编年只是素材存放顺序，全部素材挂一条主线，设问只做调味。

再用结构选型器判断题材类型。**五段流水线是唯一骨架**，五种题材类型只改变"段落里装什么、按什么顺序装"，不另起结构（如同已有的"暴君展示型：翻案段为零"）：

| 型           | 核心追问                             | 开场装什么                    | 证据群怎么排                                         | 五段变体配置                                 |
| ------------ | ------------------------------------ | ----------------------------- | ---------------------------------------------------- | -------------------------------------------- |
| A 人物认知型 | "这个人为什么会这样？"               | 主角的怪举/定格               | 按"他怎么想"的心理递进                               | 标准五段                                     |
| B 事件翻案型 | "这件事为什么和我们以为的不一样？"   | 事件的哗然瞬间                | 按证据链一层揭一层                                   | 证据群扩至 50%–60%                           |
| C 进程悬念型 | "一个国家是怎么一步步走到这一步的？" | 结局惨状先端出                | 按时间走：分论点1=第一个转折点，2=连锁反应，3=临界点 | 开场直接给终点                               |
| D 制度解释型 | "为什么这个制度必然产生这个结果？"   | 核心制度规则（B卡）直接放开场 | 按机制运作：规则→激励→连锁→结果                      | 反转段（制度运作机制）可部分提前至证据群阵间 |
| E 群体命运型 | "普通人为什么被卷入这场历史？"       | 一个小人物的遭遇              | 镜头缩放：个体→家族→朝堂→时代                        | 标准五段                                     |

选型结果写入篇级总卡「驱动分型＋结构选型」字段；变体配置必须在总卡中明示是变体选择而非漏写。

## 第二步：选题与标题（悖论即选题）

标题三要件，缺一不可：

1. **反常识对象**：表层常识与深层事实冲突的悖论（须通过第〇步分级检验）；
2. **归因式追问**：句式"为什么／怎么会"，规定本篇论证方向；
3. **语气承诺**：感叹号、问号、【系列编号】【看点标签】预告情绪强度。

大纲给出 1 个主推标题 + 2 个备选，双问句副标（"是英雄，还是汉奸？"）可加。

---

## 第三步：一句话论点 + 主线封存 + 认知变化链（人物篇追加人物弧光） 【v3 改造】

1. 把本篇要证明的压缩为**一句可证伪的判断**，写在大纲最上方——它是判断"挂不挂得上主线"的唯一标尺。

2. 逐条过素材卡：`本集用不用=封存` 的及挂不上主线的，**明示封存**（列入"封存素材"区）。封存判据两级——①挂不上主线 → 封存，标注去向（赘肉／未来篇目）；②挂得上但**只为好看、不推进论点** → 同样封存。后者是"精彩但删除"，历史内容从"资料丰富"走向"作品"的关键。封存先于认知链执行，避免赘肉卡污染推导。

3. **认知变化链【v3 新增】**：骨架六环固定（原信→动摇→失效→重建→新认知→留白），**内容不是模板，从卡片推导**——每环必须挂到具体卡号，换一批素材就换一条链。它是五段的隐形主轴，写入篇级总卡。推导不出"新认知"与"留白"，说明选题诊断（第〇步）没做透或卡片不够，退回第〇步。

4. **人物篇附加：人物弧光七步【v3 新增】**——凡 P 卡为篇主角，立即在总卡填写人物认知轨迹：

   > 初始状态（相信什么）→ 第一次选择 → 现实反馈（意外后果）→ 反应（修补而非改变）→ 第二次选择（可选方案已减少）→ 环境收紧 → 最终选择（剩余方案中代价最低者）→ 观众重新认识此人

   填写要求：每一步必须挂到具体卡片编号；没有卡片支撑的步骤标"缺料，需补查"，禁止虚构。弧光终点必须能与认知变化链的"新的认知"互相印证——"原来他不是突然变坏，而是一步一步走到了这里。

---

## 第四步：五段流水线布点

按五段结构排布素材，每段写明：任务、选用的素材（精确到卡号）、篇幅占比、验收要点。细则见 [references/five-paragraphs.md]（开场冷热双形态、翻案含无翻案变体、证据群四阵型、理性人反转七步、收束四形态、成稿顺序与删减优先级）。

| 段落           | 唯一任务                                   | 篇幅    |
| -------------- | ------------------------------------------ | ------- |
| 一、开场       | 制造情绪判断，只呈现"不对劲"               | 5%–10%  |
| 二、翻案       | 把将被推翻的对象辩护到最高点（可明示缺席） | 0%–25%  |
| 三、证据群轰炸 | 论证唯一论点，3–5 分论点 × 证据阵列        | 35%–60% |
| 四、理性人反转 | 归因从道德切换到结构＋命名理论透镜         | 15%–20% |
| 五、收束甩钩   | 情绪定格＋为下一篇开口                     | 5%–10%  |

**段间无过渡段**：上一段的最后一个元素即下一段的第一个攻击目标。
**人物传（暴君展示型）**：翻案段可为零，证据群可占 55%–60%，但"无翻案"必须在大纲中明示是变体选择而非漏写。其余结构选型变体同理。

**翻案的两个澄清【v3 补充】**：

- 翻案不需要预设反差，本质是**把观众现成的结论辩护到最强**；反差是翻案制造出来的，不是翻案的前提。
- 素材无案可翻（无主流旧结论可辩护）时，用**无翻案变体**：翻案段为零，开场用惨状/怪事直进证据群。翻案与反转是先后两步、不可互相替代——翻案让观众站进旧结论（情绪），反转换结构坐标系重新解释（理性）；反转的说服力取决于翻案的强度。

**证据群三条新规【v3 新增】**：

- **认知变化验收**：每个分论点的大纲验收要点必须写明"本组证据让观众从___认知移动到___认知"。证据不是越多越好，每一组都要让观众向下一层认知移动；写不出认知移动的分论点整组砍掉。
- **证据因果排列**：证据不许并列堆放。分论点内部按因果/递进排——证据1引出或导致证据2，证据2逼出证据3；分论点之间，上一个分论点结尾留下的疑问，就是下一个分论点开头要回答的问题。回答不了，说明排序错误或缺卡。
- **反证机制**：每个分论点须列出【最强反证】（如果有人反驳，最有力的史料/史实是什么）与【反证处理】（为什么推不翻主论点；或承认其部分成立、据此收窄论点）。主动找反例是防止过度归因、强行翻案、事后诸葛亮的唯一手段；找不到反证的分论点标"待补查"。

---

### 反转段三规（布点反转段时执行） 【v3 新增】

1. **透镜优先级**：史料证据 ＞ 因果关系 ＞ 理论命名。理论透镜必须从史料中长出来——只有当多张背景卡/事件卡反复指向同一运作机制时才允许命名（路径依赖、激励结构、委托代理、信息不对称等）。全篇只用一个透镜且有名字。禁止给"他当时没办法"扣"制度性路径依赖"的大帽子。
2. **因果跨度检查**：反转段的每个重大因果必须填四字段——【原因·时间】【中间变量】【结果·时间】【因果强度：强/中/弱】。跨度过大、中间变量缺失的因果链降级为"推断"并入 F/I/T 台账，不得作为反转段的主承重墙。
3. **价值兜底**：反转段的解释力上限由翻案段的辩护强度决定（落差守恒：二段峰值 = 三段落差上限 = 四段反转说服力上限）。反转段全程无道德词汇，但收束前必须落一句定性：**"理解不等于原谅，解释不等于免责。"** 结构性解释不是开脱。

## 第五步：布点四件事（大纲阶段必须全部锁定）

1. **悲悯段落清单**：苦难/殉国/冤死段落全部锁定，标"悲悯轨"，写作时不得临时改轨；悲悯段弹药/绰号/设问全清零，不配搞笑定场栏目。补充纪律：进入悲悯轨后不得跳回情绪攻击轨（愤怒/讽刺）。
2. **签名句式落点**：标注"话说回来""不出意外地又出现了意外""下线了"等签名句式的位置，同类不连续出现两次以上；每篇签名句式设总上限，签名句只服务节奏、不承担事实信息。
3. **缓冲/商单坑位**：固定在证据群中点之后、情绪过载拐点之前；有商单则预埋语义钩连句（内容与产品共享一个语义钩，如"直挺挺的颈椎"→护颈枕）。
4. **互动钩子位置**：每篇至少一处（向观众提问自答或征答），位置在证据群阵间或收束段之前。
5. **单段中可详细描述点**：找到一个很有趣的事件或者行为可以展开描述，讲述如何描述。

语气三轨纪律、九模块用法、称呼/弹药规则见 [references/modules-tone-credibility.md]；F/I/T 可信度台账见下文。

## 可信度台账：F/I/T 三级标注 【v3 改造】

全部素材与大纲论断按三级标注，并入同一台账管理（取代分散的"孤证存疑"说法）：

| 级别               | 含义                               | 标注方式                                                     |
| ------------------ | ---------------------------------- | ------------------------------------------------------------ |
| **F（Fact）**      | 史料直接支持                       | 正常引用，年号＋公元双标                                     |
| **I（Inference）** | 根据多个事实推导（含心理动机推断） | 【I｜推断类型｜依据：卡片编号】——如"他因恐惧而选 X"若无心理记录必须标 I |
| **T（Theory）**    | 以理论透镜作出的解释               | 【T｜透镜名｜指向卡片】                                      |

铁律：**I 不得写成 F，T 不得写成 F。** 孤证一律降为 I 并标"存疑"。宏大判断必须有 D 卡数字托底。台账附在篇级总卡之后，逐条列出本篇所有 I 与 T。

## 输出

把最终大纲写入 Markdown 文件，保存到输出目录（文件名用"标题-大纲.md"形式），严格按 [assets/outline-template-v3.md] 填充。输出物为**卡面制大纲**。

**生成顺序**：先逐段填写段级施工卡（S-001 起），篇级总卡各表（情绪地图、炸点总表、伏笔台账、弹药总表等）由施工卡对应字段**聚合生成**，不在总卡上凭空填写。目标时长未指定时默认 25 分钟（约 6750 字）。

### 篇级总卡（一张）

- 标题（主推＋备选）
- 悖论（含第〇步分级结论：因果反转／价值反转）
- 选题诊断三问（原信什么／落差是什么／删掉损失什么）
- 认知落差（一句话）
- 驱动分型＋结构选型（含五段变体配置）
- 一句话论点
- **认知变化链**（初始认知→动摇→失效→重建→新认知→留白）
- **人物弧光七步**（仅人物篇，逐步挂卡号）
- 主线因果链（每条过因果跨度检查：中间变量＋强度）
- 目标时长→字数预算（×270 字/分钟）、篇幅配比
- 理论透镜（唯一；含"从哪些卡片长出"的说明）
- 伏笔总台账（F-编号）、炸点总表、情绪地图
- 布点四件事
- 弹药总表（查重）
- 封存素材（两级判据：挂不上主线／好看但不推进）
- **F/I/T 可信度台账**（全篇所有 I 与 T 逐条列出）
- 接缝（系列篇目填，单篇填"无"）
