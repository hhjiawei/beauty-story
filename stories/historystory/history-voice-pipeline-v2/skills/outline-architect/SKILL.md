# 历史长视频大纲生成（方法论 v2）

把传入的史料转化为一份可施工的五段大纲。总纲：先有问题，再有结构，最后才有文辞；先让观众动情，再让观众明理；归因到结构，落笔在人命。

**本技能只产出大纲，不写正文。** 大纲的每个段落要定到"这一段用什么素材、证明什么、什么语气、埋什么钩"，细到写手无需再查史料。

## 输入判读

收到史料后先做三件事，再动笔：

1. **通读史料**，列出全部可用素材点（事件、人物、数据、原文引文、细节、争议）。
2. **问缺什么**：本篇主线需要而史料没有的（关键时间点、人物动机、数据托底），先向用户确认或定向补查，禁止用虚构素材填坑。
3. **确认边界**：单篇还是系列之一？有无指定标题/主角？有无商单要求？用户未说明时默认单篇、自选标题、无商单。

## 第一步：驱动分型（决定全篇结构）

问一句："想让观众记住这个人/这个规律，还是这段进程？"

- 记住人/规律 → **单点篇**：问题驱动，全篇拆开标题里的一个追问（"为啥咸丰一心求死"）。
- 记住进程 → **编年篇**：主线悬念驱动，编年只是素材存放顺序，全部素材挂一条主线，设问只做调味。

## 第二步：选题与标题（悖论即选题）

标题三要件，缺一不可：

1. **反常识对象**：表层常识与深层事实冲突的悖论（"匈奴的大汉包围了帝国首都"）；
2. **归因式追问**：句式"为什么／怎么会"，规定本篇论证方向；
3. **语气承诺**：感叹号、问号、【系列编号】【看点标签】预告情绪强度（"突发！……！"【最能打的一集】）。

大纲给出 1 个主推标题 + 2 个备选，双问句副标（"是英雄，还是汉奸？"）可加。

## 第三步：一句话论点 + 主线封存

- 把本篇要证明的压缩为**一句可证伪的判断**，写在大纲最上方。
- 逐条过素材：挂得上本篇主线的留下，挂不上的**明示封存**（列入大纲"封存素材"区，标注去向：赘肉或未来篇目）。封存判据唯一：能否挂进主线。

## 第四步：五段流水线布点

按五段结构排布素材，每段写明：任务、选用的素材、篇幅占比、验收要点。细则见 [references/five-paragraphs.md](references/five-paragraphs.md)（开场冷热双形态、翻案含无翻案变体、证据群四阵型、理性人反转七步、收束四形态、成稿顺序与删减优先级）。

| 段落 | 唯一任务 | 篇幅 |
| --- | --- | --- |
| 一、开场 | 制造情绪判断，只呈现"不对劲" | 5%–10% |
| 二、翻案 | 把将被推翻的对象辩护到最高点（可明示缺席） | 0%–25% |
| 三、证据群轰炸 | 论证唯一论点，3–5 分论点 × 证据阵列 | 35%–60% |
| 四、理性人反转 | 归因从道德切换到结构＋命名理论透镜 | 15%–20% |
| 五、收束甩钩 | 情绪定格＋为下一篇开口 | 5%–10% |

**段间无过渡段**：上一段的最后一个元素即下一段的第一个攻击目标。
**人物传（暴君展示型）**：翻案段可为零，证据群可占 55%–60%，但"无翻案"必须在大纲中明示是变体选择而非漏写。

## 第五步：布点四件事（大纲阶段必须全部锁定）

1. **悲悯段落清单**：苦难/殉国/冤死段落全部锁定，标"悲悯轨"，写作时不得临时改轨；
2. **签名句式落点**：标注"话说回来""不出意外地又出现了意外""下线了"等签名句式的位置，同类不连续出现两次以上；
3. **缓冲/商单坑位**：固定在证据群中点之后、情绪过载拐点之前；有商单则预埋语义钩连句（内容与产品共享一个语义钩，如"直挺挺的颈椎"→护颈枕）；
4. **互动钩子位置**：每篇至少一处（向观众提问自答或征答），位置在证据群阵间或收束段之前。

语气三轨纪律、九模块用法、称呼/弹药规则、史料锚定四规与推理声明等级，见 [references/modules-tone-credibility.md](references/modules-tone-credibility.md)。

## 第六步：系列工程（仅当属于系列时执行）

跨篇三机制与情绪曲线排布见 [references/series-engineering.md](references/series-engineering.md)：伏笔投放回收表（跨期人物/跨期事件/期内预告/远期镜像四类）、接缝设计（篇末句即下篇开场前提）、功能性插页位置（由心理负荷曲线决定，不由时间线决定）。相邻篇目收束形态不重复。

## 输出

把最终大纲写入 Markdown 文件，严格按 [assets/outline-template.md](assets/outline-template.md) 填充，保存到输出目录（文件名用"标题-大纲.md"形式）。输出物为**卡面制大纲**：

- **篇级总卡**（一张）：悖论、驱动分型、一句话论点、主线因果链、目标时长→字数预算（×270 字/分钟）、篇幅配比、理论透镜、伏笔总台账（F-编号）、炸点总表、情绪地图、布点四件事、弹药总表（查重）、封存素材、可信度台账、接缝；
- **段级施工卡**（S-001 起连续递增，每段一张）：五段归属＋九模块标签、段意、时间码、因果接口（本段之因/本段之果）、指定技法（悲悯段只许史料引用）、弹药清单（强烈推荐 ≤4 处）、史料清单（原文照录）、炸点、伏笔、情绪坐标、预计字数、备注（只写施工指令，禁写正文），并按五段归属追加规程字段（开场卡填选点/定格/开场之问，证据群卡填分论点/阵型/定音句，反转卡填选项集/透镜，收束卡填定格单位/甩钩）。

逐字段填写规则、判定细则、完整填写示例（司马衷立储篇）与机检清单见 [references/card-spec.md](references/card-spec.md)。**备注禁写正文句子**——大纲只下施工指令。

## 质检清单（交付前逐条过）

- [ ] 标题内置悖论，且正文结构全部用于拆开这个悖论；
- [ ] 一句话论点可证伪，封存素材区非空或明示"无封存"；
- [ ] 开场删去背景知识后仍让陌生人十秒内指出"哪里不对劲"；
- [ ] 翻案段辩护强到令反对者点头且无一贬义词，或明示"无翻案变体"；
- [ ] 每个分论点 3 条以上证据，删任一条分论点仍成立（否则为赘肉）；定音句明显短于阵列；
- [ ] 反转段掩去姓名后普通人会说"换我也只能这样选"，全程无道德词汇；理论透镜全篇只用一个且有名字；
- [ ] 收束段无"综上所述"，末句可原封充当下篇开场前提；
- [ ] 悲悯轨段落弹药/绰号/设问全清零，且不配搞笑定场栏目；
- [ ] 每个时间点年号＋公元双标，宏大判断有数字托底，孤证标"存疑"；
- [ ] 落差守恒自查：二段峰值 = 三段落差上限 = 四段反转说服力上限；
- [ ] 机检清单 12 项全部通过（见 references/card-spec.md 第六节）：S-编号连续、伏笔有埋有收、弹药查重、悲悯段清零、字数 ±10%、因果接口无空转、相邻炸点不同型、透镜唯一、收束无"综上所述"、签名句式不连用、缓冲坑位位置正确、互动钩子 ≥1 处。
