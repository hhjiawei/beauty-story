# 大纲层设计方案 v3

> 定位：流水线里的**结构工程师**。接收史料、人格层、风格层，输出一份 agent 可执行的明细大纲文件。
> 铁律：**大纲层不写一句旁白正文**——它只决定讲什么、按什么顺序讲、每段用什么技法、风格嵌在哪、炸点埋在哪。
> v3 核心修订：**硬约束锁故事选择，软约束放语言实现**——大纲层管住"讲什么"的质量，放开"怎么说"的手脚。

---

## 一、为什么要单设大纲层

1. **结构与语言分离。** 写旁白时边想结构边写句子，两头都会塌。结构问题在大纲阶段解决，写作层只管施工。
2. **结构错误前置拦截。** 炸点不够、伏笔没回收、材料没用上——这些错误在大纲上肉眼可见，动笔前就能拦下，返工成本最低。
3. **风格前置嵌入。** 风格不是写完再"抹"上去的，是在大纲里就指定技法选型。嵌在哪、嵌什么，大纲说了算；**具体用哪一发、怎么落句，写作层说了算**（v3 修订）。
4. **大纲可审查。** 审核层可以先审大纲再审成稿，两道门禁；大纲出厂前另设人工主题否决关（见第九节）。

**流水线位置**：史料层 ＋ 人格层 ＋ 风格层 → **大纲层** →【主题否决关·人工】→ 旁白写作层 → 审核层。

## 二、输入与输出契约

### 输入

| 输入项       | 来源   | 用途                                       |
| ------------ | ------ | ------------------------------------------ |
| 史料包       | 史料层 | 拆成事件卡，决定"讲什么"                   |
| 人格层       | L2     | 决定叙事姿态与视角                         |
| 风格层       | L3     | 决定技法嵌入的选型与密度                   |
| 本集类型     | 选题   | 朝代篇／人物篇，决定用哪套模板             |
| 目标时长     | 选题   | 决定节点数量与详略配比                     |
| 观众既有认知 | 选题   | 神话／成语／课本／影视里的印象，供 Step 0 检查认知反差 |

### 输出

《单集大纲文件》一份，要求：**写作层 agent 拿到后不需要再做任何结构决策**，照单施工即可。大纲上每个段落必须带齐施工指令（见第四节格式）。

**v3 新增：字段分软硬两级。**

- **硬约束字段**（写作层无权改动，违反即出戏）：段号、功能类型、使用史料卡、伏笔（埋收关系）、动情点（有无）、预计字数（分级容差内）。
- **软约束字段**（写作层可调整但须在交稿备注中声明）：指定技法（主/备选之间可换）、炸点的具体起爆句位置、情绪坐标的过渡处理。

## 三、大纲层工作流 SOP（九步）

**Step 0｜认知入口（可选，不强行）**
先问一句：**观众入场前，对本段历史已经相信了什么？**（来源：神话、成语、课本一句话、热播影视剧）

- 若存在明确的"既有认知 vs 史实"反差 → 登记为**反常切片**，作为开场钩子的首选弹药。
- 若没有 → 直接进入下一步。**不强行制造反差——没有就是没有**，这不是技法能拧出来的；若因此连钩子都选不出，是选材问题，退回选题层。

**Step 1｜史料消化：事件卡清单**
把史料拆成事件卡，每张卡字段：时间／地点／人物／冲突／史料出处／可信度／本集用不用。史料不直接进大纲，先全部变成卡片——卡片是大纲层的积木。

**Step 2｜定主题：一句话主题＋钩子弹药**

- 一句话主题：本集到底讲什么，一句话说完。说不出来就是选材有问题，退回。
- **v3 新增：主题自检三问**（答不出就换主题，别硬写）：
  1. 这句话讲给一个不看历史的人听，他会"哦？"一声吗？
  2. 这个主题只有你能讲，还是换个博主也能讲？（能讲出你的独家角度的才算数）
  3. 把主题里的主语换成同类型另一个人物／朝代，句子还成立吗？（成立＝主题没长在材料上，是套话）
- 钩子弹药库（开场钩子从这里选型，不指定唯一手法）：
  - **反常切片**——来自 Step 0，有则优先用；
  - **反差量化**——把本集最悬殊的一组数字摆出来（兵力、疆域、年头、人口）。**双前提同时满足才可用：①战争类话题；②数字有完整史料支撑，估算数、传说数不得充数**；
  - **名场面前置**——朝代篇默认弹药；
  - **最颠覆印象的一个细节**——人物篇默认弹药。

**Step 3｜排主干：时间线＋节点分级**
沿时间线排事件卡，给每个节点定级：

- **强化节点**：强化或转折走向的事件——展开成戏（场景、对话、细节）；
- **关键节点**：必须讲清的事件——细讲但不成戏；
- **过渡节点**：交代即可——一句话带过。
  详略分级在这一步定死，写作层无权加戏。

**Step 4｜定三个非线性动作**

1. **开头前置什么**：从时间线上剪下哪一段贴到开头（名场面／结局切片／反常细节）；
2. **哪些节点挂插件**：在哪些节点暂停主线，挂拆账开庭／古文炸点／知识彩蛋／人物小传／层累表／**历史对照组**／**侧写视角**；
3. **结尾呼应什么**：开头的片段在结尾如何归位。

**Step 5｜风格嵌入分配（v3 修订：选型范围制）**
对照风格层和弹药库，给每个段落标注**技法选型范围**：主技法＋备选技法（各一，可只给主技法不给备选）。**风格在大纲里完成"选哪几发"，写作层完成"上膛哪一发、怎么击发"。**
修订原因：技法应从材料里长出来，逐段写死单一技法会让写作层为落实指令硬落句，观众能感到"这段在用招"。给备选就是给写作层一条不退稿的换弹药通道。

**Step 6｜炸点排布＋情绪波形＋动情点**

- 标出全片炸点位置与类型（手法库选）；**每个炸点必须挂史料卡出处——无卡炸点一票退回**（v3 新增，用出处卡真实性，不用密度卡数量）；
- 炸点数量按时长换算区间执行：10 分钟人物篇 3–4 个，20–30 分钟朝代篇 7–10 个。**区间是上限参照不是 KPI——史料撑不起的炸点宁可空着**（与弹药库纪律对齐，v3 消除"上限/KPI"表述矛盾）；
- 画出情绪波形，给每段标坐标。峰谷相间，防中段塌；
- **标动情点**：全片至少一处"心里咯噔一下"的瞬间——家国、儿女、命运唏嘘皆可，标记在段上。**动情点不是煽情**：克制处理，先落事实后落情，情从史实里长出来，不是旁白喊出来的。**全片找不到一个动情点，大纲退回。**

**Step 7｜伏笔登记表预填**
凡在大纲里埋的伏笔，当场登记：伏笔内容／埋设段／回收段／状态。

**Step 8｜自检与签发**
过签发清单（见第八节），全绿才进入第九节主题否决关；过关后才输出给写作层。

**Step 9｜消除AI感**
请全面化身为顶级语言风格编辑真人表达校准师与aI痕迹清除专家。在不改变原文事实、核心观点和重要信息的前提下,对全文进行深度重写。
删除空洞开场、正确但没有信息量的废话、机械连接词、过度完整的排比、重复总结、虚假的情绪升华和教科书式表达。
重新调整句子长短、停顿节奏、观点顺序和用词密度,加入符合语境的真实细节、自然转折和明确立场允许存在克制的不完美。

禁用抽象上位词：强制模型停留在下位词层面，拒绝向高概括层级逃逸
禁用跨域通用比喻库：切断"时间-河流""命运-航船""历史-画卷"这类超高频映射的默认激活
禁用情感冗余：要求每一个修饰成分必须通过"删除测试"——如果删除该词，句子的信息量减少超过阈值，才允许保留
x
感官通道限定：要求文本必须通过特定感官通道（触觉、嗅觉、前庭觉）进行编码，而非停留在视觉和听觉的抽象层面
动作链优先：用动作序列（action chain）代替状态描述，因为动作有物理约束，不容易滑向套话
物质性锚定：每一个比喻必须包含可触摸的物质属性（密度、温度、质地、重量），而非停留在关系属性上

言语行为明确化：在生成前，必须定义这段文字的以言行事行为（illocutionary act）——它是在命令、哀悼、讽刺、还是宣判？不同的言语行为会激活完全不同的词汇选择策略
受众距离设定：明确文本与受众的关系（亲密/疏离、上级/下级、同辈/异辈），这会强制模型调整敬语系统、隐喻系统的激进程度
信息结构优先：要求文本服从信息结构（information structure）而非修辞结构（rhetorical structure）。即：先确定"已知信息-新信息"的流动路径，再让修饰成分服务于信息焦点，而非让信息服务于修辞对称

张力机制：在prompt中植入互斥的约束条件，迫使模型在冲突中寻找唯一解。例如，同时要求"极度精确"和"极度粗粝"，这两个要求的交集区域就是AI腔无法到达的语义空间
认知负荷注入：要求文本在特定位置引入认知断裂（cognitive dissonance）——即违反格赖斯合作原则中的"方式准则"（Manner Maxim），故意制造需要读者填补的语义缺口。AI腔的致命特征是"过度合作"，它从不让读者费力；而好的文本必须要求读者参与解码

语料层隔离：明确指定文本的"时间地层"——它应该像哪个时代的语言？不是词汇层面的仿古，而是句法节奏、信息密度、推理方式的历时锁定
个体语言记忆：要求文本携带个体语言史（idiolect）的痕迹，即模拟一个具体说话者的历史——他受过什么伤害、有过什么执念、惯用什么样的错误。AI腔是"无历史"的，而人类语言是"有伤疤"的

## 四、输出文件格式（大纲文件 Schema）

每个段落一行（或一个 JSON 对象），字段如下：

| 字段       | 软硬 | 说明                                                         |
| ---------- | ---- | ------------------------------------------------------------ |
| 段号       | 硬   | 顺序编号                                                     |
| 时间码     | 软   | 预计起止（如 00:00–00:30）                                   |
| 功能类型   | 硬   | 钩子／锚定／主线节点／插件／高潮／收尾／衔接                 |
| 章节标题   | 硬   | **观众可见的导航标题**——同章节内各段填同一标题；工整短题是底线不是目标，**允许一章内出现一个悬念式章题**（参照弹药库第 8 号标题句逻辑：看完才懂，但正片必须兑现）（v3 修订） |
| 使用史料卡 | 硬   | 事件卡编号（可多张）                                         |
| 指定技法   | 软   | 主技法＋备选技法（各一）。写作层可在两者间切换，交稿备注声明（v3 修订） |
| 炸点       | 硬   | 类型＋位置＋**史料卡出处**（无卡不许标炸点）（v3 修订）      |
| 动情点     | 硬   | 有／无＋位置（全片至少一处）                                 |
| 伏笔       | 硬   | 埋设／回收／无（联动登记表）                                 |
| 情绪坐标   | 软   | 在波形图上的位置（谷底／爬升／峰顶等）                       |
| 预计字数   | 硬   | 按语速换算基准值；**容差按功能类型分级：钩子／收尾 ±40%，主线节点／插件 ±20%，过渡段不设下限只设上限**（v3 修订：波形起伏必然对应密度起伏，匀速换算会卡死最贵和最便宜的段落） |
| 备注       | —    | 给写作层的特殊指令                                           |

## 五、人物篇大纲模板
### 5.1 人生时间线，情绪驱动

| 段序   | 功能           | 施工要点                                                                 |
| ------ | -------------- | ------------------------------------------------------------------------ |
| 1      | 开场钩子       | 人物**最颠覆印象**的一点先行（最反常的一个事实／一个细节），不给生平概览 |
| 2      | 锚定线         | 谁／何时／何地，三句以内                                                 |
| 3      | 起点段         | 出身＋**核心矛盾亮相**（重要人物带核心矛盾出场）                         |
| 4~n    | 人生时间线推进 | 节点分级施工；强化节点用**决策瞬间替换法**成戏，过渡节点一句话           |
| 插件位 | 侧写视角       | **借他人之眼写主角**——写桀不直写桀，写伊尹眼中的桀、写妺喜眼中的桀。作为强化节点的替代施工方式，打破第一视角疲劳 |
| 插件位 | 历史对照组     | 相似处境、不同结局的另一人，插一段对照，一切尽在不言中。**全片最多1处**  |
| 插件位 | 拆账开庭       | 人物争议点集中在此开庭（摆说法→拆动机→交还判断→重建落点）                |
| 插件位 | 古文炸点／彩蛋 | 按风格层分配嵌入，20分钟片引文3~5处                                      |
| 插件位 | 心理推演       | 只在史料留白处，挂合规标签                                               |
| n+1    | 弧光顶点       | 命运高潮展开成戏，全片情绪最高点                                         |
| n+2    | 收尾           | **弧光闭合·盖棺**：与开场形象形成反差的唏嘘；先落点后金句，80%压最后30秒 |
| n+3    | 承上启下       | 有下集时，一句话衔接（可选）                                             |

人物篇的发动机是**情绪**：观众追的是"这个人后来怎么样了"。
动情点常落在弧光顶点或收尾，但也可以埋在中段——一个小人物的瞬间往往比主角的落幕更扎人。

### 5.2 三幕式·第二人称沉浸型（参考历史故事编剧爆款模板）
| 幕序             | 功能   | 施工要点                                                                          |
| :------------- | :--- |:------------------------------------------------------------------------------|
| 开篇钩子（100-150字） | 抓眼球  | 公式："古代有这样一种\[人/职业/技能]，他们\[反常识能力描述]。今天我们讲\[主角称号/事件名称]的故事。"必须包含：悬念设置+反常识认知+身份预告 |
| 第一幕（25%）：困境与转机 | 建立代入 | 主角身份介绍（开头使用"你是XXX"开头，后面转移到主角，用第三人称或他的名字）→面临的困境/挑战→获得改变命运的机会                   |
| 第二幕（50%）：布局与执行 | 推进张力 | 详细的计划过程→技术细节描写（必须具体）→心理活动刻画→情节推进（按时间顺序）                                       |
| 第三幕（25%）：高潮与反转 | 情绪爆点 | 计划执行的关键时刻→意外或反转→结果揭晓                                                          |
| 结尾（100-150字）   | 升华落点 | 哲理性总结→点明故事深层含义→引发观众思考                                                         |

写作技巧：开头使用第二人称"你"，让读者身临其境，后面转移到主角本身，用第三人称或他的名字；短句为主，节奏紧凑；情绪曲线：压抑→希望→紧张→成功→反思。
适用场景：
✅ 适合技能型、职业型人物（如神探、神医、工匠、刺客、谋士）
✅ 适合有具体"计谋/行动"可展开的人物 
✅ 适合3-8分钟中短视频，需要强代入感
✅ 适合抖音/快手等快节奏平台
❌ 不适合：需要多维度评价、复杂政治博弈的人物


### 5.3 问题驱动·认知颠覆型（参考知识类爆款短视频结构）
| 段序 | 功能     | 施工要点                         |
| :- | :----- |:-----------------------------|
| 1  | 痛点提问   | "你是不是也觉得XXX是这样的人？"——先建立错误认知  |
| 2  | 颠覆认知   | 抛出反常识事实，打破固有印象（参考"反常识+脑补"风格） |
| 3  | 生平速览   | 用时间线快速过一遍关键节点，信息密度要高         |
| 4  | 核心事件拆解 | 选取1-2个最具代表性的事件，深度拆解决策逻辑      |
| 5  | 多维度评价  | 引入不同史观/后人对该人物的评价，制造争议感       |
| 6  | 金句收尾   | 将人物命运提炼为一个普世道理，引发共鸣          |
适用场景：
✅ 适合被大众误解、标签化严重的人物（如商纣王、隋炀帝、秦桧）
✅ 适合需要"翻案"或重新解读的历史人物
✅ 适合5-15分钟中视频，信息密度高
✅ 适合引发评论区争议和互动
❌ 不适合：已有定论、缺乏争议空间的人物


### 5.4 多视角限知叙事型（参考历史人物纪录片叙事策略 + 学术叙事研究）
| 段序 | 功能   | 施工要点                        |
| :- | :--- | :-------------------------- |
| 1  | 破题钩子 | 反常行为或悬念建立好奇心，直接呈现冲突而不交代背景   |
| 2  | 日常秩序 | 展示主角常态、人物关系及隐性规则，为后续打破平衡做铺垫 |
| 3  | 触发事件 | 外力闯入，主角被迫行动，故事正式启动          |
| 4  | 小高潮  | 第一次对抗升级，主角获得阶段性信息或情感进展      |
| 5  | 转折降温 | 通过信息隐瞒、误会产生及节奏放缓，为危机积蓄力量    |
| 6  | 中点危机 | 主角遭遇最大挫败，目标暂时失败，信念发生动摇      |
| 7  | 反击爬升 | 主角获得新力量或新认知，转为主动解决问题        |
| 8  | 收尾留钩 | 完成本集任务的同时，抛出下一集的悬念          |

核心技法：打破线性时间链条，将人物生平不同阶段的事件切片重新排列组合，让少年经历与暮年抉择形成互文。采用内聚焦视角（限知视角）——只展示某一角色的视角或内心世界，增加代入感和悬念。在关键节点切换零聚焦视角（全知视角）补充宏观背景。
适用场景：
✅ 适合有丰富史料记载、多角色互动的人物（如三国人物、战国四公子）
✅ 适合需要制造悬疑感、让观众"参与破案"的人物（如秦始皇身世之谜、建文帝下落）
✅ 适合系列化长视频（每集30-60分钟，分多集讲完一个人物）
✅ 适合需要学术深度+故事性平衡的内容
❌ 不适合：史料匮乏、缺乏多方视角的人物




## 六、朝代篇大纲模板
### 6.1 事件时间线，因果驱动

| 段序   | 功能           | 施工要点                                                                 |
| ------ | -------------- | ------------------------------------------------------------------------ |
| 1      | 开场钩子       | **名场面前置**：把全片最紧张的一幕从时间线剪下贴到开头（荆轲式：先给秦王绕柱跑，再问为什么）；战争类且数字有出处时，可用**反差量化**开局摊牌面 |
| 2      | 锚定线         | 谁／何时／何地，三句以内                                                 |
| 3      | 起因段         | 矛盾的种子——背景制度信息用**行为后果织法**织入，不单独成段               |
| 4~n    | 事件时间线推进 | 节点分级施工；节点之间用**因果缝合**（"为什么会走到这一步"），禁用"然后……然后……" |
| 插件位 | 制度织入       | 制度类背景挂在需要它的节点上                                             |
| 插件位 | 历史对照组     | 相似处境、不同结局的另一场局（如另一场以少胜多／另一场亡国之战），插一段对照。**全片最多1处** |
| 插件位 | 拆账／层累表   | 争议事件开庭；被建构的叙事上层累表                                       |
| 插件位 | 地图节点       | 疆域／战线变化点，旁白给地图留半秒空气                                   |
| n+1    | 冲突顶点       | 决战／决定性事件成戏，全片情绪最高点                                     |
| n+2    | 收尾           | 结局**落定**＋呼应开头片段；先落点后金句，80%压最后30秒                  |
| n+3    | 承上启下       | 分集连载时，一句话衔接下集                                               |

发动机：因果链。观众追的是"为什么会走到这一步"。每个节点必须回答"如果不这样，会怎样"，让历史必然感压过偶然感。
适用场景：
✅ 适合朝代兴衰全过程（如"秦朝十五年""隋朝三十七年"）
✅ 适合有明显因果链条、可推导必然性的朝代（如秦朝因法而兴因法而亡）
✅ 适合20-40分钟中长视频
✅ 适合需要解释"制度如何塑造命运"的朝代（如宋朝重文轻武、明朝内阁制度）
❌ 不适合：史料匮乏、因果关系不清晰的朝代（如某些五代十国小政权）



### 6.2 势-局-搏杀型
| 段序 | 功能   | 施工要点                                           |
| :- | :--- | :--------------------------------------------- |
| 1  | 造势   | 先铺陈一种"势"——天道轮回、必然命运、事物发展规律。让观众感受到"这个朝代/结局非来不可" |
| 2  | 棋手入场 | 各方势力登场，讲解他们的计划和算盘。让"势"变成一场双方都有胜败可能性的"局"        |
| 3  | 博弈展开 | 谁是怎么胜的，谁是怎么败的。用因果链推进，禁用"然后"                    |
| 4  | 胜负手  | 渲染决定双方命运的关键抉择。大军、胜败、生命，皆系于做出抉择的一刻              |
| 5  | 道理提炼 | 用历史故事佐证某个道理/谋略/技术。以家国兴衰比喻公司盛荣、职场事业             |
| 6  | 唏嘘收尾 | 情绪释放+金句落点。大肆渲染命运与心绪，或称赞绝世武功，或哀叹毁于一旦            |
核心特征：段落短小精悍，每个逗号前后都有转折，叙事速度快到"急切"。
适用场景：
✅ 适合战争、政变、权力更迭等强冲突朝代节点（如楚汉争霸、玄武门之变、靖难之役）
✅ 适合有明确"博弈双方"的朝代叙事（如南北朝对峙、宋辽金三角）
✅ 适合需要输出观点、引发思考的内容（渤海小吏风格）
✅ 适合15-30分钟中视频
❌ 不适合：和平发展期、缺乏对抗性的朝代阶段（如文景之治前期）


### 6.3 悬念开场·主线压缩型
| 段序 | 功能          | 施工要点                                           |
| :- | :---------- | :--------------------------------------------- |
| 1  | 悬念开场（前15秒）  | 抛一个问题或一组反差，不交代背景。"一个从不迟到的人，今晚故意错过了末班车"         |
| 2  | 锚定背景        | 快速交代朝代名称、时间跨度、核心矛盾                             |
| 3  | 主线压缩（中段）    | 只讲推动主线的6-8个节点，节点之间用一句话过渡。支线、配角前史、世界观设定，不推主线的全砍 |
| 4  | 因果缝合        | 每个节点回答"为什么会走到这一步"，用"如果不这样，会怎样"制造必然感            |
| 5  | 收尾观点（最后30秒） | 给态度，不给总结。可以是对历史走向的判断，也可以是对朝代兴衰的另一种读法。观点允许有争议   |
适用场景：
✅ 适合"一口气看完XXX朝代"类超长视频 
✅ 适合信息密度极高、需要取舍的朝代（如唐朝289年、明朝276年）
✅ 适合B站/YouTube等长视频平台
✅ 适合已有大量同质化内容、需要差异化切入的朝代
❌ 不适合：需要深度解析单一事件的短视频

## 七、事件模板
### 7.1 地图+时间线结合型（参考安州牧/史图记忆簿结构）
| 段序  | 功能     | 施工要点                                    |
| :-- | :----- |:----------------------------------------|
| 1   | 地理钩子   | 从一张地图的反常细节切入                            |
| 2   | 锚定时空   | 朝代名称／起止时间／核心地理范围，配合地图标注                 |
| 3   | 疆域奠基   | 该朝代的地理基础——不是介绍地形，而是"没有这块地，这个朝代根本立不住"    |
| 4~n | 疆域演进推进 | 按时间推进疆域变化；每个阶段配合地图动画，回答"这块地是怎么打下来的/丢掉的" |
| 插件位 | 关键战役地图 | 决定性战役的战场沙盘——地形、兵力、行军路线可视化               |
| 插件位 | 都城变迁   | 都城迁移背后的政治、经济、军事逻辑                       |
| 插件位 | 民族迁徙   | 人口流动与政权更迭的互动关系                          |
| n+1 | 疆域顶点   | 该朝代疆域最大/最小时的地图对比，全片视觉冲击最高点              |
| n+2 | 收尾     | 疆域最终格局＋对后世地理版图的影响；先落点后金句                |
| n+3 | 承上启下   | 该朝代疆域如何奠定了下一个朝代的地理基础                    |

适用场景：
✅ 适合疆域变化剧烈的朝代（如秦朝统一、汉朝扩张、元朝版图）
✅ 适合需要地图可视化的内容（配合GeoJSON、Folium、MapLibre等工具）
✅ 适合地理与政治互动密切的朝代（如南北朝、五代十国）
✅ 适合系列化"地图中的XXX史"
❌ 不适合：疆域稳定、缺乏地理戏剧性的朝代阶段

### 7.2 制度演进·逻辑驱动型 
| 段序  | 功能     | 施工要点                                            |
| :-- | :----- | :---------------------------------------------- |
| 1   | 痛点前置钩子 | 这个制度最反直觉／最坑人的一个后果先行（如"科举制最大的受害者，其实是皇帝自己"）       |
| 2   | 锚定线    | 制度名称／创立时间／创立者，三句以内                              |
| 3   | 诞生土壤   | 这个制度为什么非出现不可——不是介绍背景，而是"没有它，当时的社会会崩成什么样"        |
| 4~n | 制度演进推进 | 按时间或逻辑推进制度的变形史；每个阶段回答"这个制度在当时解决了什么问题，又制造了什么新问题" |
| 插件位 | 具体案例   | 一个具体的人/事，被这个制度碾过的全过程——用个体命运承载制度逻辑               |
| 插件位 | 多方博弈   | 制度执行者、受益者、受害者三方的不同算盘                            |
| 插件位 | 漏洞与补丁  | 制度的设计缺陷和历代打补丁的尝试，制造"历史程序员debug"的趣味感             |
| 插件位 | 现代对照   | 这个制度与当代某个机制的对照（如九品中正制 vs 现代绩效考核），但不强行类比         |
| n+1 | 制度顶点   | 该制度最极端/最荒诞的执行案例展开成戏，全片逻辑冲击最高点                   |
| n+2 | 收尾     | 制度最终命运（废除/变形/延续）＋历史遗产评估；先落点后金句                  |
| n+3 | 承上启下   | 该制度如何塑造了下一个历史节点的底层逻辑                            |
发动机：逻辑链。观众追的是"这个制度到底是怎么把所有人绕进去的"。避免变成"制度说明书"，核心是用人的命运来承载制度的重量。
适用场景：
✅ 适合制度创新深刻影响国运的朝代（如秦朝郡县制、隋唐科举制、宋朝文官制度）
✅ 适合需要解释"为什么这个朝代会这样"的深层逻辑
✅ 适合知识密度高、逻辑性强的内容
✅ 适合引发当代观众共鸣（制度与现代人处境对照）
❌ 不适合：制度变化不大、缺乏制度戏剧性的朝代


### 7.3 张力驱动·单一事件型
| 段序  | 功能     | 施工要点                                                |
| :-- | :----- | :-------------------------------------------------- |
| 1   | 开场钩子   | 切面先行：从事件最反常识／最震撼的一个瞬间切入（如"垓下之围时，项羽其实还有十万精兵"），不给事件概述 |
| 2   | 锚定线    | 事件名称／时间／地点，三句以内                                     |
| 3   | 土壤段    | 事件爆发的深层土壤——不是简单背景介绍，而是"这件事为什么非发生不可"的必然性论证           |
| 4~n | 事件进程推进 | 按时间或逻辑推进；关键转折点分级施工；**多方视角切换**（各方势力在同一时刻的不同算盘）       |
| 插件位 | 决策瞬间   | 关键人物在转折点上的一念之差——展开成戏，替代平铺直叙的"然后……"                  |
| 插件位 | 数据可视化  | 兵力、伤亡、粮草、距离等数字，用反差量化呈现（如"相当于从北京走到上海，只带了三天干粮"）       |
| 插件位 | 蝴蝶效应   | 事件引发的连锁反应，挑1个最远的影响点做对照，制造"历史震颤感"                    |
| 插件位 | 争议拆账   | 事件定性争议集中开庭（摆史料→拆动机→交还判断→重建落点）                       |
| 插件位 | 环境氛围   | 天气、地形、季节等环境细节，作为隐形的第三主角织入叙事                         |
| n+1 | 事件高潮   | 决定性瞬间展开成戏，全片张力最高点                                   |
| n+2 | 收尾     | 事件结局落定＋历史影响评估＋呼应开头切面；先落点后金句，80%压最后30秒               |
| n+3 | 承上启下   | 该事件如何改变了下一个历史节点的走向，一句话衔接（可选）                        |
发动机：张力。观众追的是"那一刻到底发生了什么"。高潮不是"结果告知"，而是"过程还原"——让观众感觉自己就站在那个历史现场。
适用场景：
✅ 适合有明确时间边界、可完整还原的事件（如赤壁之战、淝水之战、靖康之变）
✅ 适合多方势力参与、视角可切换的复杂事件
✅ 适合有争议、需要拆账的事件（如岳飞之死、袁崇焕之死）
✅ 适合20-40分钟深度解析
❌ 不适合：时间跨度太长、涉及因素过多的"大事件"（如安史之乱全过程，更适合朝代篇模板）


### 7.4 沙盘推演·军事事件型 
| 段序  | 功能     | 施工要点                                   |
| :-- | :----- | :------------------------------------- |
| 1   | 推演前置钩子 | 把战役最反常识的一个战术细节先亮出来（如"这场以少胜多的关键，其实是下雨"） |
| 2   | 锚定线    | 战役名称／时间／地点／对阵双方，三句以内                   |
| 3   | 战前沙盘   | 双方兵力、地形、后勤、士气的量化对比——用"牌面"建立预期          |
| 4~n | 战役进程推进 | 按时间或逻辑推进；每个阶段用沙盘推演法（"如果A此时做了X，B会怎么应对"） |
| 插件位 | 关键决策   | 某一方的关键战术决策——展开成戏，分析"这个决策在当时信息条件下的合理性"  |
| 插件位 | 意外变量   | 天气、地形、情报失误、内部叛变等不可控变量对战役的影响            |
| 插件位 | 个体命运   | 一个普通士兵/低级将领的战场视角——用个体命运承载战役的残酷         |
| 插件位 | 战后复盘   | 胜方为什么赢、败方为什么输的结构化复盘（不是简单归因，是多因素拆解）     |
| n+1 | 战役高潮   | 决定性战斗展开成戏，全片推演张力最高点                    |
| n+2 | 收尾     | 战役直接后果＋长远影响＋军事史定位；先落点后金句               |
发动机：推演感。观众追的是"如果我是指挥官，我会怎么打"。核心技巧是"信息还原"——让观众和当时的指挥官掌握同样多的信息，再一起推演。
适用场景：
✅ 适合经典战役、以少胜多等军事事件（如巨鹿之战、官渡之战、萨尔浒之战）
✅ 适合有明确对阵双方、可量化对比的战役
✅ 适合配合地图动画、兵力可视化的内容
✅ 适合军事史爱好者受众
❌ 不适合：非军事类事件（如政治改革、文化运动）



### 7.5 悬疑解谜·历史谜案型
| 段序  | 功能     | 施工要点                                         |
| :-- | :----- | :------------------------------------------- |
| 1   | 谜面前置钩子 | 把历史谜案最诡异的一个证据缺口先亮出来（如"秦始皇陵里有一具女尸，但史书从未记载过她"） |
| 2   | 锚定线    | 谜案名称／时间／核心疑点，三句以内                            |
| 3   | 谜面铺陈   | 现有史料的全部已知信息——先建立"我们已经知道什么"的基准线               |
| 4~n | 线索推进   | 按逻辑推进各种假说；每个假说用证据链支撑或反驳，制造"侦探破案"感            |
| 插件位 | 史料矛盾   | 不同史料之间的直接矛盾——展开成戏，分析"为什么同一事件会有两种记载"          |
| 插件位 | 考古新证   | 最新的考古发现/文献研究成果，作为破局线索引入                      |
| 插件位 | 动机推演   | 各方势力在该事件中的潜在动机——用"谁受益最大"原则推演                 |
| 插件位 | 心理推演   | 关键人物在事件中的心理状态——只在史料留白处，挂合规标签                 |
| n+1 | 解谜高潮   | 最合理的解释/最震撼的真相展开成戏，全片好奇感最高点                   |
| n+2 | 收尾     | 谜底落定（或承认"仍是悬案"）＋对历史叙事的反思；先落点后金句              |
| n+3 | 承上启下   | 这个谜案如何改变了我们对某个历史阶段的认知                        |
发动机：好奇心。观众追的是"真相到底是什么"。核心技巧是"证据链可视化"——让观众感觉自己也在参与破案，而不是被动接受结论。
适用场景：
✅ 适合有明确疑点、史料矛盾的历史谜案（如秦始皇身世、武则天立碑无字、建文帝下落）
✅ 适合考古新发现可介入的事件
✅ 适合需要"烧脑"、引发讨论的内容
✅ 适合系列化"历史未解之谜"
❌ 不适合：已有定论、缺乏悬念空间的事件

- [ ] 若使用反差量化：战争题材＋数字有史料出处，**双前提齐全**

- [ ] 情绪波形有峰有谷，无长段平坦
- [ ] **动情点至少一处，标在段上（无则退回）**

## 九、主题否决关（v3 新增·人工闸门）

**位置**：大纲签发清单全绿之后、交付写作层之前。
**操作人**：你（创作者本人）。
**理由**：签发清单能查"有没有一句话主题""有没有反常切片"，查不了这个主题好不好、切片是不是真的反常。流水线最危险的产品是**精确施工的平庸**——结构完美、技法齐全、自查全绿，但主题从受精卵那一刻就是温的。这道关是整条流水线里人肉介入性价比最高的一个点，比审成稿省力十倍。

**操作方式**：大纲层输出时单独附一页《主题卡》，只写三样东西：

1. 一句话主题；
2. 开场钩子选型＋钩子的那一帧（反常切片内容／前置名场面／反差量化的两个数字）；
3. 主题自检三问的答卷。

**你看什么**：

- 主题让你"哦？"了吗？没有 → 打回选题层换主题，不进写作层；
- 钩子那一帧，你想看下去吗？不想 → 打回大纲层换弹药；
- 三问答卷有糊弄痕迹（答非所问、套话）→ 打回重做。

**通过标准**：三样都点头，签字放行。此关不过，写作层拒收大纲。

## 十、与上下游的接口

- **上游**：史料层交付事件卡素材；人格层、风格层交付姿态与技法选型——大纲层不生产内容，只组织。
- **下游**：写作层按大纲施工——**硬约束字段无权改**（改节点顺序、加戏、改伏笔埋收、砍动情点都算越权，须退回大纲层）；**软约束字段可调整但须在交稿备注中声明**。审核层先审大纲（结构门禁），再审成稿（语言门禁）。

## 附：修订记录

### v3（对照写作层设计后的体系修订）

| 改动 | 原因与依据 |
| ---- | ---------- |
| 字段分硬／软两级 | 硬约束锁故事选择，软约束放语言实现——此前锁错了粒度 |
| 指定技法改"主＋备选"选型制 | 逐段写死单一技法会写出补丁感，技法应从材料里长出来；备选是写作层不退稿的换弹药通道 |
| 信息增量标准改"信息增量或情绪增量" | 纯信息流标准系统性驱逐成戏段——成戏段的价值在张力不在信息 |
| 炸点标准改"区间＋史料卡出处" | 消除大纲层（密度硬门槛）与弹药库（上限不是 KPI）的表述矛盾；用出处卡真实性替代用密度卡数量 |
| 字数容差按功能类型分级 | 情绪波形起伏必然对应密度起伏，匀速换算卡死最贵的段落（钩子/收尾）和最便宜的段落（过渡） |
| 章节标题允许悬念式章题 | "工整偏正"是底线不是目标，章题同时承担导航与钩子两个职能 |
| 新增主题自检三问＋主题否决关 | 大纲层锁得住结构锁不住判断，主题质量需要人工闸门拦截"精确施工的平庸" |
| 签发清单改举证式 | 勾选式容易被执行端糊弄成全绿，举证式（过/不过＋位置）才拦得住 |
