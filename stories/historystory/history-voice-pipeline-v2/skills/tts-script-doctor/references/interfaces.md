# 与上游的接口

> 本文件为 SKILL.md 的参考文档，按需加载。包含上游产物在语音层的用法与打回规则。

---

## 上游产物用法

| 上游产物 | 语音层怎么用 |
|----------|-------------|
| 大纲"情绪坐标"字段 | 画本情感标注的直接输入——大纲层画好的波形，语音层照抄翻译 |
| 成稿（顿）标记 | 翻译成前/后停顿毫秒数 |
| 成稿【上屏】标记 | 引文单元单独拆分＋换声线感朗读 |
| 成稿（地图留白 X 秒） | 该单元设时长目标，用精确时长模式合成，对轴地图动画 |

---

## 打回规则

画本加工中发现"这句话根本没法读"（超过三层的复句、无法断句的长定语）→ **不是语音层的问题，是写作层朗读测试放水了，打回写作层**。
