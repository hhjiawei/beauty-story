## 能力总览

基于官方仓库与文档，IndexTTS2 对本流水线有四项关键能力：

| 能力 | 机制 | 本流水线的用法 |
|------|------|--------------|
| 零样本音色克隆 | 一段参考音频（timbre prompt）即可克隆音色，无需训练 | 建立你的**专属旁白音色库**（见 `references/voice-assets.md`） |
| 情感与音色解耦 | 音色和情感独立控制：用 A 的音色，表现 B 的情感（情感参考音频／情感向量／自然语言描述三选一） | **一个音色走全系列，情感按段落切换**——这是"新派写书人"人格在声音层的实现 |
| 自然语言情感软指令 | 基于 Qwen3 微调，用一句中文描述情感（如"压低声音，带着克制的唏嘘"） | 画本的情绪标注直接用人话写，不用学情感向量 |
| 时长控制 | 两种模式：指定 token 数精确控制时长；或自由生成忠实复现韵律 | 地图留白、时间码对齐的段落用精确模式，其余用自由模式 |

> 注意：具体参数名（emo_audio_prompt／emo_alpha／emo_vector／use_emo_text 等）以你本地部署版本的 README 为准，不同 commit 有差异。本文所有代码示例标注"示意"，跑通前先对一遍本地签名。
